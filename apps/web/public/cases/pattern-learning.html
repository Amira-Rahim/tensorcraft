Every sensor keeps its readings.

Turn an array into a tensor, then group the values by sensor. Choose a sensor to follow its readings across three moments.

readings.js

const readings = tf.tensor2d([
  [2, 20, 5, 8],
  [3, 18, 7, 8],
  [4, 16, 6, 9]
]);

const bySensor = readings.transpose();

You build the network in JavaScript.

Choose the layers that connect inputs to a prediction. Training then adjusts the model’s parameters using examples.

classifier.js

const model = tf.sequential();
model.add(tf.layers.dense({
  units: 32, inputShape: [3],
  activation: "relu"
}));
model.add(tf.layers.dense({
  units: 16, activation: "relu"
}));
model.add(tf.layers.dense({
  units: 1, activation: "sigmoid"
}));

The model runs where your UI runs.

Load a saved model with TensorFlow.js and use it in the browser. Keep input preparation consistent, then test on data the model hasn’t trained on.

predict.js

const model = await tf.loadLayersModel(
  modelUrl
);

const values = tf.tidy(() =>
  Array.from(model.predict(input).dataSync())
);

Course excerpt: modelUrl points to your saved model. input contains the prepared readings.
