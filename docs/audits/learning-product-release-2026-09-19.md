Date: 2026-09-19. Baseline: `80a3f029b8efb1968aa086c53d30c83566d98254`. Scope: the approved [development plan](../learning-product-development-plan.md), Deep Orbit's complete curriculum, shared learner surfaces and the limited Neon preview. This is an internal maintainer review, not an independent review.

The revised product is deployed to [tensorcraft.app](https://tensorcraft.app). P0-P6 and P8 are implemented and verified. P7's changes and P9's release checks pass, with one required verification still open: an actual screen-reader walkthrough. The native connector cannot start. P7 and final P9 acceptance remain unchecked until that walkthrough is completed. The content categories meet the internal A threshold; the provisional design score does not waive the missing accessibility evidence.

The release uses the approved uncommitted working tree. No commit or push was made. ## What learners receive

The opening reaches a packet experiment with inspectable values and a changed case. Seven concept interactions cover channel layout, normalization, threshold selection, learning rate, FFT windows, attention and caching. Predictions, first attempts, later attempts and help remain distinguishable. Experiments do not grant exercise completion credit.

Guided and challenge routes now reflect ML familiarity separately from JavaScript experience. Entitled learners can browse later modules with prerequisite recaps. Paid gates and completion requirements remain intact. The course offer names practical capabilities and shows a real external project, including supplied work, local setup and effort limits.

Five system stages connect the growing DEEP SCAN application to actual practice and project records. Account summaries synchronize bounded outcomes, while detailed answers remain local or explicitly downloaded. Saved exercises recover after refresh and retain the learner's code when a solution is viewed. Browser Back and Forward preserve the lesson document and its work.

The season develops all five characters through later behavior and engineering decisions. Six choices have reviewed consequences; the two revised choices preserve old saved meanings through explicit versions. Deep Orbit ends with its own final record. A later dashboard invitation opens a checked Neon filter sample. The other four complete curricula remain drafts and have separate release requirements; this release does not certify their full content.

## Defects found during release verification

The enlarged-text check originally measured before layout had settled. Waiting two animation frames exposed real overflow in objective/recap list items, code headers, decision tables and long technical words. Those surfaces now wrap or use named keyboard-scrollable regions. A full-page screenshot is taken after the width assertion because screenshot capture can alter the viewport and lazy rendering. All 18 final interaction flows pass the corrected check.

The DEEP SCAN demo retained its input/output tensors if prediction readback failed. Both are now released through `finally`; malformed and non-finite probabilities are rejected. Its result reveal respects reduced motion. Seventeen focused code-header/demo tests and six objective/recap tests pass in addition to the final broad suite.

Four initial browser failures came from stale expectations: an email placeholder also selected a hidden support field, an old first-lesson heading, an unscoped duration match and a renamed editor-pane discriminator. The tests now target the actual accessible field or relevant region. Initial playback unit mocks lacked the current MDX exports and auth listener; they were reconciled. The affected 67-flow run and final full suites pass.

Independent Vite-based checkers initially collided in a shared dependency cache. Each now has its own cache directory. Content checks run after content generation finishes. The final retained runs succeeded without overlapping a content rebuild.

The Vercel project's `apps/web` root ignored the old root configuration. The migration gate now lives in `apps/web/vercel.json` and fails closed before the cloud build. Turbo now passes the environment-owned Sentry upload token to the build. Explicit upload exclusions keep local secrets and private QA records out of the CLI context. The final cloud build confirmed the 65/65 schema gate and successful source-map upload.
