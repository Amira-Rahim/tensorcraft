How Context Detection Works

On first auth completion, set a tc_visited localStorage flag. When the auth page loads:
• No flag → "Start Learning" heading, "MODULE 1 · FREE · NO CARD" callout, "Already have an account?" link
• Has flag → "Welcome Back" heading, "PICK UP WHERE YOU LEFT OFF" callout, "New here?" link
• URL has ?redirectTo=/pricing → "Complete Your Purchase" heading, context about checkout

The "Already have an account?" and "New here?" links don't navigate — they just swap the copy state, since the form itself is identical either way.
