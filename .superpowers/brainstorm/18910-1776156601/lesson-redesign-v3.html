What Is a Tensor?

A tensor is simply a multi-dimensional array. That's it. If you can work with arrays in JavaScript, you already understand the core concept.

Identity Bridge Frontend → ML
Your Code
TypedArray
const arr = new Float32Array([1, 2, 3])
ML Equivalent
Tensor
const t = tf.tensor([1, 2, 3])

Here's the key insight: Float32Array and tf.tensor both store numbers in contiguous memory. The difference? Tensors know their shape and come with GPU-accelerated math.

tensors-are-arrays.ts TypeScript
import * as tf from '@tensorflow/tfjs'; // A scalar (0D tensor) — just a single number const scalar = tf.scalar(42); console.log(scalar.rank); // 0 // A vector (1D tensor) — like a regular array const vector = tf.tensor1d([1, 2, 3, 4, 5]); console.log(vector.rank); // 1 // A matrix (2D tensor) — like an array of arrays const matrix = tf.tensor2d([[1, 2], [3, 4], [5, 6]]); console.log(matrix.rank); // 2

Think of it like this: you already use HTMLElement[] to represent a list of DOM nodes. A tensor is a more powerful version — a typed, n-dimensional array with built-in math.
