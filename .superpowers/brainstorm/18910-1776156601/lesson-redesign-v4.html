What Is a Tensor?

A tensor is simply a multi-dimensional array. That's it. If you can work with arrays in JavaScript, you already understand the core concept.

Identity Bridge Frontend → ML
Your Code
TypedArray
const arr = new Float32Array([1, 2, 3])
ML Equivalent
Tensor
const t = tf.tensor([1, 2, 3])

Float32Array and tf.tensor both store numbers in contiguous memory. The difference? Tensors know their shape and come with GPU-accelerated math.

tensors-are-arrays.ts TypeScript
import * as tf from '@tensorflow/tfjs'; // scalar (0D) — just a number const s = tf.scalar(42); // rank: 0 // vector (1D) — like a regular array const v = tf.tensor1d([1, 2, 3, 4, 5]); // rank: 1 // matrix (2D) — array of arrays const m = tf.tensor2d([[1, 2], [3, 4]]); // rank: 2

You already use HTMLElement[] for DOM nodes. A tensor is that — but typed, n-dimensional, and with built-in math.
