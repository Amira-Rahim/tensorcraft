The Signal Arrives

The deep-space array picks up a repeating signal at 1420 MHz. Your task: classify whether this is natural background noise or something worth investigating.

You already know how Array.map() transforms data through a chain of operations. A neural network does the same thing — each layer transforms the signal, extracting increasingly abstract features.

Let's build the classifier.

model.js
// Your first neural network const model = sequential([ dense({ units: 16, activation: 'relu' }), dense({ units: 8, activation: 'relu' }), dense({ units: 1, activation: 'sigmoid' }), ]); // Like Array.map() — data flows // through each layer sequentially const prediction = model .forward(signalData);
