Challenge

Build a simple classifier that can distinguish between cosmic noise and structured signals in the Archimedes' sensor data. Start by implementing the most fundamental activation function in neural networks.

Concept — FE→ML Bridge

Frontend

Math.max(0, x)
Math.max(0, x)

In JavaScript, Math.max(0, x) returns 0 for negative values and passes positive values through unchanged.

⚔

Machine Learning

ReLU Activation
f(x) = max(0, x)

In neural networks, ReLU (Rectified Linear Unit) does exactly the same thing: it passes positive values and blocks negative ones.

Sato smiles. "See? You already know ReLU. You've been using it every time you called Math.max(0, x) in your frontend code. Neural networks are full of concepts like this — things you already understand, just with different names."

ARIA chimes in: "I have prepared an exercise in your workstation editor. Implement the ReLU function, then test it against the sample signal data. I will be evaluating your work. No pressure."
