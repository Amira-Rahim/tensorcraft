Now we assemble them into one production system. Priya, lay out the complete architecture. Every component, every connection, every failure mode.

<Dialogue speaker="Priya Sharma">
It is a dependency graph, same as a monorepo. Each module is a package with typed inputs and outputs. I connect them into a pipeline: sensor data flows in, predictions flow out, and every component in between has a clear interface and a fallback strategy.
</Dialogue>

47 sites. 12,400 devices. 2 million sensors. One pipeline from raw vibration reading to maintenance dispatch, and no component allowed to fail alone. On the whiteboard, Terra Grid Intelligence is a monorepo dependency graph, and it gets the monorepo discipline you know from Turborepo: every ML component a self-contained package with typed interfaces, every design choice captured in an architecture decision record.

{`// Terra Grid Intelligence — Complete System Architecture
// Each component maps to a module from the course

interface SystemComponent {
  name: string;
  module: string;        // Which course module built this
  inputTypes: string[];
  outputTypes: string[];
  dependencies: string[];
  fallbackStrategy: string;
  memorySizeMB: number;
}

const terraGridArchitecture: SystemComponent[] = [
  {
    name: 'sensor-ingestion',
    module: 'edge-ai-basics',
    inputTypes: ['RawSensorStream'],
    outputTypes: ['NormalizedSensorData'],
    dependencies: [],
    fallbackStrategy: 'buffer-and-retry',
    memorySizeMB: 2,
  },
  {
    name: 'feature-extraction',
    module: 'optimization-fundamentals',
    inputTypes: ['NormalizedSensorData'],
    outputTypes: ['FeatureVector'],
    dependencies: ['sensor-ingestion'],
    fallbackStrategy: 'use-cached-features',
    memorySizeMB: 4,
  },
  {
    name: 'anomaly-detector',
    module: 'quantization',
    inputTypes: ['FeatureVector'],
    outputTypes: ['AnomalyPrediction'],
    dependencies: ['feature-extraction'],
    fallbackStrategy: 'threshold-based-fallback',
    memorySizeMB: 4.2,
  },
  {
    name: 'model-updater',
    module: 'federated-learning',
    inputTypes: ['LocalGradients'],
    outputTypes: ['UpdatedWeights'],
    dependencies: ['anomaly-detector'],
    fallbackStrategy: 'keep-current-model',
    memorySizeMB: 8,
  },
  {
    name: 'ab-test-router',
    module: 'ab-testing',
    inputTypes: ['FeatureVector', 'DeviceConfig'],
    outputTypes: ['RoutedPrediction'],
    dependencies: ['anomaly-detector'],
    fallbackStrategy: 'route-to-control',
    memorySizeMB: 1,
  },
  {
    name: 'failover-controller',
    module: 'scale-reliability',
    inputTypes: ['PredictionRequest'],
    outputTypes: ['PredictionResult'],
    dependencies: ['anomaly-detector', 'ab-test-router'],
    fallbackStrategy: 'lightweight-model',
    memorySizeMB: 2,
  },
];

// Validate dependency graph
function validateArchitecture(components: SystemComponent[]): {
  valid: boolean; issues: string[];
} {
  const names = new Set(components.map(c => c.name));
  const issues: string[] = [];

  for (const component of components) {
    for (const dep of component.dependencies) {
      if (!names.has(dep)) issues.push(\`\${component.name}: missing dependency "\${dep}"\`);
    }
  }

  // Check total memory
  const totalMB = components.reduce((s, c) => s + c.memorySizeMB, 0);
  if (totalMB > 64) issues.push(\`Total memory \${totalMB}MB exceeds 64MB edge budget\`);

  return { valid: issues.length === 0, issues };
}

const result = validateArchitecture(terraGridArchitecture);
console.log('Architecture valid:', result.valid);
if (!result.valid) console.log('Issues:', result.issues);`}
