<Dialogue speaker="Hassan Al-Rashid">
Six months from now, someone who has never seen this codebase will get paged at 2 AM because model drift triggered an alert. They need exact steps. Ambiguity at 2 AM is paid for in downtime; a runbook is that bill paid in advance.
</Dialogue>

<Dialogue speaker="Tariq Hussain">
Write them for the truck, not the office. One bar of signal, no laptop, and the only thing I can do is what the step tells me to type. If a step needs me to work out which model version is live, it is not a step, it is a research project.
</Dialogue>

A runbook is four fields: a trigger condition, ordered steps, a verification command per step, and an escalation path. That structure is exactly what you wrote for web operations ("If CPU exceeds 90%, check top, identify the process, scale horizontally or restart"). What fills the fields here is different: drift alerts, accuracy degradation, failed federated learning rounds, adversarial inputs. The test of a good runbook is whether the steps survive contact with a half-awake stranger.

{`// Operational runbooks, same structure as web ops playbooks

interface RunbookStep {
  order: number;
  action: string;
  command?: string;
  expectedOutput?: string;
  ifFailed: string;
}

interface Runbook {
  id: string;
  title: string;
  trigger: string;
  severity: 'P1' | 'P2' | 'P3';
  estimatedMinutes: number;
  steps: RunbookStep[];
  escalation: { condition: string; contact: string };
}

class RunbookRegistry {
  private runbooks: Map<string, Runbook> = new Map();

  add(runbook: Runbook): void {
    this.runbooks.set(runbook.id, runbook);
  }

  get(id: string): Runbook | undefined {
    return this.runbooks.get(id);
  }

  findByTrigger(alertType: string): Runbook[] {
    return [...this.runbooks.values()].filter(r =>
      r.trigger.toLowerCase().includes(alertType.toLowerCase())
    );
  }

  generateChecklist(id: string): string {
    const runbook = this.runbooks.get(id);
    if (!runbook) return 'Runbook not found';

    let checklist = \`# \${runbook.title}\\n\`;
    checklist += \`Trigger: \${runbook.trigger}\\n\`;
    checklist += \`Severity: \${runbook.severity} | Est: \${runbook.estimatedMinutes} min\\n\\n\`;

    for (const step of runbook.steps) {
      checklist += \`[ ] Step \${step.order}: \${step.action}\\n\`;
      if (step.command) checklist += \`    Command: \${step.command}\\n\`;
      if (step.expectedOutput) checklist += \`    Expected: \${step.expectedOutput}\\n\`;
      checklist += \`    If failed: \${step.ifFailed}\\n\\n\`;
    }

    checklist += \`Escalation: \${runbook.escalation.condition}\\n\`;
    checklist += \`Contact: \${runbook.escalation.contact}\\n\`;
    return checklist;
  }
}

// Terra Grid runbooks
const registry = new RunbookRegistry();

registry.add({
  id: 'RB-001',
  title: 'Model Drift Response',
  trigger: 'Model accuracy drops below 90% for 1 hour',
  severity: 'P2',
  estimatedMinutes: 30,
  steps: [
    { order: 1, action: 'Check model accuracy dashboard',
      command: 'tg-cli metrics --model current --window 1h',
      expectedOutput: 'accuracy < 0.90',
      ifFailed: 'Dashboard may be stale; check raw metrics' },
    { order: 2, action: 'Compare against baseline model',
      command: 'tg-cli compare --current --baseline',
      expectedOutput: 'Drift report with affected features',
      ifFailed: 'Run manual comparison with test dataset' },
    { order: 3, action: 'Check for data distribution shift',
      command: 'tg-cli data-drift --window 24h',
      expectedOutput: 'Distribution comparison report',
      ifFailed: 'Manually inspect recent sensor data' },
    { order: 4, action: 'Rollback to previous model if drift confirmed',
      command: 'tg-cli rollback --to previous --confirm',
      expectedOutput: 'Rollback complete, accuracy restored',
      ifFailed: 'Escalate to ML team lead' },
  ],
  escalation: {
    condition: 'Drift persists after rollback or root cause unclear',
    contact: 'Hassan Al-Rashid, ML Infrastructure Lead',
  },
});

const checklist = registry.generateChecklist('RB-001');
console.log(checklist);`}
</CodeBlock>
