You write JavaScript once, but V8 (Chrome and Node), SpiderMonkey (Firefox), and JavaScriptCore (Safari and Bun) each compile and execute it differently. Each engine has different JIT strategies, different garbage collection, different performance characteristics. ML runtimes look like that from a distance: one trained model, several execution engines, each tuned for different hardware. The resemblance stops there. Every engine implements the same ECMAScript spec, so your code runs on all of them. Your model does not get that guarantee: TFLite, ONNX Runtime, and Core ML each support a different subset of operators, and an unsupported op does not run slowly, it fails the load. So targeting a runtime starts with an op-set audit rather than a benchmark.

## Runtime Abstraction

This is the shape of a database driver interface: `query()` and `close()` mean the same thing whether Postgres or SQLite is underneath, and the calling code never learns which. A runtime abstraction does that for ML engines:

<CodeBlock language="typescript" title="runtime-abstraction.ts">
{`import * as tf from '@tensorflow/tfjs';

interface InferenceEngine {
  load(modelPath: string): Promise<void>;
  predict(input: Float32Array): Promise<Float32Array>;
  dispose(): void;
}

class TFJSEngine implements InferenceEngine {
  private model: tf.LayersModel | null = null;

  async load(modelPath: string) {
    this.model = await tf.loadLayersModel(modelPath);
  }

  async predict(input: Float32Array): Promise<Float32Array> {
    return tf.tidy(() => {
      const tensor = tf.tensor2d(input, [1, input.length]);
      const result = this.model!.predict(tensor) as tf.Tensor;
      return new Float32Array(result.dataSync());
    });
  }

  dispose() { this.model?.dispose(); }
}

// Same interface, different engine, like a polyfill
class WASMEngine implements InferenceEngine {
  private session: any = null;

  async load(modelPath: string) {
    const wasmModule = await WebAssembly.instantiateStreaming(fetch(modelPath));
    this.session = wasmModule.instance.exports;
  }

  async predict(input: Float32Array): Promise<Float32Array> {
    const ptr = this.session.allocate(input.length * 4);
    new Float32Array(this.session.memory.buffer, ptr, input.length).set(input);
    this.session.inference(ptr, input.length);
    return new Float32Array(this.session.memory.buffer, ptr, 3); // 3 output classes
  }

  dispose() { this.session = null; }
}`}
</CodeBlock>
