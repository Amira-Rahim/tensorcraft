Station 7-Delta just lost satellite. Forecast says 14 hours minimum before link recovery. Those sensors are on their own.
</Dialogue>

<Dialogue speaker="Hassan Al-Rashid">
That is precisely why we designed for offline-first. The models run locally, the predictions buffer, and the link is a sync channel rather than a dependency. The buffer holds fourteen hours of predictions without dropping one. What it cannot hold steady is the model's picture of the grid, which ages every hour the link is down and never says so.
</Dialogue>

Any process that has to survive a flaky link is built the same way: keep what you need on local disk, write results to a queue that outlives a restart, and drain the queue when the link comes back. The gateway runs that exact shape: cache the model, buffer the predictions, sync on reconnect. What does not transfer is the word stale. A stale file is your own bytes, only older, and one fetch replaces it. A stale model is a snapshot of the world as of training day, still answering with full confidence about a world that may have moved.

## Offline Model Cache

<CodeBlock language="typescript" title="offline-cache.ts">
{`import * as tf from '@tensorflow/tfjs';

class OfflineModelCache {
  // The gateways run tfjs-node, so weights land on disk via 'file://'.
  // The same class in the browser dashboard takes the 'indexeddb://' path.
  private modelKey = typeof indexedDB !== 'undefined'
    ? 'indexeddb://terra-grid-model'
    : 'file://./cache/terra-grid-model';
  private model: tf.LayersModel | null = null;
  /** Set from the package manifest 'created' timestamp (lesson 2). */
  private trainedAt = 0;

  async initialize(): Promise<void> {
    try {
      // Try the local cache first; the network path is the miss case
      this.model = await tf.loadLayersModel(this.modelKey);
      console.log('Model loaded from local cache');
    } catch {
      // Cache miss: download and store
      this.model = await tf.loadLayersModel('/api/models/terra-grid/model.json');
      await this.model.save(this.modelKey);
      console.log('Model downloaded and cached locally');
    }
  }

  /** How old this snapshot is. Attach it to every prediction you buffer. */
  modelAgeHours(): number {
    return (Date.now() - this.trainedAt) / 3_600_000;
  }

  async predict(sensorData: number[]): Promise<Float32Array> {
    if (!this.model) throw new Error('Model not initialized');
    return tf.tidy(() => {
      const input = tf.tensor2d([sensorData]);
      const output = this.model!.predict(input) as tf.Tensor;
      return new Float32Array(output.dataSync());
    });
  }
}`}
</CodeBlock>

## Prediction Buffer

When offline, predictions queue in a ring buffer: a fixed-size circular array that overwrites the oldest entries when full, preventing memory from growing unbounded on a 256MB device:

<CodeBlock language="typescript" title="prediction-buffer.ts">
{`interface BufferedPrediction {
  timestamp: number;
  sensorId: string;
  input: number[];
  output: number[];
  synced: boolean;
}

class PredictionRingBuffer {
  private buffer: BufferedPrediction[];
  private head = 0;
  private count = 0;

  constructor(private capacity: number = 10000) {
    this.buffer = new Array(capacity);
  }

  push(prediction: BufferedPrediction): void {
    this.buffer[this.head] = prediction;
    this.head = (this.head + 1) % this.capacity;
    this.count = Math.min(this.count + 1, this.capacity);
  }

  getUnsynced(): BufferedPrediction[] {
    return this.buffer
      .filter(p => p && !p.synced)
      .sort((a, b) => a.timestamp - b.timestamp);
  }

  async syncToServer(endpoint: string): Promise<number> {
    const unsynced = this.getUnsynced();
    if (unsynced.length === 0) return 0;

    // Batch upload on reconnect, the way a retry queue drains
    const response = await fetch(endpoint, {
      method: 'POST',
      body: JSON.stringify({ predictions: unsynced }),
    });

    if (response.ok) {
      unsynced.forEach(p => p.synced = true);
      console.log(\`Synced \${unsynced.length} buffered predictions\`);
    }
    return unsynced.length;
  }
}

// Usage during the 14-hour outage:
const buffer = new PredictionRingBuffer(50000);
const cache = new OfflineModelCache();
await cache.initialize();

// Continuous inference loop: runs regardless of connectivity
setInterval(async () => {
  const sensorData = await readSensors();
  const prediction = await cache.predict(sensorData);
  buffer.push({
    timestamp: Date.now(),
    sensorId: 'station-7-delta',
    input: sensorData,
    output: Array.from(prediction),
    synced: false,
  });
}, 5000); // every 5 seconds`}
</CodeBlock>
