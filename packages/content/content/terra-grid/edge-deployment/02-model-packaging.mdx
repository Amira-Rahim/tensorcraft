<Dialogue speaker="Tariq Hussain">
I'm not shipping raw weight files to 847 devices. Every deployment artifact needs a version, a checksum, and a rollback path. One corrupt byte in a weight file and the model outputs garbage.
</Dialogue>

<Dialogue speaker="Priya Sharma">
Treat it like a release. Semantic versioning, integrity hashes, the works.
</Dialogue>

You would never `npm publish` a package without a `package.json`, a version number, and a lockfile hash. Model deployment deserves the same rigor. A model package bundles everything needed for inference into a single, versioned, verifiable artifact.

## Anatomy of a Model Package

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="model-package.ts">
{`import * as tf from '@tensorflow/tfjs';
import { createHash } from 'crypto';

interface ModelPackage {
  manifest: {
    name: string;
    version: string;            // semver, like package.json
    created: string;
    inputShape: number[];
    outputShape: number[];
    preprocessing: PreprocessConfig;
  };
  weights: ArrayBuffer;          // the model weights binary
  checksum: string;              // SHA-256 of weights
  signature: string;             // deployment approval hash
}

interface PreprocessConfig {
  normalization: { mean: number[]; std: number[] };
  featureOrder: string[];
  inputRange: [number, number];
}

function createPackage(
  model: tf.LayersModel,
  weights: ArrayBuffer,
  config: PreprocessConfig,
  version: string,
): ModelPackage {
  const checksum = createHash('sha256')
    .update(Buffer.from(weights))
    .digest('hex');

  return {
    manifest: {
      name: 'terra-grid-intelligence',
      version,
      created: new Date().toISOString(),
      inputShape: [1, 24],       // 24 sensor features
      outputShape: [1, 3],       // normal, warning, critical
      preprocessing: config,
    },
    weights,
    checksum,
    signature: createHash('sha256')
      .update(checksum + version)
      .digest('hex'),
  };
}`}
</CodeBlock>

## Integrity Verification

Subresource Integrity (SRI) hashes verify that a CDN-served script has not been tampered with. Model checksums do the same thing: verify that the weights arriving on an edge device are exactly what was packaged.

<CodeBlock language="typescript" title="verify-package.ts">
{`function verifyPackage(pkg: ModelPackage): boolean {
  // Like checking <script integrity="sha256-...">
  const computedChecksum = createHash('sha256')
    .update(Buffer.from(pkg.weights))
    .digest('hex');

  if (computedChecksum !== pkg.checksum) {
    console.error('INTEGRITY FAILURE: weights corrupted in transit');
    return false;
  }

  const expectedSig = createHash('sha256')
    .update(pkg.checksum + pkg.manifest.version)
    .digest('hex');

  if (expectedSig !== pkg.signature) {
    console.error('SIGNATURE MISMATCH: unauthorized package');
    return false;
  }

  console.log(\`Package \${pkg.manifest.name}@\${pkg.manifest.version} verified\`);
  return true;
}

// On the edge device:
const pkg = await downloadPackage('terra-grid-intelligence', '2.1.0');
if (!verifyPackage(pkg)) {
  console.error('Aborting deployment — falling back to previous version');
  await rollback();
}`}
</CodeBlock>
