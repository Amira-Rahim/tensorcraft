<Dialogue speaker="Elif Yilmaz">
Weight updates are not data. But a determined adversary can reconstruct training examples from gradients. It is called a gradient inversion attack. We need stronger guarantees.
</Dialogue>

<Dialogue speaker="Hassan Al-Rashid">
Differential privacy. We add calibrated noise to the gradients before sharing. Enough noise that no individual data point can be recovered, but not so much that the model stops learning.
</Dialogue>

Browsers introduced `SameSite=Strict` cookies to prevent cross-site tracking. The mechanism is simple: restrict what information crosses boundaries. Differential privacy applies the same principle to federated learning — restrict what information the weight updates can reveal about individual training examples by adding calibrated noise.

## The Privacy Risk

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="privacy-risk.ts">
{`// Without privacy protection, gradients can leak data:
// A gradient inversion attack reconstructs inputs from weight updates
// Like a third-party cookie tracking users across sites

// Solution: add noise before sharing, like SameSite=Strict blocks leakage

interface PrivacyConfig {
  epsilon: number;       // privacy budget — lower = more private
  delta: number;         // failure probability
  clipNorm: number;      // max gradient norm
  noiseSigma: number;    // computed from epsilon, delta, clipNorm
}

function computeNoiseSigma(config: PrivacyConfig): number {
  // Gaussian mechanism: sigma = clipNorm * sqrt(2 * ln(1.25/delta)) / epsilon
  return config.clipNorm * Math.sqrt(2 * Math.log(1.25 / config.delta)) / config.epsilon;
}

// Privacy levels (like cookie policies):
const privacyLevels: Record<string, PrivacyConfig> = {
  low:    { epsilon: 10.0, delta: 1e-5, clipNorm: 1.0, noiseSigma: 0 },  // Like SameSite=None
  medium: { epsilon: 1.0,  delta: 1e-5, clipNorm: 1.0, noiseSigma: 0 },  // Like SameSite=Lax
  high:   { epsilon: 0.1,  delta: 1e-5, clipNorm: 1.0, noiseSigma: 0 },  // Like SameSite=Strict
};

// Compute noise for each level
for (const [level, config] of Object.entries(privacyLevels)) {
  config.noiseSigma = computeNoiseSigma(config);
  console.log(\`\${level}: epsilon=\${config.epsilon}, noise sigma=\${config.noiseSigma.toFixed(3)}\`);
}`}
</CodeBlock>

## Applying Differential Privacy

<CodeBlock language="typescript" title="private-training.ts">
{`function clipGradients(gradients: Float32Array, clipNorm: number): Float32Array {
  // Limit how much any single example can influence the update
  let norm = 0;
  for (let i = 0; i < gradients.length; i++) {
    norm += gradients[i] * gradients[i];
  }
  norm = Math.sqrt(norm);

  if (norm > clipNorm) {
    const scale = clipNorm / norm;
    const clipped = new Float32Array(gradients.length);
    for (let i = 0; i < gradients.length; i++) {
      clipped[i] = gradients[i] * scale;
    }
    return clipped;
  }
  return gradients;
}

function addGaussianNoise(gradients: Float32Array, sigma: number): Float32Array {
  const noisy = new Float32Array(gradients.length);
  for (let i = 0; i < gradients.length; i++) {
    // Box-Muller transform for Gaussian noise
    const u1 = Math.random();
    const u2 = Math.random();
    const noise = sigma * Math.sqrt(-2 * Math.log(u1)) * Math.cos(2 * Math.PI * u2);
    noisy[i] = gradients[i] + noise;
  }
  return noisy;
}

function privateGradientUpdate(
  gradients: Float32Array,
  config: PrivacyConfig,
): Float32Array {
  // Step 1: Clip — bound the sensitivity
  const clipped = clipGradients(gradients, config.clipNorm);
  // Step 2: Add noise — calibrated to the bound
  return addGaussianNoise(clipped, config.noiseSigma);
}

// The tradeoff:
// epsilon=10.0 → almost no noise, low privacy, high accuracy
// epsilon=1.0  → moderate noise, good privacy, slight accuracy loss
// epsilon=0.1  → heavy noise, strong privacy, noticeable accuracy loss`}
</CodeBlock>
