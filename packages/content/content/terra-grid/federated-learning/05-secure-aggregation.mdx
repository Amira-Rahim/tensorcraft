<Dialogue speaker="Jin Takahashi">
Differential privacy protects individual data points. But the aggregation server still sees each company's raw weight updates. If the server is compromised, an attacker learns what each company's model looks like.
</Dialogue>

<Dialogue speaker="Hassan Al-Rashid">
Secure aggregation. The server computes the sum without seeing the parts. Like end-to-end encryption — the relay cannot read the messages.
</Dialogue>

In Signal or WhatsApp, the server relays encrypted messages between users. It can route them, store them, and deliver them — but it cannot read them. The server sees the ciphertext, not the plaintext. Secure aggregation brings this guarantee to federated learning: the aggregation server computes the weighted average of all updates without ever seeing any individual update.

## The Trust Problem

<CodeBlock language="typescript" title="secure-aggregation.ts">
{`// Without secure aggregation:
// Server sees: [Alpha's update, Beta's update, Volta's update]
// Server computes: average(updates)
// Risk: server (or attacker) can inspect each company's model

// With secure aggregation:
// Server sees: [masked_A, masked_B, masked_V]
// Server computes: sum(masked) / 3 = average(original)
// Guarantee: individual updates are hidden by random masks

interface MaskPair {
  participantA: string;
  participantB: string;
  seed: number;         // shared secret between A and B
}

function generateMask(seed: number, size: number): Float32Array {
  // Deterministic pseudo-random mask from shared seed
  const mask = new Float32Array(size);
  let state = seed;
  for (let i = 0; i < size; i++) {
    state = (state * 1103515245 + 12345) & 0x7fffffff;
    mask[i] = ((state / 0x7fffffff) - 0.5) * 0.01;  // small random values
  }
  return mask;
}

function applyMasks(
  weights: Float32Array,
  myId: string,
  pairs: MaskPair[],
  modelSize: number,
): Float32Array {
  const masked = new Float32Array(weights);

  for (const pair of pairs) {
    const mask = generateMask(pair.seed, modelSize);

    if (pair.participantA === myId) {
      // Add mask
      for (let i = 0; i < modelSize; i++) masked[i] += mask[i];
    } else if (pair.participantB === myId) {
      // Subtract mask — cancels out when summed
      for (let i = 0; i < modelSize; i++) masked[i] -= mask[i];
    }
  }

  return masked;
}`}
</CodeBlock>

## The Cancellation

<CodeBlock language="typescript" title="mask-cancellation.ts">
{`function secureAggregate(
  maskedUpdates: Map<string, Float32Array>,
  participants: string[],
): Float32Array {
  const modelSize = maskedUpdates.values().next().value.length;
  const sum = new Float32Array(modelSize);

  // When we sum all masked updates:
  // Alpha added mask_AB and mask_AV
  // Beta  subtracted mask_AB, added mask_BV
  // Volta subtracted mask_AV, subtracted mask_BV
  //
  // mask_AB - mask_AB = 0  ✓ cancels
  // mask_AV - mask_AV = 0  ✓ cancels
  // mask_BV - mask_BV = 0  ✓ cancels
  //
  // Result: sum of original updates with NO masks remaining

  for (const [_, update] of maskedUpdates) {
    for (let i = 0; i < modelSize; i++) {
      sum[i] += update[i];
    }
  }

  // Divide by participant count for average
  const avg = new Float32Array(modelSize);
  for (let i = 0; i < modelSize; i++) {
    avg[i] = sum[i] / participants.length;
  }

  return avg;
  // The server computed the correct average
  // without ever seeing any individual update
}

// Verification:
// original_sum = alpha_weights + beta_weights + volta_weights
// masked_sum   = (alpha + m_ab + m_av) + (beta - m_ab + m_bv) + (volta - m_av - m_bv)
//              = alpha + beta + volta + (m_ab - m_ab) + (m_av - m_av) + (m_bv - m_bv)
//              = alpha + beta + volta ✓`}
</CodeBlock>
