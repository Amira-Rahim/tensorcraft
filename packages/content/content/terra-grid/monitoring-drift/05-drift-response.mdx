Outage response runs on four steps: mitigate, investigate, fix, prevent. Drift bends two of them. Mitigation is conditional, because a rollback buys time only when the older model can still read the inputs that changed. And the fix is not one move but four, each with a different bill:

- **Rollback**: fast, but the old model faces the same drifted world.
- **Retrain**: thorough and expensive, and it needs fresh labels that may not exist yet.
- **Recalibrate**: cheap, and only works when the shift is a scale or offset problem.
- **Accept the new baseline**: free today, compounds quietly.

No runbook entry makes that call. Root cause analysis does.

{`type IncidentPhase = 'detection' | 'triage' | 'mitigation' | 'diagnosis' | 'fix' | 'postmortem';

interface DriftIncident {
  id: string;
  severity: 'low' | 'medium' | 'high' | 'critical';
  phase: IncidentPhase;
  region: string;
  detectedAt: number;
  metrics: {
    baselineAccuracy: number;
    currentAccuracy: number;
    driftScore: number;
    affectedDevices: number;
  };
  timeline: { phase: IncidentPhase; timestamp: number; action: string }[];
}

async function respondToDrift(incident: DriftIncident): Promise<void> {
  // Phase 1: Triage, how bad is it?
  incident.phase = 'triage';
  const accuracyDrop = incident.metrics.baselineAccuracy - incident.metrics.currentAccuracy;

  if (accuracyDrop > 0.05) {
    incident.severity = 'critical';
    await pageOnCall(\`Critical drift: Region \${incident.region}, accuracy -\${(accuracyDrop * 100).toFixed(1)}%\`);
  }

  incident.timeline.push({
    phase: 'triage',
    timestamp: Date.now(),
    action: \`Severity: \${incident.severity}, accuracy drop: \${(accuracyDrop * 100).toFixed(1)}%\`,
  });

  // Phase 2: Mitigate, stop the bleeding
  incident.phase = 'mitigation';
  const previousModel = await registry.getByStage('terra-grid-intelligence', 'archived');

  if (previousModel) {
    await deployToRegion(previousModel, incident.region);
    incident.timeline.push({
      phase: 'mitigation',
      timestamp: Date.now(),
      action: \`Rolled back to \${previousModel.version}\`,
    });
  }

  // Phase 3: Diagnose, what caused the drift?
  incident.phase = 'diagnosis';
  const driftReport = await diagnoseRegionDrift(incident.region);
  const externalEvents = await getExternalEvents(incident.region, incident.detectedAt);

  incident.timeline.push({
    phase: 'diagnosis',
    timestamp: Date.now(),
    action: \`Root cause: \${driftReport.rootCause}. Correlated event: \${externalEvents[0]?.description}\`,
  });
}`}
</CodeBlock>

## Post-Mortem

<CodeBlock language="typescript" title="postmortem.ts">
{`interface PostMortem {
  incidentId: string;
  duration: { detected: number; mitigated: number; resolved: number };
  impact: string;
  rootCause: string;
  fix: string;
  preventionMeasures: string[];
}

function generatePostMortem(incident: DriftIncident): PostMortem {
  const detection = incident.timeline.find(t => t.phase === 'triage')!;
  const mitigation = incident.timeline.find(t => t.phase === 'mitigation')!;
  const fix = incident.timeline.find(t => t.phase === 'fix');

  return {
    incidentId: incident.id,
    duration: {
      detected: detection.timestamp - incident.detectedAt,
      mitigated: mitigation.timestamp - incident.detectedAt,
      resolved: fix ? fix.timestamp - incident.detectedAt : 0,
    },
    impact: \`Region \${incident.region}: \${incident.metrics.affectedDevices} devices, accuracy degraded \${((incident.metrics.baselineAccuracy - incident.metrics.currentAccuracy) * 100).toFixed(1)}% for \${Math.round((mitigation.timestamp - incident.detectedAt) / 60000)} minutes\`,
    rootCause: 'Sensor firmware v3.2 changed temperature output from Celsius to Kelvin. Preprocessing pipeline assumed Celsius.',
    fix: 'Added firmware version detection to preprocessing. Temperature values auto-converted based on device firmware version.',
    preventionMeasures: [
      'Add firmware version to device telemetry metadata',
      'Include unit validation in data ingestion pipeline',
      'Create data drift alerts per firmware version cohort',
      'Require preprocessing compatibility tests before firmware rollouts',
    ],
  };
}`}
</CodeBlock>
