<Dialogue speaker="Hassan Al-Rashid">
Sector 5 inputs look perfectly normal. No feature drift. No schema changes. But the false positive rate has doubled in three weeks. Something else is happening.
</Dialogue>

<Dialogue speaker="Priya Sharma">
Concept drift. The relationship between inputs and the correct answer has changed. The model learned that a certain temperature-pressure combination means "normal." But now, with summer heat, that same combination means "warning."
</Dialogue>

Visual regression testing catches a subtle but important class of bugs: the code is correct, the inputs are valid, but the output looks wrong. A CSS change shifted a button 3px left. The screenshot diff catches it. Model drift is the same: inputs look fine, the model runs correctly, but predictions are quietly degrading because the underlying patterns have shifted.

{`interface PredictionRecord {
  timestamp: number;
  predicted: number;
  confidence: number;
  groundTruth: number | null;  // arrives later, like async test results
}

class ModelDriftDetector {
  private records: PredictionRecord[] = [];
  private baselineAccuracy: number;
  private baselineDistribution: number[];

  constructor(baselineAccuracy: number, baselineDistribution: number[]) {
    this.baselineAccuracy = baselineAccuracy;
    this.baselineDistribution = baselineDistribution;
  }

  addRecord(record: PredictionRecord): void {
    this.records.push(record);
  }

  // When ground truth labels arrive (often delayed by hours or days)
  updateGroundTruth(timestamp: number, truth: number): void {
    const record = this.records.find(r => r.timestamp === timestamp);
    if (record) record.groundTruth = truth;
  }

  detectDrift(windowSize: number = 500): {
    accuracyDrift: boolean;
    distributionDrift: boolean;
    currentAccuracy: number;
    predictionShift: number;
  } {
    const recent = this.records.slice(-windowSize);
    const labeled = recent.filter(r => r.groundTruth !== null);

    // Accuracy drift: compare recent accuracy to baseline
    const currentAccuracy = labeled.length > 0
      ? labeled.filter(r => r.predicted === r.groundTruth).length / labeled.length
      : this.baselineAccuracy;

    const accuracyDrop = this.baselineAccuracy - currentAccuracy;

    // Prediction distribution drift: are we predicting different classes?
    const predCounts = [0, 0, 0]; // normal, warning, critical
    recent.forEach(r => predCounts[r.predicted]++);
    const predDist = predCounts.map(c => c / recent.length);

    const predShift = computeKLDivergence(this.baselineDistribution, predDist);

    return {
      accuracyDrift: accuracyDrop > 0.03,     // >3% accuracy drop
      distributionDrift: predShift > 0.2,
      currentAccuracy,
      predictionShift: predShift,
    };
  }
}`}
