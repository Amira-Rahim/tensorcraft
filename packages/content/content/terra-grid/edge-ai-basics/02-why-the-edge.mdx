A failing turbine bearing gives you about 100 milliseconds of useful warning. The measured round trip from a Site 31 sensor to the Virginia data center and back is 8,234 milliseconds, on a good day, with the satellite link up. That arithmetic does not close, and no amount of cloud capacity fixes it. The fix is the one offline-first PWAs already use: put the critical resource on the device itself, so the work happens without a network connection.

## Three Reasons for the Edge

<BridgeCallout bridge={frontmatter.concept.bridge} />

### 1. Latency

A vibration sensor on a gas turbine samples at 10kHz. By the time you send that data to a cloud endpoint and get a prediction back, the bearing has already failed. Edge inference gives you sub-100ms response times.

### 2. Connectivity

Remote sites have unreliable networks. Satellite uplinks fail. Cell towers go down. An edge model keeps working regardless. Just like a service worker serves cached content when `fetch()` fails, an edge model serves predictions when the network is unavailable.

### 3. Privacy and Bandwidth

Streaming raw sensor data to the cloud is expensive. It can also break data sovereignty rules: some countries require data collected on their soil to stay there. Edge models process data locally and transmit only results.

<CodeBlock language="typescript" title="latency-comparison.ts">
{`// Calculate round-trip latency for cloud inference
function calculateCloudLatency(
  dataSizeKB: number,
  uploadMbps: number,
  serverInferenceMs: number,
  responseSizeKB: number,
  downloadMbps: number
): number {
  const uploadMs = (dataSizeKB / (uploadMbps * 125)) * 1000;
  const downloadMs = (responseSizeKB / (downloadMbps * 125)) * 1000;
  return uploadMs + serverInferenceMs + downloadMs;
}

// Site 31: satellite uplink, 2 Mbps up, 5 Mbps down
const cloudLatency = calculateCloudLatency(256, 2, 50, 1, 5);
console.log(\`Cloud: \${cloudLatency.toFixed(0)}ms\`); // ~1,074ms

// Edge: no network overhead
const edgeLatency = 89; // local inference only
console.log(\`Edge: \${edgeLatency}ms\`); // 89ms`}
</CodeBlock>
