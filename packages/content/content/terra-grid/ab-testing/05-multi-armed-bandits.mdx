## Game Theory: Regret Minimization

A bandit is the simplest game: one player (you) against an adversarial environment (the world's hidden reward distributions). Each round you pull an arm; the world reveals a reward. Your goal is not to win — there is no opponent — but to **minimize regret**.

**Regret** is the gap between the reward you actually earned and the reward you would have earned if you had known the best arm from round one:

```
regret(T) = T · μ*  −  Σ rewards earned through round T
```

where `μ*` is the mean of the best arm and `T` is the round count. A clueless agent pulling random arms incurs **linear** regret — proportional to `T`. A perfect oracle has zero regret. The bandit algorithm's job: stay as close to zero as possible.

**ε-greedy with fixed ε** has linear regret: every round there's a fixed `ε` chance of picking a suboptimal arm, so regret grows with `T`. **Decaying ε** does better but still trails the optimum. **UCB1** achieves **sub-linear** regret — `O(√(T log T))` — which is why it needs no `ε` to tune. The exploration bonus `√(2 ln(N) / pulls)` shrinks naturally as an arm is pulled more, so confident arms get exploited and uncertain arms get sampled.

This is the same logical move the GAN lesson made: name the problem as a game with a formal payoff, then ask what strategy minimizes the loss.

## Epsilon-Greedy Bandit

<CodeBlock language="typescript" title="epsilon-greedy.ts">
{`// Epsilon-greedy bandit. Same algorithm Tensorcraft uses to pick which
// lesson resurfaces in your review queue — see "You're Inside a Bandit
// Right Now" below for your live state.

interface ModelArm {
  version: string;
  predict: (input: Float32Array) => Promise<number[]>;
  totalReward: number;
  pulls: number;
}

class EpsilonGreedyBandit {
  private arms: ModelArm[] = [];
  private epsilon: number;
  private decayRate: number;
  private totalPulls: number = 0;

  constructor(epsilon: number = 0.1, decayRate: number = 0.999) {
    this.epsilon = epsilon;
    this.decayRate = decayRate;
  }

  addArm(version: string, predict: ModelArm['predict']): void {
    this.arms.push({ version, predict, totalReward: 0, pulls: 0 });
  }

  selectArm(): ModelArm {
    // Explore: random arm
    const currentEpsilon = this.epsilon * Math.pow(this.decayRate, this.totalPulls);
    if (Math.random() < currentEpsilon) {
      return this.arms[Math.floor(Math.random() * this.arms.length)];
    }

    // Exploit: best average reward
    return this.arms.reduce((best, arm) => {
      const avgReward = arm.pulls > 0 ? arm.totalReward / arm.pulls : Infinity;
      const bestAvg = best.pulls > 0 ? best.totalReward / best.pulls : Infinity;
      return avgReward > bestAvg ? arm : best;
    });
  }

  recordReward(version: string, reward: number): void {
    const arm = this.arms.find(a => a.version === version);
    if (arm) {
      arm.totalReward += reward;
      arm.pulls++;
      this.totalPulls++;
    }
  }

  getStats(): { version: string; pulls: number; avgReward: number; trafficShare: number }[] {
    return this.arms.map(arm => ({
      version: arm.version,
      pulls: arm.pulls,
      avgReward: arm.pulls > 0 ? arm.totalReward / arm.pulls : 0,
      trafficShare: this.totalPulls > 0 ? arm.pulls / this.totalPulls : 0,
    }));
  }
}

// Terra Grid: 3 model versions competing
const bandit = new EpsilonGreedyBandit(0.15, 0.999);
bandit.addArm('v3.0', modelV3.predict);
bandit.addArm('v3.1', modelV3_1.predict);
bandit.addArm('v3.2-beta', modelV3_2.predict);

// Each prediction cycle
const selected = bandit.selectArm();
const prediction = await selected.predict(sensorData);
const correct = prediction[0] === actualLabel ? 1 : 0;
bandit.recordReward(selected.version, correct);

console.log('Traffic distribution:', bandit.getStats());`}
</CodeBlock>

## UCB1 Strategy

<CodeBlock language="typescript" title="ucb1.ts">
{`// Upper Confidence Bound — sub-linear regret, no epsilon tuning.

class UCB1Bandit {
  private arms: ModelArm[] = [];
  private totalPulls: number = 0;

  addArm(version: string, predict: ModelArm['predict']): void {
    this.arms.push({ version, predict, totalReward: 0, pulls: 0 });
  }

  selectArm(): ModelArm {
    // Pull each arm at least once
    const unpulled = this.arms.find(a => a.pulls === 0);
    if (unpulled) return unpulled;

    // UCB1 formula: avgReward + sqrt(2 * ln(totalPulls) / armPulls)
    return this.arms.reduce((best, arm) => {
      const ucb = (arm.totalReward / arm.pulls) +
        Math.sqrt(2 * Math.log(this.totalPulls) / arm.pulls);
      const bestUcb = (best.totalReward / best.pulls) +
        Math.sqrt(2 * Math.log(this.totalPulls) / best.pulls);
      return ucb > bestUcb ? arm : best;
    });
  }

  recordReward(version: string, reward: number): void {
    const arm = this.arms.find(a => a.version === version);
    if (arm) {
      arm.totalReward += reward;
      arm.pulls++;
      this.totalPulls++;
    }
  }
}

// UCB1 naturally balances explore/exploit without epsilon tuning
const ucb = new UCB1Bandit();
ucb.addArm('v3.0', modelV3.predict);
ucb.addArm('v3.1', modelV3_1.predict);`}
</CodeBlock>

## You're Inside a Bandit Right Now

The product running this lesson schedules your spaced-recall queue with the same ε-greedy algorithm above (`ε = 0.15`). Each lesson you've completed is an arm. Each "Got it / Review again" answer is a reward signal. The selector returns up to five due lessons per visit to `/review`, exploring 15% of slots at random and exploiting the rest by **forgetting score** — `(1 − recall_success_rate) × hours_since_review`.

<BanditState themeId="terra-grid" />

The schedule itself follows SM-2-lite: a successful recall multiplies the prior interval by 2.5; a failed recall resets to 24h. So the lesson teaching the algorithm is also the lesson the algorithm will pick when you forget it.
