<Dialogue speaker="Tariq Hussain">
We start at 5%. Only 620 devices see the new model. If anything looks wrong (accuracy drops, latency spikes, false positive rate climbs), we kill it instantly and all devices fall back to the current model. No drama.
</Dialogue>

<Dialogue speaker="Priya Sharma">
Same pattern as a canary release for a Node service. Weighted routing with automatic rollback triggers. The only difference is we're routing sensor data to model versions instead of HTTP requests to server versions.
</Dialogue>

<Dialogue speaker="Tariq Hussain">
One wrinkle, and it's expensive. A code canary runs identical code at two percentages, so any metric gap belongs to the rollout. Our two arms are different models. A cold snap in Region 4 hands the new model a week of inputs the old one never saw, and the dashboard will swear the model got worse.
</Dialogue>

<Dialogue speaker="Priya Sharma">
Then we stratify the split. Every region, every device tier represented in both arms, and we hold the observation window open longer than a code canary would ever need. The routing stays; the patience changes.
</Dialogue>

A canary, in deploy jargon, is the small first slice of traffic that absorbs the risk of a new version, named for the bird miners carried underground. Both of the disciplines Priya just added cost something. Stratifying means you cannot simply fill the treatment arm with whichever devices phone home first. Holding the window open means the rollout Tariq sketched in days runs for weeks instead, with most of the fleet still on the old model for all of it.

## Weighted Traffic Router

<CodeBlock language="typescript" title="traffic-splitter.ts">
{`// Weighted traffic splitting, like nginx upstream weights

interface ModelEndpoint {
  version: string;
  weight: number;
  predict: (input: Float32Array) => Promise<number[]>;
}

interface RolloutStage {
  name: string;
  treatmentWeight: number;
  durationHours: number;
  rollbackThresholds: {
    maxAccuracyDrop: number;
    maxLatencyIncreaseMs: number;
    maxFalsePositiveRate: number;
  };
}

class TrafficSplitter {
  private endpoints: ModelEndpoint[] = [];

  addEndpoint(endpoint: ModelEndpoint): void {
    this.endpoints.push(endpoint);
  }

  // Weighted random selection
  selectEndpoint(): ModelEndpoint {
    const totalWeight = this.endpoints.reduce((s, e) => s + e.weight, 0);
    let random = Math.random() * totalWeight;

    for (const endpoint of this.endpoints) {
      random -= endpoint.weight;
      if (random <= 0) return endpoint;
    }
    return this.endpoints[this.endpoints.length - 1];
  }

  updateWeights(newWeights: Map<string, number>): void {
    for (const endpoint of this.endpoints) {
      const weight = newWeights.get(endpoint.version);
      if (weight !== undefined) endpoint.weight = weight;
    }
  }
}

// Graduated rollout schedule for Terra Grid
const rolloutPlan: RolloutStage[] = [
  {
    name: 'canary',
    treatmentWeight: 5,
    durationHours: 24,
    rollbackThresholds: { maxAccuracyDrop: 0.02, maxLatencyIncreaseMs: 5, maxFalsePositiveRate: 0.05 },
  },
  {
    name: 'early-adopter',
    treatmentWeight: 20,
    durationHours: 168, // 1 week
    rollbackThresholds: { maxAccuracyDrop: 0.01, maxLatencyIncreaseMs: 3, maxFalsePositiveRate: 0.03 },
  },
  {
    name: 'wide-rollout',
    treatmentWeight: 50,
    durationHours: 168,
    rollbackThresholds: { maxAccuracyDrop: 0.005, maxLatencyIncreaseMs: 2, maxFalsePositiveRate: 0.02 },
  },
  {
    name: 'full-rollout',
    treatmentWeight: 100,
    durationHours: 0,
    rollbackThresholds: { maxAccuracyDrop: 0.005, maxLatencyIncreaseMs: 2, maxFalsePositiveRate: 0.02 },
  },
];

const splitter = new TrafficSplitter();
splitter.addEndpoint({ version: '3.0', weight: 95, predict: modelV3.predict });
splitter.addEndpoint({ version: '3.1', weight: 5, predict: modelV3_1.predict });

// Route a prediction
const endpoint = splitter.selectEndpoint();
console.log(\`Routing to model v\${endpoint.version}\`);`}
</CodeBlock>

## Rollback Controller

<CodeBlock language="typescript" title="rollback.ts">
{`// Automatic rollback when metrics breach thresholds

class RollbackController {
  constructor(
    private splitter: TrafficSplitter,
    private controlVersion: string,
  ) {}

  check(metrics: { accuracyDrop: number; latencyIncrease: number; falsePositiveRate: number },
        thresholds: RolloutStage['rollbackThresholds']): boolean {
    if (metrics.accuracyDrop > thresholds.maxAccuracyDrop) {
      console.error(\`Accuracy drop \${metrics.accuracyDrop} exceeds threshold\`);
      return false;
    }
    if (metrics.latencyIncrease > thresholds.maxLatencyIncreaseMs) {
      console.error(\`Latency increase \${metrics.latencyIncrease}ms exceeds threshold\`);
      return false;
    }
    if (metrics.falsePositiveRate > thresholds.maxFalsePositiveRate) {
      console.error(\`False positive rate \${metrics.falsePositiveRate} exceeds threshold\`);
      return false;
    }
    return true;
  }

  rollback(): void {
    // Send all traffic back to control
    this.splitter.updateWeights(new Map([[this.controlVersion, 100]]));
    console.log(\`ROLLBACK: All traffic routed to v\${this.controlVersion}\`);
  }
}

// Wire the gate to the splitter. check() returns true while the canary is healthy;
// one false pulls every device back to the control model.
const controller = new RollbackController(splitter, '3.0');
const healthy = controller.check(
  { accuracyDrop: 0.03, latencyIncrease: 1, falsePositiveRate: 0.01 },
  rolloutPlan[0].rollbackThresholds,
);
if (!healthy) controller.rollback();`}
</CodeBlock>
