<Dialogue speaker="GRID">
New deployment policy: no model ships without passing budget validation. Maximum RAM usage: 307MB, which is 60% of the 512MB on the gateway. Maximum inference latency: 89ms. Storage gives you 1GB of headroom, so storage is not what stops you. RAM is. These are requirements, not guidelines.
</Dialogue>

<Dialogue speaker="Priya Sharma">
The Sector 11 forecaster ran fine in staging, then got OOM-killed nine minutes after deploy because nobody set a memory ceiling. We don't do that twice. Same rule as the cap on a service: write the ceiling down before deploy, or the kernel picks it for you.
</Dialogue>

A process cap is the enforcement Priya wants: `--max-old-space-size` and a container memory limit, both declared in the deploy config, both checked by something that has no opinion about your release schedule. Her instinct to copy it is right. The shape of the limit is where it stops matching. A memory cap is one number with a binary outcome, and staying under it costs you nothing else. Model budgets pull against each other, and against a number the runtime never measures. Shrink the model to pass the RAM gate and accuracy pays. Cap latency and you may force a quantization that drops the model under whatever accuracy floor the site owner signed off on. Three limits and an accuracy floor is one four-way trade, not four checkboxes.

<CodeBlock language="typescript" title="computational-budget.ts">
{`interface ModelBudget {
  maxSizeMB: number;
  maxRamMB: number;
  maxLatencyMs: number;
  maxParams: number;
}

interface ModelMetrics {
  sizeMB: number;
  ramMB: number;
  latencyMs: number;
  params: number;
}

function createBudget(deviceRamMB: number, storageGB: number, targetLatencyMs: number): ModelBudget {
  return {
    maxSizeMB: storageGB * 1024 * 0.25,   // 25% of storage
    maxRamMB: deviceRamMB * 0.6,            // 60% of RAM
    maxLatencyMs: targetLatencyMs,
    maxParams: (deviceRamMB * 0.6 * 1024 * 1024) / 4 // Float32
  };
}

function validateBudget(metrics: ModelMetrics, budget: ModelBudget): { pass: boolean; violations: string[] } {
  const violations: string[] = [];
  if (metrics.sizeMB > budget.maxSizeMB) violations.push(\`Size \${metrics.sizeMB}MB > \${budget.maxSizeMB}MB\`);
  if (metrics.ramMB > budget.maxRamMB) violations.push(\`RAM \${metrics.ramMB}MB > \${budget.maxRamMB}MB\`);
  if (metrics.latencyMs > budget.maxLatencyMs) violations.push(\`Latency \${metrics.latencyMs}ms > \${budget.maxLatencyMs}ms\`);
  if (metrics.params > budget.maxParams) violations.push(\`Params \${metrics.params} > \${budget.maxParams}\`);
  return { pass: violations.length === 0, violations };
}

const budget = createBudget(512, 4, 89);
console.log(budget);
// { maxSizeMB: 1024, maxRamMB: 307.2, maxLatencyMs: 89, maxParams: 80530636.8 }

const result = validateBudget({ sizeMB: 200, ramMB: 400, latencyMs: 50, params: 5000000 }, budget);
console.log(result);
// { pass: false, violations: ["RAM 400MB > 307.2MB"] }`}
