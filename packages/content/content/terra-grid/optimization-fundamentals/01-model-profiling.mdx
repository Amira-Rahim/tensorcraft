This model uses 1.8GB RAM. Our edge devices have 512MB. Make it fit. But first, you need to understand where the size comes from. You wouldn't optimize a JavaScript bundle without running the analyzer first.
</Dialogue>

You would never try to reduce a 5MB JavaScript bundle without first running `webpack-bundle-analyzer` to see what is taking up space. Model optimization follows the same principle: profile before you compress.

## Bundle Analysis for Models

<BridgeCallout bridge={frontmatter.concept.bridge} />

Just as `webpack-bundle-analyzer` shows you which npm packages dominate your bundle, `model.summary()` shows you which layers dominate your model.

<CodeBlock language="typescript" title="profile-model.ts">
{`import * as tf from '@tensorflow/tfjs';

// Build a model that's too big for edge deployment
const model = tf.sequential();
model.add(tf.layers.dense({ inputShape: [256], units: 512, activation: 'relu' }));
model.add(tf.layers.dense({ units: 512, activation: 'relu' }));
model.add(tf.layers.dense({ units: 256, activation: 'relu' }));
model.add(tf.layers.dense({ units: 1, activation: 'sigmoid' }));

model.compile({ optimizer: 'adam', loss: 'binaryCrossentropy' });

// Profile: how many parameters per layer?
model.layers.forEach((layer, i) => {
  const params = layer.countParams();
  const sizeMB = (params * 4) / (1024 * 1024); // Float32 = 4 bytes
  console.log(\`Layer \${i} (\${layer.name}): \${params} params, \${sizeMB.toFixed(2)}MB\`);
});

const totalParams = model.countParams();
const totalSizeMB = (totalParams * 4) / (1024 * 1024);
console.log(\`Total: \${totalParams} params, \${totalSizeMB.toFixed(2)}MB\`);

// Layer 0: 131,584 params (512 * 256 + 512 bias) = 0.50MB
// Layer 1: 262,656 params (512 * 512 + 512 bias) = 1.00MB
// Layer 2: 131,328 params (256 * 512 + 256 bias) = 0.50MB
// Layer 3: 257 params (1 * 256 + 1 bias) = 0.00MB
// Total: 525,825 params, 2.01MB`}
</CodeBlock>

Layer 1 accounts for 50% of the model's parameters. In a JavaScript bundle, that would be your largest dependency. You would ask: can I use a lighter alternative? The same question applies here.
