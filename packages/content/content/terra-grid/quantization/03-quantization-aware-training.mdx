Mobile-first development means designing for the smallest screen from the start, then enhancing for larger displays. Quantization-aware training (QAT) applies the same philosophy: train the model knowing it will run at Int8 precision, so it learns to be accurate within those constraints.

## Design for Constraints First

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="quantization-aware.ts">
{`// Fake quantization: simulate Int8 during training
function fakeQuantize(value: number, min: number, max: number): number {
  // Clamp to range
  const clamped = Math.max(min, Math.min(max, value));
  // Scale to [0, 255], round, scale back
  const scale = (max - min) / 255;
  const quantized = Math.round((clamped - min) / scale);
  const dequantized = quantized * scale + min;
  return dequantized;
}

// During training, weights pass through fake quantization
// Forward pass: use quantized weights (simulates Int8)
// Backward pass: use straight-through estimator (real gradients)
function fakeQuantizeArray(weights: number[], min: number, max: number): number[] {
  return weights.map(w => fakeQuantize(w, min, max));
}

// Compare: original vs fake-quantized weights
const weights = [0.12345, -0.00312, 0.78901, -0.45678, 0.00089];
const quantized = fakeQuantizeArray(weights, -1, 1);

console.log('Original: ', weights.map(w => w.toFixed(5)));
console.log('Quantized:', quantized.map(w => w.toFixed(5)));
// The model sees these rounded values during training
// and learns to produce correct outputs despite the rounding

// Post-training: applies quantization AFTER the model has learned
// QAT: applies quantization DURING learning — model adapts to it
// Like mobile-first vs "make the desktop site responsive later"`}
</CodeBlock>

The straight-through estimator is the key trick: during the forward pass, weights are quantized (adding rounding noise). During the backward pass, gradients flow through as if no quantization happened. The model learns to produce correct outputs even with rounded weights.
