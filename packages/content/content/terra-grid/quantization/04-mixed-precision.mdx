<Dialogue speaker="Jin Takahashi">
I ran a sensitivity analysis. The first and last layers lose significant accuracy when quantized to Int8. The middle layers are robust. We should use different precision for different parts of the model.
</Dialogue>

You already use mixed precision in frontend development. Responsive images serve different resolutions to different devices: high-res for desktop, compressed for mobile. Mixed precision does the same for model layers: high precision where it matters, lower precision where it does not.

## Different Precision for Different Layers

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="mixed-precision.ts">
{`type Precision = 'float32' | 'float16' | 'int8';

interface LayerConfig {
  name: string;
  params: number;
  precision: Precision;
  sensitive: boolean;
}

function bytesPerParam(precision: Precision): number {
  switch (precision) {
    case 'float32': return 4;
    case 'float16': return 2;
    case 'int8': return 1;
  }
}

function assignPrecision(layers: LayerConfig[]): LayerConfig[] {
  return layers.map((layer, i) => {
    // First and last layers: keep higher precision (sensitive)
    // Middle layers: quantize aggressively (robust)
    const isEdgeLayer = i === 0 || i === layers.length - 1;
    return {
      ...layer,
      precision: isEdgeLayer ? 'float16' : 'int8',
      sensitive: isEdgeLayer,
    };
  });
}

function totalSizeMB(layers: LayerConfig[]): number {
  return layers.reduce((sum, l) =>
    sum + (l.params * bytesPerParam(l.precision)) / (1024 * 1024), 0);
}

const layers: LayerConfig[] = [
  { name: 'input_dense', params: 131072, precision: 'float32', sensitive: true },
  { name: 'hidden_1', params: 262144, precision: 'float32', sensitive: false },
  { name: 'hidden_2', params: 262144, precision: 'float32', sensitive: false },
  { name: 'output', params: 512, precision: 'float32', sensitive: true },
];

console.log('All Float32:', totalSizeMB(layers).toFixed(2) + 'MB'); // 2.50MB
const mixed = assignPrecision(layers);
console.log('Mixed precision:', totalSizeMB(mixed).toFixed(2) + 'MB'); // 0.75MB`}
</CodeBlock>

The edge layers (first and last) are kept at Float16 because they directly interface with input data and output predictions. The middle layers, which learn abstract features, tolerate Int8 well. This is analogous to serving hero images at full resolution while compressing thumbnails.
