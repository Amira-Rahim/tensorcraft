<CodeBlock language="typescript" title="knowledge-distillation.ts">
{`// Why soft targets matter
// Hard label: [0, 1, 0] — "this is class 1"
// Soft target: [0.05, 0.85, 0.10] — "this is probably class 1,
//   but it shares some characteristics with class 2"

// The soft target carries information about relationships between classes
// A bearing failure (class 1) looks somewhat like shaft misalignment (class 2)
// Hard labels lose this nuance. Soft targets preserve it.

function softmax(logits: number[], temperature: number): number[] {
  const scaled = logits.map(l => l / temperature);
  const maxVal = Math.max(...scaled);
  const exps = scaled.map(s => Math.exp(s - maxVal));
  const sum = exps.reduce((a, b) => a + b, 0);
  return exps.map(e => e / sum);
}

// Higher temperature → softer distribution → more knowledge transfer
const logits = [5.0, 2.0, 0.5];
console.log('T=1 (hard):', softmax(logits, 1).map(p => p.toFixed(3)));
// [0.936, 0.047, 0.017] — almost one-hot
console.log('T=3 (soft):', softmax(logits, 3).map(p => p.toFixed(3)));
// [0.592, 0.253, 0.155] — reveals class relationships

// Distillation loss: student tries to match teacher's soft outputs
function distillationLoss(teacherProbs: number[], studentProbs: number[]): number {
  return teacherProbs.reduce((loss, tp, i) =>
    loss - tp * Math.log(studentProbs[i] + 1e-8), 0);
}`}
</CodeBlock>

Temperature is the key parameter. At temperature 1, the teacher's outputs are nearly one-hot (hard). At higher temperatures, the distribution softens, revealing relationships between classes that the student can learn from. It is like the difference between binary "used/unused" in tree-shaking versus the nuanced dependency graph that code splitting uses.

<DerivationDrawer summary="Distillation loss with temperature softmax">
**Knowledge distillation (KD)** trains a student model to match a teacher's soft predictions. The student loss combines two terms:

```
L = α · L_KD(student_soft, teacher_soft, T) + (1 − α) · L_CE(student_hard, true_labels)
```

**Softmax with temperature T:**

`p_i = exp(z_i / T) / Σ_j exp(z_j / T)`

- T = 1: standard softmax
- T > 1: "softer" distribution — probabilities pulled toward uniform, exposing the relative ordering of low-probability classes
- T → ∞: uniform

**Why high T?** The teacher's most informative signal isn't the top-1 prediction (that matches the label). It's the relative confidence on alternative classes — "this image is mostly cat (0.85), then small dog (0.10), then nothing else (0.05)" tells you the cat-dog boundary. With T=1 those low values round to noise. With T=4 they expand to meaningful signal.

**KD loss:**

`L_KD = T² · KL(softmax(z_student / T) || softmax(z_teacher / T))`

The T² factor compensates for the gradient scale change from temperature.
</DerivationDrawer>
