<Dialogue speaker="Hassan Al-Rashid">
We have a massive model that knows everything. We need a tiny model that knows just enough. Look at the weight distribution: 60% of the values are near zero. They are unused exports. Tree-shake them.
</Dialogue>

Webpack's tree-shaker reads your import statements and deletes whatever nothing references. Weight pruning applies the same principle to a neural network: weights near zero contribute almost nothing to the output, so out they go.

## Tree-Shaking for Neural Networks

<CodeBlock language="typescript" title="weight-pruning.ts">
{`// Magnitude-based pruning: zero out weights below threshold
function pruneWeights(weights: number[], sparsityTarget: number): {
  pruned: number[];
  sparsity: number;
  nonZeroCount: number;
} {
  // Sort by absolute value to find the threshold
  const sorted = weights.map(Math.abs).sort((a, b) => a - b);
  const cutoffIndex = Math.floor(sorted.length * sparsityTarget);
  const threshold = sorted[cutoffIndex];

  // Zero out weights below threshold (tree-shake them)
  const pruned = weights.map(w => Math.abs(w) < threshold ? 0 : w);

  const nonZeroCount = pruned.filter(w => w !== 0).length;
  const sparsity = 1 - (nonZeroCount / pruned.length);

  return { pruned, sparsity, nonZeroCount };
}

// Example: prune 60% of weights
const weights = [0.82, -0.01, 0.003, -0.91, 0.05, -0.002, 0.67, 0.008, -0.73, 0.001];
const result = pruneWeights(weights, 0.6);

console.log('Original weights:', weights.length);           // 10
console.log('Non-zero after pruning:', result.nonZeroCount); // 4
console.log('Sparsity:', (result.sparsity * 100).toFixed(0) + '%'); // 60%

// The large weights (0.82, -0.91, 0.67, -0.73) carry the signal
// The small weights (0.003, -0.002, 0.001) are noise, like unused imports`}
</CodeBlock>

Most trained networks are over-parameterized, which is why 60% of the weights can go without the predictions moving much. What magnitude alone cannot tell you is which surviving weights were compensating for the ones you just zeroed, so a production prune is followed by a few epochs of fine-tuning to let the rest re-absorb the work. Tree-shaking never needs that step: the exports it deletes were doing nothing at all.
