<Dialogue speaker="Hassan Al-Rashid">
The distillation process has two objectives. First, the student should match the teacher's predictions, learning the patterns. Second, the student should still be correct on the actual labels. Balance both.
</Dialogue>

Two objectives means two loss terms, and one number, alpha, decides which one wins. Push alpha toward 1 and the student inherits the teacher's judgment on the ambiguous readings, including the ones the teacher is confidently wrong about. The ground-truth term is the only check that catches those, and pushing alpha up is turning that check down. Pair programming fails the same way: a junior who has learned the mentor's habits has learned the mentor's bugs.

## The Combined Loss

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="teacher-student.ts">
{`import * as tf from '@tensorflow/tfjs';

// Combined distillation loss
function distillationLoss(
  studentLogits: number[],
  teacherLogits: number[],
  trueLabels: number[],
  temperature: number,
  alpha: number
): number {
  // Soft targets from teacher (high temperature)
  const teacherSoft = softmax(teacherLogits, temperature);
  const studentSoft = softmax(studentLogits, temperature);

  // Distillation loss: match teacher's soft distribution
  const distillLoss = teacherSoft.reduce((loss, tp, i) =>
    loss - tp * Math.log(studentSoft[i] + 1e-8), 0);

  // Task loss: match ground truth labels
  const studentHard = softmax(studentLogits, 1);
  const taskLoss = trueLabels.reduce((loss, label, i) =>
    loss - label * Math.log(studentHard[i] + 1e-8), 0);

  // Combined: alpha balances teacher knowledge vs ground truth
  // alpha = 0.7 → lean on teacher (pair programming mode)
  // alpha = 0.3 → lean on ground truth (independent work mode)
  return alpha * distillLoss * (temperature * temperature) + (1 - alpha) * taskLoss;
}

function softmax(logits: number[], temperature: number): number[] {
  const scaled = logits.map(l => l / temperature);
  const maxVal = Math.max(...scaled);
  const exps = scaled.map(s => Math.exp(s - maxVal));
  const sum = exps.reduce((a, b) => a + b, 0);
  return exps.map(e => e / sum);
}

// Teacher (200MB cloud model) output for a sensor reading
const teacherLogits = [4.5, 1.2, 0.3]; // confident: class 0 (normal)
// Student (40MB distilled model) output
const studentLogits = [2.1, 1.8, 0.9]; // less confident, learning
// Ground truth
const trueLabels = [1, 0, 0]; // class 0 is correct

const loss = distillationLoss(studentLogits, teacherLogits, trueLabels, 3.0, 0.7);
console.log(\`Combined loss: \${loss.toFixed(4)}\`);
// Student will be pushed toward teacher's output distribution`}
</CodeBlock>

The `temperature * temperature` scaling factor compensates for the softened gradients at high temperature. Without it, the distillation loss would be underweighted relative to the task loss. Alpha typically starts at 0.7 (trusting the teacher) and can be reduced as the student improves.

<DerivationDrawer summary="Why distillation works (information theory)">
**Hard labels carry less information than soft labels.** A hard label says "this is class 7." A soft distribution from a well-trained teacher says "this is class 7 (0.82), but it shares features with class 1 (0.10) and class 9 (0.05)."

**Information content:**
- Hard one-hot label: one class index per sample. Every sample of class 7 hands the student the identical target.
- Soft distribution: 999 extra numbers per sample on ImageNet, and they differ sample to sample. Two class-7 images with different backgrounds put their runner-up mass on different classes, so the gradient carries per-sample detail that a one-hot target cannot express.

**Implication:** the student can learn from far fewer samples when supervised by a teacher's soft labels, because each sample carries more information.

**Dark knowledge** (Hinton's term): the implicit similarity structure encoded in the soft labels ("cats look more like dogs than like cars") that hard labels destroy. Distillation transfers this structure.

**Limits:** distillation can't transfer skills the teacher doesn't have. If the teacher is wrong on a class, the student learns to be wrong the same way.
</DerivationDrawer>
