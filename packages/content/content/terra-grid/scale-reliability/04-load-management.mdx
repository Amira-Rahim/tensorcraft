<Dialogue speaker="Priya Sharma">
We can't process everything at peak load, so we prioritize. Gas leaks, electrical faults, structural anomalies: safety-critical predictions go first, always. Routine temperature monitoring can wait 500ms. The same way a web server handles health check endpoints before serving static assets under load.
</Dialogue>

During the Region 2 heat event last summer, request volume quadrupled in under an hour and the queue did what unmanaged queues do: served whatever arrived first. Routine temperature telemetry held its place in line while two gas-leak detections waited 480ms behind it. Nothing crashed, and that was the problem. The fix is rate limiting as you already know it (100 requests per minute per client, priority bypass for health checks), with the priorities made explicit: queue by priority, rate-limit by device, shed low-priority load before the critical path feels anything.

## Priority Queue

<CodeBlock language="typescript" title="load-manager.ts">
{`// Priority-based load management — like API rate limiting with priority lanes

type Priority = 'critical' | 'high' | 'normal' | 'low';

interface PredictionRequest {
  id: string;
  deviceId: string;
  priority: Priority;
  input: Float32Array;
  enqueuedAt: number;
}

class PriorityInferenceQueue {
  private queues: Map<Priority, PredictionRequest[]> = new Map([
    ['critical', []], ['high', []], ['normal', []], ['low', []],
  ]);
  private maxQueueSize: number;

  constructor(maxQueueSize: number = 1000) {
    this.maxQueueSize = maxQueueSize;
  }

  enqueue(request: PredictionRequest): boolean {
    const queue = this.queues.get(request.priority)!;
    // Load shedding: drop low-priority when queue is full
    if (this.totalSize() >= this.maxQueueSize) {
      if (request.priority === 'low') return false; // shed
      // Drop oldest low-priority to make room
      const lowQueue = this.queues.get('low')!;
      if (lowQueue.length > 0) {
        lowQueue.shift();
      } else {
        return false;
      }
    }
    queue.push(request);
    return true;
  }

  dequeue(): PredictionRequest | null {
    // Process highest priority first
    for (const priority of ['critical', 'high', 'normal', 'low'] as Priority[]) {
      const queue = this.queues.get(priority)!;
      if (queue.length > 0) return queue.shift()!;
    }
    return null;
  }

  totalSize(): number {
    let total = 0;
    this.queues.forEach(q => total += q.length);
    return total;
  }

  stats(): { priority: Priority; queued: number }[] {
    return [...this.queues.entries()].map(([p, q]) => ({
      priority: p, queued: q.length,
    }));
  }
}

// Token bucket rate limiter per device
class TokenBucket {
  private tokens: number;
  private lastRefill: number;

  constructor(
    private maxTokens: number,
    private refillRatePerSecond: number,
  ) {
    this.tokens = maxTokens;
    this.lastRefill = Date.now();
  }

  tryConsume(): boolean {
    this.refill();
    if (this.tokens > 0) {
      this.tokens--;
      return true;
    }
    return false;
  }

  private refill(): void {
    const now = Date.now();
    const elapsed = (now - this.lastRefill) / 1000;
    this.tokens = Math.min(
      this.maxTokens,
      this.tokens + elapsed * this.refillRatePerSecond
    );
    this.lastRefill = now;
  }
}

const queue = new PriorityInferenceQueue(500);
const rateLimiter = new TokenBucket(50, 10); // 50 burst, 10/sec refill

// Process incoming prediction request
if (rateLimiter.tryConsume()) {
  queue.enqueue({
    id: 'req-001', deviceId: 'device-7alpha',
    priority: 'critical', input: sensorData,
    enqueuedAt: Date.now(),
  });
}
console.log('Queue stats:', queue.stats());`}
