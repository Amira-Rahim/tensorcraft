Stress test: Device-3 offline. Shard-2 unavailable. 2,100 devices in Region 3 have lost access to the ensemble's second processing stage. Inference pipeline interrupted.
</Dialogue>

<Dialogue speaker="Hassan Al-Rashid">
This is the real test. Not whether the system works when everything is fine. Anyone can build that. The question is: when a component fails, does the system degrade gracefully or does it crash and take everything down with it?
</Dialogue>

You wrap an unreliable dependency in a circuit breaker: count the failures, and once they cross a threshold, stop calling it and serve the fallback until a probe says it is healthy again. Model failover borrows that controller, with one difference you cannot ignore: a broken dependency throws or times out, and the breaker hears it. A failing model often does neither. It keeps returning predictions, silently wrong, on schedule. So the failover controller cannot count exceptions alone. It watches health signals, and when it trips, it picks a fallback with its own correctness cost: a simpler model (worse but live), cached predictions (stale), or no prediction at all. Degraded accuracy beats no predictions, but only when you know you are degraded.

{`// Model failover: a circuit breaker whose dependency is a model
import * as tf from '@tensorflow/tfjs';

interface ModelEndpoint {
  name: string;
  predict: (input: tf.Tensor) => Promise<tf.Tensor>;
  healthCheck: () => Promise<boolean>;
}

type FailoverStatus = 'primary' | 'fallback' | 'degraded' | 'offline';

class FailoverController {
  private status: FailoverStatus = 'primary';
  private consecutiveFailures: number = 0;
  private maxFailures: number;

  constructor(
    private primary: ModelEndpoint,
    private fallback: ModelEndpoint,
    maxFailures: number = 3,
  ) {
    this.maxFailures = maxFailures;
  }

  async predict(input: tf.Tensor): Promise<{
    prediction: tf.Tensor;
    source: string;
    status: FailoverStatus;
  }> {
    // Try primary model first
    if (this.status === 'primary') {
      try {
        const prediction = await this.primary.predict(input);
        this.consecutiveFailures = 0;
        return { prediction, source: this.primary.name, status: 'primary' };
      } catch (error) {
        this.consecutiveFailures++;
        console.error(\`Primary model failed (\${this.consecutiveFailures}/\${this.maxFailures})\`);

        if (this.consecutiveFailures >= this.maxFailures) {
          this.status = 'fallback';
          console.warn('Switching to fallback model');
        }
      }
    }

    // Fallback model
    try {
      const prediction = await this.fallback.predict(input);
      return { prediction, source: this.fallback.name, status: 'fallback' };
    } catch (error) {
      this.status = 'offline';
      throw new Error('Both primary and fallback models unavailable');
    }
  }

  // Silent degradation never reaches a catch block, so probe health on a timer
  async probeHealth(): Promise<void> {
    if (this.status !== 'primary') return;
    const healthy = await this.primary.healthCheck();
    if (!healthy) {
      this.status = 'fallback';
      console.warn('Health probe failed, switching to fallback model');
    }
  }

  async tryRecovery(): Promise<boolean> {
    if (this.status !== 'fallback') return false;

    const healthy = await this.primary.healthCheck();
    if (healthy) {
      this.status = 'primary';
      this.consecutiveFailures = 0;
      console.log('Primary model recovered, switching back');
      return true;
    }
    return false;
  }

  getStatus(): { status: FailoverStatus; consecutiveFailures: number } {
    return { status: this.status, consecutiveFailures: this.consecutiveFailures };
  }
}

// Terra Grid failover configuration
const controller = new FailoverController(
  {
    name: 'ensemble-v3.1',
    predict: async (input) => ensembleModel.predict(input) as tf.Tensor,
    healthCheck: async () => { /* ping model endpoint */ return true; },
  },
  {
    name: 'lightweight-v2.0',
    predict: async (input) => lightModel.predict(input) as tf.Tensor,
    healthCheck: async () => true,
  },
  3 // switch after 3 consecutive failures
);

setInterval(() => controller.probeHealth(), 30_000);
const result = await controller.predict(sensorTensor);
console.log(\`Prediction from: \${result.source} (status: \${result.status})\`);`}
