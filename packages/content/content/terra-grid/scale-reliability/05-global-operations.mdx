<Dialogue speaker="Hassan Al-Rashid">
47 sites. 8 time zones. When I push a model update, Region 1 is running midday industrial operations and Region 7 is in overnight maintenance mode. We cannot treat them the same. Region-aware deployment or nothing.
</Dialogue>

<Dialogue speaker="Priya Sharma">
Same pattern as CDN multi-region deployment. Replicate models to regional edge nodes. Schedule updates during each region's maintenance window. Verify consistency after rollout. If any region fails to update, it keeps running the previous version until the next window.
</Dialogue>

Priya's CDN playbook is the right starting point and the wrong place to stop. A CDN replicates identical static bytes to every node; nothing about one PoP's cache depends on local law or local load. Models are different cargo. Data residency rules can mean a region's model is not allowed to leave that region. A freshly activated model answers slowly until it warms up. And an update that politely waits for every maintenance window is trading staleness for safety, which is a choice, not a default. The job is still replication across 47 sites and 8 time zones; the playbook needs three pages CDNs never wrote.

{`// Global model deployment — like CDN edge node management

interface Region {
  id: string;
  name: string;
  timeZoneOffset: number; // hours from UTC
  siteCount: number;
  deviceCount: number;
  currentModelVersion: string;
  maintenanceWindowUTC: { start: number; end: number }; // hours
}

interface DeploymentPlan {
  modelVersion: string;
  regions: { regionId: string; scheduledUTC: Date; status: string }[];
}

class GlobalCoordinator {
  private regions: Region[] = [];

  addRegion(region: Region): void {
    this.regions.push(region);
  }

  // Schedule deployment during each region's maintenance window
  createDeploymentPlan(newVersion: string): DeploymentPlan {
    const now = new Date();
    const plan: DeploymentPlan = { modelVersion: newVersion, regions: [] };

    for (const region of this.regions) {
      const scheduledTime = this.nextMaintenanceWindow(region, now);
      plan.regions.push({
        regionId: region.id,
        scheduledUTC: scheduledTime,
        status: 'scheduled',
      });
    }

    // Sort by scheduled time
    plan.regions.sort((a, b) => a.scheduledUTC.getTime() - b.scheduledUTC.getTime());
    return plan;
  }

  private nextMaintenanceWindow(region: Region, after: Date): Date {
    const result = new Date(after);
    result.setUTCHours(region.maintenanceWindowUTC.start, 0, 0, 0);
    if (result <= after) {
      result.setUTCDate(result.getUTCDate() + 1);
    }
    return result;
  }

  // Check version consistency across all regions
  checkConsistency(): {
    consistent: boolean;
    versions: Map<string, string[]>;
  } {
    const versions = new Map<string, string[]>();
    for (const region of this.regions) {
      const regions = versions.get(region.currentModelVersion) || [];
      regions.push(region.id);
      versions.set(region.currentModelVersion, regions);
    }
    return {
      consistent: versions.size === 1,
      versions,
    };
  }

  getStatus(): { regionId: string; version: string; devices: number }[] {
    return this.regions.map(r => ({
      regionId: r.id,
      version: r.currentModelVersion,
      devices: r.deviceCount,
    }));
  }
}

// Terra Grid global deployment
const coordinator = new GlobalCoordinator();
coordinator.addRegion({
  id: 'region-1', name: 'North America East',
  timeZoneOffset: -5, siteCount: 12, deviceCount: 3200,
  currentModelVersion: '3.0',
  maintenanceWindowUTC: { start: 6, end: 8 }, // 1-3 AM local
});
coordinator.addRegion({
  id: 'region-3', name: 'Central Europe',
  timeZoneOffset: 1, siteCount: 8, deviceCount: 2100,
  currentModelVersion: '3.0',
  maintenanceWindowUTC: { start: 2, end: 4 }, // 3-5 AM local
});
coordinator.addRegion({
  id: 'region-7', name: 'East Asia',
  timeZoneOffset: 9, siteCount: 15, deviceCount: 4200,
  currentModelVersion: '3.0',
  maintenanceWindowUTC: { start: 18, end: 20 }, // 3-5 AM local
});

const plan = coordinator.createDeploymentPlan('3.1');
console.log('Deployment schedule:');
plan.regions.forEach(r =>
  console.log(\`  \${r.regionId}: \${r.scheduledUTC.toISOString()}\`)
);`}
