## Saving State, Saving Models

<BridgeCallout bridge={frontmatter.concept.bridge} />

As a frontend engineer, you save application state constantly: to localStorage, to IndexedDB, to a server. Model export is the same pattern. The model's "state" is its architecture (layers, shapes, activations) plus its weights (the learned numbers). TensorFlow.js splits these into a JSON topology file and one or more binary weight shards.

<CodeBlock language="typescript" title="model-export.ts">
{`import * as tf from '@tensorflow/tfjs';

// Assume 'model' is your trained Protocol Sentinel model

// Save to browser localStorage
await model.save('localstorage://protocol-sentinel');

// Save to IndexedDB (better for large models)
await model.save('indexeddb://protocol-sentinel');

// Trigger a file download (model.json + .bin weight shards)
await model.save('downloads://protocol-sentinel');

// Save to an HTTP endpoint (POST request)
await model.save('http://safehouse-api.neon-city.net/models');

// Check what has been saved locally
const savedModels = await tf.io.listModels();
console.log(savedModels);
// {
//   'localstorage://protocol-sentinel': { dateSaved, modelTopologyBytes, weightSpecsBytes, weightDataBytes },
//   'indexeddb://protocol-sentinel': { ... }
// }`}
</CodeBlock>

## Understanding the Export Format

When you export a TensorFlow.js model, you get two pieces:

- **model.json**: The architecture topology (layer types, shapes, activation functions) plus a manifest listing weight shard files
- **group1-shard1of1.bin**: The actual weight data as a binary ArrayBuffer, split into shards for large models

<CodeBlock language="typescript" title="model-topology.ts">
{`// The model.json structure (simplified)
const topology = {
  modelTopology: {
    class_name: "Sequential",
    config: {
      layers: [
        { class_name: "Conv2D", config: { filters: 32, kernel_size: [3, 3] } },
        { class_name: "MaxPooling2D", config: { pool_size: [2, 2] } },
        { class_name: "Dense", config: { units: 128, activation: "relu" } },
        { class_name: "Dense", config: { units: 5, activation: "softmax" } }
      ]
    }
  },
  weightsManifest: [{
    paths: ["group1-shard1of1.bin"],
    weights: [
      { name: "conv2d/kernel", shape: [3, 3, 3, 32], dtype: "float32" },
      { name: "conv2d/bias", shape: [32], dtype: "float32" }
    ]
  }]
};

// Loading from hosted files
const model = await tf.loadLayersModel('/models/sentinel/model.json');

// Verify the loaded model works
const testInput = tf.randomNormal([1, 224, 224, 3]);
const prediction = model.predict(testInput) as tf.Tensor;
console.log('Output shape:', prediction.shape); // [1, 5]
prediction.print();`}
</CodeBlock>

## Verifying Export Integrity

Never deploy without verifying. A corrupted export means silent failures in the field.

<CodeBlock language="typescript" title="verify-export.ts">
{`async function verifyModelExport(
  original: tf.LayersModel,
  savedPath: string
): Promise<boolean> {
  // Load the exported model
  const loaded = await tf.loadLayersModel(savedPath);

  // Create identical test input
  const testInput = tf.randomNormal([1, 224, 224, 3]);

  // Run both models
  const originalOutput = original.predict(testInput) as tf.Tensor;
  const loadedOutput = loaded.predict(testInput) as tf.Tensor;

  // Compare outputs
  const originalData = await originalOutput.data();
  const loadedData = await loadedOutput.data();

  const isIdentical = originalData.every(
    (val, i) => Math.abs(val - loadedData[i]) < 1e-6
  );

  // Clean up
  testInput.dispose();
  originalOutput.dispose();
  loadedOutput.dispose();

  console.log(isIdentical ? 'Export verified.' : 'MISMATCH DETECTED.');
  return isIdentical;
}

await verifyModelExport(model, 'indexeddb://protocol-sentinel');`}
</CodeBlock>
