<Dialogue speaker="Dilan">
Protocol Sentinel is not a weapon. It is a tool. And a tool without documentation is a liability. When we distribute this to 200 cells, every operator needs to understand what this system can do, what it cannot do, and when it will fail. Write it all down.
</Dialogue>

<Dialogue speaker="Noor">
I've written hundreds of README files. Package documentation, API references, component storybooks. A model card is the same thing: introduction, usage, API, limitations, contributing guidelines. Just with different section headers.
</Dialogue>

<Dialogue speaker="NEON">
Meridian never documented my limitations. They deployed me to track 14 million people without a single line about my 23% false positive rate on dark-skinned faces. Documentation is not just courtesy. It is accountability.
</Dialogue>

Every open-source package you have used has a README. Every API you have integrated has documentation. Model cards serve the same purpose for ML systems. They tell the next developer (or operator, or resistance cell) what the model does, how it performs, where it fails, and when it should not be trusted. The format is standardized. If you can write a good README, you can write a good model card.

## Pipeline API Documentation

<CodeBlock language="typescript" title="api-docs.ts">
{`// API documentation, same structure as REST API docs
interface PipelineAPIDoc {
  endpoint: string;
  description: string;
  input: {
    type: string;
    shape?: string;
    required: boolean;
    description: string;
  }[];
  output: {
    type: string;
    shape?: string;
    description: string;
  };
  errors: {
    code: string;
    description: string;
    resolution: string;
  }[];
  example: string;
}

const preprocessorDoc: PipelineAPIDoc = {
  endpoint: 'preprocessor.process()',
  description: 'Resizes and normalizes a raw camera frame for model inference',
  input: [
    {
      type: 'tf.Tensor3D',
      shape: '[height, width, 3]',
      required: true,
      description: 'Raw RGB frame from camera feed. Any resolution.',
    },
  ],
  output: {
    type: 'tf.Tensor4D',
    shape: '[1, 224, 224, 3]',
    description: 'Batched, resized, normalized frame. Values in [0, 1].',
  },
  errors: [
    {
      code: 'INVALID_RANK',
      description: 'Input tensor is not rank 3',
      resolution: 'Ensure input is [height, width, channels], not batched',
    },
    {
      code: 'INVALID_CHANNELS',
      description: 'Input has channels != 1 or 3',
      resolution: 'Convert to RGB (3 channels) or grayscale (1 channel)',
    },
  ],
  example: \`const frame = tf.browser.fromPixels(canvas);
const processed = await preprocessor.process(frame);
// processed.shape === [1, 224, 224, 3]\`,
};

// Generate markdown from structured docs
function generateMarkdown(doc: PipelineAPIDoc): string {
  let md = \`## \${doc.endpoint}\\n\\n\`;
  md += \`\${doc.description}\\n\\n\`;
  md += \`### Input\\n\\n\`;
  for (const input of doc.input) {
    md += \`- **\${input.type}** \${input.shape || ''} \`;
    md += \`(\${input.required ? 'required' : 'optional'}): \${input.description}\\n\`;
  }
  md += \`\\n### Output\\n\\n\`;
  md += \`- **\${doc.output.type}** \${doc.output.shape || ''}: \${doc.output.description}\\n\`;
  md += \`\\n### Errors\\n\\n\`;
  for (const error of doc.errors) {
    md += \`- **\${error.code}**: \${error.description}. Fix: \${error.resolution}\\n\`;
  }
  md += \`\\n### Example\\n\\n\\\`\\\`\\\`typescript\\n\${doc.example}\\n\\\`\\\`\\\`\\n\`;
  return md;
}`}
</CodeBlock>
