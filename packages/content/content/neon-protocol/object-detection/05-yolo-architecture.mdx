YOLO does object detection in a **single forward pass**: one network reads the whole image and predicts all the boxes, labels, and confidence scores at once, with no separate region-proposal stage.

## YOLO Grid Output

YOLO divides the image into an S x S grid. Each cell predicts B bounding boxes with confidence scores and C class probabilities.

<CodeBlock language="typescript" title="yolo-grid.ts">
{`// YOLO output structure:
// Grid: S x S cells (e.g., 7x7 = 49 cells)
// Per cell: B anchor boxes (e.g., 3 anchors)
// Per anchor: [tx, ty, tw, th, confidence, ...classProbs]
//             4 coords + 1 conf + numClasses values

interface YOLOConfig {
  gridSize: number;     // S: grid divisions (7, 13, 26, 52)
  numAnchors: number;   // B: anchors per cell
  numClasses: number;   // C: object categories
  anchors: Array<[number, number]>; // pre-defined anchor dimensions
}

const config: YOLOConfig = {
  gridSize: 13,
  numAnchors: 3,
  numClasses: 4, // drone, person, vehicle, camera
  anchors: [[0.1, 0.15], [0.25, 0.35], [0.5, 0.6]],
};

// Output tensor shape:
// [gridSize, gridSize, numAnchors * (5 + numClasses)]
// [13, 13, 3 * (5 + 4)] = [13, 13, 27]
// Total predictions: 13 * 13 * 3 = 507 candidate boxes

const outputSize = config.gridSize * config.gridSize * config.numAnchors;
console.log('Total candidate boxes:', outputSize); // 507`}
</CodeBlock>

## Decoding YOLO Output

The raw output tensor needs to be decoded into usable bounding boxes. This is like parsing a serialized data structure into usable objects.

<CodeBlock language="typescript" title="decode-yolo.ts">
{`interface DecodedDetection {
  box: number[];       // [xmin, ymin, xmax, ymax]
  confidence: number;
  classId: number;
  classScore: number;
}

function sigmoid(x: number): number {
  return 1 / (1 + Math.exp(-x));
}

function decodeYOLOOutput(
  output: number[][][],  // [gridSize][gridSize][anchorData]
  config: YOLOConfig
): DecodedDetection[] {
  const detections: DecodedDetection[] = [];
  const valuesPerAnchor = 5 + config.numClasses;

  for (let row = 0; row < config.gridSize; row++) {
    for (let col = 0; col < config.gridSize; col++) {
      for (let a = 0; a < config.numAnchors; a++) {
        const offset = a * valuesPerAnchor;
        const cell = output[row][col];

        // Decode box coordinates
        const tx = sigmoid(cell[offset]);
        const ty = sigmoid(cell[offset + 1]);
        const tw = cell[offset + 2];
        const th = cell[offset + 3];
        const conf = sigmoid(cell[offset + 4]);

        // Convert grid-relative coords to image-relative
        const cx = (col + tx) / config.gridSize;
        const cy = (row + ty) / config.gridSize;
        const w = config.anchors[a][0] * Math.exp(tw);
        const h = config.anchors[a][1] * Math.exp(th);

        // Decode class probabilities
        const classScores: number[] = [];
        for (let c = 0; c < config.numClasses; c++) {
          classScores.push(sigmoid(cell[offset + 5 + c]));
        }
        const classId = classScores.indexOf(Math.max(...classScores));
        const classScore = classScores[classId];

        // Final confidence = objectness * class probability
        const finalConf = conf * classScore;

        if (finalConf > 0.25) { // confidence threshold
          detections.push({
            box: [cx - w/2, cy - h/2, cx + w/2, cy + h/2],
            confidence: finalConf,
            classId,
            classScore,
          });
        }
      }
    }
  }

  return detections;
}`}
</CodeBlock>

## The Full Pipeline

Detection is a pipeline: predict, decode, filter, NMS. Each step is a familiar pattern.

<CodeBlock language="typescript" title="detection-pipeline.ts">
{`// The complete detection pipeline: all concepts from this module combined

function detectObjects(
  imageData: number[][][],  // preprocessed image tensor
  config: YOLOConfig
): DecodedDetection[] {
  // Step 1: Forward pass (single-shot: one pass, all predictions)
  // Like requestAnimationFrame: batch everything into one call
  const rawOutput = model.predict(imageData);

  // Step 2: Decode raw output into bounding boxes
  // Like JSON.parse(), converting wire format to usable objects
  const decoded = decodeYOLOOutput(rawOutput, config);

  // Step 3: Confidence threshold (filter low-quality detections)
  // Like filtering events by relevance
  const confident = decoded.filter(d => d.confidence > 0.5);

  // Step 4: Non-Max Suppression (remove duplicates)
  // Like debounce(): keep the best, suppress redundant
  const final = nms(confident, 0.5);

  return final;
}

// Performance comparison:
// Two-stage (Faster R-CNN): ~5 FPS  (too slow for real-time)
// YOLO v5:                  ~30 FPS (real-time on GPU)
// YOLO in browser (WebGL):  ~15 FPS (good enough to see drones first)
// YOLO in browser (WebGPU): ~24 FPS (the resistance's advantage)

// The resistance's edge: Meridian never expects detection
// running from a browser tab, with no server or API to trace.
// Just JavaScript, WebGL, and a model small enough to fit
// in a service worker cache.`}
</CodeBlock>
