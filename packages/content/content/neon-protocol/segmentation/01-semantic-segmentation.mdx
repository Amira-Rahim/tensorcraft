<Dialogue speaker="Zara">
A bounding box tells you "there is a drone here." But it cannot tell you the shape of the drone against the sky, or where the road meets the wall behind it. Semantic segmentation classifies every single pixel. It is the difference between pointing at a crowd and tracing every silhouette.
</Dialogue>

<Dialogue speaker="Noor">
So instead of outputting a rectangle, the model outputs a full-resolution map where every pixel is labeled?
</Dialogue>

Yes. That map is called a **segmentation mask**: a tensor with the same height and width as the input, where each value is a class label. One label per pixel, no rectangles anywhere.

## From Boxes to Pixels

<BridgeCallout bridge={frontmatter.concept.bridge} />

Detection was `find`: sweep the frame, come back with a handful of boxes. Segmentation is `map`: every pixel that goes in gets a value out, and the result has the same height and width as the input. One difference matters before the code. The callback you hand to `map` sees one element and returns a settled answer. The model labels a pixel from what surrounds it, and it can be wrong about any one of them.

<CodeBlock language="typescript" title="semantic-segmentation.ts">
{`import * as tf from '@tensorflow/tfjs';

// Segmentation model output: [1, height, width, numClasses]
// Each pixel gets one raw score (a logit) per class
const NUM_CLASSES = 6;
const CLASSES = ['background', 'road', 'building', 'person', 'drone', 'vehicle'];

// Simulate a model prediction for a 224x224 image
// In practice: const prediction = model.predict(inputTensor);
const prediction = tf.randomNormal([1, 224, 224, NUM_CLASSES]);

// argMax picks the winning class per pixel. Softmax is monotonic,
// so the argMax of the logits equals the argMax of the probabilities:
// you only need softmax when you want a confidence number back
const mask = tf.argMax(prediction.squeeze(), -1);
console.log(mask.shape); // [224, 224], one class index per pixel

// Same contract as map(): one entry out for every entry in,
// except the entry is a pixel and the value is a class index`}
</CodeBlock>

## Visualizing Masks

To render the segmentation mask, map each class index to a color and draw it as a semi-transparent overlay.

<CodeBlock language="typescript" title="mask-visualization.ts">
{`// Color palette for each class
const COLORS: Record<string, [number, number, number]> = {
  background: [0, 0, 0],
  road: [0, 100, 255],
  building: [0, 200, 100],
  person: [255, 50, 50],
  drone: [255, 165, 0],
  vehicle: [200, 200, 0],
};

function renderMask(mask: tf.Tensor2D, canvas: HTMLCanvasElement): void {
  const [h, w] = mask.shape;
  canvas.width = w;
  canvas.height = h;
  const ctx = canvas.getContext('2d')!;
  const imageData = ctx.createImageData(w, h);

  const data = mask.dataSync();
  for (let i = 0; i < data.length; i++) {
    const classIdx = data[i];
    const color = COLORS[CLASSES[classIdx]] || [0, 0, 0];
    imageData.data[i * 4] = color[0];
    imageData.data[i * 4 + 1] = color[1];
    imageData.data[i * 4 + 2] = color[2];
    imageData.data[i * 4 + 3] = 180; // semi-transparent overlay
  }
  ctx.putImageData(imageData, 0, 0);
}

// Stack this canvas over the video element in CSS to get the overlay.
// putImageData writes straight into the bitmap and ignores globalAlpha
// and compositing, so calling it on the feed canvas would erase the frame`}
</CodeBlock>

## Challenge

Build a function that converts raw segmentation logits (the per-class scores the model outputs before softmax) into a class-index mask.

<Exercise slug="semantic-segmentation" />

<DerivationDrawer summary="Pixel-wise softmax + class-balanced cross-entropy">
**Semantic segmentation output:** per-pixel class predictions. For input [H, W, 3], output is [H, W, num_classes] logits → softmax along channel axis → argmax = predicted class per pixel.

**Loss function**: per-pixel cross-entropy summed over the image:

`L = − Σ_{h, w} log(softmax(logits[h, w])[true_class[h, w]])`

**Class imbalance problem:** in many datasets, one class (background, road) covers 90%+ of pixels. A model can score high accuracy by predicting background everywhere.

**Class-balanced cross-entropy:**

`L = − Σ_{h, w} w_{class} · log(softmax(logits[h, w])[true_class[h, w]])`

Where `w_class = 1 / sqrt(class_pixel_count)` or `1 / class_frequency`.

**Focal loss** (for extreme imbalance):

`L = − (1 − p_true)^γ · log(p_true)`

Where γ ≥ 1 (typical 2). Down-weights easy examples (high p_true) → focuses gradient on hard examples. Standard in object detection (RetinaNet) and applies to segmentation too.
</DerivationDrawer>
