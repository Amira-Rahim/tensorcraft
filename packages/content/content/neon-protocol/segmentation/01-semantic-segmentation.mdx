<Dialogue speaker="Zara">
A bounding box tells you "there is a drone here." But it cannot tell you the shape of the drone against the sky, or where the road meets the wall behind it. Semantic segmentation classifies every single pixel. It is the difference between pointing at a crowd and tracing every silhouette.
</Dialogue>

<Dialogue speaker="Noor">
So instead of outputting a rectangle, the model outputs a full-resolution map where every pixel is labeled?
</Dialogue>

That is exactly right. In CSS, you use `clip-path` to define complex regions that determine which parts of an element are visible. Semantic segmentation does the same thing for an image — it partitions every pixel into a named region. The output is a **segmentation mask**: a tensor with the same height and width as the input, where each value is a class label.

## From Boxes to Pixels

<BridgeCallout bridge={frontmatter.concept.bridge} />

With `clip-path`, you define polygon regions that carve out visible areas of an element. A segmentation model does this for every object category in the image — roads, buildings, people, sky — producing a dense map of non-overlapping regions.

<CodeBlock language="typescript" title="semantic-segmentation.ts">
{`import * as tf from '@tensorflow/tfjs';

// Segmentation model output: [1, height, width, numClasses]
// Each pixel gets a probability distribution over classes
const NUM_CLASSES = 6;
const CLASSES = ['background', 'road', 'building', 'person', 'drone', 'vehicle'];

// Simulate a model prediction for a 224x224 image
// In practice: const prediction = model.predict(inputTensor);
const prediction = tf.randomNormal([1, 224, 224, NUM_CLASSES]);

// Convert probabilities to class labels using argMax
// This picks the highest-probability class for each pixel
const mask = tf.argMax(prediction.squeeze(), -1);
console.log(mask.shape); // [224, 224] — one class index per pixel

// This is like applying a different clip-path region
// for every object category in the scene`}
</CodeBlock>

## Visualizing Masks

To render the segmentation mask, map each class index to a color — exactly like applying a color-coded `clip-path` overlay.

<CodeBlock language="typescript" title="mask-visualization.ts">
{`// Color palette for each class
const COLORS: Record<string, [number, number, number]> = {
  background: [0, 0, 0],
  road: [0, 100, 255],
  building: [0, 200, 100],
  person: [255, 50, 50],
  drone: [255, 165, 0],
  vehicle: [200, 200, 0],
};

function renderMask(mask: tf.Tensor2D, canvas: HTMLCanvasElement): void {
  const [h, w] = mask.shape;
  canvas.width = w;
  canvas.height = h;
  const ctx = canvas.getContext('2d')!;
  const imageData = ctx.createImageData(w, h);

  const data = mask.dataSync();
  for (let i = 0; i < data.length; i++) {
    const classIdx = data[i];
    const color = COLORS[CLASSES[classIdx]] || [0, 0, 0];
    imageData.data[i * 4] = color[0];
    imageData.data[i * 4 + 1] = color[1];
    imageData.data[i * 4 + 2] = color[2];
    imageData.data[i * 4 + 3] = 180; // semi-transparent overlay
  }
  ctx.putImageData(imageData, 0, 0);
}

// Overlay onto the original feed — the resistance can now
// see District 7 parsed into meaningful regions`}
</CodeBlock>
