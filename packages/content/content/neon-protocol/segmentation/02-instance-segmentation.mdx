<Dialogue speaker="Zara">
Semantic segmentation says "these pixels are people." Instance segmentation says "these pixels are person one, those are person two, and that cluster in the back is person three." It is the difference between `document.querySelectorAll('.person')` and selecting each element by its unique ID.
</Dialogue>

<Dialogue speaker="Noor">
So semantic segmentation is `.className` and instance segmentation is `#elementId`?
</Dialogue>

Exactly. In the DOM, elements with the same class share a category but remain distinct nodes. Instance segmentation does the same for pixels: every object gets its own mask, even when multiple objects share the same class label.

## Class vs Instance

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="instance-segmentation.ts">
{`import * as tf from '@tensorflow/tfjs';

// Semantic: all people = class 3
// semanticMask[y][x] = 3 means "this pixel is a person"

// Instance: each person gets a unique mask
interface InstanceMask {
  classId: number;
  className: string;
  instanceId: number;
  mask: tf.Tensor2D;    // binary mask: 1 = this instance, 0 = not
  confidence: number;
  bbox: [number, number, number, number]; // [x, y, w, h]
}

// A scene with 3 people and 2 drones = 5 instance masks
const instances: InstanceMask[] = [
  {
    classId: 3, className: 'person', instanceId: 1,
    mask: tf.zeros([224, 224]),  // binary mask for person 1
    confidence: 0.95, bbox: [0.1, 0.2, 0.15, 0.4],
  },
  {
    classId: 3, className: 'person', instanceId: 2,
    mask: tf.zeros([224, 224]),  // binary mask for person 2
    confidence: 0.91, bbox: [0.4, 0.25, 0.12, 0.35],
  },
  {
    classId: 4, className: 'drone', instanceId: 3,
    mask: tf.zeros([224, 224]),  // binary mask for drone 1
    confidence: 0.88, bbox: [0.7, 0.05, 0.1, 0.08],
  },
];`}
</CodeBlock>

## Building Instance Maps

Combine individual binary masks into a single labeled image where each pixel's value is its instance ID.

<CodeBlock language="typescript" title="instance-map.ts">
{`function buildInstanceMap(
  instances: InstanceMask[],
  height: number,
  width: number
): tf.Tensor2D {
  // Start with zeros (background)
  let instanceMap = tf.zeros([height, width]);

  instances.forEach((inst) => {
    // Where this instance's mask is 1, write the instance ID
    // mask is binary: 1 = this object, 0 = not
    const idTensor = inst.mask.mul(inst.instanceId);
    // Where mask is 0, keep existing value; where 1, write ID
    const keepExisting = instanceMap.mul(
      tf.scalar(1).sub(inst.mask)
    );
    instanceMap = keepExisting.add(idTensor);
  });

  return instanceMap as tf.Tensor2D;
}

// Like building a z-index stack in CSS:
// each element occupies its own layer, and the final composite
// shows which element "owns" each pixel

// Render with unique colors per instance
function instanceColor(id: number): [number, number, number] {
  const hue = (id * 137.508) % 360; // golden angle for spread
  return hslToRgb(hue, 80, 60);
}`}
</CodeBlock>
