<Dialogue speaker="Zara">
The encoder is the descent: convolutions and pooling that compress a 224-by-224 image down to a 28-by-28 feature map. Rich in meaning, poor in spatial detail. The decoder is the ascent: transposed convolutions that expand back to full resolution. But without skip connections, the decoded output loses fine edges. That is why the U shape matters.
</Dialogue>

<Dialogue speaker="Noor">
So the decoder gets the original detail handed to it directly? Like passing a prop straight to a deeply nested child instead of making it re-derive the value from compressed context?
</Dialogue>

That is the move. The U-Net is the workhorse of segmentation, and its encoder behaves like compressed context: each level summarizes harder and throws spatial detail away. A skip connection takes the full-resolution feature map from an encoder level and concatenates it onto the decoder level at the matching resolution. Nothing is inherited and nothing is re-derived; the detail arrives as extra channels, sitting beside the abstract features the decoder built up from the bottleneck.

## The U Shape

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="unet-architecture.ts">
{`import * as tf from '@tensorflow/tfjs';

function encoderBlock(input: tf.SymbolicTensor, filters: number) {
  let x = tf.layers.conv2d({
    filters, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(input) as tf.SymbolicTensor;
  x = tf.layers.conv2d({
    filters, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(x) as tf.SymbolicTensor;
  const pooled = tf.layers.maxPooling2d({
    poolSize: 2
  }).apply(x) as tf.SymbolicTensor;
  return { skip: x, downsampled: pooled };
}

function decoderBlock(
  input: tf.SymbolicTensor,
  skip: tf.SymbolicTensor,
  filters: number
) {
  let x = tf.layers.conv2dTranspose({
    filters, kernelSize: 2, strides: 2, padding: 'same'
  }).apply(input) as tf.SymbolicTensor;
  // Skip connection: concatenate encoder features
  x = tf.layers.concatenate().apply([x, skip]) as tf.SymbolicTensor;
  x = tf.layers.conv2d({
    filters, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(x) as tf.SymbolicTensor;
  return x;
}`}
</CodeBlock>

## Assembling the Network

<CodeBlock language="typescript" title="build-unet.ts">
{`function buildUNet(inputShape: [number, number, number], numClasses: number) {
  const input = tf.input({ shape: inputShape });

  // Encoder (descending path)
  const enc1 = encoderBlock(input, 32);   // 224 -> 112
  const enc2 = encoderBlock(enc1.downsampled, 64);  // 112 -> 56
  const enc3 = encoderBlock(enc2.downsampled, 128); // 56  -> 28

  // Bottleneck: same padding and no pooling, so it stays 28x28
  let bottleneck = tf.layers.conv2d({
    filters: 256, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(enc3.downsampled) as tf.SymbolicTensor;

  // Decoder (ascending path) with skip connections
  const dec3 = decoderBlock(bottleneck, enc3.skip, 128); // 28 -> 56
  const dec2 = decoderBlock(dec3, enc2.skip, 64);        // 56 -> 112
  const dec1 = decoderBlock(dec2, enc1.skip, 32);        // 112 -> 224

  // Final 1x1 convolution: one score per class per pixel
  const output = tf.layers.conv2d({
    filters: numClasses, kernelSize: 1, activation: 'softmax'
  }).apply(dec1) as tf.SymbolicTensor;

  return tf.model({ inputs: input, outputs: output });
}

const model = buildUNet([224, 224, 3], 6);
model.summary(); // Output shape: [null, 224, 224, 6]`}
</CodeBlock>

<DerivationDrawer summary="U-Net detailed architecture: skip connections math">
**U-Net structure:**

```
Input [224, 224, 3]
  Conv block 1 -> [224, 224, 32] ---------------------+   (skip 1)
    MaxPool -> [112, 112, 32]                         |
      Conv block 2 -> [112, 112, 64] ---------------+ |   (skip 2)
        MaxPool -> [56, 56, 64]                     | |
          Conv block 3 -> [56, 56, 128] ---------+  | |   (skip 3)
            MaxPool -> [28, 28, 128]             |  | |
              Bottleneck -> [28, 28, 256]        |  | |
            ConvTranspose -> [56, 56, 128]       |  | |
          Concat with skip 3 -> [56, 56, 256] <--+  | |
          Conv -> [56, 56, 128]                     | |
        ConvTranspose -> [112, 112, 64]             | |
      Concat with skip 2 -> [112, 112, 128] <-------+ |
      Conv -> [112, 112, 64]                          |
    ConvTranspose -> [224, 224, 32]                   |
  Concat with skip 1 -> [224, 224, 64] <--------------+
  Conv -> [224, 224, 32]
  Conv 1x1 -> [224, 224, num_classes]
```

**Why skip connections matter:** the bottleneck loses spatial detail (28×28 from 224×224). The decoder upsamples back, but without skips it would have to invent fine details from coarse features. Skips concatenate the original high-resolution features at each upsample stage, restoring boundary detail.

**Concatenation channel math:** decoder layer at resolution R has `C_decoder` channels. The corresponding encoder layer has `C_encoder` channels. After concatenation: `C_decoder + C_encoder`. Then a conv layer reduces back to `C_decoder` for the next upsample stage.

**Variants:** U-Net++ adds dense skip connections, ResUNet adds residual blocks within each conv block, Attention U-Net adds gating at skip connections to filter noisy features.
</DerivationDrawer>
