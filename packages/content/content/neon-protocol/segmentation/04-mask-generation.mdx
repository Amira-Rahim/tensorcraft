The model gives you probabilities: 0.87 chance this pixel is a drone, 0.12 chance it is sky. You need to turn that into a clean yes-or-no mask. It is the same workflow as building an SVG mask: define the shape, refine the edges, apply it as a cutout.
</Dialogue>

<Dialogue speaker="Noor">
My drawing app had a magic-wand selection tool. Same shape: pick a tolerance, walk the pixel buffer, write 1 into a `Uint8ClampedArray` where the pixel is inside the selection and 0 where it is not. Nobody ever agreed on one tolerance, so I shipped a slider.
</Dialogue>

That slider is the part to keep. In SVG a `<mask>` reveals wherever the mask is white and hides wherever it is black, and thresholding lands in the same two states: above the cutoff becomes 1 (object), below becomes 0 (background). The difference is who draws the edge. You place an SVG path exactly where you want it. Here the edge falls wherever 0.5 happens to land on a noisy probability map, which is why the threshold is a knob and not a constant. At 0.4 the drone grows a halo of sky. At 0.6 its rotor arms disappear.

## From Probabilities to Masks

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="mask-thresholding.ts">
{`import * as tf from '@tensorflow/tfjs';

// Model outputs per-class probabilities: [H, W, numClasses]
// Extract the drone class (index 4) probability map
const classProbabilities = tf.randomUniform([224, 224, 6]);
const droneProbMap = classProbabilities.slice([0, 0, 4], [-1, -1, 1]).squeeze();
// droneProbMap shape: [224, 224], values 0.0 to 1.0

// Threshold: probability > 0.5 becomes 1, else 0
const THRESHOLD = 0.5;
const binaryMask = droneProbMap.greater(THRESHOLD).cast('float32');
console.log(binaryMask.shape); // [224, 224]

// Like an SVG mask:
// <mask><rect fill="white" where="prob > 0.5" /></mask>
// White (1) = object present, Black (0) = background`}
</CodeBlock>

## Cleaning Masks with Morphological Operations

Raw masks often have noise: small holes and stray pixels. Morphological operations clean them up, just like smoothing SVG paths.

<CodeBlock language="typescript" title="mask-cleanup.ts">
{`// Erosion: shrink the mask to remove small noise
// Dilation: expand the mask to fill small holes
// Opening (erode then dilate): removes noise
// Closing (dilate then erode): fills holes

function morphologicalOp(
  mask: tf.Tensor2D,
  kernelSize: number,
  operation: 'erode' | 'dilate'
): tf.Tensor2D {
  // Use a conv2d with an all-ones kernel
  const kernel = tf.ones([kernelSize, kernelSize, 1, 1]);
  const expanded = mask.expandDims(0).expandDims(-1) as tf.Tensor4D;
  const total = kernelSize * kernelSize;

  const convolved = tf.conv2d(expanded, kernel, 1, 'same');

  if (operation === 'erode') {
    // All neighbors must be 1; pixel stays only if fully surrounded
    return convolved.squeeze().greaterEqual(total).cast('float32') as tf.Tensor2D;
  } else {
    // Any neighbor is 1; pixel activates if any neighbor is present
    return convolved.squeeze().greater(0).cast('float32') as tf.Tensor2D;
  }
}

// Clean up: opening removes specks, closing fills gaps
function cleanMask(mask: tf.Tensor2D): tf.Tensor2D {
  const eroded = morphologicalOp(mask, 3, 'erode');
  const opened = morphologicalOp(eroded, 3, 'dilate');
  const dilated = morphologicalOp(opened, 3, 'dilate');
  return morphologicalOp(dilated, 3, 'erode');
}`}
</CodeBlock>
