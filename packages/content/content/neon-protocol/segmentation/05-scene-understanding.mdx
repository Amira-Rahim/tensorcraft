WAR ROOM - DISTRICT 7 COMPOSITE. On the holotable the district renders as regions instead of video: roads in blue, rooftops in green, four red silhouettes moving along Carmine Street, one orange drone hanging above the transit hub. Every pixel in the frame carries a label now. The question has changed, from what is in the frame to what the frame is doing.

<Dialogue speaker="Dilan">
A segmentation mask tells you what each pixel is. Scene understanding tells you what it means. If a person is on a road next to a crosswalk, that is a pedestrian crossing. If a drone is above a building, that is a surveillance post. Context comes from relationships.
</Dialogue>

<Dialogue speaker="Noor">
It is like semantic HTML. A `<nav>` element inside a `<header>` means something different than a `<nav>` inside a `<footer>`. The tag alone is not enough; position and context define the meaning.
</Dialogue>

Semantic HTML gives meaning to structure: `<nav>` implies navigation, `<main>` implies primary content. Scene understanding does the same for segmentation: it reads spatial relationships between labeled regions to extract higher-level meaning. A "road" region adjacent to a "building" region forms a "street." A "drone" region above a "person" region forms a "surveillance event."

## Structure Implies Meaning

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="scene-analysis.ts">
{`import * as tf from '@tensorflow/tfjs';

const CLASSES = ['background', 'road', 'building', 'person', 'drone', 'vehicle'];

interface SceneEvent {
  type: string;
  location: { row: number; col: number };
  involvedClasses: string[];
}

// Analyze which classes are adjacent in the segmentation mask
function buildAdjacencyMap(mask: Int32Array, width: number, height: number) {
  const adjacency = new Set<string>();

  for (let y = 0; y < height - 1; y++) {
    for (let x = 0; x < width - 1; x++) {
      const current = mask[y * width + x];
      const right = mask[y * width + x + 1];
      const below = mask[(y + 1) * width + x];

      if (current !== right) {
        const pair = [CLASSES[current], CLASSES[right]].sort().join('-');
        adjacency.add(pair);
      }
      if (current !== below) {
        const pair = [CLASSES[current], CLASSES[below]].sort().join('-');
        adjacency.add(pair);
      }
    }
  }
  return adjacency;
}`}
</CodeBlock>

## Detecting Scene Events

<CodeBlock language="typescript" title="scene-events.ts">
{`// Like semantic HTML: the combination of elements defines meaning
// <nav> + <header> = site navigation
// drone + person = surveillance event

const EVENT_RULES: Record<string, (adj: Set<string>) => boolean> = {
  'surveillance-active': (adj) => adj.has('drone-person'),
  'street-scene': (adj) => adj.has('person-road') || adj.has('road-vehicle'),
  'aerial-patrol': (adj) => adj.has('building-drone'),
  'clear-corridor': (adj) =>
    adj.has('person-road') && !adj.has('drone-person') && !adj.has('drone-road'),
};

function detectEvents(adjacency: Set<string>): string[] {
  const events: string[] = [];
  for (const [eventType, check] of Object.entries(EVENT_RULES)) {
    if (check(adjacency)) {
      events.push(eventType);
    }
  }
  return events;
}

// Scene summary for the resistance war room
function analyzeScene(mask: tf.Tensor2D): { adjacency: Set<string>; events: string[] } {
  const data = mask.dataSync() as Int32Array;
  const [h, w] = mask.shape;
  const adjacency = buildAdjacencyMap(data, w, h);
  const events = detectEvents(adjacency);
  return { adjacency, events };
}

// Output: { events: ['street-scene', 'clear-corridor'] }
// The resistance knows: this street has people but no drones, safe to move`}
</CodeBlock>
