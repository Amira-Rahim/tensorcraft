<Dialogue speaker="Dilan">
You have convolution for feature extraction and pooling for compression. Now compose them. Think about how you build a React page — Layout wraps Sidebar wraps NavList. Each component transforms data and passes it down. A CNN is the same pattern: each layer transforms the feature maps and passes them to the next.
</Dialogue>

<Dialogue speaker="Noor">
So the model is basically a component tree? Conv is like a data-fetching component, pooling is like a summarization component, and the dense layer at the end is the leaf that renders the final output?
</Dialogue>

That analogy is spot on. A CNN is a pipeline of composed layers, each transforming its input and passing the result downstream. The standard pattern is: convolution blocks (conv + activation + pool) stacked to extract increasingly abstract features, followed by dense layers for classification.

<CodeBlock language="typescript" title="cnn-architecture.ts">
{`// Component composition in React:
// <Layout>         — wraps everything
//   <Sidebar>      — transforms layout
//     <NavList />   — renders final output
//   </Sidebar>
// </Layout>

// CNN layer composition follows the same pattern:
// Conv Block 1    — extracts low-level features (edges)
//   Conv Block 2  — extracts mid-level features (shapes)
//     Conv Block 3  — extracts high-level features (objects)
//       Dense      — classifies based on features

interface LayerConfig {
  type: 'conv2d' | 'maxPool' | 'flatten' | 'dense';
  outputShape: number[];
  params: number;
}

function designCNN(inputShape: [number, number, number]): LayerConfig[] {
  const layers: LayerConfig[] = [];
  let [h, w, ch] = inputShape;

  // Block 1: 8 filters, 3x3 kernel
  const f1 = 8;
  const k = 3;
  // Conv params: (kernelH * kernelW * inputChannels + 1) * numFilters
  layers.push({
    type: 'conv2d',
    outputShape: [h, w, f1],  // same padding preserves size
    params: (k * k * ch + 1) * f1,
  });
  ch = f1;

  // Pool: halves spatial dimensions
  h = Math.floor(h / 2);
  w = Math.floor(w / 2);
  layers.push({
    type: 'maxPool',
    outputShape: [h, w, ch],
    params: 0,  // pooling has no learnable parameters
  });

  // Block 2: 16 filters
  const f2 = 16;
  layers.push({
    type: 'conv2d',
    outputShape: [h, w, f2],
    params: (k * k * ch + 1) * f2,
  });
  ch = f2;

  h = Math.floor(h / 2);
  w = Math.floor(w / 2);
  layers.push({
    type: 'maxPool',
    outputShape: [h, w, ch],
    params: 0,
  });

  // Block 3: 32 filters
  const f3 = 32;
  layers.push({
    type: 'conv2d',
    outputShape: [h, w, f3],
    params: (k * k * ch + 1) * f3,
  });
  ch = f3;

  h = Math.floor(h / 2);
  w = Math.floor(w / 2);
  layers.push({
    type: 'maxPool',
    outputShape: [h, w, ch],
    params: 0,
  });

  // Flatten: convert 3D feature maps to 1D vector
  const flatSize = h * w * ch;
  layers.push({
    type: 'flatten',
    outputShape: [flatSize],
    params: 0,
  });

  // Dense classifier: 64 hidden units
  const hiddenUnits = 64;
  layers.push({
    type: 'dense',
    outputShape: [hiddenUnits],
    params: (flatSize + 1) * hiddenUnits,
  });

  // Output: 5 camera types
  const numClasses = 5;
  layers.push({
    type: 'dense',
    outputShape: [numClasses],
    params: (hiddenUnits + 1) * numClasses,
  });

  return layers;
}

// Build the Protocol Sentinel architecture
const layers = designCNN([224, 224, 3]);
layers.forEach((l, i) => {
  console.log(
    'Layer ' + i + ' (' + l.type + '): ' +
    JSON.stringify(l.outputShape) + ' — ' + l.params + ' params'
  );
});

const totalParams = layers.reduce((sum, l) => sum + l.params, 0);
console.log('Total trainable parameters:', totalParams);`}
</CodeBlock>

## The Feature Hierarchy

Each conv block learns increasingly abstract features. This is the key insight: early layers see pixels and find edges, middle layers combine edges into shapes, and deep layers combine shapes into objects.
