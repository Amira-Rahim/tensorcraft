Loss 1.6094 is not a malfunction. It is ln(5), the exact loss of a five-class model that knows nothing. Every network starts here: random weights, random guesses. The question is what happens over the next 49 epochs.

## The Training Pipeline

<BridgeCallout bridge={frontmatter.concept.bridge} />

One vocabulary item before the code: the raw, unbounded scores a network's final layer emits are called **logits**. Softmax squashes logits into probabilities that sum to 1, and cross-entropy scores those probabilities against the true label.

<CodeBlock language="typescript" title="training-pipeline.ts">
{`// Build pipeline stages:
// 1. Lint     -> Forward pass (process input)
// 2. Test     -> Loss computation (measure errors)
// 3. Analyze  -> Backpropagation (find what caused errors)
// 4. Fix      -> Weight update (adjust parameters)
// 5. Repeat   -> Next epoch

interface TrainingConfig {
  epochs: number;
  batchSize: number;
  learningRate: number;
  numClasses: number;
}

interface EpochResult {
  epoch: number;
  loss: number;
  accuracy: number;
}

// Cross-entropy loss for multi-class classification
function crossEntropyLoss(
  predictions: number[],  // softmax probabilities
  trueLabel: number       // correct class index
): number {
  // Clamp to avoid log(0)
  const clampedPred = Math.max(predictions[trueLabel], 1e-7);
  return -Math.log(clampedPred);
}

// Softmax: convert raw scores to probabilities
function softmax(logits: number[]): number[] {
  const maxLogit = Math.max(...logits);
  const exps = logits.map(l => Math.exp(l - maxLogit));
  const sumExps = exps.reduce((a, b) => a + b, 0);
  return exps.map(e => e / sumExps);
}

// Simulate one training epoch
function trainEpoch(
  dataSize: number,
  batchSize: number,
  numClasses: number
): EpochResult {
  const numBatches = Math.floor(dataSize / batchSize);
  let totalLoss = 0;
  let correctPredictions = 0;

  for (let b = 0; b < numBatches; b++) {
    // Simulate forward pass: random logits for each sample in the batch
    for (let s = 0; s < batchSize; s++) {
      const logits = Array.from({ length: numClasses }, () =>
        Math.random() * 2 - 1
      );
      const probs = softmax(logits);
      const trueLabel = Math.floor(Math.random() * numClasses);

      // Loss computation
      totalLoss += crossEntropyLoss(probs, trueLabel);

      // Accuracy tracking
      const predicted = probs.indexOf(Math.max(...probs));
      if (predicted === trueLabel) correctPredictions++;
    }
  }

  const totalSamples = numBatches * batchSize;
  return {
    epoch: 0,
    loss: totalLoss / totalSamples,
    accuracy: correctPredictions / totalSamples,
  };
}`}
</CodeBlock>

## Monitoring Training

<CodeBlock language="typescript" title="training-monitor.ts">
{`// Track training progress across epochs
function runTraining(config: TrainingConfig, dataSize: number): EpochResult[] {
  const history: EpochResult[] = [];

  for (let e = 0; e < config.epochs; e++) {
    const result = trainEpoch(dataSize, config.batchSize, config.numClasses);
    result.epoch = e + 1;
    history.push(result);

    // Log progress like a build pipeline status
    const lossBar = '='.repeat(Math.round(result.loss * 10));
    const accBar = '='.repeat(Math.round(result.accuracy * 20));
    console.log(
      'Epoch ' + result.epoch + '/' + config.epochs +
      ' - loss: ' + result.loss.toFixed(4) +
      ' [' + lossBar + ']' +
      ' - acc: ' + (result.accuracy * 100).toFixed(1) + '%' +
      ' [' + accBar + ']'
    );
  }

  return history;
}

// Protocol Sentinel training configuration
const config: TrainingConfig = {
  epochs: 50,
  batchSize: 32,
  learningRate: 0.001,
  numClasses: 5,  // 5 camera types in Neon City
};

// Simulate training on 2000 surveillance camera images
const history = runTraining(config, 2000);

// Check for convergence: is loss still decreasing?
function isConverging(history: EpochResult[], window: number): boolean {
  if (history.length < window) return true;
  const recent = history.slice(-window);
  const firstLoss = recent[0].loss;
  const lastLoss = recent[recent.length - 1].loss;
  return lastLoss < firstLoss;
}

console.log('Still converging:', isConverging(history, 5));`}
</CodeBlock>

<DerivationDrawer summary="FLOPs vs parameters: why a small model can still be slow">
**Parameters** = total weights to learn. **FLOPs** = floating-point operations per forward pass.

For a conv layer: `FLOPs ≈ K · K · C_in · C_out · H_out · W_out`

A conv layer with 32 filters, K=3, 16 input channels, output 56×56 costs `9 · 16 · 32 · 56 · 56 = ~14.4M FLOPs` for ~4,640 parameters.

**Implication:** parameter count tells you memory cost; FLOPs tell you inference time. A 1M-parameter model with high spatial resolution can be slower than a 10M-parameter model with low resolution. Mobile-targeted architectures (MobileNet, EfficientNet) optimize both axes; pruning a model for memory may not speed it up if the FLOP profile is unchanged.
</DerivationDrawer>
