</Dialogue>

<Dialogue speaker="NEON">
i18n is a lookup table. Total, deterministic, done. Domain adaptation has no table. You nudge learned feature distributions toward the target with augmented data and more training, the alignment is partial, and pushing accuracy up at 2AM can pull it down at noon. Measure both domains or you have only moved the failure somewhere you are not looking.
</Dialogue>

In i18n, you do not rewrite the entire app for each locale. You adapt the surface: translations, date formats, currency symbols. The architecture stays the same. Domain adaptation follows the same principle: you adapt the model to handle different visual conditions without rebuilding from scratch.

## The Domain Gap

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="domain-shift.ts">
{`// Source domain: ImageNet daylight photos
// Target domain: Neon City streets at night
//
// The gap between them is like:
// Source locale: English (training data)
// Target locale: Japanese (deployment)
// Same content, different presentation.

interface DomainStats {
  meanBrightness: number;  // 0-255
  contrast: number;        // standard deviation of pixel values
  noiseLevel: number;      // signal-to-noise ratio
  conditions: string[];
}

const sourceDomain: DomainStats = {
  meanBrightness: 128,
  contrast: 45,
  noiseLevel: 0.02,
  conditions: ['daylight', 'clear sky', 'low noise'],
};

const targetDomain: DomainStats = {
  meanBrightness: 40,
  contrast: 75,
  noiseLevel: 0.15,
  conditions: ['neon lighting', 'rain', 'fog', 'sensor noise'],
};

// The model trained on sourceDomain has never seen:
// - Low brightness (night scenes)
// - High contrast (neon signs against dark sky)
// - High noise (rain, fog, low-light sensor artifacts)
// Like an app that renders perfectly in English but breaks
// when Japanese characters overflow the layout.`}
</CodeBlock>

## Bridging with Augmentation

<CodeBlock language="typescript" title="domain-augmentation.ts">
{`import * as tf from '@tensorflow/tfjs';

// Like building i18n transforms:
// t('date', { locale }) applies locale-specific formatting
// augment(image, { domain }) applies domain-specific transforms

function augmentForNightDomain(image: tf.Tensor3D): tf.Tensor3D {
  return tf.tidy(() => {
    let augmented = image.toFloat().div(255);

    // Reduce brightness to simulate night
    const brightnessFactor = 0.3 + Math.random() * 0.4; // 0.3-0.7
    augmented = augmented.mul(brightnessFactor);

    // Boost contrast; neon lights create harsh light/dark boundaries
    const mean = augmented.mean();
    const contrastFactor = 1.2 + Math.random() * 0.6; // 1.2-1.8
    augmented = augmented.sub(mean).mul(contrastFactor).add(mean);

    // Add sensor noise; low-light cameras produce grainy footage
    const noise = tf.randomNormal(augmented.shape, 0, 0.05);
    augmented = augmented.add(noise);

    // Clamp to valid range
    return augmented.clipByValue(0, 1).mul(255).cast('int32') as tf.Tensor3D;
  });
}

// Apply augmentation to every training batch
function augmentBatch(batch: tf.Tensor4D): tf.Tensor4D {
  return tf.tidy(() => {
    const images = tf.unstack(batch);
    const augmented = images.map(img =>
      augmentForNightDomain(img as tf.Tensor3D)
    );
    return tf.stack(augmented) as tf.Tensor4D;
  });
}

// Now the model sees both daylight AND simulated night during training.
// Like testing your app with English AND Japanese simultaneously.`}
</CodeBlock>

## Advanced Adaptation Strategies

<CodeBlock language="typescript" title="adaptation-strategies.ts">
{`// i18n has different levels of adaptation:
// Level 1: Text translation (string replacement)
// Level 2: Format adaptation (dates, currencies)
// Level 3: Layout adaptation (RTL, character width)
// Level 4: Cultural adaptation (color meaning, icons)

// Domain adaptation has the same levels:

interface AdaptationLevel {
  name: string;
  technique: string;
  dataRequired: string;
  i18nAnalogy: string;
}

const levels: AdaptationLevel[] = [
  {
    name: 'Simple augmentation',
    technique: 'Brightness, contrast, noise transforms',
    dataRequired: 'None; synthetic transforms on existing data',
    i18nAnalogy: 'String translation: swap surface values',
  },
  {
    name: 'Style transfer',
    technique: 'Transform source images to look like target domain',
    dataRequired: 'A few unlabeled target domain images',
    i18nAnalogy: 'Format adaptation: dates, currencies, numbers',
  },
  {
    name: 'Few-shot adaptation',
    technique: 'Fine-tune on a handful of labeled target images',
    dataRequired: '10-50 labeled target domain images',
    i18nAnalogy: 'Layout adaptation: restructure for the locale',
  },
  {
    name: 'Full domain transfer',
    technique: 'Adversarial training to align feature distributions',
    dataRequired: 'Large unlabeled target domain dataset',
    i18nAnalogy: 'Cultural adaptation: deep structural changes',
  },
];

// The resistance uses Level 1 (augmentation) + Level 3 (few-shot).
// Amir's 500 images include some night shots. Combined with synthetic
