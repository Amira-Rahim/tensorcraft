<Dialogue speaker="Amir">
When you need to sort an array, you do not implement mergesort from scratch. You call `Array.sort()`. When you need date formatting, you install `date-fns`. Pre-trained models are the same principle applied to AI. Someone else spent the compute, the data, the engineering hours. You download the result and build on top.
</Dialogue>

<Dialogue speaker="Noor">
So `tf.loadLayersModel('mobilenet')` is basically `npm install mobilenet`?
</Dialogue>

<Dialogue speaker="Amir">
Exactly. Except the package cost two million credits to build.
</Dialogue>

An npm package encapsulates thousands of hours of development. A pre-trained model encapsulates thousands of GPU-hours of training. Both let you start with a proven foundation instead of building from zero. This is the core insight of transfer learning: knowledge learned on one task transfers to another.

## One Line, Millions of Dollars

<BridgeCallout bridge={frontmatter.concept.bridge} />

When you run `npm install react`, you get a decade of engineering from hundreds of contributors. When you load MobileNetV2, you get months of GPU training on 14 million images. The economics are identical: amortize the cost of creation across every user who downloads the artifact.

<CodeBlock language="typescript" title="load-mobilenet.ts">
{`import * as tf from '@tensorflow/tfjs';

// Loading MobileNetV2 — lightweight, fast, optimized for browsers
// Like installing a well-maintained npm package: battle-tested and production-ready
async function loadMobileNet() {
  const model = await tf.loadGraphModel(
    'https://tfhub.dev/google/tfjs-model/mobilenet_v2/classification/3/default/1',
    { fromTFHub: true }
  );

  console.log('MobileNetV2 loaded');
  console.log('Input shape:', model.inputs[0].shape);   // [null, 224, 224, 3]
  console.log('Output shape:', model.outputs[0].shape);  // [null, 1000]

  return model;
}

// Loading ResNet50 — heavier, more accurate, deeper architecture
// Like choosing between lodash (lightweight) and ramda (comprehensive)
async function loadResNet() {
  const model = await tf.loadGraphModel(
    'https://tfhub.dev/tensorflow/tfjs-model/resnet_50/classification/1/default/1',
    { fromTFHub: true }
  );

  console.log('ResNet50 loaded');
  return model;
}`}
</CodeBlock>

## Inference Without Training

The moment you load a pre-trained model, you can classify images. No training loop, no dataset, no GPU hours. One function call.

<CodeBlock language="typescript" title="pretrained-inference.ts">
{`import * as tf from '@tensorflow/tfjs';

async function classifyImage(
  model: tf.GraphModel,
  imageElement: HTMLImageElement
): Promise<{ classIndex: number; confidence: number }> {
  // Preprocess — MobileNet expects 224x224 normalized pixels
  const tensor = tf.tidy(() => {
    const img = tf.browser.fromPixels(imageElement);
    const resized = tf.image.resizeBilinear(img, [224, 224]);
    const normalized = resized.div(255.0);
    return normalized.expandDims(0); // [1, 224, 224, 3]
  });

  // Predict — 1000 ImageNet classes, instantly
  const predictions = model.predict(tensor) as tf.Tensor;
  const classIndex = predictions.argMax(-1).dataSync()[0];
  const confidence = predictions.max().dataSync()[0];

  // Clean up tensors
  tensor.dispose();
  predictions.dispose();

  return { classIndex, confidence };
}

// No training. No dataset. Just load and predict.
// Two million credits of compute, delivered in one function call.`}
</CodeBlock>

  accuracy: string;       // ImageNet top-1
  inferenceTime: string;  // browser estimate
  useCase: string;

const models: PretrainedModel[] = [
  {
    name: 'MobileNetV2',
    params: '3.4M',

    inferenceTime: '~30ms',

  {

    name: 'EfficientNet-B0',
    params: '5.3M',
    downloadSize: '20 MB',
    accuracy: '77.1%',
    inferenceTime: '~50ms',
    useCase: 'Best accuracy-per-parameter — sweet spot for browsers',
  },
];
