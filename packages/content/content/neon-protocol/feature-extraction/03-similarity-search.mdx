<Dialogue speaker="Zara">
In frontend search, you type a misspelled word and fuzzy matching finds what you meant. Visual similarity search works the same way — but instead of comparing strings, you compare feature vectors. Feed in a query image, find the database entries with the smallest distance. The closest neighbors are the most visually similar.
</Dialogue>

<Dialogue speaker="Kira">
So it is autocomplete, but for images. I give it one drone photo and it retrieves every visually similar frame from the archive?
</Dialogue>

Fuzzy text search ranks results by edit distance — how many character changes separate the query from each candidate. Similarity search ranks results by vector distance — how far apart two feature vectors are in embedding space. The algorithm is the same: compute a distance, sort by closeness, return the top results.

## Nearest Neighbor Search

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="similarity-search.ts">
{`interface SearchResult {
  index: number;
  similarity: number;
  label: string;
}

function cosineSim(a: number[], b: number[]): number {
  let dot = 0, normA = 0, normB = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    normA += a[i] * a[i];
    normB += b[i] * b[i];
  }
  return dot / (Math.sqrt(normA) * Math.sqrt(normB));
}

function findKNearest(
  query: number[],
  database: { vector: number[]; label: string }[],
  k: number
): SearchResult[] {
  const scored = database.map((item, index) => ({
    index,
    similarity: cosineSim(query, item.vector),
    label: item.label,
  }));

  // Sort by similarity descending (most similar first)
  scored.sort((a, b) => b.similarity - a.similarity);
  return scored.slice(0, k);
}

// Like fuzzy text search:
// fuse.search('drne') → [{item: 'drone', score: 0.95}, ...]
// findKNearest(queryVec, db, 5) → [{label: 'drone-x7', similarity: 0.97}, ...]`}
</CodeBlock>

## Building a Search Index

<CodeBlock language="typescript" title="search-index.ts">
{`import * as tf from '@tensorflow/tfjs';

class VisualSearchIndex {
  private vectors: number[][] = [];
  private labels: string[] = [];
  private extractor: tf.LayersModel | null = null;

  async init(modelUrl: string) {
    this.extractor = await tf.loadLayersModel(modelUrl);
  }

  async addImage(image: tf.Tensor3D, label: string) {
    const features = this.extractor!.predict(
      image.expandDims(0)
    ) as tf.Tensor2D;
    const vector = Array.from(features.dataSync());
    this.vectors.push(vector);
    this.labels.push(label);
    features.dispose();
  }

  search(queryVector: number[], k: number = 5): SearchResult[] {
    return findKNearest(
      queryVector,
      this.vectors.map((v, i) => ({ vector: v, label: this.labels[i] })),
      k
    );
  }
}

// Usage: index drone footage, then search for matching drones
