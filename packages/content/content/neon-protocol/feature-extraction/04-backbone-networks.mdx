<Dialogue speaker="Amir">
When you start a new frontend project, you do not write a button component from scratch. You import a component library. Backbone networks are the same idea. Someone trained a massive CNN on millions of images. You import it and use its features as a foundation for your specific task.
</Dialogue>

<Dialogue speaker="Noor">
So MobileNet is like a lightweight UI library, fast but basic. And ResNet is like a full design system, powerful but heavier?
</Dialogue>

<Dialogue speaker="Amir">
Half right, and the wrong half will cost you. ResNet is not "more powerful" the way a design system has more features. Both backbones do one job: turn an image into a feature vector. ResNet just spends more layers doing it. On this laptop, MobileNetV2 runs a frame in 45 milliseconds at 71.8% ImageNet accuracy. ResNet50 takes 180 milliseconds for 76.1%. Four times the latency buys you four points. You pick by constraint: inference speed, accuracy, memory footprint.
</Dialogue>

<DerivationDrawer summary="Transfer learning: why backbone features generalize">
A pretrained backbone (e.g. ResNet-50 trained on ImageNet) learns features in this hierarchy:

- **Layer 1-2:** edge detectors, color blobs (universal; transfer to any image task)
- **Layer 3-4:** textures, simple shapes (transfer to most natural-image tasks)
- **Layer 5+:** object parts, class-specific features (specific to ImageNet; may not transfer)

**Transfer learning recipes:**

```
Feature extraction:  freeze backbone, train new head
  - Cheap: O(forward pass + small head training)
  - Works when target distribution ≈ source distribution

Fine-tuning:  unfreeze top K layers, retrain with small LR
  - More expensive: O(full backprop on K layers)
  - Better when target distribution differs (medical, satellite, etc)

Differential learning rates:  bottom layers tiny LR, top layers larger LR
  - Preserves general features, adapts task-specific ones
  - fast.ai standard practice
```

**When transfer fails:** target images very different from ImageNet (tiny grayscale microscopy, medical scans with fixed orientation). The hierarchy doesn't apply; pretrained features are random for your domain. Train from scratch, or use domain-specific backbones (RadImageNet, etc).
</DerivationDrawer>
