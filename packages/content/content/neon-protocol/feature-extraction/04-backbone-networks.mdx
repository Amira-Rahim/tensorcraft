<Dialogue speaker="Ryo">
When you start a new frontend project, you do not write a button component from scratch. You import a component library. Backbone networks are the same idea. Someone trained a massive CNN on millions of images. You import it and use its features as a foundation for your specific task.
</Dialogue>

<Dialogue speaker="Kira">
So MobileNet is like a lightweight UI library — fast but basic. And ResNet is like a full design system — powerful but heavier?
</Dialogue>

Exactly. Just as you choose a component library based on your project's constraints — bundle size, performance, feature set — you choose a backbone network based on your model's constraints: inference speed, accuracy, and memory footprint.

  { name: 'EfficientNet-B0', featureSize: 1280, paramsMillion: 5.3,

## Using a Backbone

<CodeBlock language="typescript" title="use-backbone.ts">
{`async function loadBackbone(name: string): Promise<tf.LayersModel> {
  // TensorFlow.js provides pre-converted backbones
  const urls: Record<string, string> = {
    'mobilenet_v2': 'https://tfhub.dev/google/tfjs-model/mobilenet_v2/feature_vector/1/default/1',
    'mobilenet_v3': 'https://tfhub.dev/google/tfjs-model/mobilenet_v3_small/feature_vector/1/default/1',
  };

  const model = await tf.loadGraphModel(urls[name]);
  return model;
}

// Build a custom model on top of the backbone
// Like composing UI library components into a custom page
async function buildDroneDetector() {
  const backbone = await loadBackbone('mobilenet_v2');

  // Freeze backbone weights (pre-trained, don't change)
  // Add custom layers on top for our specific task
  const input = tf.input({ shape: [224, 224, 3] });
  const features = backbone.predict(input); // [1, 1280]

  // Custom classification head: drone vs not-drone
