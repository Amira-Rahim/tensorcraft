<Dialogue speaker="Amir">
In a production Express server, you do not write one giant handler that does authentication, validation, logging, and business logic. You build a middleware pipeline — each function does one thing and passes the result to the next. Feature extraction works the same way. Preprocess the image. Extract features with a backbone. Normalize the vector. Add it to the index. Each stage is independent. Each stage is replaceable.
</Dialogue>

<Dialogue speaker="Noor">
So the pipeline is middleware for images. Each step transforms the data and passes it forward. If I swap MobileNet for EfficientNet, only one stage changes — the rest of the pipeline stays the same.
</Dialogue>

The middleware pattern decouples processing stages. In Express, `cors()` does not know about `auth()`, and `auth()` does not know about the route handler. Each middleware transforms the request and calls `next()`. A feature pipeline works identically — each stage transforms data and passes it to the next stage. This decoupling is what makes production systems maintainable.

type PreprocessFn = (image: tf.Tensor3D) => tf.Tensor4D;

type NormalizeFn = (features: tf.Tensor2D) => tf.Tensor2D;
type IndexFn = (vector: number[], label: string) => void;

// Just like middleware signatures:
// (req: Request, res: Response, next: NextFunction) => void

## Building Each Stage

<CodeBlock language="typescript" title="pipeline-stages.ts">
{`import * as tf from '@tensorflow/tfjs';

// Stage 1: Preprocess — resize and normalize pixels
function preprocess(image: tf.Tensor3D): tf.Tensor4D {
  return tf.tidy(() => {
    const resized = tf.image.resizeBilinear(image, [224, 224]);
    const normalized = resized.div(255.0);
    return normalized.expandDims(0) as tf.Tensor4D; // [1, 224, 224, 3]
  });
}

// Stage 2: Extract — run through backbone
async function extract(
  batch: tf.Tensor4D,
  backbone: tf.LayersModel
): Promise<tf.Tensor2D> {
  const features = backbone.predict(batch) as tf.Tensor2D;
  return features; // [1, 1280]
}

// Stage 3: Normalize — L2 normalize the feature vector
// Makes cosine similarity equivalent to dot product
function normalizeL2(features: tf.Tensor2D): tf.Tensor2D {
  return tf.tidy(() => {
    const norm = features.norm('euclidean', 1, true); // [1, 1]
    return features.div(norm) as tf.Tensor2D; // unit vector
  });
}

// Stage 4: Index — store in the search index
class FeatureIndex {
  private vectors: number[][] = [];
  private labels: string[] = [];

  add(vector: number[], label: string): void {
    this.vectors.push(vector);
    this.labels.push(label);
  }

  search(query: number[], k: number): { label: string; score: number }[] {
    // With L2-normalized vectors, dot product = cosine similarity
    const scored = this.vectors.map((v, i) => ({
      label: this.labels[i],
      score: v.reduce((sum, val, j) => sum + val * query[j], 0),
    }));
    scored.sort((a, b) => b.score - a.score);
    return scored.slice(0, k);
  }

  get size(): number { return this.vectors.length; }
}`}
</CodeBlock>

## The Complete Pipeline

<CodeBlock language="typescript" title="feature-pipeline.ts">
{`import * as tf from '@tensorflow/tfjs';

interface PipelineConfig {
  backboneUrl: string;
  inputSize: [number, number];
  normalize: boolean;
}

class FeaturePipeline {
  private backbone: tf.LayersModel | null = null;
  private index = new FeatureIndex();
  private config: PipelineConfig;

  constructor(config: PipelineConfig) {
    this.config = config;
  }

  // Initialize — load the backbone (like app.listen())
  async init(): Promise<void> {
    this.backbone = await tf.loadLayersModel(this.config.backboneUrl);
    console.log('Pipeline ready. Backbone loaded.');
  }

  // Process a single image through the full pipeline
  async process(image: tf.Tensor3D, label: string): Promise<number[]> {
    // Stage 1: Preprocess
    const batch = preprocess(image);

    // Stage 2: Extract features
    const raw = await extract(batch, this.backbone!);

    // Stage 3: Normalize (optional)
    const features = this.config.normalize ? normalizeL2(raw) : raw;

    // Stage 4: Get the vector
    const vector = Array.from(features.dataSync());

    // Stage 5: Index
    this.index.add(vector, label);

    // Clean up tensors
    tf.dispose([batch, raw, features]);

    return vector;
  }

  // Query the index
  search(queryVector: number[], k: number = 5) {
    return this.index.search(queryVector, k);
  }

  // Process a batch of frames (like batch API requests)
  async processBatch(
    frames: { image: tf.Tensor3D; label: string }[]
  ): Promise<void> {
    for (const frame of frames) {
      await this.process(frame.image, frame.label);
    }
    console.log(\`Indexed \${this.index.size} frames.\`);
  }
}

// Usage — just like setting up an Express app:
// const app = express();
// app.use(cors());
// app.use(auth());
// app.listen(3000);

const pipeline = new FeaturePipeline({
  backboneUrl: 'https://tfhub.dev/google/tfjs-model/mobilenet_v2/feature_vector/1/default/1',
  inputSize: [224, 224],
  normalize: true,
});
