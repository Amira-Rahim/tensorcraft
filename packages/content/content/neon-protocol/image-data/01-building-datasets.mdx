## From Asset Folders to Dataset Directories

In frontend projects, you organize assets by type and purpose. A well-structured icon library might look like:

```
assets/
  icons/
    navigation/
      arrow-left-24.svg
      arrow-right-24.svg
    actions/
      delete-16.svg
      edit-16.svg
```

<BridgeCallout bridge={frontmatter.concept.bridge} />

ML datasets mirror this pattern exactly. The ImageNet dataset, for example, organizes millions of images into folders named after their class:

```
dataset/
  dome-camera/
    img_0001.png
    img_0002.png
  bullet-camera/
    img_0001.png
    img_0002.png
```

The folder name *is* the label. This convention, called "image folder" format, is the most common way to structure classification datasets.

## Anatomy of a Dataset Sample

Every image in a dataset is more than just pixels. It carries metadata that helps you track quality, provenance, and distribution.

<CodeBlock language="typescript" title="dataset-types.ts">
{`// Frontend: asset manifest entry
interface AssetEntry {
  path: string;
  name: string;
  category: string;
  width: number;
  height: number;
}

// ML: dataset sample — same structure, different domain
interface ImageSample {
  id: string;
  label: string;
  path: string;
  width: number;
  height: number;
  metadata: {
    source: string;
    capturedAt: string;
    verified: boolean;
  };
}`}
</CodeBlock>

Notice how similar these structures are. Both track dimensions, categorization, and file paths. The ML version adds verification status because mislabeled data is one of the most common causes of poor model performance.

## Building the Collection

Zara's process for building the surveillance camera dataset mirrors how you'd build a design system asset library: methodical collection, consistent formatting, and quality checks at every step.

<CodeBlock language="typescript" title="dataset-builder.ts">
{`interface ImageSample {
  id: string;
  label: string;
  path: string;
  width: number;
  height: number;
}

interface DatasetSummary {
  totalSamples: number;
  labels: string[];
  samplesPerLabel: Record<string, number>;
}

class DatasetBuilder {
  private samples: ImageSample[] = [];

  addSample(sample: ImageSample): void {
    // Validate before adding — like input validation on a form
    if (!sample.label || !sample.path) {
      throw new Error("Sample must have a label and path");
    }
    this.samples.push(sample);
  }

  getSamplesByLabel(label: string): ImageSample[] {
    return this.samples.filter(s => s.label === label);
  }

  getSummary(): DatasetSummary {
    const labelCounts: Record<string, number> = {};
    for (const sample of this.samples) {
      labelCounts[sample.label] = (labelCounts[sample.label] || 0) + 1;
    }
    return {
      totalSamples: this.samples.length,
      labels: Object.keys(labelCounts),
      samplesPerLabel: labelCounts,
    };
  }
}`}
</CodeBlock>

The `getSummary` method is critical. Just as you'd audit a component library to find missing variants, you audit a dataset to find underrepresented classes. If your dataset has 500 dome cameras but only 12 hidden cameras, the model will struggle to recognize the rare type.

## Quality Control

<Dialogue speaker="Zara">
I've seen resistance cells waste months training on dirty data. Duplicate images, wrong labels, corrupted files. Check everything before you feed it to the Sentinel.
</Dialogue>

Dataset quality checks are the ML equivalent of linting your codebase. Common issues include:

- **Duplicates**: the same image appearing multiple times inflates your count without adding information
- **Mislabels**: a dome camera photo filed under "bullet-camera" teaches the model the wrong pattern
- **Corrupt files**: images that can't be decoded will crash your training pipeline
- **Inconsistent dimensions**: while models resize inputs, wildly different aspect ratios can cause information loss

<CodeBlock language="typescript" title="quality-checks.ts">
{`function findDuplicates(samples: ImageSample[]): string[][] {
  const pathGroups = new Map<string, string[]>();

  for (const sample of samples) {
    // Simple duplicate detection by normalized path
    const key = sample.path.toLowerCase().trim();
    if (!pathGroups.has(key)) {
      pathGroups.set(key, []);
    }
    pathGroups.get(key)!.push(sample.id);
  }

  return Array.from(pathGroups.values()).filter(ids => ids.length > 1);
}

function validateSample(sample: ImageSample): string[] {
  const errors: string[] = [];

  if (sample.width <= 0 || sample.height <= 0) {
    errors.push("Invalid dimensions: width and height must be positive");
  }
  if (!sample.label.trim()) {
    errors.push("Empty label");
  }
  if (!sample.path.match(/\\.(png|jpg|jpeg|webp)$/i)) {
    errors.push("Unsupported image format");
  }

  return errors;
}`}
</CodeBlock>
