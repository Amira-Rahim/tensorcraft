<Dialogue speaker="Dr. Farah">
The simple RNN forgets. By the time it reaches time step 50, information from step 1 has vanished, its gradients multiplied through too many small numbers. LSTMs solve this with gates: learned switches that control what flows through and what gets discarded.
</Dialogue>

<Dialogue speaker="Ensign Demir">
Gates, like a cache with TTL? Keep the important entries, let the stale ones expire?
</Dialogue>

<Dialogue speaker="Chief Nazari">
Don't tell me what it's like, Ensign. Tell me how far back it can hold a pattern, and what that costs after last night's six hours of nothing.
</Dialogue>

<Dialogue speaker="Dr. Farah">
Hundreds of steps, for roughly four times the parameters of the simple RNN. And there is no clock in it anywhere. A forget gate reads the current input and outputs a number between 0 and 1 for every dimension of the cell state: keep 90% of this, drop most of that. Partial and learned, with no timer. That is why it can hold a pattern from 72 hours ago.
</Dialogue>

The three gates (forget, input, output) are each a small sigmoid layer with its own learned weights. That [0,1] output is what makes a gate a dimmer rather than a switch.

## Three Gates, One Cell

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="lstm-gates.ts">
{`// LSTM Cell: three gates controlling information flow

// 1. FORGET GATE: what to discard from memory
//    forgetGate = sigmoid(W_f · [prevHidden, input])
//    Output: values between 0 (forget completely) and 1 (keep fully)

// 2. INPUT GATE: what new information to store
//    inputGate = sigmoid(W_i · [prevHidden, input])
//    candidate = tanh(W_c · [prevHidden, input])
//    newCell = forgetGate * prevCell + inputGate * candidate

// 3. OUTPUT GATE: what to expose as hidden state
//    outputGate = sigmoid(W_o · [prevHidden, input])
//    newHidden = outputGate * tanh(newCell)

// The cell state acts as a conveyor belt; information flows through
// with minimal transformation, preventing gradient vanishing`}
</CodeBlock>

## Building an LSTM in TF.js

<CodeBlock language="typescript" title="lstm-model.ts">
{`import * as tf from '@tensorflow/tfjs';

// LSTM: drop-in replacement for SimpleRNN (same API, much better memory)
const model = tf.sequential();
model.add(tf.layers.lstm({
  units: 64,              // hidden state size
  inputShape: [50, 3],    // 50 time steps, 3 features; handles long sequences!
  returnSequences: false,  // only need final output for classification
}));
model.add(tf.layers.dense({ units: 1, activation: 'sigmoid' }));

model.compile({ optimizer: 'adam', loss: 'binaryCrossentropy', metrics: ['accuracy'] });

// Training on long sequences, where SimpleRNN failed
const x = tf.randomNormal([100, 50, 3]);  // 100 samples, 50 time steps
const y = tf.randomUniform([100, 1]).round();

const history = await model.fit(x, y, {
  epochs: 20,
  validationSplit: 0.2,
  callbacks: {
    onEpochEnd: (epoch, logs) => {
      if (epoch % 5 === 0) {
        console.log(\`Epoch \${epoch}: loss=\${logs?.loss.toFixed(4)}, val_loss=\${logs?.val_loss.toFixed(4)}\`);
      }
    },
  },
});
// Unlike SimpleRNN, loss actually converges on long sequences!

x.dispose();
y.dispose();`}
</CodeBlock>

## GRU: The Lighter Alternative

<CodeBlock language="typescript" title="gru-comparison.ts">
{`import * as tf from '@tensorflow/tfjs';

// GRU (Gated Recurrent Unit): fewer parameters, often similar performance
// Two gates instead of three: reset gate + update gate
// No separate cell state: simpler architecture

const gruModel = tf.sequential();
gruModel.add(tf.layers.gru({
  units: 64,
  inputShape: [50, 3],
}));
gruModel.add(tf.layers.dense({ units: 1, activation: 'sigmoid' }));

// Comparison:
// LSTM: 4 sets of weight matrices: forget, input, and output gates plus the
//       candidate state (more parameters, better long-range memory)
// GRU:  3 sets: reset gate, update gate, candidate state (~25% fewer params, faster training)
// Rule of thumb: try both and compare, like choosing between React and Preact`}
</CodeBlock>
