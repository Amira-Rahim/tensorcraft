<Dialogue speaker="Ensign Demir">
The signal feed is continuous: readings every second, forever. But the LSTM needs fixed-size input: exactly 50 time steps. I need to convert a stream into windows, like IntersectionObserver processing what's currently in view.
</Dialogue>

Slice 50 readings. Step forward one. Slice again. That's the entire pipeline: a fixed-size window walks the continuous stream, and every position it stops at becomes one perfectly shaped sample for the LSTM. If the rhythm reminds you of IntersectionObserver processing elements as they scroll through the viewport, that's the right instinct, with one difference: here, every step of the walk produces training data.

## The Sliding Window Pattern

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="sliding-window.ts">
{`// Sliding window for sequence prediction
// Given: continuous signal [s0, s1, s2, s3, s4, s5, s6, s7, ...]
// Window size: 4, Stride: 1

// Window 0: [s0, s1, s2, s3] → predict s4
// Window 1: [s1, s2, s3, s4] → predict s5
// Window 2: [s2, s3, s4, s5] → predict s6

function createWindows(
  signal: number[][],
  windowSize: number,
  stride: number = 1,
): { inputs: number[][][]; labels: number[][] } {
  const inputs: number[][][] = [];
  const labels: number[][] = [];

  for (let i = 0; i <= signal.length - windowSize - 1; i += stride) {
    inputs.push(signal.slice(i, i + windowSize));
    labels.push(signal[i + windowSize]);
  }

  return { inputs, labels };
}

const readings = [
  [0.5, 0.3], [0.8, 0.2], [0.3, 0.1], [0.5, 0.3],
  [0.9, 0.4], [0.2, 0.1], [0.7, 0.5], [0.4, 0.2],
];

const { inputs, labels } = createWindows(readings, 4);
console.log('Sequences:', inputs.length);  // 4`}
</CodeBlock>

## Real-Time Streaming Buffer

<CodeBlock language="typescript" title="streaming-buffer.ts">
{`import * as tf from '@tensorflow/tfjs';

class SignalBuffer {
  private buffer: number[][] = [];
  private readonly windowSize: number;

  constructor(windowSize: number) {
    this.windowSize = windowSize;
  }

  push(reading: number[]): number[][] | null {
    this.buffer.push(reading);
    if (this.buffer.length > this.windowSize) {
      this.buffer.shift();
    }
    return this.buffer.length === this.windowSize ? [...this.buffer] : null;
  }
}

const buffer = new SignalBuffer(80);

signalFeed.addEventListener('reading', (event: CustomEvent) => {
  const window = buffer.push(event.detail.features);
  if (window) {
    const prediction = tf.tidy(() => {
      const input = tf.tensor3d([window]);
      return (model.predict(input) as tf.Tensor).dataSync();
    });
    updateDashboard(prediction);
  }
});`}
