<Dialogue speaker="Ensign Demir">
So an RNN is just... a reducer? It takes the previous hidden state and the new input, runs them through a function, and outputs new hidden state? I use this pattern every day with useReducer.
</Dialogue>

<Dialogue speaker="Dr. Farah">
The shape is right; the guarantees are gone. Your reducer is a pure function you wrote. Same state, same action, same result, and you can read the logic. This one is learned from data. Nobody authored the transition function; the weights are the function. And the same input produces different outputs depending on everything that came before. The hidden state is the network's memory.
</Dialogue>

The cell itself is small: a weight matrix for the previous hidden state, a weight matrix for the input, a bias, a `tanh`. What makes it recurrent is the wiring: the output loops back in as the hidden state at the next time step.

## The Learned Reducer

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="rnn-as-reducer.ts">
{`import * as tf from '@tensorflow/tfjs';

// React useReducer: you write the state transition function
function signalReducer(state: { count: number; trend: string }, action: { value: number }) {
  const trend = action.value > 0.5 ? 'rising' : 'falling';
  return { count: state.count + 1, trend };
}

// RNN: the network LEARNS the state transition function
// At each time step:
//   newHidden = tanh(W_h * prevHidden + W_x * input + bias)
//
// W_h and W_x are weight matrices learned during training
// tanh squashes output to [-1, 1]
// prevHidden carries memory of all previous time steps

// Build a simple RNN in TF.js
const model = tf.sequential();
model.add(tf.layers.simpleRNN({
  units: 32,           // hidden state size (like the shape of your Redux store)
  inputShape: [5, 3],  // 5 time steps, 3 features each
}));
model.add(tf.layers.dense({ units: 1, activation: 'sigmoid' }));

model.compile({ optimizer: 'adam', loss: 'binaryCrossentropy', metrics: ['accuracy'] });

// Input: [batch, timeSteps, features] = [32, 5, 3]
const x = tf.randomNormal([32, 5, 3]);
const y = tf.randomUniform([32, 1]).round();

await model.fit(x, y, { epochs: 10 });

x.dispose();
y.dispose();`}
</CodeBlock>

## How the RNN Processes a Sequence

<CodeBlock language="typescript" title="rnn-unrolled.ts">
{`// Unrolling the RNN: what happens at each time step:

// Time step 0: hidden = f(zeros, input[0])
// Time step 1: hidden = f(hidden, input[1])  ← remembers step 0
// Time step 2: hidden = f(hidden, input[2])  ← remembers steps 0-1
// Time step 3: hidden = f(hidden, input[3])  ← remembers steps 0-2
// Time step 4: hidden = f(hidden, input[4])  ← remembers steps 0-3

// Like dispatching a sequence of actions to a reducer:
// state = reducer(initialState, actions[0])
// state = reducer(state, actions[1])
// state = reducer(state, actions[2])
// ...

// The final hidden state encodes the entire sequence
// We pass it to a Dense layer for classification

// Return sequences: get hidden state at EVERY step (not just the last)
const modelAllSteps = tf.sequential();
modelAllSteps.add(tf.layers.simpleRNN({
  units: 32,
  inputShape: [5, 3],
  returnSequences: true,  // output shape: [batch, 5, 32] instead of [batch, 32]
}));
// Useful when you need the full temporal output (e.g., for stacking RNN layers)`}
</CodeBlock>

## The Vanishing Gradient Problem

<CodeBlock language="typescript" title="vanishing-gradient.ts">
{`// Simple RNNs have a critical flaw: vanishing gradients
// As information passes through many time steps, gradients shrink exponentially
// Like a game of telephone: the message degrades with each relay

// For DEEP SCAN: the anomaly pattern repeats every ~73 seconds
// At 1 sample/second, that's a 73-step dependency
// A simple RNN "forgets" information after ~10-20 steps

// Demo: training on short vs long sequences
const shortModel = tf.sequential();
shortModel.add(tf.layers.simpleRNN({ units: 32, inputShape: [5, 3] }));    // 5 steps: works
shortModel.add(tf.layers.dense({ units: 1, activation: 'sigmoid' }));

const longModel = tf.sequential();
longModel.add(tf.layers.simpleRNN({ units: 32, inputShape: [100, 3] }));   // 100 steps: fails
longModel.add(tf.layers.dense({ units: 1, activation: 'sigmoid' }));

// Short sequence: loss converges nicely
// Long sequence: loss plateaus; gradients vanish before reaching early time steps
// Solution: LSTM (next lesson)`}
</CodeBlock>

<RecallPrompt
  question="A simple RNN trains on long windows, but the dependency it must learn spans dozens of time steps. After many epochs the loss is stuck at 0.693. What is happening, and what fixes it?"
  answer="Vanishing gradients. Backpropagation through time multiplies the gradient by recurrent weights and the tanh derivative at every step, so over dozens of steps it shrinks toward zero and the early time steps never learn. Loss pinned at 0.693 (ln 2) is the binary cross-entropy of a coin flip, meaning the network has learned nothing. Batch size and returnSequences do not change gradient depth; tanh is the standard activation. The fix is an LSTM, whose gated cell state carries gradient across long spans."
/>
