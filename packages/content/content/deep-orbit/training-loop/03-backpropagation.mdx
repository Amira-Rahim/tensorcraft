## Estimate a gradient by changing a weight

One weight, one question: if I move this a little, does the loss go down? Nothing stops you from asking it 673 times.

<CodeBlock language="typescript" title="gradient-by-nudging.ts (sketch)">
{`// Numeric gradient: nudge one weight, rerun, compare. No calculus.
// A sketch rather than a runnable block: computeLoss() stands in for
// your own forward pass over the batch and returns a plain number, and
// w1 is the layer-1 weight variable it reads.
const EPS = 1e-3;

function nudgedLoss(w: tf.Variable, index: number): number {
  const original = w.dataSync().slice();
  const nudged = original.slice();
  nudged[index] += EPS;
  try {
    tf.tidy(() => w.assign(tf.tensor(nudged, w.shape)));
    return computeLoss();
  } finally {
    tf.tidy(() => w.assign(tf.tensor(original, w.shape)));
  }
}

const base = computeLoss();             // forward pass 0
// gradient ≈ how much the loss moved, per unit of nudge
const grad = (nudgedLoss(w1, 0) - base) / EPS;`}
</CodeBlock>

This method is called a **forward finite difference**. It estimates a derivative from two nearby values. A large nudge gives a rough estimate. A very small one can lose accuracy when nearly equal floating-point numbers are subtracted.

Checking all 673 weights this way needs 673 extra forward passes. It can help check a small calculation, but becomes costly as the model grows. The scene timings are fictional. Measure your own code to compare speed.

## Working Backwards

**Backpropagation** calculates gradients by working backward through the operations used in the forward pass. The forward pass produces the loss. The backward pass uses the chain rule to calculate how each earlier variable affected it.

The direction may remind you of an error traveling from `parseRow` through `readFile` to `main`. The mechanism is different: backpropagation multiplies derivatives rather than throwing an exception.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="backpropagation.ts">
{`import * as tf from '@tensorflow/tfjs';

// Build a simple network with trackable weights
const w1 = tf.tidy(() => tf.variable(tf.randomNormal([3, 4])));  // layer 1 weights
const b1 = tf.tidy(() => tf.variable(tf.zeros([4])));              // layer 1 bias
const w2 = tf.tidy(() => tf.variable(tf.randomNormal([4, 1])));   // layer 2 weights
const b2 = tf.tidy(() => tf.variable(tf.zeros([1])));              // layer 2 bias

const input = tf.tensor2d([[0.5, 0.8, 0.2]]);
const label = tf.tensor2d([[1]]);

// Forward pass + loss computation + automatic backprop
const { value: loss, grads } = tf.variableGrads(() => {
  // Forward: input → layer1 → relu → layer2 (raw logits)
  // sigmoidCrossEntropy applies the sigmoid itself, so feed it logits
  const hidden = tf.relu(input.matMul(w1).add(b1));
  const logits = hidden.matMul(w2).add(b2);
  return tf.losses.sigmoidCrossEntropy(label, logits) as tf.Scalar;
});

// grads now contains gradients for ALL 4 variables
console.log('Loss:', loss.dataSync()[0]);
console.log('w1 gradient shape:', grads[w1.name].shape); // [3, 4]
console.log('w2 gradient shape:', grads[w2.name].shape); // [4, 1]

// Gradients are local slopes, not the optimizer update itself.
tf.dispose([input, label, loss, ...Object.values(grads), w1, b1, w2, b2]);`}
</CodeBlock>

`tf.variableGrads()` records every operation during the forward pass, then computes gradients for all variables by applying the chain rule backwards. The drawer below traces that calculation through a two-layer network.

<DerivationDrawer summary="Chain rule applied to a 2-layer network, by hand">
**The chain rule:** if `y = f(g(x))`, then `dy/dx = f'(g(x)) · g'(x)`. For a two-layer scalar example (one unit per layer):

```
z₁ = w₁·x + b₁          ← layer 1 pre-activation
a₁ = ReLU(z₁)            ← layer 1 activation
z₂ = w₂·a₁ + b₂          ← layer 2 pre-activation
ŷ  = σ(z₂)               ← layer 2 output (sigmoid)
L  = ½(ŷ - y)²           ← loss
```

**Goal:** compute `∂L/∂w₁` (gradient of loss w.r.t. layer-1 weights). Apply chain rule from L back to w₁:

```
∂L/∂w₁ = ∂L/∂ŷ · ∂ŷ/∂z₂ · ∂z₂/∂a₁ · ∂a₁/∂z₁ · ∂z₁/∂w₁
       = (ŷ - y)  · σ'(z₂)  ·   w₂    ·  ReLU'(z₁)  ·  x
```

Each factor is local to one layer. `tf.variableGrads()` builds the computational graph during the forward pass, then walks it backward multiplying these local derivatives. This is the backward pass referred to above.

**Vanishing gradients** occur when repeated derivative factors make early gradients very small. Twenty factors near 0.1 multiply to about 10⁻²⁰. For vectors, the derivatives are matrices called **Jacobians**. Backpropagation multiplies them and adds contributions from different paths. Small factors can still weaken the result.

A residual block, `y = x + F(x)`, adds a direct path from input to output. Its Jacobian is `I + J_F`, where `I` is the identity matrix. This can help gradients pass through, but does not guarantee they will never vanish or grow too large.
</DerivationDrawer>
