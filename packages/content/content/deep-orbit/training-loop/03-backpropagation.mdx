## Working Backwards

React's reconciliation algorithm finds what changed by comparing the virtual DOM tree from leaves to root. Backpropagation finds how to change each weight by propagating the loss gradient from output to input, backwards through the network.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="backpropagation.ts">
{`import * as tf from '@tensorflow/tfjs';

// Build a simple network with trackable weights
const w1 = tf.variable(tf.randomNormal([3, 4]));  // layer 1 weights
const b1 = tf.variable(tf.zeros([4]));              // layer 1 bias
const w2 = tf.variable(tf.randomNormal([4, 1]));   // layer 2 weights
const b2 = tf.variable(tf.zeros([1]));              // layer 2 bias

const input = tf.tensor2d([[0.5, 0.8, 0.2]]);
const label = tf.tensor2d([[1]]);

// Forward pass + loss computation + automatic backprop
const { value: loss, grads } = tf.variableGrads(() => {
  // Forward: input → layer1 → relu → layer2 → sigmoid
  const hidden = tf.relu(input.matMul(w1).add(b1));
  const output = tf.sigmoid(hidden.matMul(w2).add(b2));
  return tf.losses.sigmoidCrossEntropy(label, output).mean() as tf.Scalar;
});

// grads now contains gradients for ALL 4 variables
console.log('Loss:', loss.dataSync()[0]);
console.log('w1 gradient shape:', grads[w1.name].shape); // [3, 4]
console.log('w2 gradient shape:', grads[w2.name].shape); // [4, 1]

// Each gradient tells us: "adjust this weight by this much"`}
</CodeBlock>

No magic involved: `tf.variableGrads()` records every operation during the forward pass, then computes gradients for all variables by applying the chain rule backwards. The drawer below walks the exact multiplication chain by hand. You never have to implement it manually, but you can.

<DerivationDrawer summary="Chain rule applied to a 2-layer network, by hand" companionSlug="calculus-of-neurons">
**The chain rule:** if `y = f(g(x))`, then `dy/dx = f'(g(x)) · g'(x)`. For a 2-layer network:

```
z₁ = w₁·x + b₁          ← layer 1 pre-activation
a₁ = ReLU(z₁)            ← layer 1 activation
z₂ = w₂·a₁ + b₂          ← layer 2 pre-activation
ŷ  = σ(z₂)               ← layer 2 output (sigmoid)
L  = ½(ŷ - y)²           ← loss
```

**Goal:** compute `∂L/∂w₁` (gradient of loss w.r.t. layer-1 weights). Apply chain rule from L back to w₁:

```
∂L/∂w₁ = ∂L/∂ŷ · ∂ŷ/∂z₂ · ∂z₂/∂a₁ · ∂a₁/∂z₁ · ∂z₁/∂w₁
       = (ŷ - y)  · σ'(z₂)  ·   w₂    ·  ReLU'(z₁)  ·  x
```

Each factor is local to one layer. `tf.variableGrads()` builds the computational graph during forward pass, then walks it backward multiplying these local derivatives. **That backward walk is the entire algorithm**: there is no other magic. The "1 backward pass" claim above is exactly this multiplication chain.

**Vanishing gradients = the chain product collapsing.** If `σ'(z₂) ≈ 0.1`, `ReLU'(z₁) ∈ {0,1}`, and you have 20 layers, the product can be `0.1²⁰ ≈ 10⁻²⁰`. The early-layer weights stop updating. Residual connections add `+1` to each link in the chain to prevent this collapse.
</DerivationDrawer>
