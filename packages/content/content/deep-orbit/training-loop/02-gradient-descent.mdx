## Finding Downhill

Imagine you're blindfolded on a hill and need to reach the bottom. You feel the slope under your feet — that's the gradient. You step in the direction that slopes down — that's gradient descent.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="gradient-descent.ts">
{`import * as tf from '@tensorflow/tfjs';

// Simple example: find the x that minimizes (x - 3)^2
let x = tf.variable(tf.scalar(0)); // start at 0
const learningRate = 0.1;

for (let step = 0; step < 20; step++) {
  // Compute loss and gradient
  const { value: loss, grads } = tf.variableGrads(() => {
    return x.sub(3).square() as tf.Scalar; // loss = (x - 3)^2
  });

  // Update x: move opposite to gradient direction
  const grad = grads[x.name];
  x.assign(x.sub(grad.mul(learningRate)));

  if (step % 5 === 0) {
    console.log(\`Step \${step}: x=\${x.dataSync()[0].toFixed(3)}, loss=\${loss.dataSync()[0].toFixed(3)}\`);
  }
}
// Step 0:  x=0.600, loss=9.000
// Step 5:  x=2.806, loss=0.038
// Step 10: x=2.993, loss=0.000
// Step 15: x=3.000, loss=0.000`}
</CodeBlock>

**Learning rate** is crucial: too high and you overshoot the minimum (like scrolling past your target), too low and training takes forever (like scrolling one pixel at a time).
