## The Learning Loop

In frontend animation, `requestAnimationFrame` creates a loop that updates state and re-renders until the target is reached. Training is the same pattern: update weights and re-evaluate until the loss is minimized.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="training-loop.ts">
{`import * as tf from '@tensorflow/tfjs';

// Prepare the model (from previous lesson)
const model = tf.sequential();
model.add(tf.layers.dense({ units: 32, activation: 'relu', inputShape: [3] }));
model.add(tf.layers.dense({ units: 16, activation: 'relu' }));
model.add(tf.layers.dense({ units: 1, activation: 'sigmoid' }));
model.compile({ optimizer: 'adam', loss: 'binaryCrossentropy', metrics: ['accuracy'] });

// Training data: 100 signal readings with labels
const trainX = tf.randomNormal([100, 3]);  // 100 samples, 3 features
const trainY = tf.randomUniform([100, 1]).round();  // binary labels

// THE TRAINING LOOP — model.fit() handles everything
const history = await model.fit(trainX, trainY, {
  epochs: 50,             // iterate over dataset 50 times
  batchSize: 32,          // process 32 samples at a time
  validationSplit: 0.2,   // hold out 20% for validation
  callbacks: {
    onEpochEnd: (epoch, logs) => {
      if (epoch % 10 === 0) {
        console.log(\`Epoch \${epoch}: loss=\${logs?.loss.toFixed(4)}, acc=\${logs?.acc.toFixed(4)}\`);
      }
    },
  },
});

// Epoch 0:  loss=0.6931, acc=0.5125
// Epoch 10: loss=0.4203, acc=0.7750
// Epoch 20: loss=0.2115, acc=0.8875
// Epoch 40: loss=0.0823, acc=0.9625`}
</CodeBlock>

**Key parameters:**
- **epochs**: How many times to iterate over the full dataset. More epochs = more learning (up to a point).
- **batchSize**: How many samples to process before updating weights. 32 is a good default.
- **validationSplit**: Fraction of data held out to check for overfitting.
