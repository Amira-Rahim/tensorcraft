## How Wrong Are We?

0.52 against a true label of 1.0 means the network is off by 0.48. Square that and you get 0.23, and averaging the squares across every prediction in a batch gives you mean squared error: one number that answers Farah's question. If you've written `expect(actual).toBe(expected)`, you've used the same idea before. A loss function is an assertion that returns a distance instead of a pass/fail.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="loss-functions.ts">
{`import * as tf from '@tensorflow/tfjs';

// Actual labels (ground truth)
const labels = tf.tensor([1, 0, 1, 0, 1]);

// Network predictions (untrained, pretty bad)
const predictions = tf.tensor([0.6, 0.4, 0.3, 0.7, 0.8]);

// Mean Squared Error: average of (prediction - label)^2
const mse = tf.losses.meanSquaredError(labels, predictions);
console.log('MSE:', mse.dataSync()); // 0.268

// Binary Crossentropy: better for classification (0 or 1).
// sigmoidCrossEntropy expects raw logits (pre-sigmoid outputs), not probabilities
const logits = tf.tensor([0.4, -0.4, -0.8, 0.8, 1.4]);
const bce = tf.losses.sigmoidCrossEntropy(labels, logits);
console.log('BCE:', bce.dataSync()); // ~0.718

// Perfect predictions → loss approaches 0
const perfect = tf.tensor([1, 0, 1, 0, 1]);
const perfectLoss = tf.losses.meanSquaredError(labels, perfect);
console.log('Perfect MSE:', perfectLoss.dataSync()); // 0`}
</CodeBlock>

The rest of this module is machinery for making that one number smaller: gradients to find the direction, backprop to compute them fast, the loop to keep stepping.

<DerivationDrawer summary="MSE and cross-entropy from first principles" companionSlug="information-theory">
**Why squared error?** MSE squares the residuals so positive and negative errors don't cancel, AND so large errors are penalized more than small ones (a 0.4 error counts 4× more than a 0.2 error). The formula:

`MSE = (1/n) Σ (yᵢ - ŷᵢ)²`

**Why cross-entropy for classification?** Squaring works for continuous outputs, but for probabilities it produces a flat gradient near 0 and 1 that stalls learning. Cross-entropy uses log to keep gradients steep where the model is most wrong:

`BCE = -(1/n) Σ [ yᵢ log(ŷᵢ) + (1-yᵢ) log(1-ŷᵢ) ]`

When the true label is 1 and the model predicts 0.01, `-log(0.01) ≈ 4.6`: a strong gradient signal. When MSE would say "off by 0.99² ≈ 0.98", BCE says "off by 4.6". The loss curve shape is what trains.
</DerivationDrawer>
