<Dialogue speaker="Chief Nazari">
Every weight is a 32-bit float: 4 bytes. Your model has 85 million weights. That's 340 MB just for the numbers. Cut the precision to 8-bit integers and you're at 85 MB. The model is 4x smaller and inference runs on integer hardware, faster on every device.
</Dialogue>

Nazari's arithmetic is the whole technique. If you've ever converted a 2 MB PNG to a 200 KB WebP and squinted at the invisible difference, you know the trade. Store each weight in one byte instead of four and the file lands at 85 MB; the cost is roughly a point of accuracy. ## Precision Reduction

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="quantization.ts">
{`import * as tf from '@tensorflow/tfjs';

// Float32: full precision (default)
// 1.2345678 → stored as 4 bytes
// Model size: 85M params × 4 bytes = 340 MB

// Float16: half precision
// 1.234 → stored as 2 bytes (some precision lost)
// Model size: 85M params × 2 bytes = 170 MB

// Int8: integer precision
// 1 → stored as 1 byte (significant precision lost, but usually OK)
// Model size: 85M params × 1 byte = 85 MB

// Simulate quantization effect
function quantizeWeights(weights: Float32Array, bits: 8 | 16): { quantized: number[]; scale: number; zeroPoint: number } {
  const min = Math.min(...weights);
  const max = Math.max(...weights);
  const range = max - min;
  const levels = (1 << bits) - 1;  // 255 for 8-bit, 65535 for 16-bit
  const scale = range / levels;
  const zeroPoint = Math.round(-min / scale);

  const quantized = Array.from(weights).map(w =>
    Math.round((w - min) / scale)
  );

  return { quantized, scale, zeroPoint };
}

// Dequantize back to float
function dequantize(quantized: number[], scale: number, zeroPoint: number): number[] {
  return quantized.map(q => (q - zeroPoint) * scale);
}

// The error between original and quantized weights is small
// Accuracy typically drops < 2% for int8 quantization`}
</CodeBlock>

## Saving Quantized Models

<CodeBlock language="typescript" title="save-quantized.ts">
{`// TensorFlow.js supports quantization during model saving
// This is the easiest way to quantize in practice

async function saveQuantized(model: tf.LayersModel, path: string) {
  // Save with uint16 quantization (2 bytes per weight)
  await model.save(\`file://\${path}\`, {
    quantizationBytes: 2,  // 1 = uint8, 2 = uint16
  });
}

// Size comparison for DEEP SCAN:
// float32 (no quantization): 340 MB, accuracy: 94.2%
// float16 (quantizationBytes: 2): 170 MB, accuracy: 94.0% (-0.2%)
// uint8   (quantizationBytes: 1): 85 MB,  accuracy: 93.0% (-1.2%)`}
</CodeBlock>
