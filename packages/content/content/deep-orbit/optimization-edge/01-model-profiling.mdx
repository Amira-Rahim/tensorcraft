The bundle audit Demir filed under "later" is now exhibit one: the crew's trained models total under a megabyte; the pretrained language component and its tables carry almost all of the 340. Profiling a model means three measurements: memory footprint, inference latency (mean and tail), and which layers hold the parameters. Get all three before touching a single weight; the numbers decide where the knife goes.

<CodeBlock language="typescript" title="profiling.ts">
{`import * as tf from '@tensorflow/tfjs';

interface ModelProfile {
  memorySizeMB: number;
  parameterCount: number;
  inferenceMeanMs: number;
  inferenceP95Ms: number;
  layerBreakdown: { name: string; params: number; outputShape: number[] }[];
}

// createInput is a callback, not a shape: a profiler that builds its own
// tf.randomNormal only works on models whose first layer takes floats.
async function profileModel(model: tf.LayersModel, createInput: () => tf.Tensor): Promise<ModelProfile> {
  // Live tensor memory the backend is holding right now. Not the same
  // number as the weight bytes below: tf.memory() counts every tensor
  // currently allocated, including the ones a sloppy loop forgets to
  // dispose.
  const residentBytesBefore = tf.memory().numBytes;

  // Parameter count
  const parameterCount = model.countParams();
  // float32 = 4 bytes. Divide by 1e6, not 1024^2: everyone who will read your
  // report quotes model size in MB, and 1024^2 gives you MiB wearing an MB
  // label. It is the difference between reporting 324.2 and 340.0 for the
  // same weights, and the second one is the number Nazari is holding.
  const memorySizeMB = (parameterCount * 4) / 1e6;

  // Layer breakdown
  const layerBreakdown = model.layers.map(layer => ({
    name: layer.name,
    params: layer.countParams(),
    outputShape: layer.outputShape as number[],
  }));

  // Inference timing (warm up + 100 iterations). The warmup call pays the
  // one-off compilation cost, and it runs outside the loop below, so that
  // cost does not land in the average. Read its result back the same way
  // the timed calls do, then throw the result away.
  const warmupInput = createInput();
  const warmupOutput = model.predict(warmupInput) as tf.Tensor;
  await warmupOutput.data();
  warmupOutput.dispose();
  warmupInput.dispose();

  const times: number[] = [];
  for (let i = 0; i < 100; i++) {
    const input = createInput();
    const start = performance.now();
    const output = model.predict(input) as tf.Tensor;
    // Module 4's benchmarking rule applies to profiles too: read the
    // result back INSIDE the timed region, or on GPU backends you are
    // profiling how fast you can enqueue GPU kernels, not run them, and
    // every mean and P95 below is fiction.
    await output.data();
    times.push(performance.now() - start);
    output.dispose();
    input.dispose();
  }

  times.sort((a, b) => a - b);

  // If this is not zero the loop leaked, and every number below was
  // measured on a backend still holding the garbage.
  const leakedBytes = tf.memory().numBytes - residentBytesBefore;
  if (leakedBytes !== 0) console.warn('Leaked bytes while profiling:', leakedBytes);

  return {
    memorySizeMB,
    parameterCount,
    inferenceMeanMs: times.reduce((a, b) => a + b) / times.length,
    inferenceP95Ms: times[Math.floor(times.length * 0.95)],
    layerBreakdown,
  };
}

// The 340 MB here is the pretrained language component from the bundle
// audit. It opens with an embedding lookup, so it takes 80 token ids, not
// the eleven-feature float vector the signal classifier reads. Hand it
// randomNormal and the lookup throws: "GatherV2: the index value -2 is not
// in [0, 49999]". 50,000 is the tokenizer vocabulary, 256 dims wide, which
// is the 12,800,000 row below. The rest of the shape: a flatten over the 80
// positions (80 * 256 = 20,480 features), a 3,320-unit hidden layer
// ((20,480 + 1) * 3,320 = 67,996,920) and a 1,264-unit output layer
// ((3,320 + 1) * 1,264 = 4,197,744). Every row in the breakdown is one of
// those products, so you can check the profiler against the architecture.
const profile = await profileModel(model, () => tf.randomUniform([1, 80], 0, 50000, 'int32'));
console.log('Model size:', profile.memorySizeMB.toFixed(1), 'MB');
console.log('Parameters:', profile.parameterCount.toLocaleString());
console.log('Inference mean:', profile.inferenceMeanMs.toFixed(1), 'ms');
console.log('Inference P95:', profile.inferenceP95Ms.toFixed(1), 'ms');

// A total tells you the model is too big. A share tells you where to cut.
console.log('Layer breakdown:');
for (const layer of profile.layerBreakdown) {
  const share = (layer.params / profile.parameterCount) * 100;
  console.log(\`  \${layer.name.padEnd(22)}\${layer.params.toLocaleString().padStart(12)}  \${share.toFixed(1)}%\`);
}

// DEEP SCAN, as it stood at 0249:
//
//   Model size: 340.0 MB
//   Parameters: 84,994,664
//   Inference mean: 45.0 ms
//   Inference P95: 112.0 ms
//   Layer breakdown:
//     embedding_Embedding1    12,800,000  15.1%
//     flatten_Flatten1                 0  0.0%
//     dense_Dense1            67,996,920  80.0%
//     dense_Dense2             4,197,744  4.9%
//
// Both timings are wasm-backend numbers: the dashboard had no working
// WebGL context that night, so the profile ran on the fallback.
//
// The flatten row is in there because the loop walks model.layers, not
// only the layers that hold weights. It reshapes the embedding's 80 by 256
// output into 20,480 values and owns nothing, so its share is 0.0%.
// Rounded to millions the bundle is the 85 million weights Nazari quotes.
// The profiler prints the exact count, and 84,994,664 float32 weights are
// 340.0 MB.
//
// Read the shares, not the total. 80% of this model is one Dense layer, so
// that layer holds most of the 340 MB. The 45 ms mean and the 112 ms P95 are
// the latency baseline, not an explanation of the crash: the dashboard died
// with the free-memory line at zero, 340 MB of weights loading into a 512 MB
// budget. In that baseline the tail is the number to gate on. It is 2.5x the
// mean, so a budget written against the mean alone misses one call in twenty.
// Both numbers survive into module 11; neither was a guess.`}
