Train in PyTorch, export once, run anywhere — that is the pitch, and Nazari has already told you what she thinks of pitches. ONNX (Open Neural Network Exchange) is ML's attempt at a web standard: a shared format that any compliant runtime can execute, regardless of which framework trained the model. It carries the same fine print every web standard does — "universal" means "universal where implemented."

// npm install onnxruntime-web
import * as ort from 'onnxruntime-web';

// Load an ONNX model (exported from PyTorch, TF, sklearn, etc.)
const session = await ort.InferenceSession.create('/models/deep-scan.onnx', {
  executionProviders: ['wasm'],  // 'wasm' or 'webgl'
});

// Check model inputs/outputs — like inspecting an API schema
console.log('Inputs:', session.inputNames);    // ['input']
console.log('Outputs:', session.outputNames);  // ['output']

// Create input tensor
const inputData = new Float32Array([0.5, 0.3, 0.7]);  // normalized signal
const inputTensor = new ort.Tensor('float32', inputData, [1, 3]);

// Run inference
const results = await session.run({ input: inputTensor });
const output = results.output;
console.log('Prediction:', output.data[0]);  // 0.847`}

## TF.js vs ONNX Runtime: Head-to-Head

<CodeBlock language="typescript" title="benchmark-comparison.ts">
{`import * as tf from '@tensorflow/tfjs';
import * as ort from 'onnxruntime-web';

interface BenchmarkResult {
  runtime: string;
  coldStartMs: number;
  avgInferenceMs: number;
  memoryMB: number;
}

// Benchmark TensorFlow.js
async function benchmarkTFJS(): Promise<BenchmarkResult> {
  const t0 = performance.now();
  const model = await tf.loadLayersModel('/models/deep-scan/model.json');
  const coldStartMs = performance.now() - t0;

  // Warm up
  const warmup = tf.tensor2d([[0.5, 0.3, 0.7]]);
  (model.predict(warmup) as tf.Tensor).dispose();
  warmup.dispose();

  // Sustained inference (100 iterations)
  const times: number[] = [];
  for (let i = 0; i < 100; i++) {
    const start = performance.now();
    tf.tidy(() => {
      const input = tf.tensor2d([[Math.random(), Math.random(), Math.random()]]);
      model.predict(input);
    });
    times.push(performance.now() - start);
  }

  return {
    runtime: 'TF.js (WebGL)',
    coldStartMs,
    avgInferenceMs: times.reduce((a, b) => a + b, 0) / times.length,
    memoryMB: tf.memory().numBytes / (1024 * 1024),
  };
}

// Benchmark ONNX Runtime
async function benchmarkONNX(): Promise<BenchmarkResult> {
  const t0 = performance.now();
  const session = await ort.InferenceSession.create('/models/deep-scan.onnx');
  const coldStartMs = performance.now() - t0;

  // Sustained inference (100 iterations)
  const times: number[] = [];
  for (let i = 0; i < 100; i++) {
    const input = new ort.Tensor('float32',
      new Float32Array([Math.random(), Math.random(), Math.random()]), [1, 3]);
    const start = performance.now();
    await session.run({ input });
    times.push(performance.now() - start);
  }

  return {
    runtime: 'ONNX (WASM)',
    coldStartMs,
    avgInferenceMs: times.reduce((a, b) => a + b, 0) / times.length,
    memoryMB: 0, // WASM memory tracked separately
  };
}

// Typical results for a small signal classifier:
// TF.js (WebGL):  cold=340ms, inference=2.1ms, mem=0.8MB
// ONNX (WASM):    cold=180ms, inference=3.8ms, mem=1.2MB`}
</CodeBlock>

## When to Choose Which

| Factor | TF.js | ONNX Runtime Web |
|--------|-------|-------------------|
| **Ecosystem** | Largest (React of ML) | Growing (Vue of ML) |
| **GPU acceleration** | WebGL (excellent) | WebGL (experimental) |
| **Python interop** | Export from TF/Keras | Any framework via ONNX export |
| **Cold start** | Slower (WebGL shader compilation) | Faster (WASM) |
| **Sustained speed** | Faster (GPU shaders cached) | Good (SIMD-optimized WASM) |
| **Memory management** | Manual (tf.tidy/dispose) | Automatic (GC) |
| **Bundle size** | ~800KB | ~600KB |

For DEEP SCAN: TF.js wins on sustained inference (the dashboard runs continuously). ONNX wins on cold start (backup system that loads on demand). Nazari's decision to use both is pragmatic engineering.
