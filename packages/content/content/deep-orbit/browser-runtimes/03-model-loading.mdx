You download it like an asset. You manage it like a process.

The model's architecture lives in `model.json`; the learned weights live in binary `.bin` shards alongside it. `tf.loadLayersModel()` fetches both over HTTP and assembles the model in memory.

## The Fetch Pattern You Already Know

<CodeBlock language="typescript" title="model-loading.ts">

// Loading a model is a fetch with extra steps
// model.json contains the architecture (layers, shapes, activations)
// group1-shard1of1.bin contains the learned weights (Float32Array)
const model = await tf.loadLayersModel('/models/deep-scan/model.json');

Under the hood, `tf.loadLayersModel()` does exactly what you'd do manually:

// 1. Fetch the manifest (architecture)
const manifest = await fetch('/models/deep-scan/model.json').then(r => r.json());
// manifest.modelTopology = layer config (Dense, activation, shapes)
// manifest.weightsManifest = list of .bin files and their tensor names

// 2. Fetch the weight binaries
const weightData = await fetch('/models/deep-scan/group1-shard1of1.bin')
  .then(r => r.arrayBuffer());
// Raw Float32 values — the numbers the network learned during training

// 3. Reconstruct the model from architecture + weights
// tf.loadLayersModel() handles all of this in one call`}
</CodeBlock>

## Caching with IndexedDB

Models run 5-50MB. You don't re-download that on every page load, for the same reason your static assets sit behind a service worker.

<CodeBlock language="typescript" title="model-caching.ts">
{`import * as tf from '@tensorflow/tfjs';

const MODEL_URL = '/models/deep-scan/model.json';
const CACHE_KEY = 'indexeddb://deep-scan-v1';

async function loadModelWithCache(): Promise<tf.LayersModel> {
  try {
    // Try loading from IndexedDB cache first
    const cached = await tf.loadLayersModel(CACHE_KEY);
    console.log('Loaded from cache');
    return cached;
  } catch {
    // Cache miss — fetch from server and save to IndexedDB
    console.log('Cache miss — fetching from server');
    const model = await tf.loadLayersModel(MODEL_URL);
    await model.save(CACHE_KEY);  // saves to IndexedDB
    console.log('Saved to cache');
    return model;
  }
}

// Usage — first load fetches from network, subsequent loads hit cache
const model = await loadModelWithCache();

// Check what's cached
const savedModels = await tf.io.listModels();
console.log(savedModels);
// { 'indexeddb://deep-scan-v1': { dateSaved: '...', modelTopologyBytes: 1234, ... } }

// Clear cache when deploying a new model version
await tf.io.removeModel(CACHE_KEY);`}
</CodeBlock>

Check cache first, fall back to network, store for next time. And remove the cached entry when you ship a new model version, or users keep running the old weights.

## Loading States in the UI

<CodeBlock language="typescript" title="loading-ui.ts">
{`import * as tf from '@tensorflow/tfjs';

type ModelState =
  | { status: 'idle' }
  | { status: 'loading'; progress: number }
  | { status: 'ready'; model: tf.LayersModel }
  | { status: 'error'; message: string };

async function loadWithProgress(
  url: string,
  onProgress: (state: ModelState) => void,
): Promise<tf.LayersModel> {
  onProgress({ status: 'loading', progress: 0 });

  try {
    const model = await tf.loadLayersModel(url, {
      onProgress: (fraction) => {
        // fraction goes from 0 to 1 as weight shards download
        onProgress({ status: 'loading', progress: fraction });
      },
    });

    onProgress({ status: 'ready', model });
    return model;
  } catch (err) {
    const message = err instanceof Error ? err.message : 'Failed to load model';
    onProgress({ status: 'error', message });
    throw err;
  }
}

</CodeBlock>
