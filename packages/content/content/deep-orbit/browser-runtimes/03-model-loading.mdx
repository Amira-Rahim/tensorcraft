## Where the Two Files Come From

The training module kept this network in memory. `model.save()` exports its architecture and learned weights so another app can load them. These examples write one JSON manifest and one weight file.

<CodeBlock language="typescript" title="export.ts">
{`// Node, with @tensorflow/tfjs-node installed: writes model.json and
// weights.bin into ./models/deep-scan/, the exact pair the loader wants.
await model.save('file://./models/deep-scan');

// Browser: this downloads two files, named off the prefix you pass.
// 'downloads://deep-scan' gives you deep-scan.json and
// deep-scan.weights.bin. Serve both with those names and load deep-scan.json.
// If you rename the weight file, update weightsManifest.paths inside the
// JSON too; renaming the files alone leaves the loader requesting a missing shard.
await model.save('downloads://deep-scan');

// For this classifier, the weight shard holds 673 float32 values: 2,692 bytes.`}
</CodeBlock>

A model trained in Python arrives by a different route. `tensorflowjs_converter` can produce a LayersModel from a supported Keras export or a GraphModel from a supported SavedModel. Both use JSON and weight shards, but load a GraphModel with `tf.loadGraphModel()`, not `tf.loadLayersModel()`. Converters such as `tf2onnx` serve a different route to ONNX; lesson 5 uses a small exporter for this course's exact dense network.

## Caching with IndexedDB

A URL load requests the manifest and weight files. HTTP or service-worker caching may serve those files without another full download. IndexedDB gives the app a model copy it can load explicitly.

DEEP SCAN’s float32 weights take only 2,692 bytes, excluding the manifest and runtime. The main benefit here is working when the compute-bay link fails. The IndexedDB copy can keep predictions running if the page, runtime and all other required files are also available offline. It also needs a versioning plan: later in this lesson, the cached model and retrained model disagree about a reading.

<CodeBlock language="typescript" title="model-caching.ts">
{`import * as tf from '@tensorflow/tfjs';

const MODEL_URL = '/models/deep-scan/model.json';
const CACHE_KEY = 'indexeddb://deep-scan-v1';

async function loadModelWithCache(): Promise<tf.LayersModel> {
  try {
    // Try loading from IndexedDB cache first
    const cached = await tf.loadLayersModel(CACHE_KEY);
    console.log('Loaded from cache');
    return cached;
  } catch {
    // Cache miss: fetch from server and save to IndexedDB
    console.log('Cache miss; fetching from server');
    const model = await tf.loadLayersModel(MODEL_URL);
    try {
      await model.save(CACHE_KEY);
    } catch (error) {
      // A quota or storage-permission failure must not discard a usable model.
      console.warn('Model ready, but unavailable offline:', error);
    }
    return model;
  }
}

// Usage: first load fetches from network, subsequent loads hit cache
const model = await loadModelWithCache();

// Check what's cached
const savedModels = await tf.io.listModels();
console.log(savedModels);
// { 'indexeddb://deep-scan-v1': { dateSaved: '...', modelTopologyBytes: 1234, ... } }

// Shipping new weights means a new key: CACHE_KEY becomes
// 'indexeddb://deep-scan-v2', and nothing reads the v1 entry after that.
// After v2 is loaded and verified, removeModel frees the old bytes.
// Do not delete your current offline copy immediately after saving it.
// await tf.io.removeModel('indexeddb://deep-scan-v1');`}
</CodeBlock>

Try the cache first. If it is missing, download the model and try to save a copy. A failed download prevents loading. A failed cache write does not: the downloaded model is already usable in memory. Browser storage can be cleared or evicted, so test both cache hits and misses.

When the weights change, use a new version in the cache key. Otherwise, users keep loading the old weights. Once the new version is loaded and verified, remove the unused old entry to free storage.

## Loading States in the UI

<CodeBlock language="typescript" title="loading-ui.ts">
{`import * as tf from '@tensorflow/tfjs';

type ModelState =
  | { status: 'idle' }
  | { status: 'loading'; progress: number }
  | { status: 'ready'; model: tf.LayersModel }
  | { status: 'error'; message: string };

async function loadWithProgress(
  url: string,
  onProgress: (state: ModelState) => void,
): Promise<tf.LayersModel> {
  onProgress({ status: 'loading', progress: 0 });

  try {
    const model = await tf.loadLayersModel(url, {
      onProgress: (fraction) => {
        // fraction goes from 0 to 1 as weight shards download
        onProgress({ status: 'loading', progress: fraction });
      },
    });

    onProgress({ status: 'ready', model });
    return model;
  } catch (err) {
    const message = err instanceof Error ? err.message : 'Failed to load model';
    onProgress({ status: 'error', message });
    throw err;
  }
}
