## Three Browser ML Runtimes, Three Jobs

Transformers.js adds task-specific preprocessing and output handling around pretrained models. Its browser inference uses ONNX Runtime. The tools overlap; choose based on the model and application you need.

<BridgeCallout bridge={frontmatter.concept.bridge} />

| Tool | Useful when | Check before shipping |
|---|---|---|
| TensorFlow.js | You need its training APIs or a supported TFJS model | Backend support, model behavior and size |
| ONNX Runtime Web | You have a compatible ONNX graph and can supply preprocessing | Operators, input/output contract and numerical parity |
| Transformers.js | A supported pipeline fits your NLP, vision or audio task | Model license, domain performance, asset sizes and latency |

A custom task does not automatically require training from scratch. Check whether an existing model, adaptation or an ordinary rule meets the need. A convenient pipeline API does not establish that the model is suitable.

## Pipeline in Ten Lines

<CodeBlock language="typescript" title="sentiment-pipeline.ts">
{`// The package moved from '@xenova/transformers' to the official
// '@huggingface/transformers' at v3; old tutorials cite the former.
import { pipeline } from '@huggingface/transformers';

// Pin model, revision, dtype and device when reproducing results.
const classifier = await pipeline(
  'sentiment-analysis',
  'Xenova/distilbert-base-uncased-finetuned-sst-2-english',
  {
    revision: '0b6928efcb76139cae2c6881d49cda67fe119f42',
    dtype: 'q8',
    device: 'wasm',
  },
);
try {
  const reports = [
    'Starboard array cleared diagnostics ahead of schedule.',
    'Sensor array is functioning within tolerance.',
    'Catastrophic failure on the port-side coupling.',
    'Signal classification: anomalous.',
  ];
  const predictions = await classifier(reports);
  console.table(reports.map((text, i) => ({ text, ...predictions[i] })));
} finally {
  await classifier.dispose();
}`}
</CodeBlock>

The first load may download model weights, tokenizer assets and the runtime. Browser Cache Storage can retain model assets, but quota, eviction and browser settings affect it. A cache hit still needs asset reads, initialization and inference. TFJS's `indexeddb://` model storage uses a different browser API.

The real lab runs this revision with both `q8` and `fp32`, records exact asset sizes and scores, and reloads the q8 pipeline with the network disabled after initialization. Run `node scripts/check-runtime-lab.mjs --pretrained`; setup and measurement limits are in the [browser runtime lab README](/assignments/browser-runtime-lab-v1.zip). Do not expect scores from different dtypes or runtimes to match exactly.

## Tasks the Pipeline Handles Out of the Box

```
sentiment-analysis          NER (named entities)        question-answering
translation                 summarization               text-generation
image-classification        image-segmentation          image-to-text (caption)
zero-shot-classification    feature-extraction          automatic-speech-recognition
```

The pipeline supplies task-specific preprocessing, inference and output handling. Not every model supports every pipeline. Inspect the model's supported task and required assets before using it.

This model uses ONNX, so TensorFlow.js tools such as `model.layers` and `tensorflowjs_converter` do not apply. Use tools that support the ONNX model. You cannot assume that any transformer can be converted to a TFJS LayersModel. DEEP SCAN was trained in TensorFlow.js and stays there.

Aboard the Archimedes the download comes from the ship's mirrored model archive, synced at the last relay pass; the live Hub is eleven light-minutes of latency away on a good day. A local mirror changes where the assets come from. It does not remove cache eviction, versioning or cold-start work.

## Check the Model Against the Task

The selected sentiment model was fine-tuned on SST-2 movie-review sentences. Crew status reports are operational text. Its labels are POSITIVE and NEGATIVE; it has no neutral or “needs human attention” label. A high softmax score expresses the model's preference among its trained labels, not a calibrated probability that a report has been understood correctly.

Label representative reports before inspecting the model's predictions. Compare mistakes and the current manual process. Keep an untouched evaluation set if you use earlier examples to choose prompts, models or thresholds. Twenty reports can reveal an obvious mismatch; they cannot establish a reliable rare-error rate.

Mirza's confidence ordering is a workflow experiment. Test whether it helps her find reports needing attention. It is not a measure of crew morale, severity or urgency.

Download size can make browser inference impractical for a target connection. Measure the selected files and startup on that connection. Prefetching may reduce waiting later, but cannot guarantee a cold-start deadline when assets are missing or the network is unavailable. Transformers.js provides inference, not a browser training loop; fine-tuning needs separate tooling and a compatible export.
