Backwards, in one important way. Your keyframes are steps you authored for that one animation. The FFT does not invent its steps. It projects every signal onto the same fixed basis of sinusoids, N complex basis functions for an N-sample window, and returns a complex coefficient for each: magnitude and phase. One vocabulary check, because "complex" is the wrong scare word: a complex coefficient here is just a PAIR of numbers per frequency, how much of that frequency is present and where its peaks sit in time. `tf.abs()` throws away the where and keeps the how-much, and the how-much is the only half of the transform's output this course reads. DEEP SCAN's third input feature is also called phase, but that one is a time-domain angle taken off the first two samples of a window, not this one; lesson 4 builds it and says so. The full transform of N samples produces N such coefficients, but for a real-valued signal the top half mirrors the bottom half, so `tf.spectral.rfft` returns the floor(N/2)+1 bins that carry unique information.

## Decomposing Signals

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="fft-basics.ts">
{`import * as tf from '@tensorflow/tfjs';

// A signal made of two sine waves: 5 Hz and 20 Hz
const sampleRate = 128;  // samples per second
const duration = 1;      // 1 second
const n = sampleRate * duration;

const signal: number[] = [];
for (let i = 0; i < n; i++) {
  const t = i / sampleRate;
  signal.push(
    1.0 * Math.sin(2 * Math.PI * 5 * t) +    // 5 Hz component (strong)
    0.3 * Math.sin(2 * Math.PI * 20 * t)      // 20 Hz component (weak)
  );
}

// Compute the FFT: decompose into frequencies
const signalTensor = tf.tensor1d(signal);
const fftResult = tf.spectral.rfft(signalTensor);     // complex-valued output
const magnitudes = tf.abs(fftResult);                   // get magnitude of each frequency
const magArray = await magnitudes.array();

// Each index corresponds to a frequency bin:
// bin[i] = i * (sampleRate / n) Hz
// bin[0] = 0 Hz (DC offset)
// bin[5] = 5 Hz  → magnitude ≈ 64.0 (strong!)
// bin[20] = 20 Hz → magnitude ≈ 19.2 (weaker)
// All others ≈ 0 (no other frequencies present)

console.log('5 Hz magnitude:', magArray[5].toFixed(1));   // ~64.0
console.log('20 Hz magnitude:', magArray[20].toFixed(1));  // ~19.2
console.log('10 Hz magnitude:', magArray[10].toFixed(1));  // ~0.0

// Clean up
signalTensor.dispose();
fftResult.dispose();
magnitudes.dispose();`}
</CodeBlock>

## Understanding the Output

For a real-valued signal, `rfft` transforms an array of N time-domain samples into floor(N/2)+1 frequency bins. Each bin tells you how much of that frequency is present in the signal.

<CodeBlock language="typescript" title="fft-interpretation.ts">
{`import * as tf from '@tensorflow/tfjs';

// The key relationship: bin index → frequency
function binToFrequency(binIndex: number, sampleRate: number, fftSize: number): number {
  return binIndex * (sampleRate / fftSize);
}

// For our signal: sampleRate=128, fftSize=128
// bin 0  → 0 Hz   (DC coefficient: sum of samples, N times their mean)
// bin 1  → 1 Hz
// bin 5  → 5 Hz   ← our first sine wave
// bin 20 → 20 Hz  ← our second sine wave
// bin 64 → 64 Hz  (Nyquist bin for this even-length input)

// Nyquist frequency: half the sample rate. Unambiguous reconstruction
// requires the input band to be strictly below it.
// = sampleRate / 2
// A faster component still shows up, folded down into a lower bin (aliasing)
const nyquist = sampleRate / 2;  // 64 Hz
console.log('Nyquist frequency:', nyquist, 'Hz');

// Every bin, labeled with the frequency it stands for
function spectrum(signal: number[], sampleRate: number): { hz: number; magnitude: number }[] {
  return tf.tidy(() => {
    const magnitudes = tf.abs(tf.spectral.rfft(tf.tensor1d(signal))).arraySync() as number[];
    return magnitudes.map((magnitude, bin) => ({
      hz: binToFrequency(bin, sampleRate, signal.length),
      magnitude,
    }));
  });
}

const bins = spectrum(signal, 128);
console.table(bins.filter((b) => b.magnitude > 1));
// hz  5   magnitude 64.0   (the 1.0 sine: amplitude times N/2)
// hz 20   magnitude 19.2   (the 0.3 sine)
// The other 63 bins, bin 0 included, sit under 2e-6: nothing else is in
// this signal. The loudest entry after bin 0 is the dominant frequency,
// and finding it is the challenge below.`}
</CodeBlock>

## The FFT for DEEP SCAN

One number to keep straight before reading the ship's spectra: the demo above sampled at 128 Hz because two sine waves need nothing more. That caps its spectrum at a 64 Hz Nyquist ceiling. The hull sensor array samples at 256 Hz, so DEEP SCAN's spectra read out to 128 Hz. A component above the ceiling does not disappear. It folds back down and reports at a lower, wrong frequency, and that folding is called aliasing. Feed the demo's 128 Hz sampling a 73.4 Hz tone and the peak comes back near 54.6 Hz, which is 128 minus 73.4, indistinguishable from a real tone sitting there. Use an anti-alias filter before sampling to remove higher-frequency content. Then choose a rate above twice the highest retained frequency, and why an under-sampled capture can plant a line that was never there.

<CodeBlock language="typescript" title="deep-scan-fft.ts">
{`import * as tf from '@tensorflow/tfjs';

// Analyze the deep space signal for anomalous frequencies
function analyzeSignal(signal: number[], sampleRate: number) {
  return tf.tidy(() => {
    const fft = tf.spectral.rfft(tf.tensor1d(signal));
    const magnitudes = tf.abs(fft).arraySync() as number[];

    // Background frequencies declared by this synthetic story fixture
    const naturalFrequencies = new Set([5, 12, 23, 47]);

    // Toy detector: use the median magnitude as a robust reference level.
    // In this noiseless fixture it mostly measures leakage, not physical
    // noise. The factor 100 is chosen for the example, not calibrated to
    // a false-alarm rate. Real thresholds need representative validation.
    const sorted = [...magnitudes].sort((a, b) => a - b);
    const mid = Math.floor(sorted.length / 2);
    const noiseFloor = sorted.length % 2 ? sorted[mid] : (sorted[mid - 1] + sorted[mid]) / 2;
    const threshold = noiseFloor * 100;

    const peaks: { frequency: number; magnitude: number; natural: boolean }[] = [];
    for (let i = 1; i < magnitudes.length; i++) {
      if (magnitudes[i] > threshold) {
        const freq = i * sampleRate / signal.length;  // this bin's frequency
        peaks.push({
          frequency: +freq.toFixed(1),
          magnitude: +magnitudes[i].toFixed(1),
          natural: naturalFrequencies.has(freq),
        });
      }
    }

    return peaks;
  });
}

// Run it on lesson 01's anomalousSignal: 512 samples at the hull rate,
// 256 Hz, which makes every bin 0.5 Hz wide (256 / 512).
analyzeSignal(anomalousSignal, 256);
// [
//   { frequency: 5,    magnitude: 204.8, natural: true },
//   { frequency: 12,   magnitude: 153.6, natural: true },
//   { frequency: 23,   magnitude: 102.4, natural: true },
//   { frequency: 47,   magnitude: 51.2,  natural: true },
//   { frequency: 73.5, magnitude: 12.0,  natural: false },  // ← ANOMALY
// ]
// Each natural magnitude is amplitude x N/2 (0.8 x 256 = 204.8). The
// intruder reads 73.5, not 73.4: its true frequency sits between bins,
// so the grid reports the nearest line, with a small sub-threshold
// shoulder in bin 146 (73.0 Hz). Lesson 05 gives that smearing its
// name: spectral leakage.`}
</CodeBlock>

<DerivationDrawer summary="Discrete Fourier Transform (DFT)">
The DFT decomposes a length-N signal into N complex coefficients, one per frequency:

`X[k] = Σ_{n=0..N-1} x[n] · e^(-2π·i·k·n/N)`

For each frequency index k, this is a sum of input samples weighted by complex sinusoids. The output `X[k]` is complex: the magnitude `|X[k]|` is the amount of frequency k present, the phase `arg(X[k])` is its alignment.

**Inverse:**

`x[n] = (1/N) · Σ_{k=0..N-1} X[k] · e^(2π·i·k·n/N)`

The discrete sample vector is reconstructible from its full DFT in exact arithmetic. This does not undo aliasing or recover data outside the recorded interval.

**Why rfft returns floor(N/2)+1 bins:** for real-valued input, `X[N-k]` is the complex conjugate of `X[k]`; the upper half of the spectrum duplicates the lower half. `rfft` keeps only bins 0 through floor(N/2), the unique ones.

**Cost of naive DFT:** O(N²). For each of N frequencies, sum over N inputs. The FFT algorithm computes the same result in O(N log N), which is what makes real-time spectrograms (next lesson) possible. This course uses the FFT through `tf.spectral.rfft` and never derives the algorithm itself; if you want the recursion, look up Cooley-Tukey.
</DerivationDrawer>
