Farah has kept that frame pinned to the corner of her display since the day she found it: 450 readings down, one column for each of the 64 hull channels. The swell has never gotten a name. Today she drags the old capture to the center of the screen and puts the live plot beside it.

<Dialogue speaker="Dr. Farah">
Same swell, Demir. The day I found the shape, and now, live. Amplitude over time: you see noise with occasional spikes, and this slow breathing nobody has explained. I suspect there's hidden structure: periodic components buried in the noise that only reveal themselves in the frequency domain.

<Dialogue speaker="Ensign Demir">
Two views of the same data? That's like... the DOM and the CSSOM. Same page, completely different representations. The DOM shows structure, the CSSOM shows styling.
</Dialogue>

<Dialogue speaker="Dr. Farah">
As a first sketch. But the DOM and CSSOM are both lossless views of markup someone wrote. The frequency view is a lossless view of the samples we captured, and the samples are not the whole signal. We sample at a finite rate and cut finite windows, and both of those throw things away before the transform runs. The time domain shows you *when* things happen. The frequency domain shows you *what repeats*, inside what we kept.
</Dialogue>

The rest of this lesson is learning to read that second view.

## Two Views, One Signal

<CodeBlock language="typescript" title="dual-representation.ts">
{`// TIME DOMAIN: amplitude at each sample
// Like reading the DOM: what is the value at each point in time?
// Twelve samples at 12 Hz, so this is one second holding exactly one cycle.
const timeDomain = [0.5, 0.87, 1.0, 0.87, 0.5, 0.0, -0.5, -0.87, -1.0, -0.87, -0.5, 0.0];
// ^ This looks like... a wave? Hard to tell from raw numbers.

// FREQUENCY DOMAIN: which frequencies are present and how strong
// Like reading the CSSOM: what styles (patterns) are applied?
// Magnitude here is the sketch's own convention: the amplitude of the tone.
// A transform reports something larger. Run rfft on the array above and
// bin 1 comes back at 6.0, the amplitude times half the sample count, and
// that is the unit lesson 2 onward reads its peaks in.
const frequencyDomain = [
  { frequency: 1, magnitude: 1.0 },   // a 1 Hz sine wave, full strength
  { frequency: 2, magnitude: 0.0 },   // no 2 Hz component
  { frequency: 3, magnitude: 0.0 },   // no 3 Hz component
];
// ^ Crystal clear: this is a pure 1 Hz sine wave.

// Generate a time-domain signal from known frequencies
function generateSignal(frequencies: { hz: number; amplitude: number }[], samples: number, sampleRate: number): number[] {
  const signal: number[] = [];
  for (let i = 0; i < samples; i++) {
    const t = i / sampleRate;
    let value = 0;
    for (const f of frequencies) {
      value += f.amplitude * Math.sin(2 * Math.PI * f.hz * t);
    }
    signal.push(value);
  }
  return signal;
}

// A signal with three frequencies: easy to define, hard to see in time domain
const complex = generateSignal([
  { hz: 5, amplitude: 0.8 },    // 5 Hz component
  { hz: 12, amplitude: 0.6 },   // 12 Hz component
  { hz: 23, amplitude: 0.4 },   // 23 Hz component
], 256, 256);
// Every one of these lines is in the catalog of known natural frequencies
// (5, 12, 23, 47 Hz), so none of them is anomalous.

console.log(complex.slice(0, 10));
// [0, 0.49, 0.89, 1.15, ...]: a shapeless wiggle.`}
</CodeBlock>

## Why Frequency Matters for DEEP SCAN

In the time domain, the Sector 7-G capture reads as noise. The frequency domain turns Farah's suspicion into a test you can run: list every frequency present, and any one with no natural source is an anomaly you can point to.

<CodeBlock language="typescript" title="why-frequency.ts">
{`import * as tf from '@tensorflow/tfjs';

// In the time domain, these two signals look almost identical:
const cosmicNoise = generateSignal([
  { hz: 5, amplitude: 0.8 },
  { hz: 12, amplitude: 0.6 },
  { hz: 23, amplitude: 0.4 },
  { hz: 47, amplitude: 0.2 },
], 512, 256);

const anomalousSignal = generateSignal([
  { hz: 5, amplitude: 0.8 },
  { hz: 12, amplitude: 0.6 },
  { hz: 23, amplitude: 0.4 },
  { hz: 47, amplitude: 0.2 },
  { hz: 73.4, amplitude: 0.05 },  // tiny anomalous frequency
], 512, 256);  // hull-array rate: 256 Hz, so 73.4 Hz is representable

// In the time domain: nearly impossible to distinguish
// cosmicNoise[100] = -0.671, anomalousSignal[100] = -0.715

// The transform that makes the difference visible. The challenge below
// runs this exact call on both captures; lesson 2 explains what it does.
const mags = tf.abs(tf.spectral.rfft(tf.tensor1d(anomalousSignal))).arraySync() as number[];
console.log(mags[94].toFixed(1), mags[146].toFixed(1), mags[147].toFixed(1));
// "51.2 3.0 12.0": the 47 Hz we authored, then energy at 73-73.5 Hz
// (bins 146-147 at this run's 0.5 Hz resolution) that no catalog explains.`}
</CodeBlock>
