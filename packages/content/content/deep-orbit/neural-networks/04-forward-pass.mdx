## Data Flows Forward

`ValueError: expected dense_Dense1_input to have shape [null,3] but got array with shape [3]`. That was the bridge display at 0940 this morning, four minutes into the demo slot Nazari had cleared, with Commander Mirza standing behind the console. Demir's reasoning was pure DOM: an event handler receives one event object, so `predict()` should receive one reading — he fed it a flat tensor of three values. Mirza left at minute four. Demir needed eleven more to find the missing batch dimension.

The forward pass itself is the simple part: data enters the first layer, gets transformed, and flows on until it reaches the output. The part that bit Demir is the shapes.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="forward-pass.ts">
{`import * as tf from '@tensorflow/tfjs';

const model = tf.sequential();
model.add(tf.layers.dense({ units: 16, activation: 'relu', inputShape: [3] }));
model.add(tf.layers.dense({ units: 8, activation: 'relu' }));
model.add(tf.layers.dense({ units: 1, activation: 'sigmoid' }));

// Forward pass: push sensor data through the network
const sensorReading = tf.tensor2d([[0.5, 0.8, 0.2]]);  // shape: [1, 3]

// predict() runs the full forward pass
const prediction = model.predict(sensorReading) as tf.Tensor;
console.log(prediction.shape);     // [1, 1]
console.log(prediction.dataSync()); // ~0.5 (random, untrained)

// Shape flow through layers:
// Input:   [1, 3]  → 3 sensor values
// Layer 1: [1, 16] → 16 features detected
// Layer 2: [1, 8]  → 8 higher-level patterns
// Output:  [1, 1]  → probability of anomaly`}
</CodeBlock>

Every input carries a batch dimension, even a batch of one: `[1, 3]`, not `[3]`. The network is built to process stacked readings in parallel, and a single reading is a stack of height one. Shape mismatches are the most common error in ML — and unlike a wrong prop, they fail loudly, at the worst possible moment.
