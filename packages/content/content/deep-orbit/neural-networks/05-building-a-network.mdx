## Assembly Required

Compile the network below, then call `model.predict()` immediately. It runs. It returns a probability. And the number is meaningless, because compilation wires up the optimizer and loss without ever touching the weights, which are still random. Assembly and training are separate steps, the same way composing and mounting a React app is separate from anything the user actually does with it.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="complete-network.ts">
{`import * as tf from '@tensorflow/tfjs';

// 1. Create the model
const model = tf.sequential();

// 2. Add layers (like adding components to your app)
model.add(tf.layers.dense({
  units: 32,
  activation: 'relu',
  inputShape: [3],     // 3 sensor inputs
}));
model.add(tf.layers.dense({ units: 16, activation: 'relu' }));
model.add(tf.layers.dense({ units: 1, activation: 'sigmoid' }));

// 3. Compile (like ReactDOM.render: prepares for execution)
model.compile({
  optimizer: 'adam',              // how to update weights
  loss: 'binaryCrossentropy',    // how to measure error
  metrics: ['accuracy'],          // what to track
});

// 4. Verify with summary
model.summary();
// Layer (type)          Output shape    Param #
// dense_1 (Dense)       [null, 32]      128
// dense_2 (Dense)       [null, 16]      528
// dense_3 (Dense)       [null, 1]       17
// Total params: 673

// 5. Test with a prediction
const testInput = tf.tensor2d([[0.5, 0.8, 0.2]]);
const prediction = model.predict(testInput) as tf.Tensor;
console.log('Initial prediction:', prediction.dataSync());`}
</CodeBlock>

**Compilation options explained:**
- **optimizer** (`'adam'`): The algorithm that adjusts weights during training. Adam is the default choice; it adapts the learning rate automatically.
- **loss** (`'binaryCrossentropy'`): Measures how wrong the predictions are. Binary crossentropy for yes/no classification, MSE for continuous values.
- **metrics** (`['accuracy']`): What to display during training. Accuracy = percentage of correct predictions.
