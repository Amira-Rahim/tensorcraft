## Assembly Required

Assemble the network and call `model.predict()`. Prediction does not require compilation. `compile()` configures the optimizer, loss and metrics used by training; it does not fit or reset the weights. A newly initialized model can emit confident scores without having learned anything useful.

Hidden units need different starting points so they can learn different features. If all their weights start the same, they can keep receiving the same updates. Random starting weights help avoid this. These TensorFlow.js dense layers use Glorot-normal weights and zero biases by default. Change those settings with `kernelInitializer` and `biasInitializer`.

Glorot sets the size of the random weights using the layer's input and output counts. This helps keep values from growing or shrinking too much as they pass through layers. It is a starting rule, not a guarantee. Watch what happens during training.

<CodeBlock language="typescript" title="complete-network.ts">
{`import * as tf from '@tensorflow/tfjs';

// 1. Create the model
const model = tf.sequential();

// 2. Add layers (like registering each stage of the pipeline)
model.add(tf.layers.dense({
  units: 32,
  activation: 'relu',
  inputShape: [3],     // 3 sensor inputs
}));
model.add(tf.layers.dense({ units: 16, activation: 'relu' }));
model.add(tf.layers.dense({ units: 1, activation: 'sigmoid' }));

// 3. Configure training. predict() already works on the initialized weights.
model.compile({
  optimizer: 'adam',              // how to update weights
  loss: 'binaryCrossentropy',    // how to measure error
  metrics: ['accuracy'],          // what to track
});

// 4. Verify with summary. TFJS names layers className + counter
// (dense_Dense1, not dense_1) and prints four columns:
model.summary();
// __________________________________________________________________________________________
// Layer (type)                Input Shape               Output shape              Param #
// ==========================================================================================
// dense_Dense1 (Dense)        [[null,3]]                [null,32]                 128
// __________________________________________________________________________________________
// dense_Dense2 (Dense)        [[null,32]]               [null,16]                 528
// __________________________________________________________________________________________
// dense_Dense3 (Dense)        [[null,16]]               [null,1]                  17
// ==========================================================================================
// Total params: 673
// Trainable params: 673
// Non-trainable params: 0
// __________________________________________________________________________________________

// 5. Test with a prediction
const testInput = tf.tensor2d([[0.5, 0.8, 0.2]]);
const prediction = model.predict(testInput) as tf.Tensor;
console.log('Initial prediction:', prediction.dataSync());
tf.dispose([testInput, prediction]);
model.dispose();`}
</CodeBlock>

The compile options have different jobs:

- `optimizer: 'adam'` chooses how to adjust the weights. Adam uses recent gradients and their squares to scale the updates. You still choose a base learning rate.
- `loss: 'binaryCrossentropy'` chooses how to measure errors. This loss is often used for two-class probability models. Mean squared error, or MSE, is often used to predict numerical values. Choose the loss for the task and output format.
- `metrics: ['accuracy']` logs the share of predictions that are correct. It does not choose the training updates.

This practice model reads 8 features through layers of 24, 12, and 1 units. Its parameter count is `(8 × 24 + 24) + (24 × 12 + 12) + (12 + 1) = 529`. The generated inputs have three features that differ by class and five extra noise features.
