## From Unbounded to Useful

Without activation functions, a neural network is stacked linear transformations, and stacked linear maps multiply out to a single matrix: ten layers of pure matrix math collapse into one. Activations break the collapse. They are the only place the network gets to bend.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="activations.ts">
{`import * as tf from '@tensorflow/tfjs';

const raw = tf.tensor([-2, -1, 0, 1, 2]);

// ReLU: max(0, x), the most popular activation
const relu = tf.relu(raw);        // [0, 0, 0, 1, 2]

// Sigmoid: squash to (0, 1), good for probabilities
const sigmoid = tf.sigmoid(raw);   // [0.12, 0.27, 0.5, 0.73, 0.88]

// Tanh: squash to (-1, 1), centered version of sigmoid
const tanh = tf.tanh(raw);         // [-0.96, -0.76, 0, 0.76, 0.96]

// JS equivalent of ReLU:
const jsRelu = [-2, -1, 0, 1, 2].map(x => Math.max(0, x));
// [0, 0, 0, 1, 2]: identical!`}
</CodeBlock>

## Answering the Board

Run Nazari's two readings through the sigmoid and her question answers itself:

<CodeBlock language="typescript" title="negative-eleven.ts">
{`import * as tf from '@tensorflow/tfjs';

const board = tf.tensor([-11, 600]);  // the two scores Nazari read out
tf.sigmoid(board).print();            // [0.0000167, 1]

// -11 squashes to 0.0000167: a no, four zeros deep.
// 600 comes back as exactly 1: the curve is so flat out there that
// float32 has no digits left to hedge with. A yes.
// Two unbounded scores in, two board-ready verdicts out.`}
</CodeBlock>

Placement falls out of the ranges. ReLU stays in the hidden layers, where the outputs feed more math: its slope is exactly 1 for every positive input, so the learning signal you meet in module 3 passes through it undiminished, and it is also the cheapest of the three to compute. Sigmoid takes the output slot when the question is yes/no, because (0, 1) reads as a probability. Tanh takes it when values need to swing negative.

<DerivationDrawer summary="Sigmoid's math, and the classical model built from it">
**Why sigmoid lands strictly inside (0, 1).** The formula is `sigmoid(z) = 1 / (1 + Math.exp(-z))`, where `z` is the raw pre-activation score. `Math.exp(-z)` is positive for every `z`, so the denominator is always bigger than 1 and the division always lands strictly between 0 and 1. At `z = 0`, `Math.exp(0) = 1` and the output is exactly 0.5, which is why the sigmoid line in the code above shows 0.5 in the middle slot. Push `z` positive and `Math.exp(-z)` shrinks toward zero, pulling the output toward 1; push `z` negative and the denominator blows up, pushing the output toward 0. The endpoints are approached, never reached: 600 printed as exactly 1 above only because float32 ran out of digits, not because the math got there.

**The curve is symmetric around 0.5.** `sigmoid(-z) = 1 - sigmoid(z)`: write `1 - sigmoid(z)` as `Math.exp(-z) / (1 + Math.exp(-z))`, multiply top and bottom by `Math.exp(z)`, and you are left with `1 / (Math.exp(z) + 1)`, which is `sigmoid(-z)`. Check it against the printed values: `sigmoid(-1)` is 0.27, and `1 - sigmoid(1)` is `1 - 0.73 = 0.27`. A no is exactly as confident as the mirror-image yes.

**A sigmoid on a weighted sum is a complete model by itself.** Take a single neuron's weighted sum (each input times its weight, plus a bias), put sigmoid in the output slot, and you have **logistic regression**: the classical baseline worth beating before you add a single hidden layer.
</DerivationDrawer>

## When Activations Die

Each choice has a failure mode with a name. A ReLU neuron whose weighted sum stays negative outputs zero forever and stops learning: the dying ReLU. A sigmoid pushed hard into either tail goes flat and stops responding: saturation. Both failures live inside a quantity called the gradient, which you will build in module 3; that is where the crew rounds up these suspects.
