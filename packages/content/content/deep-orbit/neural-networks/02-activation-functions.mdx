## From Unbounded to Useful

Without activation functions, a neural network is stacked linear transformations, and stacked linear maps multiply out to a single matrix: ten layers of pure matrix math collapse into one. Activations break the collapse. They are the only place the network gets to bend.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="activations.ts">
{`import * as tf from '@tensorflow/tfjs';

const raw = tf.tensor([-2, -1, 0, 1, 2]);

// ReLU: max(0, x), the most popular activation
const relu = tf.relu(raw);        // [0, 0, 0, 1, 2]

// Sigmoid: squash to (0, 1), good for probabilities
const sigmoid = tf.sigmoid(raw);   // [0.12, 0.27, 0.5, 0.73, 0.88]

// Tanh: squash to (-1, 1), centered version of sigmoid
const tanh = tf.tanh(raw);         // [-0.96, -0.76, 0, 0.76, 0.96]

// Frontend equivalent of ReLU:
const jsRelu = [-2, -1, 0, 1, 2].map(x => Math.max(0, x));
// [0, 0, 0, 1, 2]: identical!`}
</CodeBlock>

**When to use which:**
- **ReLU**: Default choice for hidden layers. Fast, simple, works well.
- **Sigmoid**: Output layer for binary classification (is this signal anomalous? yes/no).
- **Tanh**: When you need centered outputs (values can be negative).

## When Activations Die

Each choice has a failure mode, and both will matter later in this theme.

ReLU's is the dead neuron. `max(0, x)` outputs zero for every negative input, and zero output means zero gradient: no signal flows back, so the weights feeding it never update. A neuron whose weighted sum goes negative on every training example is not resting, it is dead, and it stays dead. One insurance policy is already visible in the numbers above: a small positive bias keeps the sum above zero early in training.

Sigmoid's is saturation. At z = 5 it outputs 0.9933, which sounds decisive, but its slope there is 0.0066: the curve has gone flat, so a large change in input produces almost no change in output, and almost no gradient. Push a sigmoid hard in either direction and it stops learning in that region. This is why it lives at the OUTPUT layer, where you want a probability, and not in deep stacks of hidden layers. File the phrase "the gradient goes quiet": when a training run flatlines in module 6, this is one of the suspects the crew will round up.
