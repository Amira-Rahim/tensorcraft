## Connect the three layers

Nazari's network has three dense layers and 673 trainable parameters, the weights and biases training will change. The first layer has 32 units. The second has 16. The last has one sigmoid unit that returns a score.

The model reads amplitude, frequency, and phase. Each uses a 0-1 scale based on its sensor's physical range, given in module 4. These are three summaries of a raw capture, rather than one input per sensor channel.

Each summary comes from 64 consecutive samples of one channel. At 256 samples per second, that covers a quarter of a second. The 64 samples are separate from the ship's 64 sensor channels.

Like a middleware chain, each layer reads the previous layer's result, changes it, and passes it on.

A **dense layer** with 32 units contains 32 neurons. Each reads all three inputs using its own weights and bias. ReLU then acts on each of the 32 scores.

The next layer has 16 neurons, each reading those 32 outputs. Its ReLU outputs go to the final neuron. The activations let the stack represent nonlinear patterns. Without them, all these layers would still combine into one affine calculation.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="layer-architecture.ts">
{`import * as tf from '@tensorflow/tfjs';

// Node: compose middleware
// app.use(parseBody);      ← takes the raw request
// app.use(extractFields);  ← transforms it
// app.use(sendResponse);   ← produces the result

// ML: compose layers
const model = tf.sequential();

// First hidden stage: 3 features in, 32 units out
model.add(tf.layers.dense({
  units: 32,
  activation: 'relu',
  inputShape: [3],     // 3 features in
}));

// Second hidden stage: 32 in, 16 out
model.add(tf.layers.dense({
  units: 16,
  activation: 'relu',
}));

// Output layer: binary classification
model.add(tf.layers.dense({
  units: 1,
  activation: 'sigmoid', // bounded binary score; evaluate before trusting it
}));

model.summary(); // prints layer shapes and parameter counts
model.dispose();`}
</CodeBlock>

To count a dense layer's parameters, use `(inputs * units) + units`. Every unit has one weight per input and one bias. Add the three layer counts to get 673.

Only the first layer needs `inputShape`. Later layers get their input count from the previous layer's output. Change the first input shape to `[8]` while keeping 32/16/1 units, and the count becomes 833.

## Check what the network can represent

The stack has 673 parameters. The first lesson's neuron has four: three weights and one bias. More layers can represent patterns that one neuron cannot.

Consider two inputs that can each be 0 or 1. Flag a case only when exactly one input is 1. The four cases are `[0, 0]`, `[0, 1]`, `[1, 0]`, and `[1, 1]`, with labels 0, 1, 1, and 0. Plot them at the corners of a square. One weighted sum and a threshold can only draw one straight dividing line. No such line separates these labels.

This XOR task demonstrates a capacity limit of one affine score with a threshold. More parameters alone do not prove better predictions; the arrangement and nonlinearities matter.

Two ReLU units followed by a sum can represent XOR on binary inputs. You can check this construction without training:

<CodeBlock language="javascript" title="xor-capacity.js">
{`const relu = (x) => Math.max(0, x);
const xor = (a, b) => relu(a - b) + relu(b - a);
const cases = [[0, 0], [0, 1], [1, 0], [1, 1]];
const outputs = cases.map(([a, b]) => xor(a, b)); // [0, 1, 1, 0]
// For a sigmoid output, sigmoid(20 * (xor(a, b) - 0.5)) gives
// the same classes at threshold 0.5. These weights are chosen by hand.`}
</CodeBlock>

Representing a function and learning its weights are different questions. This construction answers the first. A training experiment must answer the second separately; a model can represent a solution yet fail to learn it with a particular initialization and training schedule.

This is a small capacity demonstration, not evidence about the spacecraft data; module 5 widens a reading to eleven features, and stages are what read combinations of them.
