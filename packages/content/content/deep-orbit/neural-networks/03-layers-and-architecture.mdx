## Stages All the Way Down

Three dense layers, 673 trainable parameters. That's the whole system Nazari just asked for: a 32-unit stage that reads the raw sensor values, a 16-unit stage that finds patterns in what the first stage produces, and a single sigmoid unit for the verdict. The composition logic is a middleware chain: each stage takes what the previous stage produced, transforms it, and hands the result on.

Say exactly what a stage is, because "finds patterns" describes the result, not the mechanism. A dense layer with 32 units is 32 copies of the lesson-1 neuron, every one reading the same 3 inputs through its own weights and bias, so the layer emits 32 weighted sums. The 16-unit stage is 16 more neurons whose inputs are those 32 numbers: they vote on combinations of the first stage's votes, and the verdict neuron votes on combinations of theirs. That is the whole trick of depth. Lesson 2 already told you why the activation between stages is not optional: without it, three stages of weighted sums multiply out to one weighted sum, and the stack would know exactly as much as a single neuron.

<CodeBlock language="typescript" title="layer-architecture.ts">
{`import * as tf from '@tensorflow/tfjs';

// Node: compose middleware
// app.use(parseBody);      ← takes the raw request
// app.use(extractFields);  ← transforms it
// app.use(sendResponse);   ← produces the result

// ML: compose layers
const model = tf.sequential();

// Input layer: accepts 3 sensor readings
model.add(tf.layers.dense({
  units: 32,
  activation: 'relu',
  inputShape: [3],     // 3 features in
}));

// Hidden layer: finds patterns
model.add(tf.layers.dense({
  units: 16,
  activation: 'relu',
}));

// Output layer: binary classification
model.add(tf.layers.dense({
  units: 1,
  activation: 'sigmoid', // output 0-1 probability
}));

model.summary(); // prints layer shapes and parameter counts`}
</CodeBlock>

`units` is the only knob here with a price tag. A dense layer holds one weight for every incoming value on every unit, plus one bias per unit: `(inputs * units) + units`. Run that down the three stages above and you get Nazari's 673. Nothing else in the config moves that number.

Demir's first stack quoted 2,369 parameters, on a 64-unit stage he picked because 64 looked like a serious number. Nazari read the quote, said nothing, and went back to her console. The 32/16/1 above is the third version he brought her.
