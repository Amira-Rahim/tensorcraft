## Components All the Way Down

Three dense layers, 673 trainable parameters. That's the whole system Nazari just asked for: a 32-unit stage that reads the raw sensor values, a 16-unit stage that finds patterns in what the first stage produces, and a single sigmoid unit for the verdict. The composition logic comes straight from React, where you build complex UIs out of simple components, each transforming what it receives and passing the result on.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="layer-architecture.ts">
{`import * as tf from '@tensorflow/tfjs';

// React: compose components
// <App>
//   <InputForm />     ← takes user data
//   <ProcessingStep /> ← transforms it
//   <OutputDisplay />  ← shows result
// </App>

// ML: compose layers
const model = tf.sequential();

// Input layer: accepts 3 sensor readings
model.add(tf.layers.dense({
  units: 32,
  activation: 'relu',
  inputShape: [3],     // 3 features in
}));

// Hidden layer: finds patterns
model.add(tf.layers.dense({
  units: 16,
  activation: 'relu',
}));

// Output layer: binary classification
model.add(tf.layers.dense({
  units: 1,
  activation: 'sigmoid', // output 0-1 probability
}));

model.summary(); // prints layer shapes and parameter counts`}
</CodeBlock>

`units` is the only knob here with a price tag: every unit buys the layer one more learnable feature and charges for it in parameters. Nazari's count of 673 comes straight from these three numbers.
