ARIA's rules name them perfectly, every time, and have since launch. The stream out of Sector 7-G is the problem: it is neither tone, and a rule can only recognize the notes somebody wrote down in advance.

## The Simplest Learning Machine

A neuron takes inputs, multiplies each by a weight, sums the products, adds a bias, and emits one number. You've written this exact pattern with `Array.reduce()`.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="first-neuron.ts">
{`import * as tf from '@tensorflow/tfjs';

// A neuron with 3 inputs
const inputs = tf.tensor([0.5, 0.8, 0.2]);   // sensor readings
const weights = tf.tensor([0.4, -0.2, 0.6]);  // learned importance
const bias = tf.scalar(0.1);                   // threshold offset

// The neuron computation: weighted sum + bias
const output = tf.dot(inputs, weights).add(bias);
console.log(output.dataSync()); // [0.26]: raw output

// Compare with the reduce() equivalent:
const jsInputs = [0.5, 0.8, 0.2];
const jsWeights = [0.4, -0.2, 0.6];
const jsOutput = jsInputs.reduce((sum, x, i) => sum + x * jsWeights[i], 0.1);
console.log(jsOutput); // 0.26: identical!`}
</CodeBlock>

Each weight scales its own input: a positive weight pushes the output up, a negative one pushes against it. The bias shifts the decision threshold, the baseline the weighted sum has to clear.

## Reading the Weights

Those three numbers are hand-picked so the arithmetic stays followable; training will overwrite every one of them in module 3. The reading skill transfers to any trained network, though, so practice it here, on inputs that mean amplitude, frequency, and phase.

Sign is direction. Weight 0.4 on amplitude: louder pushes the verdict up, moderately. Weight -0.2 on frequency says this neuron treats higher frequency as mild evidence AGAINST. Run the flip to feel it: change `-0.2` to `+0.2` in the code above and the same reading scores 0.58 instead of 0.26, identical evidence now arguing for the other side.

Magnitude is sensitivity, not importance. A weight says how much the output moves per unit of that input, so the vote an input casts is weight times input. Run the row: amplitude contributes `0.5 * 0.4 = 0.20`, frequency `0.8 * -0.2 = -0.16`, phase `0.2 * 0.6 = 0.12`. Per unit of phase, 0.6 is the loudest coefficient here, and phase still cast the smallest vote, because it read low on this sample. Weight sizes rank inputs against each other only once the inputs share a scale, which is what module 1's z-scoring bought.

A weight near zero means the network learned to ignore something you thought mattered. When Nazari eventually tapes a parameter count to the engineering board, each of those parameters will be one of these numbers; sign and size are the entire vocabulary.
