## The Simplest Learning Machine

A neuron takes inputs, multiplies each by a weight, sums the products, adds a bias, and emits one number. You've written this exact pattern with `Array.reduce()`.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="first-neuron.ts">
{`import * as tf from '@tensorflow/tfjs';

// A neuron with 3 inputs
const inputs = tf.tensor([0.5, 0.8, 0.2]);   // sensor readings
const weights = tf.tensor([0.4, -0.2, 0.6]);  // learned importance
const bias = tf.scalar(0.1);                   // threshold offset

// The neuron computation: weighted sum + bias
const output = tf.dot(inputs, weights).add(bias);
console.log(output.dataSync()); // [0.26]: raw output

// Compare with the reduce() equivalent:
const jsInputs = [0.5, 0.8, 0.2];
const jsWeights = [0.4, -0.2, 0.6];
const jsOutput = jsInputs.reduce((sum, x, i) => sum + x * jsWeights[i], 0.1);
console.log(jsOutput); // 0.26: identical!`}
</CodeBlock>

Weights encode how much each input matters: a positive weight pushes the output up, a negative one pushes against it. The bias shifts the decision threshold, the baseline the weighted sum has to clear.

## Reading the Weights

Those three numbers are hand-picked so the arithmetic stays followable; training will overwrite every one of them in module 3. But the reading skill transfers to any trained network, so practice it here. The inputs are amplitude, frequency, phase. Weight 0.4 on amplitude: louder pushes the verdict up, moderately. Weight -0.2 on frequency: this neuron treats higher frequency as mild evidence AGAINST, and the sign matters more than the size. Weight 0.6 on phase: the strongest opinion in the row, for now, and "for now" is the point. When a debugger shows you a trained layer's weights, this is the whole trick: sign is direction, magnitude is how loudly that input gets to vote, and a weight near zero means the network learned to ignore something you thought mattered. Nazari will eventually tape a parameter count to the engineering board; each of those parameters is one of these votes.
