## A weighted sum of inputs

A neuron multiplies each input by a weight, sums the products, and adds a bias. The `Array.reduce()` expression below computes the same score.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="first-neuron.ts">
{`import * as tf from '@tensorflow/tfjs';

// A neuron with 3 inputs
const inputs = tf.tensor([0.5, 0.8, 0.2]);   // sensor readings
const weights = tf.tensor([0.4, -0.2, 0.6]);  // hand-picked weights
const bias = tf.scalar(0.1);                   // constant added to the score

// The neuron computation: weighted sum + bias
const output = tf.tidy(() => tf.dot(inputs, weights).add(bias));
console.log(output.dataSync()); // Float32Array(1) [ 0.2600000202655792 ]

// Compare with the reduce() equivalent:
const jsInputs = [0.5, 0.8, 0.2];
const jsWeights = [0.4, -0.2, 0.6];
const jsOutput = jsInputs.reduce((sum, x, i) => sum + x * jsWeights[i], 0.1);
console.log(jsOutput); // approximately 0.26. JS and float32 rounding may differ
tf.dispose([inputs, weights, bias, output]);`}
</CodeBlock>

Each weight scales its own input: a positive weight pushes the output up, a negative one pushes against it. The bias adds a constant to the output. If you later compare that output with a threshold, changing the bias moves the decision boundary.

## Reading the Weights

This example uses three fixed weights. Module 3 will show how training changes them. Here, one neuron reads amplitude, frequency, and phase. We can trace each input's effect directly. A deeper network has later layers that also affect the result.

A weight's sign tells you which way its input moves the score. The amplitude weight is `0.4`, so a higher amplitude raises the score. The frequency weight is `-0.2`, so a higher frequency lowers it. Change `-0.2` to `+0.2` above: the score for the same reading rises from 0.26 to 0.58.

A larger weight means the score changes more for each unit of that input. To find the contribution for one reading, multiply input by weight:

- Amplitude: `0.5 * 0.4 = 0.20`.
- Frequency: `0.8 * -0.2 = -0.16`.
- Phase: `0.2 * 0.6 = 0.12`.

Phase has the largest weight, but its contribution of 0.12 is smaller in magnitude than 0.20 and -0.16 because its input is small. All three inputs use the same 0-1 scale, so you can compare their weights as sensitivity per unit. The contribution still depends on the reading.

A weight close to zero means this neuron responds only a little when that input changes by one unit. That does not tell us whether the feature matters elsewhere in the network, or whether it causes the event we want to predict.
