## The Simplest Learning Machine

A neuron is surprisingly simple. It takes inputs, multiplies each by a weight, sums everything up, adds a bias, and outputs a number. You've written this exact pattern with `Array.reduce()`.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="first-neuron.ts">
{`import * as tf from '@tensorflow/tfjs';

// A neuron with 3 inputs
const inputs = tf.tensor([0.5, 0.8, 0.2]);   // sensor readings
const weights = tf.tensor([0.4, -0.2, 0.6]);  // learned importance
const bias = tf.scalar(0.1);                   // threshold offset

// The neuron computation: weighted sum + bias
const output = tf.dot(inputs, weights).add(bias);
console.log(output.dataSync()); // [0.18] — raw output

// Compare with the reduce() equivalent:
const jsInputs = [0.5, 0.8, 0.2];
const jsWeights = [0.4, -0.2, 0.6];
const jsOutput = jsInputs.reduce((sum, x, i) => sum + x * jsWeights[i], 0.1);
console.log(jsOutput); // 0.18 — identical!`}
</CodeBlock>

The weights determine how much each input matters. A large positive weight means "this input is important and supports the output." A negative weight means "this input pushes against the output." The bias shifts the decision threshold.
