## Now prepare the readings yourself

Help Demir create a tensor from the five readings so TensorFlow.js can work
with them. Save its shape to check that it holds five numbers.

<CodeBlock language="javascript" title="prepare-readings.js">
{`const reading = tf.tensor(streamValues);
const shape = reading.shape; // [5]`}
</CodeBlock>

For this list, `streamValues.length` and `reading.shape[0]` both give `5`.
The full **shape** is `[5]`: a list with five numbers. Shape is an array
because a tensor can also have rows and columns, each with its own size.

then releases the tensor's memory. Leave those supplied lines in place.
