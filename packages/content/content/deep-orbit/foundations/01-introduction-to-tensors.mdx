## Prepare the same packet for Farah

Farah needs the individual readings to investigate the signal. An average
alone would hide the differences between them. Help Demir create a **tensor**
that holds the full packet, then read it back to check that nothing is missing.

TensorFlow.js is available as `tf` in the exercise. Create the tensor,
then check its shape and stored values:

<CodeBlock language="javascript" title="prepare-readings.js">
{`const streamValues = [0.12, 0.94, 0.31, 0.88, 0.47];
const reading = tf.tensor(streamValues);

const shape = reading.shape; // [5]
const values = reading.arraySync();

// Provided: release the tensor's memory.
// The copied values remain available.
reading.dispose();`}
</CodeBlock>

The **shape** `[5]` describes one list of five numbers. `arraySync()` copies
them into a JavaScript array. Check that all five readings are present and
in their original order. TensorFlow.js may show tiny rounding differences
in the copied values.
