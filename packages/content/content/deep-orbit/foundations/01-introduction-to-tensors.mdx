## Make the connection in JavaScript

The viewer expects a TensorFlow.js tensor. Create one from `streamValues`,
then save its **shape**, the size of each axis.

<CodeBlock language="javascript" title="prepare-readings.js">
{`const reading = tf.tensor(streamValues);
const shape = reading.shape; // [12]`}
</CodeBlock>

The shape is `[12]`: one axis holding 12 values. It does not tell us which
sensor produced a value. That information comes from the recording’s header.

The supplied viewer code groups the readings by sensor and draws their
lines. Leave that code in place for now. Farah will help you build those
steps in the next mission.

You could plot these values with plain JavaScript too. Here you are connecting
to a TensorFlow.js pipeline that the crew will extend for machine learning.
