## Now prepare the readings yourself

Demir starts his calculation by creating a tensor. Practise that step with
the same five readings, then save the tensor's shape to check how many it holds.

<CodeBlock language="javascript" title="prepare-readings.js">
{`const reading = tf.tensor(streamValues);
const shape = reading.shape; // [5]`}
</CodeBlock>

For this list, `streamValues.length` and `reading.shape[0]` both give `5`.
The full **shape** is `[5]`: one length per dimension. Tensors can also have
rows and columns, so shape is an array.

The starter already copies the readings into a JavaScript array for Farah,
then releases the tensor's memory. Leave those supplied lines in place.
