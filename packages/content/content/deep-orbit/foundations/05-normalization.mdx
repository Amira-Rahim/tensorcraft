## Keep each feature on its own scale

The visual uses the challenge's four rows: `[20, 0.2]`, `[22, 0.8]`,
`[24, 0.4]`, and `[26, 0.6]`. Columns are temperature and signal strength.
Their units differ, so fit one set of statistics per column.

A **z-score** subtracts the column mean and divides by its standard deviation,
its spread around that mean. `tf.moments(batch, 0)` reduces down the rows,
returning each column's mean and population variance. The square root of
variance is the standard deviation.

<CodeBlock language="typescript" title="fit-and-scale.ts">
{`const { mean, variance } = tf.moments(batch, 0);
const std = variance.sqrt();
variance.dispose();

const normalized = tf.tidy(() => {
  const divisor = tf.where(std.equal(0), tf.onesLike(std), std);
  return batch.sub(mean).div(divisor);
});`}
</CodeBlock>

The challenge separates this calculation into `fitStats(rows)` and
`scaleFeatures(rows, offset, scale)`. Return the saved mean and std from the
first function; use the supplied offset and scale in the second.

For this batch, mean is `[23, 0.5]` and std is approximately `[2.236, 0.224]`.
Broadcasting applies those two statistics to every row. `tf.where` chooses
1 for a zero scale so constant training columns become zero, while the saved
statistics stay unchanged. A changed future value then becomes its difference
from the saved offset; the model has not learned that new variation.

Fit statistics on training rows only. Reuse them for validation and future
readings so the same raw value keeps the same meaning.

## Run the fixed preview neuron

The starter supplies Farah's model: two weights `[0.9, -1.4]`, bias `-0.3`,
and sigmoid, a function that maps the weighted sum into 0 to 1. You are
preparing its inputs and running it. Building and training models comes next.
The score is not a calibrated probability.

<CodeBlock language="typescript" title="score-the-scaled-input.ts">
{`const scores = previewModel.predict(normalized); // [4, 1]

// Inspect one of those readings as a one-row batch.
const reading = tf.tensor1d([22, 0.8]);
const oneScore = tf.tidy(() => {
  const divisor = tf.where(std.equal(0), tf.onesLike(std), std);
  const scaled = reading.sub(mean).div(divisor);
  return previewModel.predict(scaled.expandDims(0));
});
reading.dispose();
oneScore.dispose();`}
</CodeBlock>

`predict()` expects a batch. `expandDims(0)` makes one `[2]` reading into a
`[1, 2]` batch. The returned prediction stays alive for its caller; temporary
tensors are released. This path uses saved statistics even after the original
training batch is disposed.

## Compare with min-max scaling

Min-max uses `(value - min) / (max - min)`. Fit each column's bounds with
`batch.min(0)` and `batch.max(0)`, then reuse `scaleFeatures` with the minimum
and range. The same zero-scale rule applies.

<CodeBlock language="typescript" title="min-max-columns.ts">
{`const min = batch.min(0);
const max = batch.max(0);
const range = max.sub(min);
// Pass the minimum and range to your scaleFeatures function.
// Keep min and max; release range after scaling.`}
</CodeBlock>

Nonconstant training columns span 0 to 1. A later value outside the fitted
bounds can fall outside that range. Scaling changes numerical units; it does
not decide which feature contains useful information.

<ConceptReference summary="Reference: choosing a scaler and the supplied neuron">

<BridgeCallout bridge={frontmatter.concept.bridge} />

Z-score centers a nonconstant training column at mean 0 and standard deviation
1. Min-max maps its fitted bounds to 0 and 1. Outliers affect both methods:
they change the mean and spread, or stretch the range. Known physical bounds
can also supply min-max limits.

The population variance used here divides by n. The usual unbiased sample
variance divides by n minus 1; its square root is not an unbiased estimator
of standard deviation. Use the population convention required by this task.

The starter builds the fixed neuron this way:

<CodeBlock language="typescript" title="supplied-preview-neuron.ts">
{`const previewModel = tf.sequential();
previewModel.add(tf.layers.dense({
  units: 1, activation: 'sigmoid', inputShape: [2],
}));
tf.tidy(() => previewModel.setWeights([
  tf.tensor2d([[0.9], [-1.4]]), tf.tensor1d([-0.3]),
]));`}
</CodeBlock>

For `[20, 0.2]`, the scaled row is approximately `[-1.342, -1.342]`.
The weighted sum is about 0.371; sigmoid returns about 0.592. Without scaling,
the temperature term alone is 18 and the output saturates near 1. The weights
have not changed. A confident score does not establish that an input is
familiar or that the answer is correct.
