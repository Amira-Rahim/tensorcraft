## Ensemble Detection

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="ensemble-detector.ts">
{`import * as tf from '@tensorflow/tfjs';

interface DetectionResult {
  isAnomaly: boolean;
  agreement: number;   // detectors that fired, out of 3: evidence, not a probability
  detectors: {
    statistical: { triggered: boolean; zScore: number };
    autoencoder: { triggered: boolean; error: number };
    lstm: { triggered: boolean; predictionError: number };
  };
}

function detectAnomaly(
  signal: number[],
  baseline: { mean: number; std: number },
  autoencoder: tf.LayersModel,
  lstm: tf.LayersModel,
  recentWindow: number[][],
  thresholds: { zScore: number; reconstruction: number; prediction: number },
): DetectionResult {
  // Detector 1: Statistical z-score on the amplitude feature (signal[0]).
  // baseline is amplitude's mean/std over normal-period data, the module's
  // opening lesson. A max over the whole 11-dim vector would fold in the
  // FFT bins' scale and stop measuring amplitude.
  const amplitude = signal[0];
  const zScore = Math.abs(amplitude - baseline.mean) / baseline.std;
  const statTriggered = zScore > thresholds.zScore;

  // Detector 2: Autoencoder reconstruction error
  const reconError = tf.tidy(() => {
    const input = tf.tensor2d([signal]);
    const reconstructed = autoencoder.predict(input) as tf.Tensor;
    return tf.losses.meanSquaredError(input, reconstructed).dataSync()[0];
  });
  const aeTriggered = reconError > thresholds.reconstruction;

  // Detector 3: LSTM prediction deviation
  const predError = tf.tidy(() => {
    const input = tf.tensor3d([recentWindow]);
    // The LSTM (module 6) forecasts the next RAW reading: 3 values.
    // Compare against the raw slice of the live feature vector, not all
    // 11 features; the 8 FFT bins have no forecast to be wrong about.
    const predicted = (lstm.predict(input) as tf.Tensor).dataSync();
    const rawNext = signal.slice(0, 3);
    return rawNext.reduce((sum, v, i) => sum + (v - predicted[i]) ** 2, 0) / rawNext.length;
  });
  const lstmTriggered = predError > thresholds.prediction;

  // Ensemble: count how many detectors agree
  const votes = [statTriggered, aeTriggered, lstmTriggered].filter(Boolean).length;

  return {
    isAnomaly: votes >= 2,  // majority vote
    agreement: votes / 3,   // 2 of 3 is not "67% likely"; it is two independent yeses
    detectors: {
      statistical: { triggered: statTriggered, zScore },
      autoencoder: { triggered: aeTriggered, error: reconError },
      lstm: { triggered: lstmTriggered, predictionError: predError },
    },
  };
}

// The anomalous signal:
// statistical: z=8.7 ✓, autoencoder: error=0.062 ✓, lstm: predError=0.041 ✓
// Agreement: 3 of 3. Every detector fired; none of them says how likely.`}
</CodeBlock>

## The Discovery

While the ensemble votes, Farah runs a script she has been putting off: an interval decomposition. Not the gap between pulses; that number is boring now, 73.4 seconds, steady as a metronome; the crew has known it since the spectrogram lesson. The timing *inside* each pulse. Every pulse, it turns out, is not one event but a train of sub-pulses, and the gaps between them run in Fibonacci proportion: 1, 1, 2, 3, 5, 8, 13, each gap the sum of the two before it. The carrier keeps its clock. The freight it carries keeps a different one.
