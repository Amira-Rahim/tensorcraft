      interface EnsembleVerdict {
        zScore: number | null;
        verdicts: { statistical: boolean; autoencoder: boolean; lstm: boolean };
        votes: number;
        isAnomaly: boolean;
      }

      function detectAnomalyEnsemble(
        window: number[],
        actual: number,
        reconstructionError: number,
        reconThreshold: number,
        predicted: number,
        predTolerance: number,
      ): EnsembleVerdict {
        if (
          !Array.isArray(window) ||
          window.length === 0 ||
          !window.every(Number.isFinite) ||
          !Number.isFinite(actual)
        )
          throw new Error('Invalid window or reading');
        const constant = window.every((value) => value === window[0]);
        const { mean, variance } = tf.tidy(() => {
          const m = tf.moments(tf.tensor1d(window));
          return { mean: m.mean.dataSync()[0], variance: m.variance.dataSync()[0] };
        });
        const std = Math.sqrt(variance);
        const zScore = constant || std === 0 ? null : (actual - mean) / std;

        const verdicts = {
          statistical: zScore === null ? actual !== window[0] : Math.abs(zScore) > 3,
          autoencoder: reconstructionError > reconThreshold,
          lstm: Math.abs(predicted - actual) > predTolerance,
        };
        const votes = [verdicts.statistical, verdicts.autoencoder, verdicts.lstm].filter(Boolean).length;

        return { zScore, verdicts, votes, isAnomaly: votes >= 2 };
      }

In Node, `process.on('uncaughtException')` handles a throw that escaped earlier handlers. It can be a familiar bug. The ensemble is also an escalation point, but its triggers are statistical checks that can be wrong. Two fired here while the amplitude check stayed quiet; that tells us which checks failed, not whether the signal is new. That quiet dial is why sample 7741 sat in the archive for eight days. The alert rule is not one cutoff. The autoencoder detector still uses last lesson's locked cutoff of 1.0, and this reading came back at 6.2, twelve times the highest error any normal signal produced. That detector casts one vote of three, and the alert needs two.

## Ensemble Detection

<CodeBlock language="typescript" title="ensemble-detector.ts">
{`import * as tf from '@tensorflow/tfjs';

interface DetectionResult {
  isAnomaly: boolean;
  agreement: number;   // detectors that fired, out of 3: evidence, not a probability
  detectors: {
    statistical: { triggered: boolean; zScore: number | null };
    autoencoder: { triggered: boolean; error: number };
    lstm: { triggered: boolean; predictionError: number };
  };
}

function detectAnomaly(
  signal: number[],     // the 11 features module 5 z-scored, for the autoencoder
  amplitude: number,    // the same capture's min-max amplitude, 0 to 1
  baseline: { mean: number; std: number },  // amplitude's normal-period mean/std
  autoencoder: tf.LayersModel,
  lstm: tf.LayersModel,
  recentWindow: number[][],
  thresholds: { zScore: number; reconstruction: number; prediction: number },
): DetectionResult {
  // Detector 1: Statistical z-score on the capture's amplitude.
  // Two arrays describe this one capture and they are on different scales.
  // amplitude is what module 4's preprocess hands the classifier: the raw
  // count divided by the sensor's 2048-count full scale, so 0 to 1. signal
  // is what module 5 hands the autoencoder: eleven features z-normalized to
  // mean 0 and std 1. This detector takes the min-max one as its own
  // argument, because baseline is amplitude's mean and std in min-max
  // units, measured over the normal period in this module's first lesson.
  // Passing signal[0] here would divide a z-score by a min-max spread.
  // The count is reported signed, so a dip reads negative, and the gate
  // compares its size: a reading that far below the mean is as far out as one
  // that far above it.
  if (!Number.isFinite(baseline.std) || baseline.std < 0) throw new Error('Invalid baseline spread');
  const zScore = baseline.std === 0 ? null : (amplitude - baseline.mean) / baseline.std;
  const statTriggered = zScore === null ? amplitude !== baseline.mean : Math.abs(zScore) > thresholds.zScore;

  // Detector 2: Autoencoder reconstruction error
  const reconError = tf.tidy(() => {
    const input = tf.tensor2d([signal]);
    const reconstructed = autoencoder.predict(input) as tf.Tensor;
    return tf.losses.meanSquaredError(input, reconstructed).dataSync()[0];
  });
  const aeTriggered = reconError > thresholds.reconstruction;

  // Detector 3: LSTM prediction deviation
  const predError = tf.tidy(() => {
    const input = tf.tensor3d([recentWindow]);
    // The LSTM (module 6) forecasts the next reading's three raw features,
    // and it reads and writes the per-feature z-scores it was trained on.
    // Compare its forecast against those three features on that same
    // scale, not against all 11; the 8 FFT bins have no forecast to be
    // wrong about.
    const predicted = (lstm.predict(input) as tf.Tensor).dataSync();
    const nextFeatures = signal.slice(0, 3);
    return nextFeatures.reduce((sum, v, i) => sum + (v - predicted[i]) ** 2, 0) / nextFeatures.length;
  });
  const lstmTriggered = predError > thresholds.prediction;

  // Ensemble: count how many detectors agree
  const votes = [statTriggered, aeTriggered, lstmTriggered].filter(Boolean).length;

  return {
    isAnomaly: votes >= 2,  // majority vote
    agreement: votes,       // a count of yeses, not a probability: 2 is not "67% likely"
    detectors: {
      statistical: { triggered: statTriggered, zScore },
      autoencoder: { triggered: aeTriggered, error: reconError },
      lstm: { triggered: lstmTriggered, predictionError: predError },
    },
  };
}

// The anomalous signal:
// statistical: z=-0.1 ✗, autoencoder: error=6.2 ✓, lstm: predError=0.041 ✓
// Agreement: 2 of 3. Two detectors fired; neither says how likely.
// The statistical vote stays quiet, and that is the tell: the capture's
// amplitude came in at 0.50, 0.1 sigma under lesson 1's baseline of mean
// 0.52, std 0.15, so the one dial this gate reads is inside its band. For
// scale, the gate opens at 3 sigma. A spike pegged at the sensor's
// full-scale 1.00 is 3.2 sigma, as high as the count goes, because the
// sensor saturates there; a dead channel reading 0.00 is 3.47 sigma the
// other way.
//
// thresholds.prediction is 0.01 here, set the way lesson 4 set the
// reconstruction cutoff: above every forecast miss the LSTM made on the
// calm slice. predError is a mean squared error over the three z-scored
// features, so this reading's 0.041 is four times the gate.`}
</CodeBlock>

Separately computed is not the same as independent. All three detectors score the same capture. The statistical gate reads its amplitude channel min-max normalized, and the autoencoder reads that same channel z-scored, as one of the eleven features it is trying to rebuild. That is one hull sensor read twice through two different scalings. If the sensor drifts, both detectors get the drifted number, and neither can tell that the other got it too. The autoencoder and the LSTM were fitted on the same eleven days of telemetry. The votes can therefore fail together, which is why a majority is not three odds multiplied.

Lesson 2's first run shows the shape of it. 412 contaminated rows taught the autoencoder the 73.4 Hz component, so it rebuilt the anomalous signal at 1.4x baseline and the reading walked past the threshold. The same eleven days sit under the LSTM's training windows. One bad archive takes two votes out at once, and the third is reading a channel one of them already saw. Sample 7741's replay was carried by exactly that pair. Lesson 1's drawer made the point about sensors bolted to one hull, which share their noise. Read 2 of 3 as two checks that failed.

## The Discovery

While the ensemble votes, Farah runs a script she has been putting off: an interval decomposition. Not the gap between pulses; that number is boring now, 73.4 seconds, steady as a metronome; the crew has known it since the spectrogram lesson. The timing *inside* each pulse. Every pulse, it turns out, is not one event but a train of sub-pulses, and the gaps between them run in Fibonacci proportion: 1, 1, 2, 3, 5, 8, 13, each gap the sum of the two before it.

## Challenge

Write the verdict layer: derive the z-score yourself from the eight recent amplitudes you are handed, take the autoencoder's and the LSTM's scores as they arrive, and return the 2-of-3 vote as a count of failed checks. The statistical detector moves off lesson 1's eleven-day baseline onto that window, so the same full-scale reading that scored 3.2 sigma there scores 32 here. The LSTM moves too: there it forecasts one amplitude and its miss is compared in 0-to-1 units, not in this lesson's z-space mean squared error.

A constant window has no standard deviation to divide by. This exercise reports a null z-score and uses an exact equality policy for its statistical vote. Real sensors need a tolerance chosen from their resolution and noise.
