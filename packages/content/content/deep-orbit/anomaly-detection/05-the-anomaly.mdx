      interface EnsembleVerdict {
        zScore: number | null;
        verdicts: { statistical: boolean; autoencoder: boolean; lstm: boolean };
        votes: number;
        isAnomaly: boolean;
      }

      function detectAnomalyEnsemble(
        window: number[],
        actual: number,
        reconstructionError: number,
        reconThreshold: number,
        predicted: number,
        predTolerance: number,
      ): EnsembleVerdict {
        if (
          !Array.isArray(window) ||
          window.length === 0 ||
          !window.every(Number.isFinite) ||
          ![actual, reconstructionError, reconThreshold, predicted, predTolerance].every(Number.isFinite) ||
          reconstructionError < 0 || reconThreshold < 0 || predTolerance < 0
        )
          throw new Error('Invalid window or reading');
        const constant = window.every((value) => value === window[0]);
        const { mean, variance } = tf.tidy(() => {
          const m = tf.moments(tf.tensor1d(window));
          return { mean: m.mean.dataSync()[0], variance: m.variance.dataSync()[0] };
        });
        const std = Math.sqrt(variance);
        if (!Number.isFinite(mean) || !Number.isFinite(std) || (!constant && std === 0)) {
          throw new Error('Window statistics lost precision');
        }
        const zScore = constant ? null : (actual - mean) / std;

        const verdicts = {
          statistical: zScore === null ? actual !== window[0] : Math.abs(zScore) > 3,
          autoencoder: reconstructionError > reconThreshold,
          lstm: Math.abs(predicted - actual) > predTolerance,
        };
        const votes = [verdicts.statistical, verdicts.autoencoder, verdicts.lstm].filter(Boolean).length;

        return { zScore, verdicts, votes, isAnomaly: votes >= 2 };
      }

An ensemble alert also asks for attention, but it comes from statistical checks that can be wrong. Here two checks fired while the amplitude check stayed quiet. That identifies the checks that fired. We still need to find out what caused the signal.

The quiet amplitude check let sample 7741 sit in the archive for eight days. The ensemble now uses three separate checks. The autoencoder keeps last lesson's cutoff of 1.0. This reading scores 6.2, twelve times the highest normal error. That gives one vote. The alert needs two.

<CodeBlock language="typescript" title="ensemble-detector.ts">
{`import * as tf from '@tensorflow/tfjs';

interface DetectionResult {
  isAnomaly: boolean;
  agreement: number;   // number of detectors that fired, out of 3
  detectors: {
    statistical: { triggered: boolean; zScore: number | null };
    autoencoder: { triggered: boolean; error: number };
    lstm: { triggered: boolean; predictionError: number };
  };
}

function detectAnomaly(
  signal: number[],     // 11 features using the AUTOENCODER training scaler
  actualLstmFeatures: number[], // 3 features using the LSTM training scaler
  amplitude: number,    // the same capture's min-max amplitude, 0 to 1
  baseline: { mean: number; std: number },  // amplitude's normal-period mean/std
  autoencoder: tf.LayersModel,
  lstm: tf.LayersModel,
  recentWindow: number[][],
  thresholds: { zScore: number; reconstruction: number; prediction: number },
): DetectionResult {
  if (signal.length !== 11 || actualLstmFeatures.length !== 3 || recentWindow.length === 0 ||
      recentWindow.some(row => row.length !== 3 || !row.every(Number.isFinite)) ||
      ![...signal, ...actualLstmFeatures, amplitude, baseline.mean, ...Object.values(thresholds)].every(Number.isFinite) ||
      Object.values(thresholds).some(value => value < 0)) throw new Error('Invalid detector inputs');
  // Detector 1: check the capture's min-max-scaled amplitude.
  // amplitude is the raw sensor count divided by 2048, giving 0 to 1.
  // signal instead holds eleven z-scored features with mean 0 and std 1.
  // Use amplitude because baseline uses the same min-max units.
  // Using signal[0] would mix incompatible scales.
  // Report a signed z-score, but compare its absolute value with the cutoff.
  // Both unusually low and unusually high readings can trigger a vote.
  if (!Number.isFinite(baseline.std) || baseline.std < 0) throw new Error('Invalid baseline spread');
  const zScore = baseline.std === 0 ? null : (amplitude - baseline.mean) / baseline.std;
  const statTriggered = zScore === null ? amplitude !== baseline.mean : Math.abs(zScore) > thresholds.zScore;

  // Detector 2: Autoencoder reconstruction error
  const reconError = tf.tidy(() => {
    const input = tf.tensor2d([signal]);
    const reconstructed = autoencoder.predict(input) as tf.Tensor;
    if (reconstructed.rank !== 2 || reconstructed.shape[0] !== 1 || reconstructed.shape[1] !== 11) {
      throw new Error('Invalid reconstruction shape');
    }
    return tf.losses.meanSquaredError(input, reconstructed).dataSync()[0];
  });
  if (!Number.isFinite(reconError)) throw new Error('Invalid reconstruction score');
  const aeTriggered = reconError > thresholds.reconstruction;

  // Detector 3: LSTM prediction deviation
  const predError = tf.tidy(() => {
    const input = tf.tensor3d([recentWindow]);
    // The LSTM predicts three features using its own frozen training scaler.
    // Apply that scaler to recentWindow and actualLstmFeatures.
    // The autoencoder may use different training rows and statistics,
    // even when its feature names match.
    const output = lstm.predict(input) as tf.Tensor;
    if (output.rank !== 2 || output.shape[0] !== 1 || output.shape[1] !== 3) {
      throw new Error('Invalid forecast shape');
    }
    const predicted = output.dataSync();
    const nextFeatures = actualLstmFeatures;
    return nextFeatures.reduce((sum, v, i) => sum + (v - predicted[i]) ** 2, 0) / nextFeatures.length;
  });
  if (!Number.isFinite(predError)) throw new Error('Invalid forecast score');
  const lstmTriggered = predError > thresholds.prediction;

  // Ensemble: count how many detectors agree
  const votes = [statTriggered, aeTriggered, lstmTriggered].filter(Boolean).length;

  return {
    isAnomaly: votes >= 2,  // majority vote
    agreement: votes,       // number of checks that fired. This has no calibrated probability meaning
    detectors: {
      statistical: { triggered: statTriggered, zScore },
      autoencoder: { triggered: aeTriggered, error: reconError },
      lstm: { triggered: lstmTriggered, predictionError: predError },
    },
  };
}

// Fictional mission scores:
// statistical: z=-0.1 ✗, autoencoder: error=6.2 ✓, lstm: predError=0.041 ✓
// Two of three checks flag it. This count is not a probability.
// Amplitude is 0.50, about 0.1 sigma below mean 0.52 with std 0.15.
// The 3-sigma check therefore stays quiet.
// At the sensor's maximum of 1.00, the z-score is 3.2.
// At a dead channel's 0.00, it is 3.47 in the other direction.
//
// thresholds.prediction is 0.01, above every LSTM error in the calm slice.
// predError is MSE across three z-scored features.
// This reading's 0.041 is about four times that cutoff.`}
</CodeBlock>

The three detectors run separate calculations, but they can still make related errors. They all read the same capture. The statistical check uses its min-max-scaled amplitude. The autoencoder sees that amplitude again, z-scored, among its eleven features. If the sensor drifts, both receive the changed reading.

The models also use training rows from the same archive, although the LSTM used only its first day. A problem in shared data can affect several votes. You cannot treat those votes as independent probabilities.

In lesson 2, 412 contaminated rows taught the autoencoder to rebuild the 73.4 Hz component. It returned an error only 1.4 times the baseline, below the cutoff, so it missed the anomaly.

The LSTM trained on the archive's first day. If contaminated examples appear in both training sets, both detectors can learn the unwanted pattern. The amplitude check also shares a sensor with the autoencoder. A majority vote can therefore miss an event too. The later replay of sample 7741 relied on the autoencoder and LSTM, the same pair that could share this weakness. As lesson 1's drawer showed, sensors on one hull can also share noise.

## Challenge

Combine the three detector results into one decision. Calculate the z-score from the eight recent amplitudes. Compare the supplied autoencoder and LSTM scores with their cutoffs. Count the failed checks and raise an alert when at least two flag the reading.

This exercise uses a different baseline from lesson 1. The same maximum reading that scored 3.2 sigma against the eleven-day archive scores 32 against this quieter window. The LSTM check also differs from the example above: it predicts one amplitude, and its error uses 0-to-1 amplitude units. The earlier example measures mean squared error on z-scored features.

When every value in the window is identical, its standard deviation is zero. Return a null z-score. For this exercise, an equal new value gives no statistical vote and a different value gives one vote. Real sensors need a tolerance based on measurement precision and noise. If different window values become identical after float32 conversion, reject the calculation. Rounding away a difference does not make the original readings constant.
