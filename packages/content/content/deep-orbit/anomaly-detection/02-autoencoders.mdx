<Dialogue speaker="Dr. Farah">
Z-scores work for simple distributions. But our signals are high-dimensional: amplitude, frequency, phase, plus FFT features. We need a model that learns the full structure of normal signals. An autoencoder compresses and reconstructs. If it can't reconstruct a signal, that signal is anomalous.
</Dialogue>

Think of gzip: it learns patterns in your data and compresses them efficiently. When you decompress, you get back the original. But if you tried to decompress data that was encoded with a completely different pattern set, the output would be garbage. Autoencoders work the same way. They learn to compress and reconstruct "normal," so "abnormal" gets mangled.

## Encoder → Bottleneck → Decoder

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="autoencoder.ts">
{`import * as tf from '@tensorflow/tfjs';

// Build an autoencoder for signal anomaly detection
const inputDim = 11;  // 3 raw features + 8 FFT features

// ENCODER: compress 11 features → 4 (the bottleneck)
const encoder = tf.sequential();
encoder.add(tf.layers.dense({ units: 32, activation: 'relu', inputShape: [inputDim] }));
encoder.add(tf.layers.dense({ units: 16, activation: 'relu' }));
encoder.add(tf.layers.dense({ units: 4, activation: 'relu' }));  // bottleneck

// DECODER: reconstruct 4 → 11
const decoder = tf.sequential();
decoder.add(tf.layers.dense({ units: 16, activation: 'relu', inputShape: [4] }));
decoder.add(tf.layers.dense({ units: 32, activation: 'relu' }));
decoder.add(tf.layers.dense({ units: inputDim }));  // reconstruct original

// Full autoencoder: input → encoder → decoder → reconstruction
const autoencoder = tf.sequential();
autoencoder.add(tf.layers.dense({ units: 32, activation: 'relu', inputShape: [inputDim] }));
autoencoder.add(tf.layers.dense({ units: 16, activation: 'relu' }));
autoencoder.add(tf.layers.dense({ units: 4, activation: 'relu' }));   // bottleneck
autoencoder.add(tf.layers.dense({ units: 16, activation: 'relu' }));
autoencoder.add(tf.layers.dense({ units: 32, activation: 'relu' }));
autoencoder.add(tf.layers.dense({ units: inputDim }));

// Train to reconstruct its own input: input = label
autoencoder.compile({ optimizer: 'adam', loss: 'meanSquaredError' });`}
</CodeBlock>
