      const FIT_OPTIONS = { epochs: 400, batchSize: 16, verbose: 0 };

      async function trainNormalityModel(
        archive: number[][],
        flagged: boolean[],
        providedModel?: tf.Sequential,
      ): Promise<{ model: tf.Sequential; history: tf.History }> {
        if (flagged.length !== archive.length) throw new Error('Mismatched flags');
        const trainingRows = archive.filter((_, i) => !flagged[i]);
        if (!trainingRows.length) throw new Error('No training rows');
        const model = providedModel || tf.sequential();
        if (!providedModel) {
          model.add(tf.layers.dense({ units: 4, activation: 'relu', inputShape: [8] }));
          model.add(tf.layers.dense({ units: 2, activation: 'relu' }));
          model.add(tf.layers.dense({ units: 4, activation: 'relu' }));
          model.add(tf.layers.dense({ units: 8 }));
          model.compile({ optimizer: 'adam', loss: 'meanSquaredError' });
        }
        const xs = tf.tensor2d(trainingRows);
        try {
          const history = await model.fit(xs, xs, FIT_OPTIONS);
          return { model, history };
        } catch (error) {
          if (!providedModel) model.dispose();
          throw error;
        } finally {
          xs.dispose();
        }
      }

Gzip reconstructs the original bytes exactly. An autoencoder learns a compressed representation and tries to rebuild the input from it. A narrow bottleneck encourages it to use regularities in the training examples. We measure the difference between input and reconstruction as an anomaly score.

That score is a heuristic, a rule we must test on data. The bottleneck does not guarantee that unfamiliar inputs reconstruct badly. Normal inputs can also reconstruct poorly if the model has not learned their variation. Evaluate both misses and false alarms before using the score to wake anyone.

## Encoder → Bottleneck → Decoder

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="autoencoder.ts">
{`import * as tf from '@tensorflow/tfjs';

// Build an autoencoder for signal anomaly detection
const inputDim = 11;  // 3 raw features + 8 FFT features

// Encoder stages: 11 -> 32 -> 16 -> 4. Decoder stages: 4 -> 16 -> 32 -> 11.
// One Sequential owns all layers and gives this example one model lifetime.
const autoencoder = tf.sequential();
autoencoder.add(tf.layers.dense({ units: 32, activation: 'relu', inputShape: [inputDim] }));
autoencoder.add(tf.layers.dense({ units: 16, activation: 'relu' }));
autoencoder.add(tf.layers.dense({ units: 4, activation: 'relu' })); // bottleneck
autoencoder.add(tf.layers.dense({ units: 16, activation: 'relu' }));
autoencoder.add(tf.layers.dense({ units: 32, activation: 'relu' }));
autoencoder.add(tf.layers.dense({ units: inputDim })); // linear reconstruction

// Train to reconstruct its own input: input = label
autoencoder.compile({ optimizer: 'adam', loss: 'meanSquaredError' });`}
</CodeBlock>

Those eleven features describe 64 samples from one channel at 256 Hz: a quarter-second window. An archive capture is a 33-second block from 64 channels. Samples and channels are different axes.

The mission's 412 suspect rows are fictional review findings. A 73.4-second recurrence interval alone cannot tell us how many extraction windows contain a pulse: we also need its duration and the window-selection schedule.

## Challenge

Screen the archive against the flag log, then train the autoencoder on what survives. The grader checks row selection and measures errors on a small synthetic holdout. Those checks do not validate a real detector. A contaminated model may reconstruct anomalies well, but no fixed error ratio proves contamination. For a comparison experiment, start both runs from identical weights and keep the fitting schedule fixed.
