The z-score gate cleared a reading this morning that I flagged by eye an hour later. Amplitude normal, frequency normal, phase normal, and the three have never once occurred together in eleven days of archive. A threshold reads one dial at a time. Whatever replaces it has to learn what normal looks like across every dial at once.
</Dialogue>

Think of gzip: it finds repeated patterns in your data and exploits them to compress. Decompress and you get the original back byte for byte, and if the stream is not what the decoder expects, it throws rather than guess. An autoencoder takes the same bet on patterns and settles it the other way: it learns what "normal" looks like and rebuilds anything you hand it, so "abnormal" comes back mangled instead of refused. The bottleneck is what makes that bet honest. Four numbers cannot store eleven arbitrary values, so the only way through the squeeze is to learn the regularities normal readings share and rebuild from those. A reading that follows the regularities survives the trip; one that breaks them comes out as the nearest normal-looking thing, and the gap between the two is the signal.

## Encoder → Bottleneck → Decoder

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="autoencoder.ts">
{`import * as tf from '@tensorflow/tfjs';

// Build an autoencoder for signal anomaly detection
const inputDim = 11;  // 3 raw features + 8 FFT features

// ENCODER: compress 11 features → 4 (the bottleneck)
const encoder = tf.sequential();
encoder.add(tf.layers.dense({ units: 32, activation: 'relu', inputShape: [inputDim] }));
encoder.add(tf.layers.dense({ units: 16, activation: 'relu' }));
encoder.add(tf.layers.dense({ units: 4, activation: 'relu' }));  // bottleneck

// DECODER: reconstruct 4 → 11
const decoder = tf.sequential();
decoder.add(tf.layers.dense({ units: 16, activation: 'relu', inputShape: [4] }));
decoder.add(tf.layers.dense({ units: 32, activation: 'relu' }));
decoder.add(tf.layers.dense({ units: inputDim }));  // reconstruct original

// Full autoencoder: input → encoder → decoder → reconstruction
// (a model is a layer in TFJS, so the two halves stack directly)
const autoencoder = tf.sequential();
autoencoder.add(encoder);  // 11 → 4
autoencoder.add(decoder);  // 4 → 11

// Keeping the halves as their own models pays off later:
// encoder.predict(signal) lets you inspect the 4-number bottleneck directly

// Train to reconstruct its own input: input = label
autoencoder.compile({ optimizer: 'adam', loss: 'meanSquaredError' });`}
</CodeBlock>
