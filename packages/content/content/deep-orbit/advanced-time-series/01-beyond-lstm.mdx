<Dialogue speaker="Dr. Farah">
The LSTM must process time steps sequentially: step 1, then 2, then 3. It can't skip ahead. But what if the relevant pattern is at step 5 and step 72? Attention lets the model look at all steps simultaneously and focus on what matters.
</Dialogue>

<Dialogue speaker="Ensign Demir">
Like CSS :focus. Instead of styling every element equally, you highlight just the one that's active. Attention highlights the time steps that are most relevant to the current prediction.
</Dialogue>

<Dialogue speaker="Dr. Farah">
:focus lands on one element. Softmax never does — every step gets a weight, and most of them sit near zero. Keep your picture, but read the weights as a budget, not a spotlight.
</Dialogue>

When a user tabs through a form, CSS `:focus` moves to the active element. The browser doesn't re-render every element; it identifies which one matters and highlights it. Attention runs the softer version of that move: it computes a relevance score for every time step, then spends most of its weight where the score is high — and a little everywhere else.

## The Query-Key-Value Framework

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="attention-basics.ts">
{`import * as tf from '@tensorflow/tfjs';

// Attention in three steps:
// 1. Query: "What am I looking for?"
// 2. Keys: "Here are the candidates"
// 3. Values: "Here's the information at each candidate"

// Score = how well each key matches the query
// Weight = softmax(score) — normalize to probabilities
// Output = weighted sum of values — focus on high-weight positions

function simpleAttention(
  query: tf.Tensor2D,   // [1, dim] — what we're looking for
  keys: tf.Tensor2D,    // [seqLen, dim] — candidates at each time step
  values: tf.Tensor2D,  // [seqLen, dim] — information at each time step
): { output: tf.Tensor; weights: tf.Tensor } {
  return tf.tidy(() => {
    // Score each key against the query
    const scores = tf.matMul(query, keys, false, true);  // [1, seqLen]

    // Normalize to probabilities
    const weights = tf.softmax(scores, 1);  // [1, seqLen]

    // Weighted sum of values
    const output = tf.matMul(weights, values);  // [1, dim]

    return { output, weights };
  });
}

// The weights tell you WHERE the model is "looking"
// High weight at step 5 and step 72 = those steps matter most
// This is interpretable — unlike LSTM hidden state`}
</CodeBlock>

## LSTM vs Attention

<CodeBlock language="typescript" title="comparison.ts">
{`// LSTM processes sequentially:
// step 1 → step 2 → step 3 → ... → step 80
// Information must pass through EVERY intermediate step
// Long-range dependencies degrade (even with gates)

// Attention processes in parallel:
// [step 1, step 2, ..., step 80] → score ALL at once
// Direct connection between ANY two steps
// No degradation over distance

// Speed comparison for 80-step sequences:
// LSTM:      80 sequential operations (can't parallelize)
// Attention: 1 matrix multiply (fully parallelizable on GPU)

// Build an attention-enhanced model
const model = tf.sequential();
// Use a 1D convolution + attention hybrid
model.add(tf.layers.conv1d({
  filters: 64,
  kernelSize: 3,
  activation: 'relu',
  inputShape: [80, 3],
}));
model.add(tf.layers.globalAveragePooling1d());  // simple attention: average all positions
model.add(tf.layers.dense({ units: 32, activation: 'relu' }));
model.add(tf.layers.dense({ units: 3 }));

model.compile({ optimizer: 'adam', loss: 'meanSquaredError' });`}
</CodeBlock>
