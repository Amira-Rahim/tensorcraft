<Dialogue speaker="Dr. Farah">
The signal's period isn't constant; it's drifting. We need a filter that tracks a moving target under noise. The Kalman filter predicts where the signal should be, then corrects with each new measurement. It's the optimal estimator for linear systems under Gaussian noise.
</Dialogue>

<Dialogue speaker="Ensign Demir">
That's an exponential moving average! smoothed = alpha * new + (1-alpha) * old. The Kalman filter just computes the optimal alpha at each step?
</Dialogue>

You've used exponential moving averages in analytics dashboards, smoothing noisy metrics to reveal the underlying trend. The Kalman filter is the mathematically optimal version of this: it dynamically adjusts how much to trust new data vs the historical estimate, based on the noise levels of each.

## Predict, Then Correct

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="kalman-filter.ts">
{`// 1D Kalman Filter — optimal smoothing under noise

interface KalmanState {
  estimate: number;      // current best guess
  variance: number;      // uncertainty in our estimate
}

class KalmanFilter {
  private state: KalmanState;
  private processNoise: number;      // how much the true value changes between steps
  private measurementNoise: number;  // how noisy our measurements are

  constructor(initial: number, processNoise: number, measurementNoise: number) {
    this.state = { estimate: initial, variance: 1 };
    this.processNoise = processNoise;
    this.measurementNoise = measurementNoise;
  }

  update(measurement: number): KalmanState {
    // PREDICT: where do we think the state is?
    const predicted = this.state.estimate;
    const predictedVariance = this.state.variance + this.processNoise;

    // UPDATE: how much to trust the new measurement?
    const gain = predictedVariance / (predictedVariance + this.measurementNoise);
    // gain ≈ 0: trust prediction (measurement is noisy)
    // gain ≈ 1: trust measurement (prediction is uncertain)

    // CORRECT: blend prediction with measurement
    this.state = {
      estimate: predicted + gain * (measurement - predicted),
      variance: (1 - gain) * predictedVariance,
    };

    return { ...this.state };
  }
}

// Track the anomaly timing interval
const kf = new KalmanFilter(73.4, 0.1, 1.0);  // initial estimate: 73.4 seconds

const measurements = [73.4, 73.7, 74.1, 73.8, 74.2, 74.5, 74.3, 74.8];
for (const m of measurements) {
  const state = kf.update(m);
  console.log(\`Measurement: \${m.toFixed(1)}, Estimate: \${state.estimate.toFixed(2)}\`);
}
// The filter smoothly tracks the upward drift: 73.4 → 74.3
// The interval is increasing by ~0.3 seconds per cycle`}
