The LSTM is great at short-range patterns. The attention model catches long-range dependencies. The Kalman filter tracks drift. Why choose one when we can combine all three?
</Dialogue>

<Dialogue speaker="Dr. Farah">
Because all three run on every input. An ensemble isn't a router that picks the right specialist. Every model fires every time, and you pay the sum of their inference costs. If the compute budget covers that, then yes: each model has blind spots, and the ensemble covers them.
</Dialogue>

`Promise.all([svcA(x), svcB(x), svcC(x)])` is the shape that carries over: one input, three calls that all run, one bill that is the sum of the three. What does not carry over is the reason you fan out. Three services hand back three different pieces of an answer. Three models hand back three answers to the same question, and the only thing that makes the third one worth paying for is that it is wrong in places the other two are right.

## Combining Models

<CodeBlock language="typescript" title="ensemble.ts">
{`import * as tf from '@tensorflow/tfjs';

interface ModelPrediction {
  modelName: string;
  prediction: number[];
  confidence: number;
}

// Simple averaging: each model gets equal vote
function averageEnsemble(predictions: ModelPrediction[]): number[] {
  const n = predictions.length;
  const dim = predictions[0].prediction.length;
  const result = new Array(dim).fill(0);

  for (const p of predictions) {
    for (let i = 0; i < dim; i++) {
      result[i] += p.prediction[i] / n;
    }
  }
  return result;
}

// Weighted averaging: trust better models more
function weightedEnsemble(predictions: ModelPrediction[]): number[] {
  const totalConf = predictions.reduce((s, p) => s + p.confidence, 0);
  const dim = predictions[0].prediction.length;
  const result = new Array(dim).fill(0);

  for (const p of predictions) {
    const weight = p.confidence / totalConf;
    for (let i = 0; i < dim; i++) {
      result[i] += p.prediction[i] * weight;
    }
  }
  return result;
}

// DEEP SCAN ensemble
const predictions: ModelPrediction[] = [
  { modelName: 'LSTM', prediction: [0.82, 37.4, 0.45], confidence: 0.85 },
  { modelName: 'Attention', prediction: [0.79, 36.9, 0.51], confidence: 0.90 },
  { modelName: 'Kalman', prediction: [0.80, 37.6, 0.48], confidence: 0.75 },
];

const avg = averageEnsemble(predictions);
const weighted = weightedEnsemble(predictions);
console.log('Average:', avg);    // [0.803, 37.300, 0.480]
console.log('Weighted:', weighted); // attention contributes most

// Stacking: the third rung. Instead of hand-picking weights, TRAIN a
// meta-model on the members' outputs: each meta-feature row is the three
// members' predictions for one window, the label is the true value.
const metaX = tf.tensor2d(heldOutWindows.map(w => members.map(m => m.predictScalar(w))));
const metaY = tf.tensor2d(heldOutTargets, [heldOutTargets.length, 1]);
const metaModel = tf.sequential();
metaModel.add(tf.layers.dense({ units: 1, inputShape: [3] }));  // learned blend
metaModel.compile({ optimizer: 'adam', loss: 'meanSquaredError' });
await metaModel.fit(metaX, metaY, { epochs: 20 });
// Fit the meta-model on HELD-OUT predictions, never on the members' own
// training windows, or it learns to trust whichever member memorized them.`}

## Why Ensembles Work

<CodeBlock language="typescript" title="why-ensembles.ts">
{`// Each model makes different errors
// When you average, individual errors cancel out

// LSTM:      good at short patterns, misses long-range drift
// Attention: good at long-range, may overfit on small datasets
// Kalman:    good at tracking drift, assumes linear dynamics

// Error reduction: if models have uncorrelated errors,
// ensemble error ≈ individual error / sqrt(N)

// Example:
// LSTM MAE: 0.045
// Attention MAE: 0.038
// Kalman MAE: 0.052
// Ensemble MAE: 0.028  ← better than any individual model

function evaluateEnsemble(
  models: { name: string; predictions: number[][] }[],
  actual: number[][],
): { individual: Record<string, number>; ensemble: number } {
  const individual: Record<string, number> = {};

  for (const model of models) {
    let totalError = 0;
    for (let i = 0; i < actual.length; i++) {
      for (let j = 0; j < actual[i].length; j++) {
        totalError += Math.abs(model.predictions[i][j] - actual[i][j]);
      }
    }
    individual[model.name] = totalError / (actual.length * actual[0].length);
  }

  // Ensemble prediction
  let ensembleError = 0;
  for (let i = 0; i < actual.length; i++) {
    for (let j = 0; j < actual[i].length; j++) {
      const avg = models.reduce((s, m) => s + m.predictions[i][j], 0) / models.length;
      ensembleError += Math.abs(avg - actual[i][j]);
    }
  }

  return { individual, ensemble: ensembleError / (actual.length * actual[0].length) };
}`}
</CodeBlock>

<DerivationDrawer summary="Where the sqrt(N) error cut comes from, and the correlation floor">
**The sqrt(N) claim above has fine print, and the fine print is one formula.** Model each member's error on a given input as a random variable `eᵢ` with variance `σ²`, the same spread for every member. The ensemble averages predictions, so its error is the mean of the N member errors.

**Variance of a sum runs through covariance.** For two variables, `Var(x + y) = Var(x) + Var(y) + 2·Cov(x, y)`; the covariance term measures how the two move together. Write each pairwise covariance through the correlation `ρ = Cov(eᵢ, eⱼ) / σ²`. Summing the N member errors picks up one `σ²` per member plus one `ρσ²` per ordered pair, and there are `N(N-1)` ordered pairs:

`Var(sum of the N errors) = Nσ² + N(N-1)·ρσ²`

**Averaging divides variance by N².** Divide through and regroup:

`Var(ensemble error) = σ²/N + ((N-1)/N)·ρσ² = ρσ² + (1-ρ)·σ²/N`

**Read the two terms.** `(1-ρ)·σ²/N` is the part averaging can cancel; it dies as members are added. `ρσ²` does not contain N: it is a floor that no ensemble size removes. At `ρ = 0` the formula collapses to `σ²/N`, the sqrt(N) cut in typical error. At `ρ = 0.5`, three members give `0.5σ² + 0.5σ²/3 ≈ 0.667σ²`: a variance cut of one third, where independent members would have delivered two thirds. And the formula is about variance only; shared bias, like every member training on the same mislabeled batch, passes through the average untouched.
</DerivationDrawer>

<RecallPrompt question="Why do model ensembles often outperform any single model?" answer="When ensemble members are trained independently (different architectures, random seeds, or subsets of data), their errors are partially uncorrelated, and averaging cancels part of them. The factor-N variance cut (typical error shrinking by sqrt(N)) holds only for fully uncorrelated errors. With average pairwise correlation rho between member errors of variance sigma^2, ensemble variance is rho*sigma^2 + (1 - rho)*sigma^2/N: it floors at rho*sigma^2 no matter how many members you add." />
