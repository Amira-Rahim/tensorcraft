      function ensembleGain(members, actual) {
        const mae = (values) =>
          values.reduce((sum, v, i) => sum + Math.abs(v - actual[i]), 0) /
          actual.length;

        const perMember = Object.create(null);
        for (const member of members) {
          perMember[member.name] = mae(member.predictions);
        }

        const blended = actual.map(
          (_, i) =>
            members.reduce((sum, m) => sum + m.predictions[i], 0) / members.length,
        );
        const ensemble = mae(blended);

        // Multiplying every inverse-square weight by minError^2 cancels
        // during normalization and avoids overflow for very small errors.
        const minError = Math.min(...members.map(member => member.heldOutError));
        const inverseSquaredError = members.map(
          (member) => (minError / member.heldOutError) ** 2,
        );
        const total = inverseSquaredError.reduce((sum, v) => sum + v, 0);
        const weights = Object.create(null);
        members.forEach((member, i) => {
          weights[member.name] = inverseSquaredError[i] / total;
        });

        const weightedBlend = actual.map((_, i) =>
          members.reduce((sum, m) => sum + m.predictions[i] * weights[m.name], 0),
        );
        const weighted = mae(weightedBlend);

        const best = Math.min(...Object.values(perMember));
        return { perMember, ensemble, weights, weighted, beatsBest: ensemble < best };
      }

## Earlier errors set weights, current targets test the blend

The exercise supplies four synthetic targets `[10,20,30,40]`, in arbitrary
units, and aligned predictions from three named members. Its prior errors
come from a separate period and are range-normalized MAEs. They set weights.
The current MAEs use the current targets' units and compare performance.

| Member | Earlier normalized MAE | Current predictions | Current MAE |
| --- | --- | --- | --- |
| LSTM | 0.045 | [12,18,30,40] | 1 |
| Attention | 0.038 | [8,22,30,40] | 1 |
| Kalman | 0.058 | [10,20,33,37] | 1.5 |

// Simple averaging: each model gets equal vote
function averageEnsemble(predictions: ModelPrediction[]): number[] {
  validatePredictions(predictions);
  const n = predictions.length;
  const dim = predictions[0].prediction.length;
  const result = new Array(dim).fill(0);

  for (const p of predictions) {
    for (let i = 0; i < dim; i++) {
      result[i] += p.prediction[i] / n;
    }
  }
  return result;
}

// Weighted averaging: use validation-derived blend coefficients
function weightedEnsemble(predictions: ModelPrediction[]): number[] {
  validatePredictions(predictions);
  // Scale before summing so finite, large weights do not overflow.
  const largestWeight = Math.max(...predictions.map(p => p.weight));
  const totalWeight = predictions.reduce((s, p) => s + p.weight / largestWeight, 0);
  const dim = predictions[0].prediction.length;
  const result = new Array(dim).fill(0);

  for (const p of predictions) {
    const weight = (p.weight / largestWeight) / totalWeight;
    for (let i = 0; i < dim; i++) {
      result[i] += p.prediction[i] * weight;
    }
  }
  return result;
}

We choose each model's `weight` from validation results. It determines that model’s share of the blend. It carries no probability interpretation. Here e_i is MAE on an earlier held-out week, with each channel's error divided by its range.

The rule is `w_i = (1 / e_i^2) / sum_j (1 / e_j^2)`. Squared MAE is not error variance, so this rule does not guarantee the lowest-variance blend. Errors 0.045, 0.038, and 0.058 give weights near 0.333, 0.467, and 0.200.

Compare those weights with equal weighting on a separate evaluation week. The exercise supplies positive errors. A real system also needs a policy for zero or invalid errors.

## Why Ensembles Work

Averaging helps when the models' errors partly cancel. Different architectures, random seeds, or training samples can produce different errors, but do not guarantee it. Bagging trains models on random resamples of the training data. For time-series models, those samples must preserve the time structure the model needs.

The story's equal-weight blend has MAE 0.036 on the held-out week. Dividing the mean model MAE by sqrt(3) would not predict that result. The variance calculation below measures something different.

Compare the blend's 0.036 with 0.038, the best member on the same week. For equal-weight averaging under MAE, the blend's error cannot exceed the arithmetic mean of the members' MAEs, and it can tie it. That bound does not promise a win over the best member. Choose members and weights on validation data, then report the selected system on a final untouched period.

<DerivationDrawer summary="Where the sqrt(N) error cut comes from, and the correlation floor">
**A variance calculation with explicit assumptions.** Model each member's error on a given input as a random variable `eᵢ` with variance `σ²`, the same spread for every member. The ensemble averages predictions, so its error is the mean of the N member errors.

**Variance of a sum runs through covariance.** For two variables, `Var(x + y) = Var(x) + Var(y) + 2·Cov(x, y)`. The covariance term measures how the two move together. Write each pairwise covariance through the correlation `ρ = Cov(eᵢ, eⱼ) / σ²`. Summing the N member errors picks up one `σ²` per member plus one `ρσ²` per ordered pair, and there are `N(N-1)` ordered pairs:

`Var(sum of the N errors) = Nσ² + N(N-1)·ρσ²`

**Averaging divides variance by N².** Divide through and regroup:

`Var(ensemble error) = σ²/N + ((N-1)/N)·ρσ² = ρσ² + (1-ρ)·σ²/N`

The term `(1-ρ)·σ²/N` decreases as you add models. With a fixed nonnegative correlation, `ρσ²` is the variance that remains as N grows.

At `ρ = 0`, the variance is `σ²/N`, so the standard deviation falls by sqrt(N). This is not a general formula for MAE. At `ρ = 0.5`, three models give `0.5σ² + 0.5σ²/3 ≈ 0.667σ²`. That reduces variance by one third. Independent models would reduce it by two thirds.

The formula only describes variance. A shared bias, such as all models learning from the same mislabeled batch, remains after averaging.
</DerivationDrawer>
