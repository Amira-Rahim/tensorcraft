A more specific search query can narrow retrieved results. A prompt instead asks a model to generate an answer. Both benefit from a clear task and relevant context, but precise wording guarantees neither a useful result nor a true claim.

The word `role` has two meanings here. In lesson 1's API client, it labels the message type, such as system or user. In Farah's checklist, it is an instruction inside the prompt, such as asking the model to answer as a signal analyst. Those are different things.

Demir needs to send each new reading with the same reference facts and response requirements. You will build that prompt and inspect the exact text the client would send.

The prompt uses instrument units so a reviewer can check it against the log. The classifier instead receives three scaled features: amplitude divided by 2048, a zero-crossing count divided by 63, and phase mapped from minus-pi-to-pi onto 0 to 1.

Frequency needs special care. The prompt uses the 73.4 Hz estimate from the crew's longer spectrum measurement. The classifier instead counts zero crossings in 64 samples, a quarter second at 256 Hz. That short window has FFT bins 4 Hz apart, so it does not directly give a 73.4 Hz bin. Keep the frequency estimate and crossing count separate.

<DerivationDrawer summary="Checking the instrument units in this example">
The story supplies these fictional mission measurements. The fictional normal period has normalized mean 0.52, standard deviation 0.15, p5 0.28 and p95 0.76. Multiplying the percentile endpoints by 2048 gives roughly 570 to 1560 counts. This is the central 90% reference band. The 3-sigma decision rule uses a separate threshold.

1024 counts becomes 0.50, about 0.13 standard deviations below that mean. A clean 73.4 Hz sinusoid spans about 18.35 cycles in a quarter second, so the recorder might capture roughly 36 or 37 zero crossings. The exact count depends on phase, sampling and noise. Frequency does not uniquely determine it. A measured count of 37 normalizes to 37/63, about 0.59. Phase 0.23 rad maps to about 0.54 across the minus-pi-to-pi range.

The story's classifier score of 51.8% does not establish a calibrated probability. The listed natural frequencies are a limited local catalogue. If a frequency is missing from it, investigate further. The catalogue cannot rule out every natural source.
</DerivationDrawer>

## Prompt Templates

<CodeBlock language="typescript" title="templates.ts">
{`// Farah's v8 includes the amplitude reference but still lacks
// the sector's frequency catalogue. Keep that omission in view.

interface SignalData {
  amplitude: number;   // hull counts against the sensor's 2048-count full scale
  frequency: number;   // the FFT line under review, measured in Hz
  phase: number;       // radians
}

function classificationPrompt(signal: SignalData): string {
  return \`You are DEEP SCAN, an AI signal classification system.

## Context
You are analyzing signals from deep space Sector 7-G.
Central 90% normal amplitude band: 570 to 1560 counts.

## Signal Data
- Amplitude: \${signal.amplitude} counts
- Frequency: \${signal.frequency} Hz
- Phase: \${signal.phase} rad

## Task
Classify this signal and explain your reasoning.

Allowed classes: noise, anomaly, unknown. Risk: low, medium, high.
Confidence is a self-reported score from 0 to 1, not measured calibration.
## Output Format (example JSON)
{
  "classification": "unknown",
  "confidence": 0.0,
  "reasoning": "Evidence is insufficient to classify this reading.",
  "risk_level": "low"
}\`;
}

// Teaching contract: one JSON object, with no other braces in the reply.
// For general responses, use a strict structured-output contract and schema.
// Even schema-valid output still needs factual review.
// Parse the response
function parseClassification(response: string) {
  const jsonMatch = response.match(/\\{[\\s\\S]*\\}/);
  if (!jsonMatch) throw new Error('No JSON found in response');
  const value = JSON.parse(jsonMatch[0]);
  if (!['noise', 'anomaly', 'unknown'].includes(value.classification) ||
      !Number.isFinite(value.confidence) || value.confidence < 0 || value.confidence > 1 ||
      typeof value.reasoning !== 'string' || !value.reasoning.trim() ||
      !['low', 'medium', 'high'].includes(value.risk_level)) {
    throw new Error('Invalid classification fields');
  }
  return value;
}`}
</CodeBlock>
