<Dialogue speaker="Ensign Demir">
Each model does one thing well. The classifier knows signal types. The autoencoder knows what's normal. The LSTM knows temporal patterns. The LLM knows language. I just need to wire them together, like an API gateway routing to micro-services.
</Dialogue>

Four models, four contracts: a class and a confidence from the classifier, a reconstruction error from the autoencoder, predicted next values from the LSTM, and prose from the LLM that consumes the other three. Orchestration is the discipline of wiring those contracts together so one weak stage can't silently poison the report.

Four stages that are each right 95% of the time are right 81% of the time together if their mistakes are independent. They rarely are: module 7 showed that stages reading the same channel fail together, and a shared failure is the one no vote downstream catches. Either way the product is why the check sits between stages. A stage that is wrong rather than broken raises no exception, so the check has to sit between stages, while you still know what the stage promised.

<CodeBlock language="typescript" title="pipeline.ts">
{`import * as tf from '@tensorflow/tfjs';
import { verifyClaims } from './verify-claims';  // the checker from lesson 3

interface PipelineResult {
  classification: { class: string; confidence: number };
  anomaly: { isAnomaly: boolean; score: number };
  prediction: { nextValues: number[] };
  report: string | null;
}

// A stage that is merely wrong throws nothing. Check what it promised before
// the next stage treats it as fact: pass the value on, swap in the fallback,
// or stop the run.
function validateStage<T>(
  stage: string,
  value: T,
  ok: (v: T) => boolean,
  fallback?: T,
): T {
  if (ok(value)) return value;
  if (fallback === undefined) throw new Error(\`\${stage} broke its contract\`);
  console.warn(\`\${stage} broke its contract; using the fallback\`);
  return fallback;
}

// One capture, three input contracts. Each stage gets its own argument
// because no one array satisfies two of these models.
async function processSignal(
  features: number[],   // module 4's preprocess: [amplitude, frequency, phase], min-max to 0..1
  signal: number[],     // module 5's 11 features, z-normalized to mean 0, std 1
  window: number[][],   // module 6's input: 80 steps of 3 per-channel z-scores
  models: {
    classifier: tf.LayersModel;
    autoencoder: tf.LayersModel;
    lstm: tf.LayersModel;
    llm: LLMClient;
  },
  thresholds: { anomaly: number },
): Promise<PipelineResult> {
  // Stage 1: Classify the signal
  const classified = tf.tidy(() => {
    const input = tf.tensor2d([features]);          // shape: [1, 3]
    const output = (models.classifier.predict(input) as tf.Tensor).dataSync()[0];
    // Confidence is confidence IN THE VERDICT: a 0.2 sigmoid output means
    // "noise, 0.8 sure", not "noise, 0.2 sure".
    return {
      class: output > 0.5 ? 'anomaly' : 'noise',
      confidence: output > 0.5 ? output : 1 - output,
    };
  });
  // Every later stage quotes this number, so there is no useful fallback
  // for a confidence outside 0..1. Stop the run instead.
  const classification = validateStage('classifier', classified, (c) =>
    Number.isFinite(c.confidence) && c.confidence >= 0 && c.confidence <= 1);

  // Stage 2: Check for anomalies (autoencoder)
  const detected = tf.tidy(() => {
    const input = tf.tensor2d([signal]);            // shape: [1, 11]
    const reconstructed = models.autoencoder.predict(input) as tf.Tensor;
    const error = tf.losses.meanSquaredError(input, reconstructed).dataSync()[0];
    return { isAnomaly: error > thresholds.anomaly, score: error };
  });
  // NaN > threshold is false, so a NaN reconstruction error reports "normal"
  // and no alert ever fires. Nothing throws. This is the check that catches it.
  const anomaly = validateStage('autoencoder', detected, (a) =>
    Number.isFinite(a.score));

  // Stage 3: Predict next values (LSTM)
  const predicted = tf.tidy(() => {
    const input = tf.tensor3d([window]);            // shape: [1, 80, 3]
    const pred = (models.lstm.predict(input) as tf.Tensor).dataSync();
    return { nextValues: Array.from(pred) };
  });
  // The model's own output width is the promise: outputShape is
  // [null, featureCount]. A short vector is a broken contract, not a shorter
  // forecast; the report reads fine without one, so this stage gets a fallback.
  const featureCount = (models.lstm.outputShape as number[])[1];  // 3 features of one step, not a horizon
  const prediction = validateStage(
    'lstm',
    predicted,
    (p) => p.nextValues.length === featureCount && p.nextValues.every(Number.isFinite),
    { nextValues: [] },
  );

  // Stage 4: Generate report if anomaly detected (LLM)
  let report: string | null = null;
  if (anomaly.isAnomaly) {
    const handed = [
      classification.confidence,
      anomaly.score,
      thresholds.anomaly,
      ...prediction.nextValues,
    ];
    const draft = await models.llm.complete(\`
Signal anomaly detected:
- Classification: \${classification.class} (confidence: \${classification.confidence.toFixed(3)})
- Anomaly score: \${anomaly.score.toFixed(4)} (threshold: \${thresholds.anomaly})
- Predicted next values: \${prediction.nextValues.map(v => v.toFixed(3)).join(', ')}

Generate a brief alert summary in 2-3 sentences. Use only the numbers above.
    \`);
    // verifyClaims is lesson 3's checker: every number in the draft has to
    // trace to one we handed it, within 0.05. Read that tolerance against
    // this hand-off before trusting it. One absolute tolerance serves a
    // mixed-scale evidence set unevenly, and lesson 3's set already mixed
    // an amplitude in counts with a confidence in 0..1. Here four of the
    // six handed numbers sit inside -1 to 1 (the reconstruction error does
    // not: it starts above module 7's cutoff of 1.0 and reads 6.2 on this
    // capture). At that scale 0.05 forgives a reprint, 0.918 as 0.92 or
    // 6.2000 as 6.20, which is what it is for, and a two-decimal number a
    // model invents still lands inside 0.05 of one of the six by luck about
    // one time in six (measured: a draft with six invented numbers came
    // back six fabricated; one that only rounded the six it was handed came
    // back clean). The prompt's "only the numbers above" and the three- and
    // four-decimal printing carry the rest. A label like "Band-7" still
    // comes back as a claim of -7, exactly as it did in lesson 3.
    const { fabricated } = verifyClaims(draft, [handed]);
    report = validateStage(
      'llm',
      draft,
      () => fabricated.length === 0,
      \`ALERT: anomaly score \${anomaly.score.toFixed(4)} over threshold \${thresholds.anomaly}. Draft held: \${fabricated.length} number(s) traced to nothing.\`,
    );
  }

  return { classification, anomaly, prediction, report };
}`}
</CodeBlock>

Three arrays describe one capture and none of them substitutes for another. The classifier reads module 4's three min-max features. The autoencoder reads module 5's eleven z-scored ones. The LSTM reads a window of module 6's per-channel z-scores. A length mismatch is the cheap mistake: hand the eleven-feature array to the classifier and tfjs throws `expected dense_Dense1_input to have shape [null,3] but got array with shape [1,11]` before the model runs at all. The costly mistake is an array of the right length on the wrong scale. Three z-scores fit the classifier's input shape, so it runs and returns a verdict with a confidence inside the legal 0..1 range. Stage 1's check finds nothing to object to. The input contract is part of the stage contract, which is why each stage takes its own argument here.

## Error Handling and Fallbacks

Two of those four checks stop the run: processSignal has no in-place substitute for a confidence outside 0..1 or a NaN reconstruction error. The other two log a warning and return a stand-in, so the run continues. resilience.ts runs the same four stages one level up. Its classifier call has no catch, so a throw there still ends the run. The other three sit in try blocks, where a throw is caught and a stand-in takes its place.

For the autoencoder that stand-in is module 7's amplitude z-score, a weaker detector rather than a drop-in. It reads one channel against a baseline measured once over the normal period, mean 0.52 and standard deviation 0.15 in min-max units, instead of eleven features against each other. A 3-sigma gate on that baseline fires only above 0.97 or below 0.07, and an amplitude pegged at 1.00, the most that feature can reach, scores 3.20 sigma; a dead channel at 0.00 is the only larger deviation, 3.47. The baseline arrives as an argument rather than being recomputed from the last eighty amplitudes, because a rolling baseline makes the sigma count depend on how quiet that stretch happened to be. The same 1.00 reading scores 342.86 sigma against a window whose standard deviation is 0.0014, and 2.29 against one whose standard deviation is 0.21.

<CodeBlock language="typescript" title="resilience.ts">
{`// Like micro-service circuit breakers: degrade around the stages that have a stand-in

async function resilientPipeline(
  features: number[],   // module 4's three min-max features
  signal: number[],     // module 5's eleven z-scored features
  window: number[][],   // module 6's window of per-channel z-scores
  models: { classifier: tf.LayersModel; autoencoder: tf.LayersModel; lstm: tf.LayersModel; llm: LLMClient },
  thresholds: { anomaly: number },
  baseline: { mean: number; std: number },  // amplitude's normal-period mean and std, in min-max units
): Promise<PipelineResult> {
  // Classification is required: fail if it fails
  const classification = await classifyWithRetry(features, models.classifier);

  // Anomaly detection: fall back to statistical check
  let anomaly;
  try {
    anomaly = await detectAnomaly(signal, models.autoencoder, thresholds);
  } catch {
    // Fallback: module 7's statistical check on the amplitude alone. Reduce
    // to one number first, or there is nothing to compare against 3. That
    // number is features[0], the min-max amplitude, measured against the
    // baseline this ship recorded over the normal period. baseline is an
    // argument, not something re-derived from the last eighty amplitudes: a
    // sigma count means one thing only while what it is counting against
    // holds still.
    const zScore = Math.abs(features[0] - baseline.mean) / baseline.std;
    anomaly = { isAnomaly: zScore > 3, score: zScore };
  }

  // Prediction: optional (skip if LSTM fails)
  let prediction: PipelineResult['prediction'] = { nextValues: [] };
  try {
    prediction = await predictNext(window, models.lstm);
  } catch {
    console.warn('LSTM prediction failed; skipping');
  }

  // Alert: optional (skip if LLM is unavailable). writeAlert stands in for
  // stage 4's LLM call. Lesson 4's generateReport is a different
  // function: the six-section report pipeline.
  let report = null;
  if (anomaly.isAnomaly) {
    try {
      report = await writeAlert(classification, anomaly, models.llm);
    } catch {
      report = \`ALERT: Anomaly detected (score: \${anomaly.score.toFixed(4)}). LLM unavailable for detailed report.\`;
    }
  }

  return { classification, anomaly, prediction, report };
}`}
