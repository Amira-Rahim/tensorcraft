// Declare the data each stage accepts and returns.

interface PipelineStage<TInput, TOutput> {
  name: string;
  // A stage may answer straight away or wait: loading weights and reading
  // a tensor back off the GPU are both async, so run() awaits either.
  process: (input: TInput) => TOutput | Promise<TOutput>;
  validate: (input: TInput) => boolean;
}

// Stage 1: Preprocessing
interface RawSignal { samples: Float32Array; sampleRate: number; }
interface ProcessedSignal { normalized: Float32Array; windowSize: number; }

// Stage 2: Feature Extraction
interface SignalFeatures { fftMagnitudes: Float32Array; spectralPeaks: number[]; }

// Stage 3: Classification
interface Classification { label: string; confidence: number; isAnomaly: boolean; }

// Stage 4: Reporting
interface Report { classification: Classification; summary: string; timestamp: number; }

class Pipeline {
  private stages: PipelineStage<any, any>[] = [];

  addStage<TIn, TOut>(stage: PipelineStage<TIn, TOut>): Pipeline {
    this.stages.push(stage);
    return this;
  }

  //   -> Error: Validation failed at: preprocessor
  // The challenge at the end of this lesson builds this method.
  async run(input: any): Promise<any> {
    // your runner
  }
}

// Integration sketch: implement run in the exercise. The application
// supplies these stages and rawSignal. This is not a complete classifier.

## Component Registry

<CodeBlock language="typescript" title="registry.ts">
{`// Record each component's version, dependencies, and data contract.

interface ComponentManifest {
  name: string;
  version: string;
  dependencies: string[];
  inputType: string;
  outputType: string;
}

const manifest: ComponentManifest[] = [
  {
    name: 'preprocessor',
    version: '1.0.0',
    dependencies: [],
    inputType: 'RawSignal',
    outputType: 'ProcessedSignal',
  },
  {
    name: 'fft-extractor',
    version: '1.0.0',
    dependencies: ['preprocessor'],
    inputType: 'ProcessedSignal',
    outputType: 'SignalFeatures',
  },
  {
    name: 'classifier',
    version: '1.0.0',
    dependencies: ['fft-extractor'],
    inputType: 'SignalFeatures',
    outputType: 'Classification',
  },
  {
    name: 'anomaly-detector',
    version: '1.0.0',
    dependencies: ['fft-extractor'],
    inputType: 'SignalFeatures',
    outputType: 'AnomalyResult',
  },
  {
    name: 'reporter',
    version: '1.0.0',
    dependencies: ['classifier', 'anomaly-detector'],
    inputType: 'Classification & AnomalyResult',
    outputType: 'Report',
  },
];

// Completeness check: every declared dependency resolves to a real component.
// Cycle detection is a second pass over the same manifest. This one only
// proves nothing is missing.
function validateGraph(components: ComponentManifest[]): boolean {
  const names = new Set(components.map(c => c.name));
  return components.every(c =>
    c.dependencies.every(dep => names.has(dep))
  );
}

console.log('Graph valid:', validateGraph(manifest)); // true`}
</CodeBlock>

Compare the runner with the manifest. The runner passes one `data` value through a chain: preprocessor, extractor, classifier, reporter. The manifest describes branches. Two stages use `fft-extractor`, and `reporter` needs results from two stages. One carried value cannot provide both. That is why the chain above leaves out the anomaly detector.

To run the branches, a scheduler must run each stage after its dependencies. It saves outputs in a map by stage name, so `reporter` can read both results.

Keeping those outputs uses memory. The peak depends on their sizes, when stages run, and which buffers remain in use. Reassigning a variable does not dispose a TFJS tensor. Decide which stage owns cleanup. Also check input schemas and dependency cycles. Checking names alone cannot catch them.

The exercise builds the chain runner. You do not need to build the scheduler for branches.

The feature interfaces here are a design sketch. The three-feature binary classifier cannot consume the FFT array directly. Supply the preprocessing and model that match each other, including a separately trained eleven-feature classifier where that is the chosen architecture.
