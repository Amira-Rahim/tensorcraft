## Domain-Specific Focus

<BridgeCallout bridge={frontmatter.concept.bridge} />

In search UIs, you highlight matching terms to draw the user's eye. Clinical attention does the same for the model. We add a bias to the attention scores for tokens that belong to a medical vocabulary, gently steering the model toward clinically meaningful relationships.

<CodeBlock language="typescript" title="clinical-attention.ts">
{`import * as tf from '@tensorflow/tfjs';

// Simplified clinical vocabulary categories
const CLINICAL_VOCAB: Record<string, string> = {
  methotrexate: 'DRUG', lisinopril: 'DRUG', warfarin: 'DRUG',
  arthritis: 'CONDITION', hypertension: 'CONDITION', diabetes: 'CONDITION',
  '20mg': 'DOSAGE', '10mg': 'DOSAGE', daily: 'FREQUENCY',
  weekly: 'FREQUENCY', nausea: 'SYMPTOM', fatigue: 'SYMPTOM'
};

function createClinicalMask(tokens: string[], biasStrength = 2.0): tf.Tensor1D {
  const mask = tokens.map(t =>
    t.toLowerCase() in CLINICAL_VOCAB ? biasStrength : 0.0
  );
  return tf.tensor1d(mask);
}

function clinicalAttention(
  Q: tf.Tensor2D,
  K: tf.Tensor2D,
  V: tf.Tensor2D,
  tokens: string[],
  dk: number
) {
  // Standard scaled dot-product scores
  const scores = tf.matMul(Q, K.transpose()).div(Math.sqrt(dk));

  // Add clinical bias — boost columns for medical terms
  const bias = createClinicalMask(tokens);
  const biasedScores = scores.add(bias.reshape([1, -1]));

  const weights = tf.softmax(biasedScores, -1);
  const output = tf.matMul(weights, V);

  return { output, weights };
}

// Example: compare standard vs clinical attention
const tokens = ['The', 'patient', 'takes', 'methotrexate', 'for', 'arthritis'];
const embeddings = tf.randomNormal([6, 32]) as tf.Tensor2D;
const dk = 16;
const Wq = tf.randomNormal([32, dk]);
const Wk = tf.randomNormal([32, dk]);
const Wv = tf.randomNormal([32, dk]);

const Q = tf.matMul(embeddings, Wq) as tf.Tensor2D;
const K = tf.matMul(embeddings, Wk) as tf.Tensor2D;
const V = tf.matMul(embeddings, Wv) as tf.Tensor2D;

const { weights } = clinicalAttention(Q, K, V, tokens, dk);
console.log('Clinical attention weights shape:', weights.shape);`}
</CodeBlock>

## Bias vs. Hard Masking

<Dialogue speaker="Vikram">
We use a soft bias, not a hard mask. The model can still attend to function words like "denied" or "without"; those carry negation, which is clinically critical. We just make it easier for drug names and conditions to get attention. Think of it as raising their hand in a crowded room, not silencing everyone else.
</Dialogue>

This is the difference between `display: none` (hard mask: token is invisible) and `font-weight: bold` (soft bias: token is emphasized but others remain visible).

<DerivationDrawer summary="Bias in attention: when the model attends to the wrong signal">
Clinical attention bias: the model learns to attend to features that correlate with the label in training but are spurious in deployment. Example: a chest X-ray classifier that attends to the X-ray machine's metadata stamp (which differs by hospital, and hospital correlates with disease prevalence) rather than the lung tissue.

**Detection:** compute attention statistics per demographic slice. If attention concentrates on features that should be irrelevant (machine model, scan timestamp, hospital ID), retrain with these features removed or with adversarial debiasing.

**Auditable property:** for each output, the top-k attended input regions should be in the regions a clinician would also attend to. Mismatches in top-k ↔ clinical relevance map are flags for review.
</DerivationDrawer>
