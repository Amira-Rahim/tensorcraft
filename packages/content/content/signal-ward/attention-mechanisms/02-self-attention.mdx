## Query, Key, Value — The Three Projections

<BridgeCallout bridge={frontmatter.concept.bridge} />

Think of self-attention like a hospital database. Each clinical term plays three roles simultaneously:
- **Query**: "What information am I looking for?" (the search term)
- **Key**: "What information do I contain?" (the index entry)
- **Value**: "What do I actually provide when matched?" (the record content)

<CodeBlock language="typescript" title="self-attention.ts">
{`import * as tf from '@tensorflow/tfjs';

function selfAttention(input: tf.Tensor2D, dk: number) {
  // input shape: [seqLen, embedDim]
  const seqLen = input.shape[0];
  const embedDim = input.shape[1];

  // Learned projection matrices
  const Wq = tf.variable(tf.randomNormal([embedDim, dk]));
  const Wk = tf.variable(tf.randomNormal([embedDim, dk]));
  const Wv = tf.variable(tf.randomNormal([embedDim, dk]));

  // Project input into Q, K, V spaces
  const Q = tf.matMul(input, Wq); // [seqLen, dk]
  const K = tf.matMul(input, Wk); // [seqLen, dk]
  const V = tf.matMul(input, Wv); // [seqLen, dk]

  // Scaled dot-product attention
  const scale = Math.sqrt(dk);
  const scores = tf.matMul(Q, K.transpose()).div(scale); // [seqLen, seqLen]
  const weights = tf.softmax(scores, -1); // normalize each row

  // Weighted sum of values
  const output = tf.matMul(weights, V); // [seqLen, dk]
  return { output, weights };
}

// Example: 8 clinical tokens, 32-dim embeddings, 16-dim attention
const input = tf.randomNormal([8, 32]) as tf.Tensor2D;
const { output, weights } = selfAttention(input, 16);
console.log('Output shape:', output.shape);  // [8, 16]
console.log('Weight matrix shape:', weights.shape);  // [8, 8]`}
</CodeBlock>

## Why Scale by sqrt(d_k)?

Without scaling, dot products grow large as dimensionality increases. Large values push softmax into regions with extremely small gradients — the model stops learning. Dividing by `sqrt(d_k)` keeps values in a reasonable range.

It's the same reason you normalize CSS values. A `z-index: 999999` works, but it makes the system brittle and hard to reason about.

<DerivationDrawer summary="Self-attention: Q, K, V from the same input">
**Self-attention** applies the attention formula where Q, K, V all come from the same input X via three learned projection matrices:

`Q = X · W_Q,   K = X · W_K,   V = X · W_V`

Then:

`SelfAttention(X) = softmax(Q · Kᵀ / √d_k) · V`

**Shape walk** for input X with shape `[seq_len, d_model]`:
- W_Q, W_K, W_V each `[d_model, d_k]`
- Q, K, V each `[seq_len, d_k]`
- Q · Kᵀ → `[seq_len, seq_len]` (the attention matrix — every token's attention to every other)
- softmax row-wise
- · V → `[seq_len, d_k]` (output, same length as input)

**Cost:** O(seq_len² · d_k). Quadratic in sequence length is why long contexts hurt.
</DerivationDrawer>
