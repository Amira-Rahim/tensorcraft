## Rendering the Weight Matrix

<BridgeCallout bridge={frontmatter.concept.bridge} />

Attention weights form a matrix where each cell `[i, j]` represents how much token `i` attends to token `j`. Visualizing this matrix shows where the model put its weight.

<CodeBlock language="typescript" title="attention-heatmap.ts">
{`import * as tf from '@tensorflow/tfjs';

interface AttentionViz {
  tokens: string[];
  weights: number[][];
}

async function extractAttentionWeights(
  tokens: string[],
  embeddings: tf.Tensor2D,
  dk: number
): Promise<AttentionViz> {
  const Wq = tf.randomNormal([embeddings.shape[1], dk]);
  const Wk = tf.randomNormal([embeddings.shape[1], dk]);

  const Q = tf.matMul(embeddings, Wq);
  const K = tf.matMul(embeddings, Wk);

  const scores = tf.matMul(Q, K.transpose()).div(Math.sqrt(dk));
  const weights = tf.softmax(scores, -1);

  const weightMatrix = await weights.array() as number[][];
  return { tokens, weights: weightMatrix };
}

function renderHeatmap(viz: AttentionViz, canvas: HTMLCanvasElement) {
  const ctx = canvas.getContext('2d')!;
  const cellSize = 40;
  const n = viz.tokens.length;

  canvas.width = cellSize * (n + 1);
  canvas.height = cellSize * (n + 1);

  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) {
      const weight = viz.weights[i][j];
      const intensity = Math.floor(weight * 255);
      ctx.fillStyle = \`rgba(0, 212, 255, \${weight})\`;
      ctx.fillRect((j + 1) * cellSize, (i + 1) * cellSize, cellSize - 1, cellSize - 1);
    }
    // Row and column labels
    ctx.fillStyle = '#8B92A5';
    ctx.font = '11px monospace';
    ctx.fillText(viz.tokens[i], 2, (i + 1) * cellSize + 25);
    ctx.fillText(viz.tokens[i], (i + 1) * cellSize + 2, 15);
  }
}

// Example usage
const tokens = ['Patient', 'prescribed', 'methotrexate', 'for', 'arthritis'];
const embeddings = tf.randomNormal([5, 32]) as tf.Tensor2D;
const viz = await extractAttentionWeights(tokens, embeddings, 16);
// renderHeatmap(viz, document.getElementById('canvas'));`}

## Reading Attention Patterns

Common patterns in clinical attention heatmaps:

- **Diagonal**: each word attends most to itself (common in early layers)
- **Vertical stripes**: all words attend to a key term like a drug name
- **Block patterns**: words within a clause attend to each other
- **Off-diagonal connections**: distant words linked semantically

<DerivationDrawer summary="Reading attention matrices honestly">
An attention heatmap visualizes the `[seq_len, seq_len]` softmax matrix from one head, one layer. Each cell `(i, j)` is the weight token i places on token j.

**What it shows:** which tokens the model attended to.

**What it does NOT show:**
- Causation. High attention is correlation between query and key, not a causal claim that token j produced the output.
- Aggregated influence. Multi-head + multi-layer means a single heatmap is one slice of dozens.
- Robustness. Tiny input perturbations can shift the heatmap dramatically without changing output.

**Aggregation tricks** (rollout, attention flow) try to combine heads/layers into one map. Each adds its own assumptions. Triangulate with multiple interpretation methods: attention alongside gradient-based ones such as integrated gradients and saliency maps.
</DerivationDrawer>
