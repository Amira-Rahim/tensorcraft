## The Problem with Equal Attention

<BridgeCallout bridge={frontmatter.concept.bridge} />

Our LSTM from Module 4 processes each word sequentially, compressing the entire sentence into a single hidden state. That's like trying to summarize a patient's entire medical history in one sentence — you inevitably lose critical details.

Consider: "Patient denied chest pain but reported shortness of breath." If the model treats "denied" and "reported" with equal weight, it might confuse which symptom is present and which is absent.

<CodeBlock language="typescript" title="attention-scores.ts">
{`import * as tf from '@tensorflow/tfjs';

// Simulated hidden states for 5 words: [seqLen, hiddenDim]
const hiddenStates = tf.randomNormal([5, 64]);

// A query vector — what are we looking for?
const query = tf.randomNormal([64]);

// Compute raw attention scores via dot product
const scores = tf.matMul(
  hiddenStates,
  query.reshape([64, 1])
).squeeze(); // shape: [5]

// Normalize with softmax — scores now sum to 1
const weights = tf.softmax(scores);
console.log('Attention weights:', await weights.array());

// Create weighted combination — the "attended" representation
const attended = tf.matMul(
  weights.reshape([1, 5]),
  hiddenStates
).squeeze(); // shape: [64]
console.log('Attended vector shape:', attended.shape);`}
</CodeBlock>

The dot product measures similarity between the query and each hidden state. Words that match what we're looking for get higher scores. Softmax turns those scores into a probability distribution — a set of weights that sum to 1.
