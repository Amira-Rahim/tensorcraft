## The Simplest Question: Yes or No

<BridgeCallout bridge={frontmatter.concept.bridge} />

The difference is where the boundary comes from. Yours is a line you wrote; the classifier's is fitted from labeled examples, and it comes back as a probability rather than a boolean. `0.51` and `0.99` both round to `true`, and only one of them should page a physician at 3am.

A sigmoid activation squashes any real number into the range [0, 1]. Values above 0.5 become "urgent," values below become "routine." But in medicine, you might lower that threshold to 0.3, because missing a truly urgent document is far worse than over-flagging a routine one.

<CodeBlock language="typescript" title="urgency-classifier.ts">
{`import * as tf from '@tensorflow/tfjs';

function buildUrgencyClassifier(inputDim: number): tf.LayersModel {
  const model = tf.sequential();

  model.add(tf.layers.dense({
    units: 64,
    activation: 'relu',
    inputShape: [inputDim]
  }));

  model.add(tf.layers.dropout({ rate: 0.3 }));

  model.add(tf.layers.dense({
    units: 32,
    activation: 'relu'
  }));

  // Single output unit with sigmoid: P(urgent)
  model.add(tf.layers.dense({
    units: 1,
    activation: 'sigmoid'
  }));

  model.compile({
    optimizer: 'adam',
    loss: 'binaryCrossentropy',
    metrics: ['accuracy']
  });

  return model;
}

// Simulated document embeddings and urgency labels
const xTrain = tf.randomNormal([200, 64]);
const yTrain = tf.tensor2d(
  Array.from({ length: 200 }, () => [Math.random() > 0.7 ? 1 : 0]),
  [200, 1]
);

const model = buildUrgencyClassifier(64);
await model.fit(xTrain, yTrain, {
  epochs: 10,
  batchSize: 32,
  validationSplit: 0.2
});

// Classify a new document
const newDoc = tf.randomNormal([1, 64]);
const urgencyScore = (model.predict(newDoc) as tf.Tensor).dataSync()[0];

// Clinical threshold: lower than 0.5 to catch more urgent cases
const THRESHOLD = 0.3;
const isUrgent = urgencyScore > THRESHOLD;
console.log(\`Urgency score: \${urgencyScore.toFixed(3)}, Flagged: \${isUrgent}\`);`}
</CodeBlock>

## Thresholds Are Clinical Decisions

<Dialogue speaker="Dr. Karimi">
Don't set that threshold at 0.5. In medicine, we'd rather flag ten routine documents as urgent than miss one truly critical finding. What's the cost of a false alarm versus a missed emergency?
</Dialogue>

<Dialogue speaker="MEDI">
Adjusting threshold. At 0.3, sensitivity is 96%: of every 100 urgent documents, 96 are caught and 4 still get through. Specificity is 71%: 29 of every 100 routine documents are flagged as urgent and land in the queue anyway.
</Dialogue>

Sensitivity is recall wearing its clinical name: the share of truly urgent documents the system catches. Specificity is the mirror on the other class, the share of routine documents correctly left alone. Drop the threshold and sensitivity rises while specificity and precision both fall, because more routine documents come along for the ride. In a triage queue that trade favors recall, and the physician on service is the one who signs it off.
