## Checkboxes, Not Radio Buttons

<BridgeCallout bridge={frontmatter.concept.bridge} />

In HTML forms, radio buttons enforce mutual exclusivity: pick exactly one. Checkboxes allow any combination. Multi-label classification works like checkboxes: each label gets its own independent sigmoid, outputting a probability between 0 and 1. You can check as many boxes as apply, or none at all.

The change is in the output activation: switch from softmax (probabilities sum to 1) to sigmoid (each probability is independent). Each output neuron is its own binary classifier.

<CodeBlock language="typescript" title="multi-label-tagger.ts">
{`import * as tf from '@tensorflow/tfjs';

const CLINICAL_TAGS = [
  'CARDIAC', 'RESPIRATORY', 'RENAL', 'NEUROLOGICAL',
  'INFECTIOUS', 'ONCOLOGICAL', 'PAIN_MANAGEMENT', 'EMERGENCY'
];

function buildMultiLabelClassifier(
  inputDim: number,
  numLabels: number
): tf.LayersModel {
  const model = tf.sequential();

  model.add(tf.layers.dense({
    units: 128,
    activation: 'relu',
    inputShape: [inputDim]
  }));

  model.add(tf.layers.dropout({ rate: 0.3 }));

  model.add(tf.layers.dense({
    units: 64,
    activation: 'relu'
  }));

  // Sigmoid: each label is independent
  model.add(tf.layers.dense({
    units: numLabels,
    activation: 'sigmoid'  // NOT softmax: labels are independent
  }));

  model.compile({
    optimizer: 'adam',
    loss: 'binaryCrossentropy',  // per-label binary decision
    metrics: ['accuracy']
  });

  return model;
}

// Simulated multi-label data
// Each document can have multiple 1s in its label vector
const xTrain = tf.randomNormal([300, 64]);
const yTrain = tf.tensor2d(
  Array.from({ length: 300 }, () =>
    CLINICAL_TAGS.map(() => Math.random() > 0.7 ? 1 : 0)
  )
);

const tagger = buildMultiLabelClassifier(64, CLINICAL_TAGS.length);
await tagger.fit(xTrain, yTrain, {
  epochs: 15,
  batchSize: 32,
  validationSplit: 0.2
});

// Tag a new document
const newDoc = tf.randomNormal([1, 64]);
const scores = await (tagger.predict(newDoc) as tf.Tensor).data();

const TAG_THRESHOLD = 0.5;
const assignedTags = CLINICAL_TAGS.filter((_, i) => scores[i] > TAG_THRESHOLD);
console.log('Assigned tags:', assignedTags);

// Show all scores
CLINICAL_TAGS.forEach((tag, i) => {
  const active = scores[i] > TAG_THRESHOLD ? ' *' : '';
  console.log(\`  \${tag}: \${(scores[i] * 100).toFixed(1)}%\${active}\`);
});`}
</CodeBlock>

## Per-Label Evaluation

With multi-class, you measure overall accuracy. With multi-label, you need to evaluate each label independently. A model might be great at detecting cardiac cases but terrible at catching infectious ones.

<CodeBlock language="typescript" title="multi-label-metrics.ts">
{`interface LabelMetrics {
  label: string;
  precision: number;
  recall: number;
  f1: number;
}

function perLabelMetrics(
  actual: number[][],
  predicted: number[][],
  labels: string[]
): LabelMetrics[] {
  return labels.map((label, i) => {
    let tp = 0, fp = 0, fn = 0;

    for (let j = 0; j < actual.length; j++) {
      const a = actual[j][i];
      const p = predicted[j][i];
      if (a === 1 && p === 1) tp++;
      if (a === 0 && p === 1) fp++;
      if (a === 1 && p === 0) fn++;
    }

    const precision = tp / (tp + fp || 1);
    const recall = tp / (tp + fn || 1);
    const f1 = 2 * precision * recall / (precision + recall || 1);

    return { label, precision, recall, f1 };
  });
}
