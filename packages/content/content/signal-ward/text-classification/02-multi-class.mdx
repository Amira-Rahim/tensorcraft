## One Document, One Destination

<BridgeCallout bridge={frontmatter.concept.bridge} />

An Express router matches each incoming request to exactly one handler. Similarly, softmax classification assigns each document to exactly one department. The softmax function guarantees that all output probabilities sum to 1. Like a router, every document goes somewhere, and no document goes to two places at once.

<CodeBlock language="typescript" title="department-router.ts">
{`import * as tf from '@tensorflow/tfjs';

const DEPARTMENTS = [
  'CARDIOLOGY', 'RADIOLOGY', 'ONCOLOGY',
  'NEUROLOGY', 'GENERAL_MEDICINE', 'EMERGENCY'
];

function buildDepartmentRouter(
  inputDim: number,
  numDepts: number
): tf.LayersModel {
  const model = tf.sequential();

  model.add(tf.layers.dense({
    units: 128,
    activation: 'relu',
    inputShape: [inputDim]
  }));

  model.add(tf.layers.dropout({ rate: 0.3 }));

  model.add(tf.layers.dense({
    units: 64,
    activation: 'relu'
  }));

  // Softmax: mutually exclusive departments
  model.add(tf.layers.dense({
    units: numDepts,
    activation: 'softmax'
  }));

  model.compile({
    optimizer: 'adam',
    loss: 'categoricalCrossentropy',
    metrics: ['accuracy']
  });

  return model;
}

// Simulated training data
const xTrain = tf.randomNormal([300, 64]);
const yTrain = tf.oneHot(
  tf.randomUniform([300], 0, DEPARTMENTS.length, 'int32'),
  DEPARTMENTS.length
);

const router = buildDepartmentRouter(64, DEPARTMENTS.length);
await router.fit(xTrain, yTrain, {
  epochs: 15,
  batchSize: 32,
  validationSplit: 0.2
});

// Route a new document
const newDoc = tf.randomNormal([1, 64]);
const probs = router.predict(newDoc) as tf.Tensor;
const deptIdx = probs.argMax(-1).dataSync()[0];
const confidence = probs.max().dataSync()[0];

console.log(\`Route to: \${DEPARTMENTS[deptIdx]}\`);
console.log(\`Confidence: \${(confidence * 100).toFixed(1)}%\`);

// Show all department probabilities
const allProbs = await probs.data();
DEPARTMENTS.forEach((dept, i) => {
  console.log(\`  \${dept}: \${(allProbs[i] * 100).toFixed(1)}%\`);
});`}
</CodeBlock>

## Softmax: The Probability Router

The key difference between binary and multi-class classification is in the output layer. Binary uses sigmoid (one probability). Multi-class uses softmax (a probability distribution). Softmax is like a competitive election: each class "votes," and the probabilities must sum to 1.

## Confusion Matrix: Where Routing Goes Wrong

When evaluating a multi-class classifier, accuracy alone isn't enough. A confusion matrix shows exactly which departments get confused with each other. If cardiology documents keep getting routed to emergency, that's a pattern worth investigating.

<CodeBlock language="typescript" title="confusion-matrix.ts">
{`// Build a confusion matrix from predictions
function confusionMatrix(
  actual: number[],
  predicted: number[],
  numClasses: number
): number[][] {
  const matrix = Array.from({ length: numClasses },
    () => new Array(numClasses).fill(0)
  );

  for (let i = 0; i < actual.length; i++) {
    matrix[actual[i]][predicted[i]]++;
  }

  return matrix;
}

// Example: check where misrouting happens
const actuals = [0, 1, 2, 0, 5, 1, 3];
const preds   = [0, 1, 2, 5, 5, 1, 3];  // One misroute: CARDIO → EMERGENCY
const cm = confusionMatrix(actuals, preds, DEPARTMENTS.length);
console.log('Confusion matrix:', cm);`}
</CodeBlock>
