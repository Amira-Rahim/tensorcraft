## Reading Both Ways

<BridgeCallout bridge={frontmatter.concept.bridge} />

In a doubly-linked list, every node knows both its predecessor and successor. BERT works the same way — every token has full attention to all tokens before and after it. This is how BERT would process the problematic note:

<CodeBlock language="typescript" title="bert-masking.ts">
{`import * as tf from '@tensorflow/tfjs';

interface BertInput {
  tokenIds: number[];
  maskedPositions: number[];
  originalTokens: number[];
}

function createMaskedInput(
  tokenIds: number[],
  maskRate: number = 0.15,
  maskTokenId: number = 103  // [MASK] token ID
): BertInput {
  const masked = [...tokenIds];
  const maskedPositions: number[] = [];
  const originalTokens: number[] = [];

  for (let i = 1; i < tokenIds.length - 1; i++) { // skip [CLS] and [SEP]
    if (Math.random() < maskRate) {
      maskedPositions.push(i);
      originalTokens.push(tokenIds[i]);
      masked[i] = maskTokenId; // replace with [MASK]
    }
  }

  return { tokenIds: masked, maskedPositions, originalTokens };
}

// BERT input format: [CLS] tokens... [SEP]
// CLS=101, SEP=102, MASK=103
const tokens = [101, 45, 892, 234, 567, 89, 102];
// "[CLS] History of diabetes resolved after [SEP]"

const bertInput = createMaskedInput(tokens);
console.log('Masked input:', bertInput.tokenIds);
console.log('Masked positions:', bertInput.maskedPositions);

// BERT predicts the masked tokens using FULL bidirectional context
// "History of [MASK] resolved after" → predicts "diabetes"
// The model sees "resolved after" BEFORE making its prediction`}
</CodeBlock>

## Why Bidirectionality Fixes MEDI's Error

The key insight: when BERT processes "History of Type 2 diabetes, resolved after bariatric surgery," the representation of "diabetes" is informed by BOTH "History of" (before) AND "resolved after" (after). The model understands the full context simultaneously.

<Dialogue speaker="Obi Nwosu">
MEDI's unidirectional model built a representation of "diabetes" using only left context — "History of Type 2 diabetes." That representation said "active condition." BERT's bidirectional model would build a representation that includes "resolved" — completely changing the clinical interpretation.
</Dialogue>
