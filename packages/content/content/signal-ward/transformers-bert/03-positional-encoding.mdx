## Injecting Order

<BridgeCallout bridge={frontmatter.concept.bridge} />

In CSS, `flex` items flow by source order unless you set the `order` property. Similarly, transformer tokens have no inherent sequence — we add positional encoding to each token embedding to tell the model where each word sits.

<CodeBlock language="typescript" title="positional-encoding.ts">
{`import * as tf from '@tensorflow/tfjs';

function sinusoidalPositionalEncoding(
  maxLen: number,
  dModel: number
): tf.Tensor2D {
  const positions = [];

  for (let pos = 0; pos < maxLen; pos++) {
    const row = [];
    for (let i = 0; i < dModel; i++) {
      const angle = pos / Math.pow(10000, (2 * Math.floor(i / 2)) / dModel);
      // Even indices use sine, odd indices use cosine
      row.push(i % 2 === 0 ? Math.sin(angle) : Math.cos(angle));
    }
    positions.push(row);
  }

  return tf.tensor2d(positions); // [maxLen, dModel]
}

// Create encoding for up to 512 positions, 64 dimensions
const posEncoding = sinusoidalPositionalEncoding(512, 64);
console.log('Positional encoding shape:', posEncoding.shape);

// Apply to token embeddings
const tokenEmbeddings = tf.randomNormal([10, 64]); // 10 tokens
const posSlice = posEncoding.slice([0, 0], [10, 64]); // first 10 positions
const encodedInput = tokenEmbeddings.add(posSlice);
console.log('Encoded input shape:', encodedInput.shape); // [10, 64]`}
</CodeBlock>

## Why Sinusoids?

The sinusoidal pattern has a clever property: the encoding for position `p + k` can be expressed as a linear function of position `p`. This means the model can learn to attend to relative positions — "the word 3 positions before me" — not just absolute positions.

<Dialogue speaker="Obi Nwosu">
In clinical text, relative position matters enormously. "Denied chest pain" — "denied" is one position before "chest." That relative distance carries the negation relationship, regardless of where in the note it appears.
</Dialogue>

Different dimensions encode different frequencies, like multiple `z-index` layers each carrying different spatial information.
