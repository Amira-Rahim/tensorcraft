<Dialogue speaker="Vikram">
Before BERT ever sees a clinical note, it trains on millions of general text documents. And it needs no labels at all. It creates its own training signal by playing two games with the text.
</Dialogue>

<Dialogue speaker="Khalil">
Self-supervised learning? That's like how VS Code IntelliSense learns from your codebase: it figures out what should fill the blank based on surrounding context, without anyone manually labeling every completion.
</Dialogue>

<Dialogue speaker="Vikram">
Useful comparison, wrong machinery. IntelliSense looks completions up in a static index keyed by symbol names. BERT learns contextual embeddings: "bank" next to "river" fills the blank differently than "bank" next to "money," and no index can store that. The first game is Masked Language Modeling, MLM. Hide a word, predict it from context. The second is Next Sentence Prediction, NSP. Given two sentences, did the second actually follow the first?
</Dialogue>

## Game 1: Masked Language Modeling

<BridgeCallout bridge={frontmatter.concept.bridge} />

MLM predicts a randomly hidden token using both left and right context, not just the tokens that came before it. That bidirectionality is what next-token predictors give up.

BERT masks 15% of tokens, but with a twist: of those 15%, 80% become `[MASK]`, 10% become a random token, and 10% stay unchanged. This prevents the model from learning that `[MASK]` is the only signal for prediction.

<CodeBlock language="typescript" title="masked-language-modeling.ts">
{`import * as tf from '@tensorflow/tfjs';

interface MLMBatch {
  inputIds: number[];
  maskedPositions: number[];
  trueLabels: number[];
}

function createMLMBatch(
  tokenIds: number[],
  vocabSize: number,
  maskTokenId: number = 103,
  maskRate: number = 0.15
): MLMBatch {
  const inputIds = [...tokenIds];
  const maskedPositions: number[] = [];
  const trueLabels: number[] = [];

  for (let i = 1; i < tokenIds.length - 1; i++) { // skip [CLS] and [SEP]
    if (Math.random() < maskRate) {
      maskedPositions.push(i);
      trueLabels.push(tokenIds[i]);

      const r = Math.random();
      if (r < 0.8) {
        inputIds[i] = maskTokenId;         // 80%: replace with [MASK]
      } else if (r < 0.9) {
        inputIds[i] = Math.floor(Math.random() * vocabSize); // 10%: random token
      }
      // 10%: keep original (do nothing)
    }
  }

  return { inputIds, maskedPositions, trueLabels };
}

// Simulated MLM prediction head
function mlmPredictionHead(
  encoderOutput: tf.Tensor2D,  // [seqLen, dModel]
  maskedPositions: number[],
  vocabSize: number
): tf.Tensor2D {
  const dModel = encoderOutput.shape[1];

  // Gather hidden states at masked positions
  const maskedStates = tf.gather(encoderOutput, maskedPositions);

  // Project to vocabulary size and softmax
  const projection = tf.randomNormal([dModel, vocabSize]);
  const logits = tf.matMul(maskedStates, projection);
  return tf.softmax(logits, -1) as tf.Tensor2D;
}

// Example: clinical note tokenized
// "[CLS] Patient has type-2 diabetes resolved after surgery [SEP]"
const tokens = [101, 450, 312, 892, 234, 567, 89, 778, 102];
const batch = createMLMBatch(tokens, 30000);
console.log('Input with masks:', batch.inputIds);
console.log('Positions to predict:', batch.maskedPositions);
console.log('True labels:', batch.trueLabels);

// Simulate encoder output and predict
const encoderOut = tf.randomNormal([tokens.length, 64]) as tf.Tensor2D;
if (batch.maskedPositions.length > 0) {
  const predictions = mlmPredictionHead(encoderOut, batch.maskedPositions, 30000);
  console.log('Prediction shape:', predictions.shape);
  // [numMasked, vocabSize]: probability over entire vocabulary
}`}
</CodeBlock>

## Game 2: Next Sentence Prediction

NSP trains BERT to understand document structure. Given sentence A and sentence B, the model predicts whether B actually followed A in the original text, or was randomly sampled from elsewhere.

<CodeBlock language="typescript" title="next-sentence-prediction.ts">
{`import * as tf from '@tensorflow/tfjs';

interface NSPExample {
  sentenceA: number[];
  sentenceB: number[];
  isNext: boolean;
}

function createNSPExamples(
  documents: number[][],  // array of tokenized sentences
  numExamples: number
): NSPExample[] {
  const examples: NSPExample[] = [];

  for (let i = 0; i < numExamples; i++) {
    const docIdx = Math.floor(Math.random() * (documents.length - 1));
    const sentenceA = documents[docIdx];

    if (Math.random() < 0.5) {
      // 50%: actual next sentence
      examples.push({
        sentenceA,
        sentenceB: documents[docIdx + 1],
        isNext: true
      });
    } else {
      // 50%: random sentence from corpus
      const randomIdx = Math.floor(Math.random() * documents.length);
      examples.push({
        sentenceA,
        sentenceB: documents[randomIdx],
        isNext: false
      });
    }
  }
  return examples;
}

// NSP classification head uses [CLS] token output
function nspHead(clsOutput: tf.Tensor2D, dModel: number): tf.Tensor2D {
  const W = tf.randomNormal([dModel, 2]);
  const logits = tf.matMul(clsOutput, W);
  return tf.softmax(logits, -1) as tf.Tensor2D; // [batch, 2]: IsNext / NotNext
}

// Clinical example:
// A: "Patient presents with elevated blood pressure."
// B: "Started on lisinopril 10mg daily."  ← IsNext (true continuation)
// B: "Lab received new centrifuge equipment."  ← NotNext (random)
const clsOutput = tf.randomNormal([1, 64]) as tf.Tensor2D;
const nspPrediction = nspHead(clsOutput, 64);
console.log('NSP prediction [IsNext, NotNext]:', await nspPrediction.array());`}
</CodeBlock>

## Why This Matters for Clinical Text

<Dialogue speaker="Dr. Karimi">
So BERT learns to fill in blanks and understand sentence flow, on Wikipedia, news articles, books. How does that help us with clinical notes?
</Dialogue>

<Dialogue speaker="Vikram">
Because language has universal patterns. A model that can predict "The patient was prescribed [MASK] for hypertension" has learned something about how medical terms relate, even from general text. But it won't know that "lisinopril" is more likely than "ibuprofen" until we fine-tune it on clinical data. Pre-training gives us the skeleton. Fine-tuning adds the medical knowledge.
</Dialogue>

## Challenge

Implement the MLM masking strategy with the 80/10/10 split and build a prediction head that maps encoder outputs to vocabulary probabilities.

<Exercise slug="mask-and-predict" />

<DerivationDrawer summary="BERT MLM loss + 80/10/10 masking strategy">
BERT pre-training uses **Masked Language Modeling (MLM)**: randomly mask 15% of tokens and predict them from context.

**Loss for one masked position i:**

`L_MLM = −log p(x_i | context)`

Summed over all masked positions in the batch.

**The 80/10/10 masking trick** (instead of always replacing with [MASK]):
- 80%: replace with `[MASK]` token
- 10%: replace with a random token
- 10%: keep the original token unchanged

**Why?** The downstream fine-tuning task never sees `[MASK]` tokens (real text). If the model only learned to fill in `[MASK]`, it would degrade on real input. The 10/10/80 mix forces the model to maintain useful representations for ALL tokens, not just masked ones, because it can't tell which tokens are "real" and which were swapped.

**Combined with NSP** (Next Sentence Prediction, since dropped in RoBERTa) for the original BERT objective. Modern models (RoBERTa, DeBERTa) keep MLM with 80/10/10 but skip NSP.
</DerivationDrawer>
