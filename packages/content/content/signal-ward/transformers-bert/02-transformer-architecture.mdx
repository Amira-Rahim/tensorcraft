## The Encoder Block

<BridgeCallout bridge={frontmatter.concept.bridge} />

A transformer encoder block has two sub-layers, each wrapped in a residual connection and layer normalization:

1. **Multi-Head Self-Attention** — tokens attend to each other
2. **Position-wise Feed-Forward Network** — each token processed independently through a small MLP

<CodeBlock language="typescript" title="encoder-block.ts">
{`import * as tf from '@tensorflow/tfjs';

function layerNorm(x: tf.Tensor2D): tf.Tensor2D {
  const mean = x.mean(-1, true);
  const variance = x.sub(mean).square().mean(-1, true);
  const epsilon = 1e-6;
  return x.sub(mean).div(variance.add(epsilon).sqrt()) as tf.Tensor2D;
}

function feedForward(x: tf.Tensor2D, dModel: number, dFF: number): tf.Tensor2D {
  const W1 = tf.randomNormal([dModel, dFF]);
  const b1 = tf.zeros([dFF]);
  const W2 = tf.randomNormal([dFF, dModel]);
  const b2 = tf.zeros([dModel]);

  const hidden = tf.relu(tf.matMul(x, W1).add(b1));
  return tf.matMul(hidden, W2).add(b2) as tf.Tensor2D;
}

function simpleMultiHeadAttention(x: tf.Tensor2D, dModel: number, numHeads: number): tf.Tensor2D {
  const dk = dModel / numHeads;
  const heads: tf.Tensor2D[] = [];

  for (let h = 0; h < numHeads; h++) {
    const Q = tf.matMul(x, tf.randomNormal([dModel, dk]));
    const K = tf.matMul(x, tf.randomNormal([dModel, dk]));
    const V = tf.matMul(x, tf.randomNormal([dModel, dk]));
    const scores = tf.softmax(tf.matMul(Q, K.transpose()).div(Math.sqrt(dk)), -1);
    heads.push(tf.matMul(scores, V) as tf.Tensor2D);
  }
  const concat = tf.concat(heads, 1) as tf.Tensor2D;
  return tf.matMul(concat, tf.randomNormal([dModel, dModel])) as tf.Tensor2D;
}

// Post-norm variant (original "Attention Is All You Need" paper, Vaswani 2017):
//   x → attention → +residual → LayerNorm → FF → +residual → LayerNorm
// Modern transformers (GPT-2 onward) use pre-norm:
//   x → LayerNorm → attention → +residual → LayerNorm → FF → +residual
// Empirical line: Vaswani 2017 trained 6 layers stably with post-norm; BERT-Large
// (24 layers) needs warmup + careful init to converge with post-norm; GPT-2 (48+)
// and modern models (96+) use pre-norm because post-norm gradient magnitudes
// diverge past ~12 layers. This example uses post-norm for clarity —
// switch the order if you stack ≥12 layers.
function encoderBlock(x: tf.Tensor2D, dModel: number, numHeads: number, dFF: number): tf.Tensor2D {
  // Sub-layer 1: Multi-head attention + residual + norm
  const attnOut = simpleMultiHeadAttention(x, dModel, numHeads);
  const norm1 = layerNorm(x.add(attnOut) as tf.Tensor2D);

  // Sub-layer 2: Feed-forward + residual + norm
  const ffOut = feedForward(norm1, dModel, dFF);
  const norm2 = layerNorm(norm1.add(ffOut) as tf.Tensor2D);

  return norm2;
}

// Stack 3 encoder blocks
let x = tf.randomNormal([10, 64]) as tf.Tensor2D; // 10 tokens, 64-dim
for (let i = 0; i < 3; i++) {
  x = encoderBlock(x, 64, 4, 256);
}
console.log('Encoder output:', x.shape); // [10, 64]`}
</CodeBlock>

## Residual Connections: Preserving What Matters

The `x.add(attnOut)` step is critical. Without it, deep networks suffer from vanishing gradients — information from early layers fades. The residual connection provides a highway for gradients and information to flow through unchanged, while the attention layer adds refinements.

<Dialogue speaker="Khalil">
That's like how React's reconciliation works — you don't rebuild the entire DOM. You keep the existing structure and apply only the changes. The residual connection is the existing DOM; the attention output is the diff.
</Dialogue>
