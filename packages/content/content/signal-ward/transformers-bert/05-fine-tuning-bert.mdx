## Theme Overrides for Neural Networks

<BridgeCallout bridge={frontmatter.concept.bridge} />

Fine-tuning follows the same pattern as theming a component library: you take a foundation that already works (pre-trained BERT), keep its core capabilities (language understanding), and customize the surface layer (task-specific head) for your domain.

<CodeBlock language="typescript" title="fine-tune-clinical.ts">
{`import * as tf from '@tensorflow/tfjs';

// Simulated pre-trained BERT encoder (in practice, load real weights)
function createBertEncoder(dModel: number, numLayers: number) {
  const model = tf.sequential();
  for (let i = 0; i < numLayers; i++) {
    model.add(tf.layers.dense({
      units: dModel,
      activation: 'relu',
      inputShape: i === 0 ? [dModel] : undefined
    }));
  }
  return model;
}

// Add clinical classification head
function addClinicalHead(
  encoder: tf.Sequential,
  numLabels: number,
  dModel: number
) {
  const input = tf.input({ shape: [dModel] });
  const encoded = encoder.apply(input) as tf.SymbolicTensor;

  // Classification head: dropout → dense → softmax
  const dropped = tf.layers.dropout({ rate: 0.1 }).apply(encoded) as tf.SymbolicTensor;
  const output = tf.layers.dense({
    units: numLabels,
    activation: 'softmax'
  }).apply(dropped) as tf.SymbolicTensor;

  return tf.model({ inputs: input, outputs: output });
}

// Build and compile
const dModel = 64;
const encoder = createBertEncoder(dModel, 3);
const clinicalModel = addClinicalHead(encoder, 5, dModel);

// Use a SMALL learning rate for fine-tuning
clinicalModel.compile({
  optimizer: tf.train.adam(2e-5), // much smaller than training from scratch
  loss: 'categoricalCrossentropy',
  metrics: ['accuracy']
});

// Simulated clinical data: [CLS] embeddings → condition labels
const xTrain = tf.randomNormal([100, dModel]);
const yTrain = tf.oneHot(
  tf.randomUniform([100], 0, 5, 'int32'),
  5
);

await clinicalModel.fit(xTrain, yTrain, {
  epochs: 3,      // few epochs — we're refining, not training from scratch
  batchSize: 16,
  validationSplit: 0.2,
  callbacks: {
    onEpochEnd: (epoch, logs) => {
      console.log(\`Epoch \${epoch + 1}: loss=\${logs.loss.toFixed(4)}, acc=\${logs.acc.toFixed(4)}\`);
    }
  }
});`}
</CodeBlock>

## Catastrophic Forgetting

<Dialogue speaker="Obi Nwosu">
The biggest risk in fine-tuning is catastrophic forgetting — the model overwrites its general language knowledge while learning clinical specifics. It's like customizing a theme so aggressively that the component library's core functionality breaks. Use small learning rates. Train for few epochs. Preserve the foundation.
</Dialogue>
