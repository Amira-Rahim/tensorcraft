## CSS Classes That Depend on Siblings

<BridgeCallout bridge={frontmatter.concept.bridge} />

In simple CSS, you assign a class to each element independently: `el.className = 'drug'`. But real-world styling often depends on context — `:first-child`, `:nth-of-type`, adjacent sibling selectors. The element's appearance depends on its neighbors.

Sequence labeling works the same way. A dictionary lookup classifies tokens in isolation. A neural sequence labeler considers the full sentence context before assigning each label:

- "Patient has a **cold**" → CONDITION (preceded by "has a")
- "Apply **cold** compress" → O (preceded by "Apply", followed by "compress")

<CodeBlock language="typescript" title="sequence-labeling.ts">
{`import * as tf from '@tensorflow/tfjs';

// BIO tag vocabulary
const TAGS = ['O', 'B-DRUG', 'I-DRUG', 'B-CONDITION', 'I-CONDITION',
              'B-DOSAGE', 'I-DOSAGE', 'B-FREQUENCY', 'I-FREQUENCY'];

// Build a neural sequence labeler
function buildSequenceLabeler(
  vocabSize: number,
  embedDim: number,
  hiddenDim: number,
  numTags: number,
  maxSeqLen: number
): tf.LayersModel {
  const input = tf.input({ shape: [maxSeqLen] });

  // Step 1: Embed each token — like assigning initial styles
  const embedded = tf.layers.embedding({
    inputDim: vocabSize,
    outputDim: embedDim,
    maskZero: true
  }).apply(input) as tf.SymbolicTensor;

  // Step 2: BiLSTM captures context from both directions
  // Like sibling selectors that look left AND right
  const contextual = tf.layers.bidirectional({
    layer: tf.layers.lstm({
      units: hiddenDim,
      returnSequences: true  // output for EVERY token, not just the last
    }) as tf.RNNLayer
  }).apply(embedded) as tf.SymbolicTensor;

  // Step 3: Classify each token using its context-aware representation
  // Like assigning final CSS classes based on full selector context
  const output = tf.layers.timeDistributed({
    layer: tf.layers.dense({
      units: numTags,
      activation: 'softmax'
    })
  }).apply(contextual) as tf.SymbolicTensor;

  return tf.model({ inputs: input, outputs: output });
}

// Prepare training data: tokens → padded integer sequences
function prepareSequence(
  tokens: string[],
  vocab: Map<string, number>,
  maxLen: number
): tf.Tensor2D {
  const ids = tokens.map(t => vocab.get(t.toLowerCase()) ?? 0);
  // Pad to maxLen — like setting a fixed container width
  while (ids.length < maxLen) ids.push(0);
  return tf.tensor2d([ids.slice(0, maxLen)]);
}

// Decode predictions back to BIO tags
async function decodePredictions(
  predictions: tf.Tensor,
  tokens: string[]
): Promise<Array<{ token: string; tag: string; confidence: number }>> {
  const probs = await predictions.squeeze().array() as number[][];
  return tokens.map((token, i) => {
    const maxIdx = probs[i].indexOf(Math.max(...probs[i]));
    return {
      token,
      tag: TAGS[maxIdx],
      confidence: probs[i][maxIdx]
    };
  });
}

// Build and compile the model
const MAX_SEQ_LEN = 64;
const model = buildSequenceLabeler(5000, 64, 128, TAGS.length, MAX_SEQ_LEN);
model.compile({
  optimizer: 'adam',
  loss: 'categoricalCrossentropy',
  metrics: ['accuracy']
});

console.log('Sequence labeler built:');
model.summary();`}
</CodeBlock>

## Training the Labeler

<Dialogue speaker="Obi Nwosu">
The key insight: `returnSequences: true` on the LSTM means we get an output for every token, not just the last one. Without it, we'd get a single vector for the whole sentence — useful for classification, useless for labeling individual tokens.
</Dialogue>

Training requires aligned token-label pairs. Each training example is a sentence where every token has a BIO tag:

const trainingExamples = [

    tags:   ['O',       'O',          'B-DRUG',       'B-DOSAGE', 'B-FREQUENCY', 'O', 'B-CONDITION']
  },
  {
    tokens: ['History', 'of', 'rheumatoid', 'arthritis', 'on', 'warfarin', '5mg'],
    tags:   ['O',       'O',  'B-CONDITION', 'I-CONDITION', 'O', 'B-DRUG', 'B-DOSAGE']
  }
];

// Convert tags to one-hot vectors for training
function tagsToOneHot(tags: string[], tagVocab: string[]): tf.Tensor {
  const indices = tags.map(t => tagVocab.indexOf(t));
  return tf.oneHot(indices, tagVocab.length);
}`}

## Santos on Validation

<Dialogue speaker="Santos">
A model that's 95% accurate per-token might still miss 30% of entities. Why? Because entity-level evaluation requires getting every token in a span correct. "B-CONDITION I-CONDITION" is only a correct entity if both tags are right. One wrong tag, and the whole entity is wrong. Always evaluate at the span level, not just the token level.
</Dialogue>
