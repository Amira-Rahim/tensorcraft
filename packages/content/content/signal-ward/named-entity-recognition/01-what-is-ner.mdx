## querySelectorAll for Text

<BridgeCallout bridge={frontmatter.concept.bridge} />

An NER model walks through every token and decides whether it belongs to an entity type. But where a CSS selector matches exactly or not at all, the model outputs probabilities. It has to learn which tokens are drugs, which are conditions, and which are just connecting words like "the" or "prescribed." It will sometimes fragment a compound term or miss a drug it has never seen.

<CodeBlock language="typescript" title="what-is-ner.ts">
{`import * as tf from '@tensorflow/tfjs';

// Entity types for clinical NER, like CSS selectors for text
const ENTITY_TYPES = ['O', 'DRUG', 'CONDITION', 'DOSAGE', 'FREQUENCY', 'PROCEDURE'];

interface Entity {
  text: string;
  type: string;
  start: number;
  end: number;
}

// querySelectorAll for clinical text
function findEntities(
  tokens: string[],
  embeddings: tf.Tensor2D,
  numClasses: number
): tf.Tensor2D {
  // Classification layer: each token → entity type probabilities
  // Like checking each DOM node against a selector
  const W = tf.variable(tf.randomNormal([embeddings.shape[1], numClasses]));
  const b = tf.variable(tf.zeros([numClasses]));

  const logits = tf.matMul(embeddings, W).add(b);
  return tf.softmax(logits, -1) as tf.Tensor2D; // [seqLen, numClasses]
}

async function extractEntities(
  tokens: string[],
  predictions: tf.Tensor2D
): Promise<Entity[]> {
  const predArray = await predictions.argMax(-1).array() as number[];
  const entities: Entity[] = [];

  for (let i = 0; i < tokens.length; i++) {
    const typeIdx = predArray[i];
    if (typeIdx !== 0) { // skip 'O' (outside), like nodes that don't match the selector
      entities.push({
        text: tokens[i],
        type: ENTITY_TYPES[typeIdx],
        start: i,
        end: i + 1
      });
    }
  }
  return entities;
}

// Example: parse a clinical sentence
const tokens = ['Patient', 'prescribed', 'methotrexate', '15mg', 'weekly'];
const embeddings = tf.randomNormal([5, 64]) as tf.Tensor2D;
const probs = findEntities(tokens, embeddings, ENTITY_TYPES.length);
const entities = await extractEntities(tokens, probs);
console.log('Found entities:', entities);
// Like: document.querySelectorAll('.drug, .dosage, .frequency')`}

## The Classification Pipeline

Every NER system follows the same pipeline, whether it's rule-based or neural:

1. **Tokenize** the input text into individual words
2. **Embed** each token into a numerical representation
3. **Classify** each token as an entity type or O (outside)
4. **Extract** contiguous entity spans from the classifications

This mirrors how a browser processes a CSS selector: parse the selector, walk the DOM, test each node, collect matches.
