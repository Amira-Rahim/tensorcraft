## The Difference in Action

<CodeBlock language="typescript" title="compare-embeddings.ts">
{`function cosineSim(a: number[], b: number[]): number {
  const dot = a.reduce((s, v, i) => s + v * b[i], 0);
  const nA = Math.sqrt(a.reduce((s, v) => s + v * v, 0));
  const nB = Math.sqrt(b.reduce((s, v) => s + v * v, 0));
  return dot / (nA * nB);
}

// "discharge" in generic embeddings: closest to "fire"
console.log('Generic: discharge ~ fire =',
  cosineSim(genericEmbeddings['discharge'], genericEmbeddings['fire']).toFixed(3)
); // ~0.95

console.log('Generic: discharge ~ hospital =',
  cosineSim(genericEmbeddings['discharge'], genericEmbeddings['hospital']).toFixed(3)
); // ~0.12

// "discharge" in medical embeddings: closest to "hospital"
console.log('Medical: discharge ~ hospital =',
  cosineSim(medicalEmbeddings['discharge'], medicalEmbeddings['hospital']).toFixed(3)
); // ~0.97

console.log('Medical: discharge ~ fire =',
  cosineSim(medicalEmbeddings['discharge'], medicalEmbeddings['fire']).toFixed(3)
); // ~-0.20

// "stat" in medical context means "immediately", not "statistics"
console.log('Medical: stat ~ urgent =',
  cosineSim(medicalEmbeddings['stat'], medicalEmbeddings['urgent']).toFixed(3)
); // ~0.92`}
</CodeBlock>

Could we keep both sets loaded and fall back to the generic vector when a word isn't in the medical set? The cascade does that: scoped value first, global value when the scope misses.
</Dialogue>

<Dialogue speaker="Vikram">
This is where the cascade stops helping you. CSS falls back cleanly because both values live in the same coordinate system. Two embedding sets don't: they were trained separately, so dimension 3 in one has nothing to do with dimension 3 in the other. Mix them naively and you can degrade both. Which blend works is an empirical question, not a cascade rule.
</Dialogue>

## Real-World Medical Embedding Models

<Dialogue speaker="MEDI">
Several pre-trained medical embedding models are available for clinical NLP. BioWordVec was trained on PubMed and MIMIC-III clinical notes. Clinical embeddings from the NLP community capture abbreviations like "PCN" (penicillin), "PRN" (as needed), and "q.i.d." (four times daily).
</Dialogue>

<CodeBlock language="typescript" title="loading-pretrained.ts">
{`import * as tf from '@tensorflow/tfjs';

// In production, you would load pre-trained medical embeddings
// from a binary file or an API endpoint:
//
// BioWordVec: trained on PubMed + MIMIC-III
// fastText-medical: trained on clinical notes
// ClinicalBERT embeddings: contextual medical vectors

async function loadMedicalEmbeddings(
  vocabSize: number,
  embeddingDim: number,
  pretrainedWeights: number[][]
): Promise<tf.LayersModel> {
  const model = tf.sequential();

  const embeddingLayer = tf.layers.embedding({
    inputDim: vocabSize,
    outputDim: embeddingDim,
    weights: [tf.tensor2d(pretrainedWeights)],
    trainable: false,  // freeze: use as-is, do not modify during training
  });

  model.add(embeddingLayer);
  return model;
}

// The key insight: freezing the embedding layer means
// your model inherits knowledge from millions of documents
// without needing millions of your own training samples.`}
</CodeBlock>
