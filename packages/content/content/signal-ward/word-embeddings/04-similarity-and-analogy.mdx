## Cosine Similarity: Measuring Meaning

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="cosine-similarity.ts">
{`// Cosine similarity measures the angle between two vectors.
// 1.0 = identical direction (same meaning)
// 0.0 = perpendicular (unrelated)
// -1.0 = opposite direction (opposite meaning)

function cosineSimilarity(a: number[], b: number[]): number {
  const dot = a.reduce((sum, val, i) => sum + val * b[i], 0);
  const normA = Math.sqrt(a.reduce((sum, val) => sum + val * val, 0));
  const normB = Math.sqrt(b.reduce((sum, val) => sum + val * val, 0));
  return dot / (normA * normB);
}

const embeddings: Record<string, number[]> = {
  'aspirin':      [0.82, 0.21, -0.11, 0.53, 0.34, -0.08],
  'ibuprofen':    [0.74, 0.29, -0.18, 0.45, 0.31, -0.12],
  'penicillin':   [-0.12, 0.81, 0.62, -0.22, 0.15, 0.71],
  'amoxicillin':  [-0.19, 0.73, 0.68, -0.15, 0.18, 0.65],
  'headache':     [0.55, -0.31, 0.22, 0.78, -0.15, 0.08],
  'infection':    [-0.08, 0.69, 0.55, -0.18, 0.42, 0.58],
  'appendectomy': [0.08, -0.31, 0.14, 0.91, 0.61, -0.33],
  'surgeon':      [0.12, -0.25, 0.19, 0.85, 0.55, -0.28],
};

// Similar medications score high
console.log('aspirin ~ ibuprofen:',
  cosineSimilarity(embeddings['aspirin'], embeddings['ibuprofen']).toFixed(3)
); // ~0.98

// Different categories score low
console.log('aspirin ~ appendectomy:',
  cosineSimilarity(embeddings['aspirin'], embeddings['appendectomy']).toFixed(3)
); // ~0.22`}
</CodeBlock>

## Finding Nearest Neighbors

<CodeBlock language="typescript" title="nearest-neighbors.ts">
{`function findMostSimilar(
  query: string,
  embeddings: Record<string, number[]>,
  topK: number = 3
): { word: string; similarity: number }[] {
  const queryVec = embeddings[query];
  const results: { word: string; similarity: number }[] = [];

  for (const [word, vec] of Object.entries(embeddings)) {
    if (word === query) continue;
    results.push({
      word,
      similarity: cosineSimilarity(queryVec, vec),
    });
  }

  return results
    .sort((a, b) => b.similarity - a.similarity)
    .slice(0, topK);
}

console.log('Most similar to aspirin:', findMostSimilar('aspirin', embeddings));
// [{word: 'ibuprofen', similarity: 0.98}, ...]

console.log('Most similar to penicillin:', findMostSimilar('penicillin', embeddings));
// [{word: 'amoxicillin', similarity: 0.97}, {word: 'infection', similarity: 0.89}, ...]`}
</CodeBlock>

## Word Analogies: Vector Arithmetic

<Dialogue speaker="Vikram">
Here is the famous result: king - man + woman = queen. The vector arithmetic captures the relationship "male royalty is to female royalty." We can do the same with medical terms.
</Dialogue>

<CodeBlock language="typescript" title="word-analogies.ts">
{`// Analogy: a is to b as c is to ???
// Formula: result = vec(a) - vec(b) + vec(c)
// Then find the word whose vector is closest to the result

function solveAnalogy(
  a: string, b: string, c: string,
  embeddings: Record<string, number[]>
): string {
  const vecA = embeddings[a];
  const vecB = embeddings[b];
  const vecC = embeddings[c];

  // result = a - b + c
  const resultVec = vecA.map((val, i) => val - vecB[i] + vecC[i]);

  // Find the closest word (excluding inputs)
  const exclude = new Set([a, b, c]);
  let bestWord = '';
  let bestSim = -Infinity;

  for (const [word, vec] of Object.entries(embeddings)) {
    if (exclude.has(word)) continue;
    const sim = cosineSimilarity(resultVec, vec);
    if (sim > bestSim) {
      bestSim = sim;
      bestWord = word;
    }
  }

  return bestWord;
}

// aspirin is to headache as penicillin is to ???
const result = solveAnalogy('aspirin', 'headache', 'penicillin', embeddings);
console.log('aspirin : headache :: penicillin :', result);
// Expected: "infection"; aspirin treats headaches, penicillin treats infections

// appendectomy is to surgeon as ??? is to ???
// Vector arithmetic discovers occupational relationships`}
</CodeBlock>

<DerivationDrawer summary="Vector arithmetic for analogies">
The famous analogy `king - man + woman ≈ queen` holds because well-trained embeddings put related concepts in linearly-related directions. Procedure:

```
target_vector = embed('king') - embed('man') + embed('woman')
result = argmax over vocab v of cosine(embed(v), target_vector)
         excluding v in {king, man, woman}
```

**Why excluding inputs:** without exclusion, the closest vocabulary word is often `king` (since the math doesn't perfectly cancel), which is not interesting.

**Why this works geometrically:** if the gender axis (man → woman) is roughly the same direction across pairs (king → queen, brother → sister, ...), then subtracting the male direction from king and adding the female direction lands near queen.

**Why this often fails:** the math is approximate. Modern contextual embeddings (BERT, GPT) don't use single vectors per word (meaning depends on context), so static-vector analogies are a property of older Word2Vec/GloVe-style embeddings, not modern LLMs.
</DerivationDrawer>
