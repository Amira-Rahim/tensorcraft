One-hot encoding is the enum of machine learning. Each word gets a unique ID, but the representation carries no information about meaning, similarity, or relationships. It is the simplest possible encoding and the starting point for understanding why we need something better.

## The Enum of ML

<BridgeCallout bridge={frontmatter.concept.bridge} />

In frontend code, enum values give each item a unique integer. One-hot encoding does the same thing, except each word becomes a vector instead of a single number. The vector has one position set to 1 (the word's index) and every other position set to 0.

<CodeBlock language="typescript" title="one-hot-encoding.ts">
{`import * as tf from '@tensorflow/tfjs';

// Our clinical vocabulary
const vocab = ['aspirin', 'ibuprofen', 'penicillin', 'amoxicillin', 'appendectomy'];

function oneHotEncode(word: string, vocabulary: string[]): tf.Tensor1D {
  const index = vocabulary.indexOf(word);
  const vector = new Array(vocabulary.length).fill(0);
  if (index !== -1) vector[index] = 1;
  return tf.tensor1d(vector);
}

// Each word becomes a unique vector
const aspirin     = oneHotEncode('aspirin', vocab);
const ibuprofen   = oneHotEncode('ibuprofen', vocab);
const appendectomy = oneHotEncode('appendectomy', vocab);

aspirin.print();      // [1, 0, 0, 0, 0]
ibuprofen.print();    // [0, 1, 0, 0, 0]
appendectomy.print(); // [0, 0, 0, 0, 1]`}
</CodeBlock>

## The Problem: No Relationships

Aspirin and ibuprofen are both NSAIDs — pain relievers that work on the same biological pathway. But their one-hot vectors are orthogonal, meaning their cosine similarity is 0. They are exactly as "different" from each other as aspirin is from appendectomy (a surgical procedure). One-hot encoding is blind to meaning.

<CodeBlock language="typescript" title="one-hot-distances.ts">
{`function cosineSimilarity(a: tf.Tensor, b: tf.Tensor): number {
  const dot = a.mul(b).sum();
  const normA = a.norm();
  const normB = b.norm();
  return dot.div(normA.mul(normB)).dataSync()[0];
}

// Aspirin vs Ibuprofen (both painkillers — should be similar)
console.log(cosineSimilarity(aspirin, ibuprofen));  // 0

// Aspirin vs Appendectomy (completely unrelated — should be different)
console.log(cosineSimilarity(aspirin, appendectomy));  // 0

// One-hot encoding says everything is equally unrelated.
// That is a problem when your model needs to know that
// aspirin and ibuprofen are interchangeable but neither
// is a surgical procedure.

// And with a real clinical vocabulary of 50,000 terms,
// each vector has 50,000 dimensions — mostly zeros.`}
</CodeBlock>

## The Scale Problem

<CodeBlock language="typescript" title="scale-problem.ts">
{`// With a 50,000-word clinical vocabulary:
const vocabSize = 50_000;

// Each one-hot vector has 50,000 dimensions
// A batch of 128 words = 128 x 50,000 = 6.4 million values
// Most of them are zeros — wasted memory

// In frontend terms: imagine a CSS file where every class name
// is a unique 50,000-character string of 0s and 1s.
// It works, but it is absurdly wasteful.

console.log('Vector dimensions:', vocabSize);
console.log('Non-zero values per vector:', 1);
console.log('Sparsity:', ((vocabSize - 1) / vocabSize * 100).toFixed(4) + '%');
// Sparsity: 99.9980% — almost entirely zeros`}
</CodeBlock>
