When you define routes like `/patients/:id/records/:recordId`, your router parses the path into meaningful segments. Subword tokenization does the same to words — breaking "electrocardiogram" into `["electro", "##cardio", "##gram"]`, where each piece carries meaning.

## Why Words Aren't Enough

<BridgeCallout bridge={frontmatter.concept.bridge} />

A word-level vocabulary of 30,000 entries can't cover every medical term. But a subword vocabulary of 5,000 pieces can represent virtually any word by composition.

<CodeBlock language="typescript" title="subword-tokenizer.ts">
{`// A simplified WordPiece tokenizer
const subwordVocab = new Set([
  'card', '##io', '##logy', '##itis', '##ectomy',
  'gastro', '##enter', 'hyper', '##tension',
  'patient', 'reports', 'pain',
  'the', 'a', 'with', 'has',
]);

function wordPieceTokenize(word: string): string[] {
  const tokens: string[] = [];
  let start = 0;

  while (start < word.length) {
    let end = word.length;
    let found = false;

    while (end > start) {
      const substr = (start === 0 ? '' : '##') + word.slice(start, end);
      if (subwordVocab.has(substr)) {
        tokens.push(substr);
        start = end;
        found = true;
        break;
      }
      end--;
    }

    if (!found) {
      tokens.push('[UNK]');
      break;
    }
  }
  return tokens;
}

console.log(wordPieceTokenize('cardiology'));
// ['card', '##io', '##logy']

console.log(wordPieceTokenize('gastroenteritis'));
// ['gastro', '##enter', '##itis']`}
</CodeBlock>

## The Power of Composability

Medical language is highly compositional. Prefixes like "hyper-", "hypo-", "cardio-" combine with suffixes like "-itis", "-ectomy", "-ology". Subword tokenization captures this structure.

<CodeBlock language="typescript" title="composable-terms.ts">
{`// Medical terms decompose into meaningful parts
// Just like React components compose into UIs

const decompositions = {
  'cardiology':     ['card', '##io', '##logy'],     // study of heart
  'carditis':       ['card', '##itis'],              // heart inflammation
  'cardioectomy':   ['card', '##io', '##ectomy'],    // heart removal (surgical)
  'gastroenteritis': ['gastro', '##enter', '##itis'], // stomach/intestine inflammation
};

// The model learns that '##itis' = inflammation
// So when it sees a new word ending in '##itis',
// it already knows the concept!`}
