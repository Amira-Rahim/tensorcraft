<Dialogue speaker="Vikram Reddy">
I asked MEDI: "What is the interaction between metformin and ibuprofen in patients with renal impairment?" MEDI responded with a detailed, confident, and entirely fabricated answer. It cited a study that does not exist. In a chat application, a hallucination is an inconvenience. In Signal Ward, it is a liability.
</Dialogue>

<Dialogue speaker="Dr. Karimi">
Every claim needs a citation. If the model cannot point to specific evidence in the patient's records, it must say so. I would rather see "insufficient evidence" than a confident wrong answer.
</Dialogue>

On the web, hyperlinks are the contract between author and reader. "Reduces risk by 40%" means nothing without a link to the study. Knowledge grounding applies the same principle to ML: every answer must link back to specific evidence in the source documents. No evidence, no answer.

## Every Claim Needs a Source

<CodeBlock language="typescript" title="grounding.ts">
{`import * as tf from '@tensorflow/tfjs';

interface GroundedAnswer {
  answer: string;
  isGrounded: boolean;
  confidence: number;
  citations: Citation[];
}

interface Citation {
  documentId: string;
  span: string;
  entailmentScore: number;
  startOffset: number;
  endOffset: number;
}

// Natural Language Inference: does the evidence support the claim?
// Labels: entailment (0), neutral (1), contradiction (2)
function buildNLIModel(vocabSize: number, embDim: number, maxLen: number): tf.LayersModel {
  const premiseInput = tf.input({ shape: [maxLen], name: 'premise' });
  const hypothesisInput = tf.input({ shape: [maxLen], name: 'hypothesis' });

  const embedding = tf.layers.embedding({ inputDim: vocabSize, outputDim: embDim });

  const premiseEmb = embedding.apply(premiseInput) as tf.SymbolicTensor;
  const hypothesisEmb = embedding.apply(hypothesisInput) as tf.SymbolicTensor;

  const lstm = tf.layers.lstm({ units: 64 });
  const premiseEnc = lstm.apply(premiseEmb) as tf.SymbolicTensor;
  const hypothesisEnc = lstm.apply(hypothesisEmb) as tf.SymbolicTensor;

  const combined = tf.layers.concatenate().apply([premiseEnc, hypothesisEnc]) as tf.SymbolicTensor;
  const dense = tf.layers.dense({ units: 64, activation: 'relu' }).apply(combined) as tf.SymbolicTensor;
  const output = tf.layers.dense({ units: 3, activation: 'softmax' }).apply(dense) as tf.SymbolicTensor;

  return tf.model({ inputs: [premiseInput, hypothesisInput], outputs: output });
}

// Ground an answer: verify every claim has supporting evidence
async function groundAnswer(
  answer: string,
  retrievedDocs: { id: string; text: string }[],
  nliModel: tf.LayersModel,
  tokenize: (text: string) => number[],
  threshold: number = 0.7
): Promise<GroundedAnswer> {
  const citations: Citation[] = [];

  for (const doc of retrievedDocs) {
    // Check if this document entails the answer
    const premiseTokens = tokenize(doc.text);
    const hypothesisTokens = tokenize(answer);

    const prediction = nliModel.predict([
      tf.tensor2d([premiseTokens]),
      tf.tensor2d([hypothesisTokens]),
    ]) as tf.Tensor;

    const probs = await prediction.array() as number[][];
    const entailmentScore = probs[0][0]; // P(entailment)

    if (entailmentScore > threshold) {
      citations.push({
        documentId: doc.id,
        span: doc.text.substring(0, 200),
        entailmentScore,
        startOffset: 0,
        endOffset: 200,
      });
    }
    prediction.dispose();
  }

  const maxScore = citations.length > 0
    ? Math.max(...citations.map(c => c.entailmentScore))
    : 0;

  return {
    answer: citations.length > 0 ? answer : 'Insufficient evidence in patient records.',
    isGrounded: citations.length > 0,
    confidence: maxScore,
    citations,
  };
}`}
</CodeBlock>

## Hallucination Detection

<CodeBlock language="typescript" title="hallucination-test.ts">
{`// Test grounding with known hallucinations
const tests = [
  {
    answer: "Patient is allergic to penicillin",
    docs: [{ id: "d1", text: "Patient reported severe allergic reaction to penicillin-class antibiotics." }],
    shouldBeGrounded: true,
  },
  {
    answer: "Metformin interacts dangerously with ibuprofen causing renal failure",
    docs: [{ id: "d1", text: "Current medications: metformin 500mg twice daily." }],
    shouldBeGrounded: false, // No evidence of this interaction in the record
  },
];

for (const test of tests) {
  const result = await groundAnswer(test.answer, test.docs, nliModel, tokenize);
  const status = result.isGrounded === test.shouldBeGrounded ? 'PASS' : 'FAIL';
  console.log(\`[\${status}] Grounded: \${result.isGrounded}, Confidence: \${result.confidence.toFixed(3)}\`);
  console.log(\`  Answer: "\${result.answer}"\`);
  console.log(\`  Citations: \${result.citations.length}\`);
}`}
</CodeBlock>
