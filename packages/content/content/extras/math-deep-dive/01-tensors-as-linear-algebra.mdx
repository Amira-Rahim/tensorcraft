## From Arrays to Vector Spaces

In frontend development, you've used CSS transforms without thinking twice:

```css
transform: matrix(0, 1, -1, 0, 0, 0); /* same transform as rotate(90deg) */
```

That 2D transform matrix acts on a vector space: the space of screen coordinates. The a, b, c, d block of every `matrix()` you've written is a linear map: it takes a coordinate, produces a new coordinate, and keeps two promises. Mapping a sum gives the sum of the maps, map(u + v) = map(u) + map(v), and mapping a scaled vector gives the scaled map, map(s * u) = s * map(u). That pair of promises is the whole definition of linear, and ML weight matrices keep both.

The last two slots, tx and ty, are the exception. A shift is not a linear map: it moves the origin, and doubling the input of a pure shift does not double the output, so the scaling promise breaks. CSS smuggles the shift in through an extra matrix column, which is why chaining transforms still composes as pure matrix multiplication. ML has the same split: the weight matrix is the linear part of a layer, and the bias vector is the shift.

<BridgeCallout bridge={frontmatter.concept.bridge} />

A **vector space** is a set of objects (vectors) where you can add any two together and multiply any one by a scalar, and the results stay in the set. JavaScript arrays of fixed length form a vector space. You can add `[1, 2, 3]` and `[4, 5, 6]` element-wise to get `[5, 7, 9]`, and that result is still a 3-element array.

## Basis Vectors and Coordinates

Every vector in a space can be written as a combination of **basis vectors**. In 2D, the standard basis is:

- **e1** = [1, 0], the x-axis direction
- **e2** = [0, 1], the y-axis direction

The point [3, 7] is really 3 * e1 + 7 * e2. CSS coordinates work the same way: the browser defines a basis (x-right, y-down), and every position is a linear combination of those directions.

<CodeBlock language="typescript" title="basis-vectors.ts">
{`import * as tf from '@tensorflow/tfjs';

// Standard basis vectors in 2D
const e1 = tf.tensor1d([1, 0]);
const e2 = tf.tensor1d([0, 1]);

// Any 2D vector is a linear combination of basis vectors
const point = tf.add(e1.mul(3), e2.mul(7));
console.log(await point.array()); // [3, 7]

// A weight matrix transforms basis vectors to new positions
// (exactly what a CSS transform matrix does). Under matMul(W, point),
// the COLUMNS of W are where the basis vectors land:
const W = tf.tensor2d([
  [2, -1],
  [1,  3]
]);
// column [2, 1] is where e1 lands; column [-1, 3] is where e2 lands

// Transform our point
const transformed = tf.matMul(W, point.reshape([2, 1]));
console.log(await transformed.array());
// [[-1], [24]]: the point [3,7] mapped through the linear transformation

// A linear map keeps two promises: map(u + v) = map(u) + map(v),
// and map(s * u) = s * map(u). Check both with W:
const u = tf.tensor1d([1, 2]);
const v = tf.tensor1d([3, 0]);
const mapOfSum = tf.matMul(W, u.add(v).reshape([2, 1]));
const sumOfMaps = tf.matMul(W, u.reshape([2, 1]))
  .add(tf.matMul(W, v.reshape([2, 1])));
console.log(await mapOfSum.array());  // [[6], [10]]
console.log(await sumOfMaps.array()); // [[6], [10]], same answer

const mapOfScaled = tf.matMul(W, u.mul(2).reshape([2, 1]));
const scaledMap = tf.matMul(W, u.reshape([2, 1])).mul(2);
console.log(await mapOfScaled.array()); // [[0], [14]]
console.log(await scaledMap.array());   // [[0], [14]], same answer`}
</CodeBlock>

## Linear Independence and Rank

Vectors are **linearly independent** if none can be written as a combination of the others. The **rank** of a matrix tells you how many independent directions it preserves. If a weight matrix has low rank, it's collapsing your data into fewer dimensions. Information is being lost.

Careful: this is a second, unrelated meaning of the word rank. The `tensor.rank` you met in Foundations lesson 1 counts axes, so every 2x2 matrix has tensor rank 2. Matrix rank counts independent directions, and the 2x2 matrix below has matrix rank 1. Linear algebra had the word first; TensorFlow overloaded it.

For two 2D vectors, independence has a one-line test. Take v1 = [a, b] and v2 = [c, d] and form the **determinant**: a * d - b * c. Geometrically it is the signed area of the parallelogram the two vectors span, and the area-scale factor of the matrix built from them. Zero area means the parallelogram has collapsed onto a single line, which is exactly dependence. Check it on the rows of the rank-1 matrix below, [1, 2] and [2, 4]: 1 * 4 - 2 * 2 = 0. Dependent, rank 1. A nonzero determinant means no direction collapses: the matrix is full rank, and the transformation can be undone. One warning before the Challenge: in floating point you never test `det === 0`. You compare `Math.abs(det)` against a small epsilon like `1e-6`, a threshold decision you'll make yourself in the exercise below.

<CodeBlock language="typescript" title="matrix-rank.ts">
{`import * as tf from '@tensorflow/tfjs';

// Full-rank matrix: preserves both dimensions
const fullRank = tf.tensor2d([
  [1, 0],
  [0, 1]
]);

// Rank-1 matrix: collapses 2D data onto a line
const rank1 = tf.tensor2d([
  [1, 2],
  [2, 4]  // Row 2 = 2 * Row 1, not independent!
]);
// Note: rank1.rank prints 2. The TFJS .rank property is tensor rank
// (it counts axes); the matrix rank we're probing counts directions.

// Apply the rank-1 matrix to three points at once. Each point sits in
// a ROW of points (one point per row). Multiplying on the RIGHT by the
// transposed matrix applies the same map as matMul(rank1, point) did
// for a single column vector, just to all three points in one op.
// (rank1 happens to be symmetric, so transpose leaves its values
// unchanged here; the transpose is about the row-vs-column convention,
// not the numbers.)
const points = tf.tensor2d([[1, 0], [0, 1], [1, 1]]);
const collapsed = tf.matMul(points, rank1.transpose());
console.log(await collapsed.array());
// All outputs land on the same line: dimension reduced

// In ML, this is why weight initialization matters: a rank-deficient
// (less than full rank) weight matrix can't learn distinct features

// The determinant turns the collapse into a number:
const [row1, row2] = await rank1.array();
const det = row1[0] * row2[1] - row1[1] * row2[0];
console.log(det); // 1 * 4 - 2 * 2 = 0: dependent rows, rank 1

// A nearly singular neighbor keeps a sliver of area:
const near = [[1, 2], [2, 4.001]];  // second row is ALMOST 2x the first
const detNear = near[0][0] * near[1][1] - near[0][1] * near[1][0];
console.log(detNear);
// 1 * 4.001 - 2 * 2 = 0.001 in exact arithmetic. The console prints
// 0.001000000000000334 instead, because doubles can't store 4.001
// exactly. That rounding noise is why you compare Math.abs(det) against an epsilon
// (the Challenge uses 1e-6) instead of testing det === 0. Numerical
// rank is always a threshold decision, never an equality test.
// (For bigger matrices, libraries read rank off a decomposition
// instead of a determinant; lesson 8 covers the SVD.)`}
</CodeBlock>

## Matrix Multiplication as Composition

When you chain CSS transforms, the browser multiplies the matrices together. Neural network layers work the same way: each layer's weight matrix is a linear map, and stacking layers composes those maps.

<CodeBlock language="typescript" title="composition.ts">
{`import * as tf from '@tensorflow/tfjs';

// Two transformations (like two neural network layers)
const rotate = tf.tensor2d([
  [0, -1],
  [1,  0]   // 90-degree rotation
]);

const scale = tf.tensor2d([
  [2, 0],
  [0, 3]    // Scale x by 2, y by 3
]);

// Composing: scale THEN rotate = single matrix
const combined = tf.matMul(rotate, scale);
console.log(await combined.array());
// [[0, -3], [2, 0]]

// This is why deep networks are powerful:
// each layer adds a new linear map (plus nonlinearity)
// The composition can represent transforms no single matrix can

// Without activation functions, N layers collapse to 1 matrix:
const layer1 = tf.randomNormal([4, 3]);
const layer2 = tf.randomNormal([3, 4]);
const collapsed = tf.matMul(layer2, layer1);
// collapsed is 3x3: two layers = one linear map
// This is why we NEED nonlinear activations between layers:
// small nonlinear gates like ReLU, covered in the Neural Networks module`}
</CodeBlock>
