## Derivatives as Rates of Change

You already think in derivatives when you write animation code. In `requestAnimationFrame`, velocity is the derivative of position with respect to time: how fast the position changes per unit of time. Dividing by `deltaTime` is what turns a raw per-frame difference into that rate.

<BridgeCallout bridge={frontmatter.concept.bridge} />

A gradient in ML is the same idea: how fast does the loss change when you nudge a weight? If the gradient is large, a small weight change causes a big loss change. If it's near zero, nudging that weight barely changes the loss right now. Careful: that does not mean the weight is unimportant. It can be sitting on a flat spot, like a ReLU whose input is negative, where a weight the network badly needs still receives a zero gradient. That stuck-on-flat situation is what vanishing gradients are, and you will see the ReLU's 0-or-1 gate up close in the chain rule section below.

<CodeBlock language="typescript" title="derivative-intuition.ts">
{`import * as tf from '@tensorflow/tfjs';

// In frontend: velocity = rate of change of position
function animationDerivative(lastPos: number, currentPos: number, dt: number) {
  return (currentPos - lastPos) / dt;  // This IS a derivative
}

// In ML: gradient = rate of change of loss with respect to a weight
// For f(x) = x^2, the derivative is f'(x) = 2x
const f = (x: tf.Tensor) => x.square();
const df = tf.grad(f);

const x = tf.scalar(3);
const gradient = df(x);
console.log(await gradient.array()); // 6, because 2 * 3 = 6
// At x=3, increasing x by a tiny amount increases x^2 by ~6 times that amount`}
</CodeBlock>

## Partial Derivatives

Neural networks have many weights. A partial derivative tells you how the loss changes when you nudge **one** weight while holding all others fixed.

<CodeBlock language="typescript" title="partial-derivatives.ts">
{`import * as tf from '@tensorflow/tfjs';

// f(x, y) = x^2 * y + y^3
// Partial with respect to x: df/dx = 2xy (treat y as constant)
// Partial with respect to y: df/dy = x^2 + 3y^2 (treat x as constant)

// Manual computation at point (2, 3):
// df/dx = 2 * 2 * 3 = 12
// df/dy = 2^2 + 3 * 3^2 = 4 + 27 = 31

// Verify with TensorFlow.js
const f = (x: tf.Tensor, y: tf.Tensor) =>
  x.square().mul(y).add(y.pow(3));

// Gradient with respect to x
const dfdx = tf.grad((x) => f(x, tf.scalar(3)));
console.log(await dfdx(tf.scalar(2)).array()); // 12

// Gradient with respect to y
const dfdy = tf.grad((y) => f(tf.scalar(2), y));
console.log(await dfdy(tf.scalar(3)).array()); // 31`}
</CodeBlock>

## The Chain Rule

The chain rule is the single most important idea in deep learning. Every neural network is a deeply nested composite function, and the chain rule tells you how to compute the derivative of the whole thing.

Why do the local derivatives multiply? Think in rates, like the velocity example above. Suppose the loss changes 2 units for every unit the layer output moves, and the layer output changes 3 units for every unit the weight moves. Then the loss changes 2 * 3 = 6 units for every unit the weight moves. Rates through a pipeline multiply, and that is the whole chain rule: the derivative of a composed function is the product of the local derivatives at each step.

<CodeBlock language="typescript" title="chain-rule.ts">
{`import * as tf from '@tensorflow/tfjs';

// Consider a 2-layer network (no bias, for simplicity):
//   z1 = w1 * x         (layer 1: linear)
//   a1 = relu(z1)       (activation)
//   z2 = w2 * a1        (layer 2: linear)
//   loss = (z2 - y)^2   (squared-error loss, the MSE from the Neural Networks module)
//
// Chain rule for dLoss/dw1:
//   dLoss/dw1 = dLoss/dz2 * dz2/da1 * da1/dz1 * dz1/dw1
//
// Each factor is a simple local derivative. Let's compute them:

const x = 2.0;
const y = 1.0;   // target
const w1 = 0.5;
const w2 = -0.3;

// Forward pass
const z1 = w1 * x;           // 1.0
const a1 = Math.max(0, z1);  // 1.0 (ReLU)
const z2 = w2 * a1;          // -0.3
const loss = (z2 - y) ** 2;  // 1.69

// Backward pass (chain rule, right to left)
const dLoss_dz2 = 2 * (z2 - y);         // 2 * (-1.3) = -2.6
const dz2_da1 = w2;                      // -0.3
const da1_dz1 = z1 > 0 ? 1 : 0;         // 1 (slope of Math.max(0, z): 1 when z > 0, else 0)
const dz1_dw1 = x;                       // 2

// Chain them together:
const dLoss_dw1 = dLoss_dz2 * dz2_da1 * da1_dz1 * dz1_dw1;
console.log('Manual gradient dL/dw1:', dLoss_dw1); // 1.56

// Verify with TensorFlow.js auto-diff
const computeLoss = (w1t: tf.Tensor) => {
  const z1t = w1t.mul(x);
  const a1t = z1t.relu();
  const z2t = tf.scalar(w2).mul(a1t);
  return z2t.sub(y).square();
};

const autoGrad = tf.grad(computeLoss);
console.log('Auto gradient dL/dw1:', await autoGrad(tf.scalar(w1)).array());
// Same value: 1.56`}
</CodeBlock>

## The Computational Graph

Every neural network builds a computational graph during the forward pass. Backpropagation walks this graph in reverse, applying the chain rule at each node. This is why TensorFlow is called TensorFlow: tensors flow through a graph of operations.

<CodeBlock language="typescript" title="computational-graph.ts">
{`import * as tf from '@tensorflow/tfjs';

// Visualize a computational graph as a pipeline:
//
//   x ──┐
//       ├─ [multiply] ─ z1 ─ [relu] ─ a1 ──┐
//  w1 ──┘                                    ├─ [multiply] ─ z2 ─ [sub y] ─ [square] ─ loss
//                                       w2 ──┘
//
// Forward: left to right (compute values)
// Backward: right to left (compute gradients via chain rule)

// With multiple weights, tf.grads returns all gradients at once.
// The function receives each weight as its own argument; the returned
// gradient function takes the concrete values as an array.
const networkLoss = (w1: tf.Tensor, w2: tf.Tensor) => {
  const x = tf.scalar(2);
  const y = tf.scalar(1);

  const z1 = w1.mul(x);
  const a1 = z1.relu();
  const z2 = w2.mul(a1);
  return z2.sub(y).square();
};

const gradFn = tf.grads(networkLoss);
const [dw1, dw2] = gradFn([tf.scalar(0.5), tf.scalar(-0.3)]);

console.log('dL/dw1:', await dw1.array()); // 1.56
console.log('dL/dw2:', await dw2.array()); // -2.6 (= dL/dz2 * a1 = -2.6 * 1.0)`}
</CodeBlock>

**Two names you will meet in papers.** Stack the partial derivatives of a vector-valued function into a matrix and you have the **Jacobian**: row i holds the partials of output i with respect to every input. When the output is a single scalar loss, the Jacobian collapses to one row, which is exactly the gradient `tf.grads` returned above. Differentiate once more and you get the **Hessian**, the matrix of second derivatives that describes curvature. If the loss curves upward along every direction you could step, you are at a minimum; if it curves up along some directions and down along others, you are at a saddle point, the shape of a mountain pass. The next lesson, the optimization landscape, walks through why saddles dominate in high dimensions.
