<Dialogue speaker="Instructor">
You've filtered arrays, mapped over objects, reduced datasets to summaries, and grouped items by category, all in JavaScript. A pandas DataFrame is that same toolkit, optimized for tabular data. If you can chain .map().filter().reduce(), you can read pandas code.
</Dialogue>

Before data reaches a model, it goes through wrangling: cleaning, transforming, splitting, normalizing. In Python, that's pandas. In JavaScript, that's the array methods you use every day. Put a pandas line next to its array-method twin and most of the mystery evaporates, so that's exactly what we'll do below.

## DataFrames Are Arrays of Objects

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="python" title="pandas-basics.py">
{`import pandas as pd

# Create a DataFrame — like an array of objects with typed columns
df = pd.DataFrame({
    'name': ['Amina', 'Ravi', 'Leyla', 'Arjun'],
    'age': [28, 35, 42, 23],
    'score': [0.85, 0.72, 0.91, 0.68]
})

#     name  age  score
# 0  Amina   28   0.85
# 1    Ravi   35   0.72
# 2  Leyla   42   0.91
# 3   Arjun   23   0.68`}
</CodeBlock>

<CodeBlock language="typescript" title="js-equivalent.ts">
{`// JavaScript equivalent

  { name: 'Arjun',  age: 23, score: 0.68 },

</CodeBlock>

## GroupBy

The `groupby` operation is the most important pattern. It's exactly a reduce that buckets items by key.

<CodeBlock language="python" title="pandas-groupby.py">
{`# pandas
grouped = df.groupby('age_group')['score'].mean()
# age_group
# junior    0.75
# senior    0.91

# JavaScript
# const grouped = data.reduce((acc, r) => {
#   const key = r.ageGroup;
#   if (!acc[key]) acc[key] = [];
#   acc[key].push(r.score);
#   return acc;
# }, {});
# const means = Object.fromEntries(
#   Object.entries(grouped).map(([k, v]) =>
#     [k, v.reduce((s, x) => s + x, 0) / v.length]
#   )
# );`}
</CodeBlock>
