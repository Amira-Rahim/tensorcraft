## The Problem

{`import * as tf from '@tensorflow/tfjs';

// PROBLEM: We need z = sample from N(mu, sigma)
// But "sample" is not differentiable; no gradient flows through it

// BAD (conceptually): z = randomSample(mu, sigma)
// Backprop asks: "how should mu change to reduce loss?"
// Answer: "I don't know, there was randomness in the way"

// SOLUTION: Reparameterization trick
// z = mu + sigma * epsilon, where epsilon ~ N(0, 1)
// Now backprop asks: "how should mu change?"
// Answer: "increase mu by this amount" (clear gradient through addition)

// Analogy: seeded random
// const random = seededRandom(42);  // epsilon is like the seed
// const result = base + scale * random;  // mu + sigma * epsilon
// The result depends on base and scale (differentiable!)
// while still being "random" via the seed`}

## The Implementation

<CodeBlock language="typescript" title="reparameterization.ts">
{`import * as tf from '@tensorflow/tfjs';

// The reparameterization trick as a custom layer
class SamplingLayer extends tf.layers.Layer {
  static className = 'SamplingLayer';

  computeOutputShape(inputShape: tf.Shape[]): tf.Shape {
    return inputShape[0]; // same shape as mu
  }

  call(inputs: tf.Tensor[]): tf.Tensor {
    const [mu, logVar] = inputs;

    // Step 1: Sample epsilon from standard normal N(0, 1)
    const epsilon = tf.randomNormal(mu.shape as number[]);

    // Step 2: Transform: z = mu + exp(logVar/2) * epsilon
    const std = logVar.mul(0.5).exp();
    const z = mu.add(std.mul(epsilon));

    return z;
    // Gradients flow through mu and logVar (math operations)
    // Epsilon is treated as a constant; no gradient needed
  }
}

// Usage in model
function buildVAE(inputDim: number, latentDim: number) {
  const input = tf.input({ shape: [inputDim] });
  const hidden = tf.layers.dense({ units: 256, activation: 'relu' }).apply(input);

  const mu = tf.layers.dense({ units: latentDim }).apply(hidden) as tf.SymbolicTensor;
  const logVar = tf.layers.dense({ units: latentDim }).apply(hidden) as tf.SymbolicTensor;

  // Sampling with reparameterization
  const z = new SamplingLayer().apply([mu, logVar]) as tf.SymbolicTensor;

  const decoderHidden = tf.layers.dense({ units: 256, activation: 'relu' }).apply(z);
  const output = tf.layers.dense({ units: inputDim, activation: 'sigmoid' }).apply(decoderHidden);

  return tf.model({ inputs: input, outputs: output as tf.SymbolicTensor });
}`}
</CodeBlock>

## Why It Works

`z = mu + sigma * epsilon` is a deterministic function of `mu`, `sigma`, and `epsilon`. Since `epsilon` is sampled *before* the computation, it acts like a constant during backpropagation. Gradients flow cleanly through `mu` and `sigma`.

## Challenge

<DerivationDrawer summary="Why reparameterization is required for backprop">
VAE encoder outputs `μ(x), σ(x)`, parameters of a distribution. To compute the loss we need a sample `z ~ N(μ, σ²)`. But **sampling is non-differentiable**: there's no gradient through a random number.

**The trick:** rewrite the sample as a deterministic function of μ, σ, and a noise variable ε ~ N(0, 1):

`z = μ + σ · ε`

Now z depends on μ and σ via deterministic operations (add, multiply), and ε is independent of model parameters. The gradient flows:

`∂L / ∂μ = ∂L / ∂z · 1`
`∂L / ∂σ = ∂L / ∂z · ε`

**Without this trick** the VAE cannot train end-to-end with backprop. With it, sampling becomes a differentiable layer. The same idea reappears in normalizing flows, Gumbel-softmax, and concrete distributions for discrete latents.
</DerivationDrawer>
