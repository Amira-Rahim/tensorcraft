The VAE loss function has two parts: **reconstruction loss** (how well it rebuilds the input) and **KL divergence** (how close the latent distribution is to a standard normal). Minimizing their sum is the same as maximizing the Evidence Lower Bound (ELBO).

## What KL Divergence Measures

KL divergence answers: "How different is the encoder's distribution from a standard normal?" If the encoder is free to place data anywhere, the latent space becomes chaotic. KL divergence gently pulls every encoding toward the origin, creating overlap and smoothness.

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="kl-divergence.ts">
{`import * as tf from '@tensorflow/tfjs';

// KL divergence for a Gaussian:
// KL(q(z|x) || p(z)) = -0.5 * sum(1 + log(sigma^2) - mu^2 - sigma^2)
// Where q(z|x) is the encoder's distribution
// and p(z) = N(0, 1) is the prior (standard normal)

function klDivergence(mu: tf.Tensor, logVar: tf.Tensor): tf.Scalar {
  // KL = -0.5 * sum(1 + logVar - mu^2 - exp(logVar))
  // Same terms, reordered so the leading sign is +0.5
  const kl = mu.square()
    .add(logVar.exp())
    .sub(logVar)
    .sub(1)
    .mul(0.5)
    .sum(1)     // sum over latent dimensions
    .mean();    // average over batch
  return kl as tf.Scalar;
}

// Intuition:
// mu far from 0 → penalty (move toward center)
// logVar far from 0 → penalty (standardize spread)
// Every encoding gets pulled into the same populated region,
// so a point between two of them still lands where the decoder has been`}
</CodeBlock>

## The Complete VAE Loss

<CodeBlock language="typescript" title="vae-loss.ts">
{`import * as tf from '@tensorflow/tfjs';

function vaeLoss(
  original: tf.Tensor,
  reconstructed: tf.Tensor,
  mu: tf.Tensor,
  logVar: tf.Tensor,
  beta: number = 1.0
): tf.Scalar {
  // Part 1: Reconstruction loss: how well did we rebuild?
  const reconLoss = tf.losses.meanSquaredError(original, reconstructed);

  // Part 2: KL divergence: how organized is the latent space?
  const klLoss = mu.square()
    .add(logVar.exp())
    .sub(logVar)
    .sub(1)
    .mul(0.5)
    .sum(1)
    .mean();

  // Combined: minimize reconstruction error + beta * KL divergence
  // beta controls the tradeoff:
  //   beta < 1: prioritize reconstruction (sharper but messy space)
  //   beta = 1: standard VAE (balanced)
  //   beta > 1: prioritize organization (blurrier but smoother space)
  return reconLoss.add(klLoss.mul(beta)) as tf.Scalar;
}`}
</CodeBlock>

// How to tell the difference:
// 1. Generate many samples and check for near-duplicates of training data
// 2. Watch the KL term while training: if it climbs and never settles, the

// 3. Interpolate between two encoded training samples;
//    smooth transitions = generalization, jumpy transitions = memorization`}

<DerivationDrawer summary="KL between two Gaussians: closed form">
VAE's KL term has a closed-form solution when q(z|x) and p(z) are both Gaussian. For q = N(μ, σ²) and p = N(0, 1) (standard normal prior), per latent dimension:

`KL[ q || p ] = ½ · ( σ² + μ² - 1 - log(σ²) )`

Summed across all latent dimensions, this is the regularization loss VAE pays to keep the encoder's distribution close to the prior.

**Asymmetry of KL:** `KL(q || p) ≠ KL(p || q)`. VAE uses `KL(q || p)`, the reverse direction, which pushes q to put mass only where the prior already has it, so the encoder's distribution stays tight around N(0, 1). The forward direction `KL(p || q)` would push q to cover all of p, which is what produces blurry, mode-averaged samples.

**β-VAE** scales this term: `L = recon + β · KL`. β > 1 forces a tighter encoder, encouraging disentanglement at the cost of reconstruction quality.
</DerivationDrawer>
