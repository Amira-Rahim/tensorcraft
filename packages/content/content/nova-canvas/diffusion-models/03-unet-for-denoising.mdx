<Dialogue speaker="Samir">
The architecture that predicts noise is called a U-Net: an encoder-decoder, the same shape as a layout component. The encoder compresses the noisy image to understand the big picture. The decoder expands it back to full resolution to predict the noise at every pixel.
</Dialogue>

<Dialogue speaker="Yara">
But if you compress and then expand, don't you lose detail? Like over-compressing a JPEG?
</Dialogue>

<Dialogue speaker="Samir">
That is what skip connections solve. They bridge from the encoder to the decoder at each resolution level, carrying the fine details that compression would destroy. Like passing `children` through a layout wrapper.
</Dialogue>

Yara's JPEG worry is the right instinct, and skip connections are the whole answer to it. Without them, every fine edge has to survive a round trip through the bottleneck, and most don't. With them, detail takes the bridge while context takes the long way down and back up. The U-Net's middle is not a clean handoff; it is a multi-resolution merge.

<CodeBlock language="typescript" title="unet-architecture.ts">
{`import * as tf from '@tensorflow/tfjs';

// Encoder block: conv + conv + downsample (halve spatial dims)
function encoderBlock(
  input: tf.SymbolicTensor,
  filters: number
): [tf.SymbolicTensor, tf.SymbolicTensor] {
  let x = tf.layers.conv2d({
    filters, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(input) as tf.SymbolicTensor;
  x = tf.layers.conv2d({
    filters, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(x) as tf.SymbolicTensor;

  const skip = x; // preserve detail for the decoder
  const downsampled = tf.layers.maxPooling2d({
    poolSize: 2
  }).apply(x) as tf.SymbolicTensor;

  return [downsampled, skip];
}

// Decoder block: upsample + concat skip + conv + conv
function decoderBlock(
  input: tf.SymbolicTensor,
  skip: tf.SymbolicTensor,
  filters: number
): tf.SymbolicTensor {
  let x = tf.layers.upSampling2d({
    size: [2, 2]
  }).apply(input) as tf.SymbolicTensor;

  // Skip connection: concatenate encoder features (the "children" passthrough)
  x = tf.layers.concatenate().apply([x, skip]) as tf.SymbolicTensor;

  x = tf.layers.conv2d({
    filters, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(x) as tf.SymbolicTensor;
  x = tf.layers.conv2d({
    filters, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(x) as tf.SymbolicTensor;

  return x;
}

// Build a simple U-Net
function buildUNet(inputShape: [number, number, number]): tf.LayersModel {
  const input = tf.input({ shape: inputShape });

  // Encoder path (going down)
  const [d1, skip1] = encoderBlock(input, 32);  // 64 -> 32
  const [d2, skip2] = encoderBlock(d1, 64);     // 32 -> 16

  // Bottleneck
  let bottleneck = tf.layers.conv2d({
    filters: 128, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(d2) as tf.SymbolicTensor;

  // Decoder path (going up)
  const u1 = decoderBlock(bottleneck, skip2, 64);  // 16 -> 32
  const u2 = decoderBlock(u1, skip1, 32);           // 32 -> 64

  // Output: predict the noise (same shape as input)
  const output = tf.layers.conv2d({
    filters: inputShape[2], kernelSize: 1, padding: 'same'
  }).apply(u2) as tf.SymbolicTensor;

  return tf.model({ inputs: input, outputs: output });
}

const unet = buildUNet([64, 64, 3]);
unet.summary();
// Total params: ~300K — small enough for browser inference`}

<DerivationDrawer summary="U-Net architecture math + skip connections">
U-Net is the standard backbone for diffusion denoising. It maps noisy input x_t (and timestep t) to a noise prediction ε_θ(x_t, t) of the same shape as x_t.

**Architecture:**

```
encoder:  256→128→64→32→16     (downsample 4×, doubling channels each step)
bottleneck: 16→16              (deep processing at low resolution)
decoder:  16→32→64→128→256     (upsample 4×, halving channels)
```

**Skip connections** concatenate encoder activations into matching-resolution decoder layers:

`decoder_layer_k_input = concat(prev_decoder_output, encoder_layer_k_activation)`

Without skips, fine spatial detail is lost in the bottleneck. Skips re-inject high-resolution information at each upsample.

**Time conditioning:** the timestep t is embedded (sinusoidal embedding → MLP) and added to every block's activations as a bias. The same network handles all timesteps; the time embedding tells it where in the schedule we are.
</DerivationDrawer>

<KeyTakeaways takeaways={["Concatenate each skip tensor at its matching resolution level: without skips the bottleneck blurs away edges and texture", "The encoder compresses spatial dimensions to capture context; the decoder expands back to full resolution", "Skip connections carry fine-grained detail from encoder to decoder at matching resolution levels", "The output has the same shape as the input — the model predicts the noise to subtract"]} />
