<Dialogue speaker="Petrov">
The gallery prints are one meter wide. I need at least 1024 by 1024 pixels. Can the model do that?
</Dialogue>

<Dialogue speaker="Ren">
Directly? No. Memory scales quadratically with resolution. A 1024x1024 image has 256 times more pixels than 64x64. The browser tab would crash before step one.
</Dialogue>

<Dialogue speaker="Kai">
So we do what responsive images do — serve the right resolution for the task. Generate at 64x64 where diffusion is fast, then upscale with a lightweight super-resolution model. Like srcset: the browser picks the size it needs.
</Dialogue>

You already handle this in frontend. `srcset` lets the browser choose the right image resolution. Cascaded diffusion does the same — generate at a manageable resolution, then upscale intelligently.

const resolutions = [64, 128, 256, 512, 1024];
for (const res of resolutions) {
  const pixels = res * res;
  const tensorSize = pixels * 3 * 4; // 3 channels, float32
  const mbPerImage = tensorSize / (1024 * 1024);
  console.log(\`\${res}x\${res}: \${pixels.toLocaleString()} pixels, \${mbPerImage.toFixed(1)} MB per tensor\`);
}

## Cascaded Generation Pipeline

<CodeBlock language="typescript" title="cascaded-pipeline.ts">
{`import * as tf from '@tensorflow/tfjs';

// Super-resolution model: upscale 64x64 -> 256x256
function buildSuperResModel(): tf.LayersModel {
  const input = tf.input({ shape: [64, 64, 3] });

  // Upscale 2x: 64 -> 128
  let x = tf.layers.upSampling2d({ size: [2, 2] }).apply(input) as tf.SymbolicTensor;
  x = tf.layers.conv2d({
    filters: 64, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(x) as tf.SymbolicTensor;

  // Upscale 2x: 128 -> 256
  x = tf.layers.upSampling2d({ size: [2, 2] }).apply(x) as tf.SymbolicTensor;
  x = tf.layers.conv2d({
    filters: 32, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(x) as tf.SymbolicTensor;

  // Output: 256x256x3
  const output = tf.layers.conv2d({
    filters: 3, kernelSize: 3, padding: 'same', activation: 'sigmoid'
  }).apply(x) as tf.SymbolicTensor;

  return tf.model({ inputs: input, outputs: output });
}

// The full cascaded pipeline
async function generateHighRes(
  baseModel: tf.LayersModel,
  superResModel: tf.LayersModel,

  guidanceScale = 7.5
