## The Forward Process: Destroying an Image

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="forward-diffusion.ts">
{`import * as tf from '@tensorflow/tfjs';

// The forward process: add Gaussian noise so total variance stays ~1.
// DDPM closed form: x_t = sqrt(alphaBar_t) * x_0 + sqrt(1 - alphaBar_t) * eps
// where alphaBar_t = product of (1 - beta_i) for i = 1..t. The √ scaling matters:
// a naive linear blend (image * (1-t) + noise * t) would shrink the signal variance,
// then the network would learn to denoise the wrong distribution.
function addNoise(
  image: tf.Tensor4D,
  alphaBar: number          // cumulative product from the noise schedule
): tf.Tensor4D {
  const noise = tf.randomNormal(image.shape);
  const signalScale = Math.sqrt(alphaBar);
  const noiseScale = Math.sqrt(1 - alphaBar);

  return tf.add(
    tf.mul(image, tf.scalar(signalScale)),
    tf.mul(noise, tf.scalar(noiseScale))
  ) as tf.Tensor4D;
}

// Cosine schedule (Nichol & Dhariwal 2021): alphaBar drops smoothly from 1 to ~0.
function cosineAlphaBar(t: number, T: number, s = 0.008): number {
  const angle = ((t / T + s) / (1 + s)) * (Math.PI / 2);
  return Math.cos(angle) ** 2;
}

// Watch an image dissolve into noise over 10 steps
const image = tf.randomUniform([1, 64, 64, 3]); // placeholder "image"
for (let t = 0; t <= 10; t++) {
  const aBar = cosineAlphaBar(t, 10);
  const noisy = addNoise(image, aBar);
  console.log(\`Step \${t}: alphaBar = \${aBar.toFixed(3)}\`);
  noisy.dispose();
}
// Step 0:  alphaBar = 1.000  (original image)
// Step 5:  alphaBar = 0.450  (~half signal, half noise after sqrt)
// Step 10: alphaBar = 0.000  (pure noise)`}
</CodeBlock>

## The Reverse Process: Recovering the Image

The model learns to reverse each step. Given a noisy image and a timestep, it predicts the noise that was added, then subtracts it.

<CodeBlock language="typescript" title="reverse-diffusion.ts">
{`// Simplified reverse diffusion step
// The model predicts noise, we subtract it
function denoiseStep(
  noisyImage: tf.Tensor4D,
  predictedNoise: tf.Tensor4D,
  timestep: number,
  totalSteps: number
): tf.Tensor4D {
  const stepSize = 1 / totalSteps;

  // Subtract the predicted noise, scaled by step size
  const cleaned = tf.sub(
    noisyImage,
    tf.mul(predictedNoise, tf.scalar(stepSize))
  );

  return cleaned as tf.Tensor4D;
}

// The full generation loop: start from noise, denoise step by step
async function generate(
  model: tf.LayersModel,
  steps: number
): Promise<tf.Tensor4D> {
  let image = tf.randomNormal([1, 64, 64, 3]) as tf.Tensor4D;

  for (let t = steps; t > 0; t--) {
    // Model predicts the noise in the current image
    const timestepTensor = tf.tensor1d([t / steps]);
    const predictedNoise = model.predict(
      [image, timestepTensor]
    ) as tf.Tensor4D;

    // Remove the predicted noise
    const cleaned = denoiseStep(image, predictedNoise, t, steps);

    image.dispose();
    predictedNoise.dispose();
    timestepTensor.dispose();
    image = cleaned;
  }

  return image; // from pure noise to a generated image
}`}
</CodeBlock>

<DerivationDrawer summary="Forward and reverse diffusion processes">
**Forward process (noising):** at each timestep t we add Gaussian noise:

`q(x_t | x_{t-1}) = N( x_t; √(1 - β_t) · x_{t-1},  β_t · I )`

After T steps (typically 1000), x_T is approximately pure noise N(0, I).

**Closed form for any t** (skip the iteration):

`q(x_t | x_0) = N( x_t; √ᾱ_t · x_0,  (1 - ᾱ_t) · I )`

Where `ᾱ_t = ∏_{s=1..t} (1 - β_s)`. So we can sample x_t directly:

`x_t = √ᾱ_t · x_0 + √(1 - ᾱ_t) · ε,    ε ~ N(0, I)`

**Reverse process (denoising)**, what the model learns:

`p_θ(x_{t-1} | x_t) = N( x_{t-1}; μ_θ(x_t, t),  Σ_θ(x_t, t) )`

The network predicts the mean (and sometimes variance) of the reverse step. Generation = start from pure noise and apply the reverse step T times.
</DerivationDrawer>
