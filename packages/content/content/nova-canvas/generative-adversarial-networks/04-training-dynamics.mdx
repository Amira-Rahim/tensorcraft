Training a GAN is notoriously tricky. Unlike training a single model where loss steadily decreases, GAN training is two competing losses that must stay in balance, and there is no autoscaler to keep them there. You are the homeostat.

## The Training Loop

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="training-loop.ts">
{`import * as tf from '@tensorflow/tfjs';

async function trainGAN(
  generator: tf.Sequential,
  discriminator: tf.Sequential,
  gan: tf.LayersModel,
  realData: tf.Tensor2D,
  epochs: number,
  batchSize: number,
  noiseDim: number
) {
  const numBatches = Math.floor(realData.shape[0] / batchSize);

  for (let epoch = 0; epoch < epochs; epoch++) {
    let dLossTotal = 0;
    let gLossTotal = 0;

    for (let batch = 0; batch < numBatches; batch++) {
      // --- Train Discriminator ---
      const realBatch = realData.slice(
        [batch * batchSize, 0],
        [batchSize, -1]
      );
      const noise = tf.randomNormal([batchSize, noiseDim]);
      const fakeBatch = generator.predict(noise) as tf.Tensor;

      // Real images labeled 1, fake images labeled 0
      const dLossReal = await discriminator.trainOnBatch(
        realBatch, tf.ones([batchSize, 1])
      ) as number[];
      const dLossFake = await discriminator.trainOnBatch(
        fakeBatch, tf.zeros([batchSize, 1])
      ) as number[];
      dLossTotal += (dLossReal[0] + dLossFake[0]) / 2;

      // --- Train Generator ---
      const genNoise = tf.randomNormal([batchSize, noiseDim]);
      // Generator wants discriminator to say "real" (1)
      const gLoss = await gan.trainOnBatch(
        genNoise, tf.ones([batchSize, 1])
      ) as number[];
      gLossTotal += gLoss[0];

      // Dispose intermediate tensors
      tf.dispose([noise, fakeBatch, genNoise]);
    }

    console.log(\`Epoch \${epoch}: D loss=\${(dLossTotal/numBatches).toFixed(4)}, G loss=\${(gLossTotal/numBatches).toFixed(4)}\`);
  }
}`}
</CodeBlock>

## Reading the Losses

Interpreting GAN losses is different from normal training. You do not want either loss to reach zero.

<CodeBlock language="typescript" title="loss-monitoring.ts">
{`// Healthy training:
// D loss hovers around 0.5-0.7 (it is unsure, good!)
// G loss hovers around 0.7-1.5 (it is learning)
// Both fluctuate but neither collapses

// DANGER: D loss → 0, G loss → large
// Discriminator is too strong. Generator has given up.
// Fix: reduce D learning rate, add dropout, train G more steps

// DANGER: D loss → large, G loss → 0
// Generator found a cheap trick. Discriminator is confused.
// Fix: check for mode collapse (next lesson)

// DANGER: Both losses oscillate wildly
// Training is unstable.
// Fix: reduce learning rate, use gradient clipping

interface TrainingMetrics {
  dLoss: number;
  gLoss: number;
  dAccuracyReal: number;
  dAccuracyFake: number;
}

function diagnose(metrics: TrainingMetrics): string {
  if (metrics.dLoss < 0.1) return 'D too strong; reduce D learning rate';
  if (metrics.gLoss < 0.1) return 'Possible mode collapse; check diversity';
  if (metrics.dAccuracyReal > 0.95 && metrics.dAccuracyFake > 0.95)
    return 'D dominating; add dropout or skip D steps';
  return 'Training looks healthy';
}`}
</CodeBlock>

<DerivationDrawer summary="Why GAN training is unstable + Wasserstein fix">
**JS divergence is undefined when supports don't overlap:** if real-data manifold and generated manifold lie in different regions of pixel space (typical at start of training), JS = log 2 (constant) → zero gradient → no learning signal. Vanilla GANs depend on initial overlap which is fragile.

**Wasserstein GAN (WGAN)** replaces JS with **Earth Mover's distance:**

`W(P, Q) = inf_{γ ∈ Π(P,Q)} E_{(x,y)~γ} [||x − y||]`

Intuition: minimum cost to transform distribution P into Q (move mass from P-locations to Q-locations).

Via Kantorovich-Rubinstein duality, this becomes a tractable formulation requiring **D to be 1-Lipschitz** (bounded slope). Enforced via weight clipping (original WGAN) or gradient penalty (WGAN-GP, modern standard):

`L_GP = λ · E_{x̂} [(||∇_{x̂} D(x̂)||_2 − 1)²]`

Where x̂ is sampled along straight lines between real and generated samples. WGAN-GP is the most stable training recipe most modern GANs use.
</DerivationDrawer>
