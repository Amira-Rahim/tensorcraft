If you have ever used a fuzzer in testing — a tool that generates random inputs to find bugs in a validator — you already understand the GAN architecture. The fuzzer (generator) creates inputs. The validator (discriminator) judges them. The tension between creation and criticism drives improvement.

// Frontend: Fuzzer vs Validator
function fuzzer() {
  // Generate random-looking form data
  return { email: randomString() + '@test.com', age: Math.floor(Math.random() * 150) };
}
function validator(input: { email: string; age: number }): boolean {
  return input.email.includes('@') && input.age > 0 && input.age < 130;
}
// Fuzzer tries to generate inputs that pass validation
// Validator tries to reject invalid inputs
// Both improve through the adversarial process

// ML: Generator vs Discriminator
// Generator: noise → fake image
// Discriminator: image → real or fake?

// Generator wins when discriminator cannot tell fake from real
// Discriminator wins when it correctly identifies all fakes

// The training loop alternates:
// Step 1: Train discriminator on real + fake data
// Step 2: Train generator to fool discriminator`}

## The Minimax Game

GANs are formalized as a minimax game. The discriminator wants to maximize its accuracy. The generator wants to minimize the discriminator's ability to detect fakes.

<CodeBlock language="typescript" title="minimax.ts">
{`import * as tf from '@tensorflow/tfjs';

// Simplified GAN training step (pseudocode)
async function ganTrainStep(
  generator: tf.LayersModel,
  discriminator: tf.LayersModel,
  realBatch: tf.Tensor,
  noiseDim: number
) {
  const batchSize = realBatch.shape[0];

  // Step 1: Train Discriminator
  // It should output 1 for real, 0 for fake
  const noise = tf.randomNormal([batchSize, noiseDim]);
  const fakeBatch = generator.predict(noise) as tf.Tensor;

  const realLabels = tf.ones([batchSize, 1]);   // real = 1
  const fakeLabels = tf.zeros([batchSize, 1]);  // fake = 0

  // D learns: "this is what real looks like, this is what fake looks like"

  // Step 2: Train Generator
  // G wants D to output 1 (real) for its fake data
  const misleadingLabels = tf.ones([batchSize, 1]);
  // G learns: "make output that D thinks is real"
}`}
</CodeBlock>

The beauty of GANs is that you do not need to define what "good" output looks like. The discriminator *learns* what good looks like from real data, and that learned judgment becomes the generator's training signal.
