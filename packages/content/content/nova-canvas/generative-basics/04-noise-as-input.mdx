## Why Start from Noise?

A generative model needs a source of variation. If you gave it the same input every time, it would produce the same output every time. Noise provides infinite variation: each random vector is a unique seed for a unique creation.

## Shaping Noise with Layers

Raw noise is formless. A neural network layer transforms it into something with structure, just like how a vertex shader transforms random mesh data into a recognizable shape.

<CodeBlock language="typescript" title="noise-through-layers.ts">
{`import * as tf from '@tensorflow/tfjs';

// A single dense layer transforms noise into a pattern
const noiseInput = tf.randomNormal([1, 64]);

// Dense layer: 64 random values → 784 structured values (28x28 grid)
const denseLayer = tf.layers.dense({ units: 784, activation: 'sigmoid' });
const output = denseLayer.apply(noiseInput) as tf.Tensor;
const reshaped = output.reshape([28, 28]);

// Render to canvas
async function renderToCanvas(tensor: tf.Tensor2D, canvas: HTMLCanvasElement) {
  const data = await tensor.array();
  const ctx = canvas.getContext('2d')!;
  const imageData = ctx.createImageData(28, 28);
  for (let i = 0; i < 784; i++) {
    const v = Math.floor(data[Math.floor(i / 28)][i % 28] * 255);
    imageData.data[i * 4] = v;
    imageData.data[i * 4 + 1] = v;
    imageData.data[i * 4 + 2] = v;
    imageData.data[i * 4 + 3] = 255;
  }
  ctx.putImageData(imageData, 0, 0);
}
// Without training: random-looking pattern
// After training: the layer learns to shape noise into meaningful images`}
</CodeBlock>

The untrained layer produces visual static. Training teaches it which shapes, edges, and textures are meaningful, just as an artist learns which marks to keep and which to discard.

<DerivationDrawer summary="Why standard normal noise + the latent prior">
Generative models almost always use **standard normal noise** as the latent prior `z ~ N(0, I)`. Reasons:

1. **Reparameterizable:** `z = μ + σ · ε` where ε ~ N(0,I) is differentiable end-to-end (the trick from VAE).
2. **Continuous:** smooth interpolation, gradient-friendly. No discrete sampling discontinuities.
3. **Centered:** zero mean, unit variance: matches typical neural network expectations after batch/layer normalization.
4. **Universal approximator:** any distribution can be expressed as a deterministic transformation of N(0,I) (this is what normalizing flows formalize).
5. **High-dim concentration:** in high d, N(0,I) mass concentrates on a thin shell of radius √d. Almost all valid latent codes lie near this shell — so the decoder mostly trains on shell-region samples, which is fine.

**Alternative priors (rare):**
- Uniform: less smooth gradients, used in some GAN variants.
- Categorical: discrete latents (VQ-VAE), needs Gumbel-softmax for differentiability.
- Mixture: more expressive but harder to train; used in some hierarchical VAEs.
</DerivationDrawer>
