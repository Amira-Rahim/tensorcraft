## Discriminative vs. Generative

Every ML model you have heard about falls into one of two camps. A **discriminative** model takes input and produces a label: "Is this image a cat or a dog?" A **generative** model takes noise and produces new data: "Here is an image that looks like a cat."

<BridgeCallout bridge={frontmatter.concept.bridge} />

You already use controlled randomness in frontend code. Every time you call `Math.random()` to generate a procedural color, a particle effect, or a placeholder avatar, you are doing the conceptual equivalent of what a generative model does: producing something new from a source of randomness. The difference is that a generative model has *learned* what "good" output looks like.

## The Core Idea

A generative model learns a probability distribution from training data. Once trained, you sample from that distribution to create new instances. The model does not memorize and replay. It captures the *structure* and *statistics* of the data, then produces novel outputs that share those properties.

<CodeBlock language="typescript" title="simple-generation.ts">
{`import * as tf from '@tensorflow/tfjs';

// The simplest possible "generative model":
// Learn the mean and variance of data, then sample new points
const trainingData = tf.tensor1d([2.1, 1.9, 2.3, 2.0, 1.8, 2.2]);

const mean = trainingData.mean();
const variance = trainingData.sub(mean).square().mean();
const std = variance.sqrt();

// Generate new samples that look like the training data
const newSamples = tf.randomNormal([10]).mul(std).add(mean);
console.log(await newSamples.array());
// Values clustered around 2.0: new data, same distribution`}
</CodeBlock>

<DerivationDrawer summary="Discriminative vs generative: model what?">
**Discriminative model:** learns p(label | data). Cheap, accurate for classification. Examples: logistic regression, BERT for classification, CNN classifier.

**Generative model:** learns p(data) or p(data | label). Expensive but enables generation, anomaly detection, semi-supervised learning. Examples: VAE, GAN, diffusion, autoregressive language models.

**Bayes connection:**

`p(label | data) = p(data | label) · p(label) / p(data)`

A full generative model (p(data | label) + p(label)) lets you compute both directions. Discriminative models skip this and learn p(label | data) directly: cheaper, more accurate when you only need classification.

**When generative is the right tool:**
- You need new samples (image generation, music, text)
- You have unlabeled data (self-supervised pretraining)
- You need uncertainty calibration (anomaly detection: low p(data) = anomaly)
- You need to handle missing data (impute by conditional sampling)
</DerivationDrawer>
