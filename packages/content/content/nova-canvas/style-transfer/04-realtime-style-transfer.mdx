Three minutes per frame. Erdem times it on the kiosk twice to be sure: 180 seconds of gradient descent for one restyled photograph, on a screen that has to feel instant. A visitor will give that screen maybe ten seconds. The optimization loop owes two orders of magnitude, and no amount of tuning pays that debt. The loop itself has to go.

<Dialogue speaker="Rohan">
The Gatys method optimizes each image from scratch: hundreds of iterations, minutes per image. That is like computing CSS styles by running gradient descent on every page load. We need to pre-compile the style into a network.
</Dialogue>

<Dialogue speaker="Samir">
A feedforward network. Train it once on the Monet style, and it applies that style in a single forward pass. Like CSS `filter`: the browser applies saturate, contrast, and blur instantly because the operations are pre-compiled.
</Dialogue>

{`import * as tf from '@tensorflow/tfjs';

// Residual block: core of the transformation network
function residualBlock(input: tf.SymbolicTensor, filters: number): tf.SymbolicTensor {
  let x = tf.layers.conv2d({
    filters, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(input) as tf.SymbolicTensor;
  x = tf.layers.conv2d({
    filters, kernelSize: 3, padding: 'same'
  }).apply(x) as tf.SymbolicTensor;
  // Skip connection: input + transformed
  return tf.layers.add().apply([input, x]) as tf.SymbolicTensor;
}

// Build a feedforward style transfer network
function buildStyleNetwork(): tf.LayersModel {
  const input = tf.input({ shape: [256, 256, 3] });

  // Encoder: downsample (like CSS filter input)
  let x = tf.layers.conv2d({
    filters: 32, kernelSize: 9, strides: 1, padding: 'same', activation: 'relu'
  }).apply(input) as tf.SymbolicTensor;
  x = tf.layers.conv2d({
    filters: 64, kernelSize: 3, strides: 2, padding: 'same', activation: 'relu'
  }).apply(x) as tf.SymbolicTensor;
  x = tf.layers.conv2d({
    filters: 128, kernelSize: 3, strides: 2, padding: 'same', activation: 'relu'
  }).apply(x) as tf.SymbolicTensor;

  // Transform: residual blocks (like CSS filter processing)
  x = residualBlock(x, 128);
  x = residualBlock(x, 128);
  x = residualBlock(x, 128);

  // Decoder: upsample back to original resolution
  x = tf.layers.upSampling2d({ size: [2, 2] }).apply(x) as tf.SymbolicTensor;
  x = tf.layers.conv2d({
    filters: 64, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(x) as tf.SymbolicTensor;
  x = tf.layers.upSampling2d({ size: [2, 2] }).apply(x) as tf.SymbolicTensor;
  x = tf.layers.conv2d({
    filters: 32, kernelSize: 3, padding: 'same', activation: 'relu'
  }).apply(x) as tf.SymbolicTensor;

  // Output: stylized image
  const output = tf.layers.conv2d({
    filters: 3, kernelSize: 9, padding: 'same', activation: 'sigmoid'
  }).apply(x) as tf.SymbolicTensor;

  return tf.model({ inputs: input, outputs: output });
}

// Speed comparison:
// Gatys (iterative): ~180 seconds for 256x256
// Fast style transfer: ~85 milliseconds for 256x256
// That is a 2000x speedup, from minutes to real-time
const net = buildStyleNetwork();
console.log('Parameters:', net.countParams().toLocaleString());`}

<DerivationDrawer summary="Instance normalization: why styles use it">
Style transfer uses **Instance Normalization (IN)** instead of BatchNorm. Both normalize activations, but along different axes.

**For input shape `[N, C, H, W]`:**

```
BatchNorm: normalize over (N, H, W) per channel; uses batch statistics
  μ_c = mean over batch + spatial          (one mean per channel)
  σ_c = std over batch + spatial            (one std per channel)

InstanceNorm: normalize over (H, W) per sample, per channel
  μ_{n,c} = mean over spatial only          (separate mean per (sample, channel))
  σ_{n,c} = std over spatial only           (separate std per (sample, channel))
```

**Why InstanceNorm for style transfer?** Style is captured by per-image feature statistics (Gram matrix). BatchNorm averages across the batch, mixing styles together. InstanceNorm preserves each image's statistics.

**Adaptive Instance Normalization (AdaIN)** generalizes IN by replacing the learned per-channel scale/shift with style-image-derived scale/shift:

`AdaIN(content, style) = σ(style) · (content − μ(content)) / σ(content) + μ(style)`

Applied at each layer of the generator. This is the basis for arbitrary style transfer (one model, any style).
</DerivationDrawer>
