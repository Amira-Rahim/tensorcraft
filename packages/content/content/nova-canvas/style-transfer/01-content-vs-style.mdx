<Dialogue speaker="Yara">
Every artist understands this instinctively. The bridge over water is the content. Monet's broken brushstrokes and diffused light, that's the style. Same subject, completely different paintings.
</Dialogue>

<Dialogue speaker="Samir">
JavaScript engineers ship this split every day. HTML is content. CSS is style. Same markup, new stylesheet, and the product looks like a different company built it. Neural networks learn the same separation.
</Dialogue>

<Dialogue speaker="Yara">
Careful with that one. HTML and CSS split cleanly because someone designed two languages. A painting isn't labeled. Content and style live in the same pixels, and the network has to compute the split from its own activations. Ask different layers and you'll get a different boundary.
</Dialogue>

Yara's caution is the real lesson, and it has a mechanical cause. VGG was never trained to analyze art. It was trained to name objects, and the content/style split falls out of that training as a side effect. Deep activations happen to track structure because naming a dog requires knowing where the dog is. Early-layer correlations happen to track texture because naming anything requires edges and color first. Neither is ground truth. Which layer you read decides where the boundary falls, and choosing that layer is the rest of this module.

## Where Content and Style Live in a CNN

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="content-style-extraction.ts">
{`import * as tf from '@tensorflow/tfjs';

// In a CNN, different layers capture different things:
// Early layers: edges, textures, colors (STYLE)
// Deep layers: objects, structure, composition (CONTENT)

// Load a pretrained feature extractor (e.g., VGG-like)
async function buildFeatureExtractor() {
  // Simplified CNN for demonstration
  const input = tf.input({ shape: [128, 128, 3] });

  // Block 1: captures edges, basic textures (style)
  let x = tf.layers.conv2d({
    filters: 32, kernelSize: 3, padding: 'same', activation: 'relu', name: 'style_1'
  }).apply(input) as tf.SymbolicTensor;
  x = tf.layers.maxPooling2d({ poolSize: 2 }).apply(x) as tf.SymbolicTensor;

  // Block 2: captures patterns, brushstrokes (style)
  x = tf.layers.conv2d({
    filters: 64, kernelSize: 3, padding: 'same', activation: 'relu', name: 'style_2'
  }).apply(x) as tf.SymbolicTensor;
  x = tf.layers.maxPooling2d({ poolSize: 2 }).apply(x) as tf.SymbolicTensor;

  // Block 3: captures objects, structure (content)
  x = tf.layers.conv2d({
    filters: 128, kernelSize: 3, padding: 'same', activation: 'relu', name: 'content'
  }).apply(x) as tf.SymbolicTensor;

  // Only the content tap is wired up here. Reaching style_1 and style_2
  // needs a multi-output model, which is lesson 3.
  return tf.model({ inputs: input, outputs: x });
}

// CONTENT: what is in the image (objects, spatial arrangement)
// Extracted from a single deep layer
function extractContent(
  model: tf.LayersModel,
  image: tf.Tensor4D
): tf.Tensor {
  return model.predict(image) as tf.Tensor;
}

// STYLE: how the image looks (textures, colors, patterns)
// Captured as correlations between features: the Gram matrix
function gramMatrix(features: tf.Tensor4D): tf.Tensor2D {
  const [batch, height, width, channels] = features.shape;
  // Reshape to 2D: (height * width) x channels
  const reshaped = features.reshape([height * width, channels]);
  // Gram = F^T * F (correlations between feature channels)
  const gram = tf.matMul(reshaped, reshaped, true, false);
  // Normalize by number of elements
  return tf.div(gram, tf.scalar(height * width)) as tf.Tensor2D;
}

// The Gram matrix captures which textures co-occur
// Monet: soft edges + warm colors = high correlation
// Basquiat: harsh lines + primary colors = different correlation pattern`}

<DerivationDrawer summary="Content + style decomposition via CNN feature maps">
**Gatys et al. observation:** in a pretrained CNN (like VGG-19), different layers capture different aspects of an image:

- **Mid-deep layers (conv4_2 in VGG):** content features. Spatial layout of objects, large structures. L2 distance between feature maps preserves "what's where".
- **All layers' Gram matrices:** style features. Texture statistics regardless of position. L2 distance between Grams preserves "how it looks".

**The decomposition is empirical, not theoretical:** there's no proof that VGG features cleanly separate content from style. It's that VGG was trained on object recognition (content-focused), and deeper layers became spatially-coarse + content-aware.

**Implication:** style transfer quality depends on:
- The choice of content layer (typically conv4_2 for VGG-19; varies for other backbones)
- The choice of style layers (typically conv1_1 + conv2_1 + conv3_1 + conv4_1 + conv5_1)
- The relative weight α : β between content loss and style loss

There is no universal "correct" decomposition. You tune for the visual effect you want.
</DerivationDrawer>
