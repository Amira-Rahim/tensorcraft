Swapping CSS themes preserves content while changing visual identity. Neural style transfer does the same. It generates an image that preserves one image's content while adopting another image's style.

## The Style Transfer Algorithm

<CodeBlock language="typescript" title="style-transfer.ts">
{`import * as tf from '@tensorflow/tfjs';

// Content loss: the generated image should have the same structure
function contentLoss(
  generatedFeatures: tf.Tensor,
  contentFeatures: tf.Tensor
): tf.Scalar {
  return tf.losses.meanSquaredError(contentFeatures, generatedFeatures);
}

// Style loss: the generated image should have the same textures
function styleLoss(
  generatedGram: tf.Tensor2D,
  styleGram: tf.Tensor2D
): tf.Scalar {
  return tf.losses.meanSquaredError(styleGram, generatedGram);
}

// Total loss: weighted combination
function totalLoss(
  contentL: tf.Scalar,
  styleL: tf.Scalar,
  contentWeight: number,
  styleWeight: number
): tf.Scalar {
  return tf.add(
    tf.mul(contentL, tf.scalar(contentWeight)),
    tf.mul(styleL, tf.scalar(styleWeight))
  ) as tf.Scalar;
}

// The optimization loop: adjust pixels to minimize loss
async function styleTransfer(
  contentImage: tf.Tensor4D,
  styleImage: tf.Tensor4D,
  featureModel: tf.LayersModel,
  iterations: number = 100,
  contentWeight: number = 1,
  styleWeight: number = 1000
): Promise<tf.Tensor4D> {
  // Extract targets (these don't change)
  const contentTarget = featureModel.predict(contentImage) as tf.Tensor;
  const styleFeatures = featureModel.predict(styleImage) as tf.Tensor4D;
  const styleTarget = gramMatrix(styleFeatures);

  // Start with the content image (faster convergence than random)
  const generated = tf.variable(contentImage.clone());
  const optimizer = tf.train.adam(0.02);

  for (let i = 0; i < iterations; i++) {
    optimizer.minimize(() => {
      const genFeatures = featureModel.predict(generated) as tf.Tensor4D;
      const genGram = gramMatrix(genFeatures);

      const cLoss = contentLoss(genFeatures, contentTarget);
      const sLoss = styleLoss(genGram, styleTarget);
      const loss = totalLoss(cLoss, sLoss, contentWeight, styleWeight);

      if (i % 20 === 0) loss.print();
      return loss;
    }, true, [generated]);
  }

  return generated as unknown as tf.Tensor4D;
}`}

## Challenge

Implement the content and style loss functions for neural style transfer.

<DerivationDrawer summary="Gram matrix + total style-transfer loss">
**Style-transfer loss** has two components:

```
L_total = α · L_content + β · L_style
```

**Content loss:** L2 distance between feature maps of generated image and content image at one mid-layer:

`L_content = || F_l(x) - F_l(content) ||²`

**Style loss:** L2 distance between Gram matrices at multiple layers. Gram matrix G captures pairwise correlations between feature channels (texture statistics, ignoring spatial layout):

`G_l[i, j] = Σ_p F_l[p, i] · F_l[p, j]    where p iterates over spatial positions`

`L_style = Σ_l w_l · || G_l(x) - G_l(style) ||²`

**Why Gram matrices?** Texture is about which features co-occur, not where. Two images of the same texture (e.g., "oil painting brush strokes") have similar Gram matrices regardless of which side of the canvas the strokes are on.

**Optimization:** start x = content image (or noise). Compute gradient of L_total w.r.t. x (NOT w.r.t. weights; VGG is frozen). Iterate: `x ← x − η · ∇_x L_total`. After ~500 iterations, x is the styled image.
</DerivationDrawer>

<KeyTakeaways takeaways={["Start the optimization from the content image instead of random noise: you converge in about 100 iterations instead of 500", "Content loss measures difference in deep CNN features between generated and content image", "Style loss measures difference in Gram matrices between generated and style image", "The balance between content weight and style weight controls how much the original structure is preserved"]} />
