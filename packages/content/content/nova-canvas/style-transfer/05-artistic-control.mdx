<Dialogue speaker="Yara">
I don't want pure Monet or pure Basquiat. I want something in between: Monet's light with Basquiat's line work. A style that doesn't exist in any museum.
</Dialogue>

<Dialogue speaker="Rohan">
In CSS, `mix-blend-mode` layers visual effects: multiply, screen, overlay. Style blending does the same thing. We interpolate between two Gram matrices and use the blend as our target. You get a style that is half Monet, half Basquiat, or any ratio you choose.
</Dialogue>

Blending works because Gram matrices live in a continuous space: any weighted average of two style fingerprints is a perfectly valid loss target. Whether it is a coherent style is a separate question. Some blends read as a third artist who never existed; others pass through visually broken territory on the way. The dial is continuous. Taste is not.

## Blending Two Styles

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="style-blending.ts">
{`import * as tf from '@tensorflow/tfjs';

// Linear interpolation between two style representations
function blendStyles(
  gramA: tf.Tensor2D[],
  gramB: tf.Tensor2D[],
  alpha: number // 0 = pure A, 1 = pure B
): tf.Tensor2D[] {
  return gramA.map((gA, i) => {
    const gB = gramB[i];
    // blended = (1 - alpha) * A + alpha * B
    return tf.add(
      tf.mul(gA, tf.scalar(1 - alpha)),
      tf.mul(gB, tf.scalar(alpha))
    ) as tf.Tensor2D;
  });
}

// Create a gradient of styles
function styleGradient(
  gramMonet: tf.Tensor2D[],
  gramBasquiat: tf.Tensor2D[],
  steps: number
): tf.Tensor2D[][] {
  const gradient: tf.Tensor2D[][] = [];
  for (let i = 0; i <= steps; i++) {
    const alpha = i / steps;
    gradient.push(blendStyles(gramMonet, gramBasquiat, alpha));
  }
  return gradient;
  // [0] = pure Monet
  // [steps/2] = 50/50 blend
  // [steps] = pure Basquiat
}

// Spatial style blending: different styles in different regions
function spatialBlend(
  gramA: tf.Tensor2D[],
  gramB: tf.Tensor2D[],
  mask: tf.Tensor2D // 0-1 mask, same spatial dims as features
): { foreground: tf.Tensor2D[]; background: tf.Tensor2D[] } {
  // Where mask = 1, use style A; where mask = 0, use style B
  // This allows Monet sky + Basquiat buildings
  return {
    foreground: gramA,
    background: gramB
  };
}

// Yara's dial: visitors control the blend in real time
// alpha = 0.0 -> "Impressionist Dawn"
// alpha = 0.3 -> "Structured Light"
// alpha = 0.5 -> "Urban Impressionism"
// alpha = 0.7 -> "Energetic Calm"
// alpha = 1.0 -> "Raw Expression"
console.log('Each blend point is a new aesthetic that exists nowhere else');`}
</CodeBlock>

## Challenge

Blend two style representations by interpolating their Gram matrices.

<Exercise slug="blend-styles" />

<DerivationDrawer summary="Style mixing math: two style sources, one image">
**Style mixing** lets you transfer one image's style to multiple regions or interpolate between two styles.

**Region mask approach:** apply different styles per spatial region using a mask M (shape [H, W], values 0-1):

```
stylized = M ⊙ stylize(content, styleA) + (1 − M) ⊙ stylize(content, styleB)
```

Works but seams are visible. Better: blend Gram matrices instead of pixels.

**AdaIN-based blending:** in a feedforward network with AdaIN layers (per lesson 04):

```
stats_blend = α · stats(styleA) + (1 − α) · stats(styleB)
output = AdaIN(content, stats_blend)
```

Result: smooth interpolation between two styles applied uniformly.

**StyleGAN-style mixing:** in a latent-driven generator, swap the latent at different layers to apply styleA's coarse structure (early layers) with styleB's fine textures (late layers). The genealogy of layer responsibility (coarse vs fine) is empirical and varies per architecture.
</DerivationDrawer>

<KeyTakeaways takeaways={["Blend before optimizing: compute one interpolated Gram target per layer rather than running two competing style losses", "The blend ratio controls the balance: 0 = pure style A, 1 = pure style B, 0.5 = equal mix", "Spatial masks enable different styles in different image regions: Monet sky, Basquiat buildings", "Every point on the interpolation gradient is a novel style that exists in no museum"]} />
