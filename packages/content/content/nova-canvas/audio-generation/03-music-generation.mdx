<Dialogue speaker="Rohan">
A melody is a sequence of events with timing constraints, which makes it the most familiar object in this whole world: animation frames, API polling, debounced input handlers. Music generation is setTimeout with taste.
</Dialogue>

<Dialogue speaker="MUSE">
Ask me for a melody and what I actually produce is 128 probabilities. After [60, 62, 64, 65], I'd give note 67 a 0.31 and note 64 a 0.22, and then we roll the dice. It's the question autocomplete asks about words, asked about pitch instead. Whether that counts as composing is your call, not mine.
</Dialogue>

A note is one integer. MIDI gives you 128 of them; middle C is 60, and every melody you've ever hummed is a short list of small numbers with timestamps. Firing timestamped events is old ground: `setTimeout`, `setInterval`, `requestAnimationFrame`. The ML twist is that nobody hardcodes the list. A model predicts each next note from the notes that came before.

## Notes as Tokens

<BridgeCallout bridge={frontmatter.concept.bridge} />

<CodeBlock language="typescript" title="note-encoding.ts">
{`// MIDI notes: integers 0-127 mapping to pitches
// Middle C = 60, D = 62, E = 64, F = 65, G = 67, A = 69, B = 71

// Encode a simple melody as a sequence of MIDI values
const melody = [60, 62, 64, 65, 67, 65, 64, 62]; // C major scale up and down

// Normalize to [0, 1] range for the network
const normalized = melody.map(note => note / 127);

// Build training windows, same sliding window pattern as time-series
function createWindows(notes: number[], windowSize: number) {
  const inputs: number[][] = [];
  const targets: number[] = [];

  for (let i = 0; i + windowSize < notes.length; i++) {
    inputs.push(notes.slice(i, i + windowSize));
    targets.push(notes[i + windowSize]);
  }

  return {
    xs: tf.tensor2d(inputs),
    ys: tf.tensor1d(targets),
  };
}

const { xs, ys } = createWindows(normalized, 4);
console.log('Input shape:', xs.shape);  // [numWindows, 4]
console.log('Target shape:', ys.shape); // [numWindows]`}
</CodeBlock>

## Melody Prediction Model

<CodeBlock language="typescript" title="melody-model.ts">
{`import * as tf from '@tensorflow/tfjs';

// Simple LSTM for melody prediction
const model = tf.sequential({
  layers: [
    tf.layers.lstm({
      inputShape: [4, 1],  // 4-note window, 1 feature (pitch)
      units: 64,
      returnSequences: false,
    }),
    tf.layers.dense({ units: 32, activation: 'relu' }),
    tf.layers.dense({ units: 1, activation: 'sigmoid' }), // output normalized pitch
  ],
});

model.compile({
  optimizer: tf.train.adam(0.01),
  loss: 'meanSquaredError',
});

// Reshape inputs for LSTM: [batch, timesteps, features]
const xsReshaped = xs.reshape([xs.shape[0], 4, 1]);
await model.fit(xsReshaped, ys, { epochs: 100, verbose: 0 });

// Generate a melody by predicting one note at a time
async function generateMelody(seed: number[], length: number): Promise<number[]> {
  const generated = [...seed];

  for (let i = 0; i < length; i++) {
    const window = generated.slice(-4).map(n => n / 127);
    const input = tf.tensor3d([window.map(v => [v])]);
    const prediction = model.predict(input) as tf.Tensor;
    const nextNote = Math.round((await prediction.data())[0] * 127);
    generated.push(Math.max(36, Math.min(96, nextNote))); // clamp to playable range
  }

  return generated;
}

const melody = await generateMelody([60, 62, 64, 65], 16);
console.log('Generated melody:', melody);`}
</CodeBlock>

## Scheduled Playback

<CodeBlock language="typescript" title="scheduled-playback.ts">
{`// Schedule notes using Web Audio API timing, precise to the sample
function scheduleMelody(
  ctx: AudioContext,
  notes: number[],
  tempo: number = 120 // BPM
) {
  const beatDuration = 60 / tempo; // seconds per beat

  notes.forEach((midiNote, i) => {
    const startTime = ctx.currentTime + i * beatDuration;
    const frequency = 440 * Math.pow(2, (midiNote - 69) / 12); // MIDI to Hz

    const osc = ctx.createOscillator();
    const gain = ctx.createGain();

    osc.frequency.value = frequency;
    osc.type = 'sine';
    gain.gain.setValueAtTime(0.3, startTime);
    gain.gain.exponentialRampToValueAtTime(0.001, startTime + beatDuration * 0.9);

    osc.connect(gain).connect(ctx.destination);
    osc.start(startTime);
    osc.stop(startTime + beatDuration);
  });
}

const ctx = new AudioContext();
scheduleMelody(ctx, melody, 100);`}
</CodeBlock>
