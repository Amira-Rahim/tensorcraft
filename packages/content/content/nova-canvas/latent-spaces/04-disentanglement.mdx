In React, a well-designed component has independent props: `size` does not affect `color`, and `disabled` does not change `variant`. Each prop controls exactly one aspect. A disentangled latent space has the same property — each dimension controls one independent factor of variation.

## Traversing Single Dimensions

To test disentanglement, fix all dimensions except one and sweep it across a range. In a disentangled space, only one visual attribute should change.

<CodeBlock language="typescript" title="dimension-traversal.ts">
{`import * as tf from '@tensorflow/tfjs';

async function traverseDimension(
  baseVector: tf.Tensor1D,
  dimension: number,
  decoder: tf.LayersModel,
  steps: number = 7,
  range: number = 3.0
): Promise<tf.Tensor[]> {
  const results: tf.Tensor[] = [];
  const baseData = await baseVector.array() as number[];

  for (let i = 0; i < steps; i++) {
    const value = -range + (2 * range * i) / (steps - 1);
    const modified = [...baseData];
    modified[dimension] = value;  // Change only this dimension
    const zModified = tf.tensor2d([modified]);
    const output = decoder.predict(zModified) as tf.Tensor;
    results.push(output);
  }
  return results;
  // Disentangled: each row shows ONE attribute changing
  // Entangled: each row shows MANY attributes changing
}

// Sweep dimension 0: only color should change
// Sweep dimension 1: only shape should change
// Sweep dimension 2: only texture should change`}
</CodeBlock>

## Why Disentanglement Matters for Art

For the Biennale installation, disentanglement means creative control. Visitors can use individual sliders to adjust specific attributes without unpredictable side effects — just like adjusting independent CSS properties.

<CodeBlock language="typescript" title="creative-control.ts">
{`// Exhibition kiosk: each slider maps to one latent dimension
interface ArtControls {
  colorWarmth: number;   // z[0]: -3 (cool blue) to +3 (warm red)
  complexity: number;    // z[1]: -3 (simple) to +3 (complex)
  symmetry: number;      // z[2]: -3 (chaotic) to +3 (symmetrical)
  organicness: number;   // z[3]: -3 (geometric) to +3 (organic)
}

function controlsToLatent(controls: ArtControls): number[] {
  return [controls.colorWarmth, controls.complexity,
          controls.symmetry, controls.organicness,
          ...new Array(12).fill(0)];  // remaining dims at default
}`}
</CodeBlock>
