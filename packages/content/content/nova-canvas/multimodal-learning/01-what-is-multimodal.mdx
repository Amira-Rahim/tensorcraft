<Dialogue speaker="Yara">
I typed "a sunset over a digital city" and MUSE did nothing. It just stared at me.
</Dialogue>

<Dialogue speaker="Samir">
MUSE currently only understands images: pixel data in, pixel data out. It is monolingual. To understand text, it needs a text encoder. To connect text and images, it needs a shared representation space.
</Dialogue>

<Dialogue speaker="Rohan">
It is like building a full-stack app. Your frontend speaks HTML and CSS. Your backend speaks Python or Node. Your database speaks SQL. They are all different languages, but they communicate through APIs and shared data formats. Multimodal AI works the same way.
</Dialogue>

Rohan's full-stack picture holds until you ask where the API contract lives. In your stack, the interface between tiers is written down: an OpenAPI spec, a schema, a TypeScript type. Between MUSE's modalities, the interface is learned: a shared embedding space whose "contract" is just geometry that training happened to converge on. When it breaks, there is no spec to diff against. That difference shapes everything this module builds.

{`import * as tf from '@tensorflow/tfjs';

// FULL-STACK ANALOGY:
// Frontend (HTML/CSS) = Image modality (pixels)
// Backend (Node/Python) = Text modality (tokens)
// Database (SQL) = Shared embedding space (vectors)
// API = Encoder/decoder interfaces

// Image encoder: pixels -> embedding vector
function buildImageEncoder(embeddingDim: number): tf.LayersModel {
  const input = tf.input({ shape: [64, 64, 3] });

  let x = tf.layers.conv2d({
    filters: 32, kernelSize: 3, strides: 2, padding: 'same', activation: 'relu'
  }).apply(input) as tf.SymbolicTensor;
  x = tf.layers.conv2d({
    filters: 64, kernelSize: 3, strides: 2, padding: 'same', activation: 'relu'
  }).apply(x) as tf.SymbolicTensor;
  x = tf.layers.globalAveragePooling2d({}).apply(x) as tf.SymbolicTensor;
  const embedding = tf.layers.dense({
    units: embeddingDim, activation: 'linear'
  }).apply(x) as tf.SymbolicTensor;

  return tf.model({ inputs: input, outputs: embedding });
}

// Text encoder: token sequence -> embedding vector
function buildTextEncoder(
  vocabSize: number,
  seqLen: number,
  embeddingDim: number
): tf.LayersModel {
  const input = tf.input({ shape: [seqLen] });

  let x = tf.layers.embedding({
    inputDim: vocabSize, outputDim: 64
  }).apply(input) as tf.SymbolicTensor;
  x = tf.layers.globalAveragePooling1d({}).apply(x) as tf.SymbolicTensor;
  const embedding = tf.layers.dense({
    units: embeddingDim, activation: 'linear'
  }).apply(x) as tf.SymbolicTensor;

  return tf.model({ inputs: input, outputs: embedding });
}

// Both encoders output vectors of the SAME dimensionality
// This shared space is where text and images "meet"
const embeddingDim = 256;
const imageEnc = buildImageEncoder(embeddingDim);
const textEnc = buildTextEncoder(10000, 32, embeddingDim);

// Now: encode("sunset") and encode(sunsetImage) should be CLOSE
// in the shared embedding space`}

<DerivationDrawer summary="Multimodal fusion strategies: early, late, attention">
**Three fusion strategies** for combining modalities (image + text, audio + visual, etc):

**1. Early fusion**: concatenate raw features at input:
```
input = concat(image_features, text_features)     // shape [B, d_img + d_text]
output = mlp(input)
```
Simple. Loses modality-specific structure. Works for low-dim modalities (sensor fusion).

**2. Late fusion**: process each modality separately, combine predictions:
```
p_image = image_classifier(image)
p_text  = text_classifier(text)
p_final = α · p_image + (1 − α) · p_text
```
Easy to implement, modalities independent. Misses cross-modal interactions.

**3. Cross-attention fusion**: let one modality attend to the other:
```
image_features = image_encoder(image)            // [n_img_tokens, d]
text_features  = text_encoder(text)              // [n_text_tokens, d]
fused = cross_attention(query=text_features, key=image_features, value=image_features)
```
Most flexible. Powers BLIP, Flamingo, GPT-4V. Expensive: O(n_text · n_img · d) per layer.

**Modern recipe:** project both modalities into a shared embedding space (CLIP-style), then add cross-attention layers in a transformer. Most modern multimodal LLMs (LLaVA, Qwen-VL) use this hybrid.
</DerivationDrawer>
