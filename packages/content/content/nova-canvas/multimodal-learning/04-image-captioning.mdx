Every image in the gallery needs a description. For the catalog, for the website, and most importantly, for visitors who cannot see the images. Accessibility is not optional.
</Dialogue>

<Dialogue speaker="Samir">
Image captioning is exactly this problem: given an image, generate a text description. It is automated alt-text generation. The model looks at pixels and produces words.
</Dialogue>

Alt text is the original vision-to-language task. You look at an image and describe it in words. Image captioning automates this with an encoder-decoder architecture: encode the image, decode into text.

<CodeBlock language="typescript" title="image-captioning.ts">
{`import * as tf from '@tensorflow/tfjs';

// Image captioning = automated alt text
// Step 1: Encode the image into a context vector
// Step 2: Decode words one at a time, conditioned on context

function buildCaptionDecoder(
  vocabSize: number,
  embeddingDim: number,
  contextDim: number
): tf.LayersModel {
  // Two inputs: previous word + image context
  const wordInput = tf.input({ shape: [1], name: 'word_input' });
  const contextInput = tf.input({ shape: [contextDim], name: 'context' });

  // Embed the previous word
  let wordEmb = tf.layers.embedding({
    inputDim: vocabSize, outputDim: embeddingDim
  }).apply(wordInput) as tf.SymbolicTensor;
  wordEmb = tf.layers.flatten().apply(wordEmb) as tf.SymbolicTensor;

  // Combine word embedding with image context
  const combined = tf.layers.concatenate().apply(
    [wordEmb, contextInput]
  ) as tf.SymbolicTensor;

  // Predict next word
  let x = tf.layers.dense({
    units: 256, activation: 'relu'
  }).apply(combined) as tf.SymbolicTensor;
  const nextWord = tf.layers.dense({
    units: vocabSize, activation: 'softmax'
  }).apply(x) as tf.SymbolicTensor;

  return tf.model({
    inputs: [wordInput, contextInput],
    outputs: nextWord
  });
}

// Autoregressive generation: one word at a time
async function generateCaption(
  imageEncoder: tf.LayersModel,
  decoder: tf.LayersModel,
  image: tf.Tensor4D,
  vocab: string[],
  maxLen: number = 20
): Promise<string> {
  const context = imageEncoder.predict(image) as tf.Tensor2D;
  const words: string[] = [];
  let currentWord = vocab.indexOf('<start>');

  for (let i = 0; i < maxLen; i++) {
    const wordTensor = tf.tensor2d([[currentWord]]);
    const prediction = decoder.predict([wordTensor, context]) as tf.Tensor2D;

    // Greedy: pick the most likely next word
    const nextIdx = prediction.argMax(1).dataSync()[0];
    const nextWord = vocab[nextIdx];

    wordTensor.dispose();
    prediction.dispose();

    if (nextWord === '<end>') break;
    words.push(nextWord);
    currentWord = nextIdx;
  }

  context.dispose();
  return words.join(' ');
}

// Output: "abstract geometric forms in blue and gold"
// This becomes: <img alt="abstract geometric forms in blue and gold" />`}

<DerivationDrawer summary="Encoder-decoder for image captioning: cross-attention math">
**Image captioning architecture:**

```
encoder:   image → [n_patches, d] visual tokens (e.g. ViT or CNN)
decoder:   start with [BOS] token, autoregressively predict next word using
           - self-attention over caption-so-far
           - cross-attention over image visual tokens
```

**Cross-attention computation per decoder layer:**

```
Q = caption_features · W_Q              // [n_caption, d]
K = image_features · W_K                // [n_image, d]
V = image_features · W_V                // [n_image, d]
attn = softmax(Q · K^T / √d_k)          // [n_caption, n_image]
out = attn · V                          // [n_caption, d]
```

Each decoder position attends to all image patches, weighted by relevance. The model learns to attend to different image regions while generating each word.

**Generation loop:**

```
tokens = [BOS]
for t in 1..max_len:
  logits = decoder(image_features, tokens)   // condition on image + history
  next_token = argmax(logits[-1])             // or sample
  tokens.append(next_token)
  if next_token == EOS: break
return detokenize(tokens)
```

**Beam search** (see `bidirectional-models` lesson) typically used for higher-quality captions than greedy.
