<Dialogue speaker="Rohan">
Dynamic routing handles paths it has never seen. You write `/:category/:item` and it matches any category, any item — without hardcoding every possibility. Zero-shot classification does the same thing. CLIP classifies images it has never seen into categories it was never trained on.
</Dialogue>

<Dialogue speaker="Erdem">
No training data at all? How?
</Dialogue>

<Dialogue speaker="Rohan">
It does not memorize categories. It compares. Encode the image, encode each candidate label as text, pick the closest match. The categories are just text — you can change them anytime.
</Dialogue>

Dynamic routing handles unknown paths by matching against patterns. Zero-shot classification handles unknown categories by matching against text descriptions. No hardcoded routes, no hardcoded labels — just flexible comparison.

## Classification Without Training

<CodeBlock language="typescript" title="zero-shot-classification.ts">
{`import * as tf from '@tensorflow/tfjs';

// Zero-shot: classify an image using text descriptions of categories
// Like dynamic routing: no hardcoded paths, just pattern matching
async function zeroShotClassify(
  clip: CLIPModel,
  image: tf.Tensor4D,
  categories: string[],
  tokenizer: (text: string) => tf.Tensor2D
): Promise<{ label: string; confidence: number }[]> {
  // Encode the image
  const imageEmb = clip.encodeImage(image);

  // Encode each category as text
  const textEmbeddings: tf.Tensor2D[] = categories.map(cat => {
    // Prompt template improves accuracy (like route patterns)
    const prompt = \`a photo of \${cat}\`;
    const tokens = tokenizer(prompt);
    return clip.encodeText(tokens);
  });

  // Stack all text embeddings into a matrix
  const textMatrix = tf.concat(textEmbeddings, 0) as tf.Tensor2D;

  // Compute similarities: image vs each category
  const similarities = tf.matMul(imageEmb, textMatrix, false, true);
  const probs = tf.softmax(tf.div(similarities, tf.scalar(0.01)));
  const probData = await probs.data();

  // Rank by similarity
  const results = categories.map((label, i) => ({
    label,
    confidence: probData[i]
  }));

  return results.sort((a, b) => b.confidence - a.confidence);
}

<DerivationDrawer summary="Prompt engineering for zero-shot: ensembling templates">
Zero-shot classification with CLIP: encode the input image, encode each class as a text prompt, pick the prompt with highest cosine similarity.

**Naive prompt:**

`text = ["cat", "dog", "car"]`     // works but ~5pp lower accuracy

**Templated prompt:**

`text = ["a photo of a {c}" for c in classes]`     // CLIP paper: +5pp accuracy

**Why "a photo of a" helps:** the text encoder was trained on captions, not bare nouns. Captions in training data follow templates like "a photo of...", "an image of...". The prompt template puts the encoder in distribution.

**Prompt ensembling:** average embeddings from multiple templates per class:

```
templates = ["a photo of a {c}", "a picture of a {c}", "an image of a {c}", ...]
class_embedding[c] = mean(text_encoder(t.format(c=c)) for t in templates)
```

CLIP paper used 80 templates and gained another 1-3pp accuracy. The cost: 80× text encodes per class, but cached once at startup.
</DerivationDrawer>
