<Dialogue speaker="Yara">
Use CLIP as a critic. Like ESLint for code: it doesn't write the code, but it steers you toward better patterns. At each generation step, ask CLIP: "Does this image match the emotional intent of the prompt?" Then nudge the image in that direction.
</Dialogue>

Yara's analogy holds about halfway. A linter's rules are deterministic; CLIP's score is a learned opinion, and the guidance scale decides how loudly that opinion speaks. Push it too hard and every output collapses toward CLIP's favorite cliche of the prompt. Too soft and the prompt washes out entirely.

<CodeBlock language="typescript" title="clip-guided-generation.ts">
{`import * as tf from '@tensorflow/tfjs';

// CLIP guidance: at each step, nudge the image toward the prompt
function clipGuidedStep(
  image: tf.Tensor4D,
  promptEmbedding: tf.Tensor2D,
  clip: CLIPModel,
  guidanceStrength: number = 100
): tf.Tensor4D {
  // Compute gradient of CLIP score w.r.t. image
  const gradientFn = tf.grad((img: tf.Tensor) => {
    const imageEmb = clip.encodeImage(img as tf.Tensor4D);
    // CLIP score: cosine similarity between image and prompt
    const similarity = tf.sum(tf.mul(
      imageEmb.squeeze() as tf.Tensor1D,
      promptEmbedding.squeeze() as tf.Tensor1D
    ));
    return similarity;
  });

  const clipGradient = gradientFn(image) as tf.Tensor4D;

  // Nudge the image in the direction that increases CLIP score
  const nudge = tf.mul(clipGradient, tf.scalar(guidanceStrength));
  const guided = tf.add(image, nudge) as tf.Tensor4D;

  clipGradient.dispose();
  nudge.dispose();

  return guided;
}

// Integrate into the diffusion loop
async function clipGuidedGenerate(
  unet: tf.LayersModel,
  clip: CLIPModel,
  promptEmbedding: tf.Tensor2D,
  steps: number = 50,
  clipGuidanceScale: number = 100
): Promise<tf.Tensor4D> {
  let image = tf.randomNormal([1, 64, 64, 3]) as tf.Tensor4D;

  for (let t = steps - 1; t >= 0; t--) {
    // Standard diffusion denoising step
    const timestep = tf.tensor1d([t / steps]);
    const noise = unet.predict([image, timestep]) as tf.Tensor4D;
    let denoised = denoiseStep(image, noise, t, steps);

    // CLIP guidance: nudge toward prompt (the ESLint step)
    const guided = clipGuidedStep(
      denoised, promptEmbedding, clip, clipGuidanceScale
    );

    image.dispose(); noise.dispose();
    denoised.dispose(); timestep.dispose();
    image = guided;
  }

  return image;
}

// "melancholy cityscape at twilight" with CLIP guidance:
// Without guidance: technically correct city at dusk
// With guidance: deep blues, long shadows, emotional atmosphere`}

<DerivationDrawer summary="CLIP guidance: backprop through CLIP score">
**CLIP-guided generation:** steer a generator (GAN, diffusion) toward an image whose CLIP embedding matches a target text embedding.

**Setup:**
```
target_text_emb = clip.encode_text(prompt)
x = generator(z)                              // current generation
image_emb = clip.encode_image(x)
loss = − cosine(image_emb, target_text_emb)
```

**Optimization:** backprop through CLIP back to either z (latent) or x (pixel space):
```
z ← z − η · ∇_z loss        // latent-space guidance (smoother)
or
x ← x − η · ∇_x loss        // pixel-space guidance (more flexible)
```

**Issues:**
- CLIP gradients are noisy → result has "CLIP look" (oversaturated, hallucinated text fragments).
- Adversarial pixel patterns can satisfy CLIP without looking right to humans.
- Fix: combine with a perceptual loss (LPIPS) or content prior.

**Modern: diffusion guidance.** Classifier-free guidance (CFG) is the dominant technique now (see the diffusion lessons). CLIP guidance was the bridge between old GAN-based art and modern diffusion.
</DerivationDrawer>
